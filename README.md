# Self-Correcting Digital-Studio Data Engine (#43)

디지털 스튜디오(제어 가능한 3D/렌더 파이프라인)가 합성 멀티태스크 데이터(뎁스·포즈·키포인트)를
GT 공짜로 뽑되, **태스크 간 기하 일관성(reprojection consistency)을 '공짜 관측'으로 + 소량 실촬영을
보정 관측으로** 칼만 루프에 묶어 **모델 붕괴를 막고 실데이터를 크게 절감**한다. = **#42(KF 예측–실데이터
보정)를 멀티태스크 3D 비전 데이터 엔진으로 스케일.**

> 상태: proof-of-concept. "일관성=공짜 관측이 오차 부분공간을 소거 → 실데이터는 게이지 한 축만 보정" 을 numpy toy로 실증.

## 동기 (AI 영상제작 툴 ↔ 연구의 접점)
- 영상제작 툴은 조명·카메라·3D 장면을 제어하는 **합성데이터 공장** — 뎁스·포즈·모캡·3DGS/4DGS 학습데이터를 GT와 함께 무한 생성.
- 그러나 합성만으로 학습하면 **sim-to-real 갭 + 재귀 생성 루프의 모델 붕괴**(스튜디오의 체계적 편향을 추정기가 상속·증폭).
- 기존 최강책 = **소량 실데이터 혼합**([2512.13411] "few real + splat synthetic > either alone"). 하지만 고정 비율 = 비효율.
- 빈 땅: **멀티태스크 상호 일관성을 자기교정 관측으로** 쓰는 필터 루프. 조각들(스플랫-포즈 [2412.00138], 월드모델-데이터엔진 [GigaWorld-0, Mirage2Matter])은 있으나 이 루프로 묶은 건 없음.

## 아이디어 (필터 프레이밍)
- **예측** = 스튜디오 합성 생성(체계적 편향 b 주입) → 공분산 증가.
- **일관성 관측(공짜)** = reprojection 잔차: 추정 포즈·구조가 관측 이미지와 기하적으로 맞아야 함. GT 라벨 불필요. 오차의 **'비일관' 방향 n̂** 을 소거.
- **실 관측(비쌈·희소)** = 소량 실촬영. 일관성이 못 보는 **게이지 방향 ĝ**(일관되지만 틀린 스케일/좌표 drift)을 보정.
- **칼만 게인** = 적응 신뢰 · **(1-K)<1 = 수축(#39)** = 붕괴 없음.
- 핵심 통찰: **gauge ambiguity**(bundle adjustment의 그 구조) — 일관성이 오차 부분공간을 공짜로 죽이므로 비싼 실데이터는 잔여 게이지 한 축만 고치면 됨 → 아주 조금으로 충분.

## toy (src/toy_selfcorrecting_engine.py)
2D 오차공간 θ̂=[포즈오차, 구조/스케일오차], 진값 0. 스튜디오 편향 b = 0.06·n̂ + 0.025·ĝ (비일관 多/게이지 少).
4법 — `naive`(둘다없음)·`cons`(일관성만)·`mix`(실데이터만)·`ours`(둘다). T=120, 300시드.

### 결과
**Part 1 — 동일 real 예산(12회) 최종 ‖오차‖ / reprojection 잔차**
- naive **7.80** (붕괴 100%, 일관성잔차 7.20)
- 일관성만 3.01 (잔차 0.27 — n̂ 소거되나 게이지 drift 잔존)
- 실혼합만 2.45 (잔차 2.26 — 실데이터만으론 기하 일관성 안 잡힘)
- **ours 0.99** (잔차 0.27) ← 실혼합 대비 **2.5× 낮음**

**Part 2 — 붕괴 궤적 ‖err‖ (g10/40/80/119)**
- naive 0.72→2.66→5.27→**7.80** (선형 발산) · ours 0.29→0.54→0.72→**0.99** (유계 수렴=수축)

**Part 3 — 샘플효율 (k_real 간격↑ = 실데이터↓, mix vs ours)**
- ours **real 3회(k=40)=1.88** > mix **real 12회(k=10)=2.45** → **4× 적은 실데이터로 우위**
- ours k=20(6회)=1.36 vs mix k=5(24회)=1.71 → 역시 4× 적게 쓰고 더 낮음

## 차별점 / 가치
- 개별 조각(스플랫-포즈 학습, few-real+synth 혼합, 월드모델 데이터엔진)은 존재 → 우리 신규 = **필터‑지배 자기교정 + 멀티태스크 상호 일관성을 관측으로 묶은 루프**(+ #42 수축 붕괴보증).
- 제품엔 즉시 유효한 데이터 전략, 논문엔 "일관성이 실데이터 예산을 접는다"는 정량 주장.
- 🧭 나침반(샘플효율·안정·물리 기하·학계 toy) 정중앙. #42 를 멀티태스크로 스케일.

## 정직한 한계
- 일관성 단독은 게이지 drift 못 막음 → 실 앵커 필수(여기 gauge ambiguity가 실데이터 필요의 근원).
- toy는 선형·일관성 방향 기지 가정. 실제 reprojection 은 비선형·방향 추정 필요(EKF/KalmanNet식 학습게인).
- "학습된 뷰/카메라 모델에서 데이터 생성"은 그 모델 오차를 상속(garbage-in) — 실관측 보정이 그 차단기.
