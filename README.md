# Spectral Memory & Creativity — "창의력 = 긴 기억력 + 위상 보강간섭" 조작화

원장 #28. 교수님 발상: **"창의력은 아주 긴 기억력이다"** — 푸리에/복소 위상 중첩 기억에서
새 조합(창의)이 **위상 보강간섭**으로 생긴다. 이를 **측정 가능한 toy로 조작화**한다.

> 상태: proof-of-concept. 논제의 세 축(위상 재조합·용량천장·긴 기억)을 numpy로 실증.

## 뼈대
- **FHRR(푸리에 홀로그래픽 기억)**: 아이템 = 단위 위상자(phasor) 복소벡터. 결합 bind=성분별 복소곱(=순환합성곱의 FFT판), 해제 unbind=켤레곱, 번들 bundle=합. "위상 보강간섭"의 수학.
- **복소 SSM(감쇠 복소진동자)**: $x_t=\Lambda x_{t-1}+\text{bind}(TIME_t,item_t)$, $\Lambda=e^{-\alpha+j\omega}$. **크기=기억길이(1/α), 위상=주파수.** 홀로그래픽 시간기억.

## toy 결과 (src/toy_fhrr_creativity.py, D=1024)
**T1 — 용량(누화 천장):** 중첩 N쌍에서 role→filler 회상. N≤100 정확도 1.00, N=150 0.85. → 중첩 용량 천장(무한주기≠무한용량).

**T2 — 창의=위상 재조합(아이템-ID 인덱싱, 부하 L):** 위상 번들대수로 **새 조합(미저장) 아이템**을 만들어 ID로 되찾아 판독.
- L=1·10·30 → **1.00**, L=60 → 0.70, L=100 → 0.39, L=150 → 0.28. → **창의적 재조합은 용량 범위(≤수십)서 coherent 성립, 넘으면 우아하게 붕괴 = 창의력 천장 = 용량.**

**T3 — 복소 SSM 긴 기억:** 스트림 누적 후 lag별 회상.
- α=0.30(길이 3.3): lag 6까지. α=0.12(8.3): lag 10까지·15서 0.80. **α=0.04(25): lag 25까지 완벽.**
- → **기억길이(1/α)가 길수록 더 먼 과거까지 동시보유 = "긴 기억" 정량화. = 재조합(창의) 재료↑.**

## 종합 — 논제 조작화
**창의력 = 긴 기억력 + 위상 보강간섭** 을 수치로 분해:
- (T2) 위상 번들대수 → coherent 새 조합 생성 = "창의"의 메커니즘·조작화.
- (T1·T2) 그 능력의 천장 = 중첩 용량(누화) = 캐비엇 "무한주기≠무한용량" 정량화.
- (T3) 긴 기억(복소 SSM 작은 α) = 더 많은 과거 동시보유 = 재조합 재료↑ → "긴 기억=창의 잠재력".

## 🟢 연구 각도 (빈 땅)
1. **생성형 홀로그래픽 기억**: 복소SSM(무한지평 retention) + FHRR 위상결합 → 읽을 때 보강간섭으로 **새 조합 생성**(단순 회상 넘어 생성).
2. **천장 상향**: sparsity·clean-up network·VSA 코드설계로 용량천장 극복(T1/T2 천장을 미는 것).
3. **위상=창의 조절손잡이**: 위상 보강/상쇄 제어로 "얼마나 창의적(새 조합) vs 충실(회상)" 연속조절.
