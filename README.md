# Filtering-based Synthetic-Data Robust Training (#42)

합성데이터 재귀학습을 **칼만필터**로 본다: **합성=노이즈 낀 예측**, **실데이터=보정 관측**,
**칼만게인 K=P/(P+R)=적응적 신뢰**, **수축인자 (1-K)<1=소산성(#39)→붕괴 없음 보증**.

> 상태: proof-of-concept. 세 축(정상상태 오차 / 분산붕괴 / 분포이동 회복)을 numpy toy로 실증.

## 동기
AI 생성물이 웹을 채우며 **모델 붕괴**(자기생성 데이터 재귀학습 → 평균 drift + 분산/꼬리 소멸)가 현안.
가장 강한 기존 완화책은 **실데이터 혼합(mix-real)** — 하지만 *고정 비율*이라 비효율.
근접논문 **arXiv 2512.00757**(Contraction-Conditioned Neural Filters)는 수축 패널티로 붕괴를 막지만
① KF/PF 아님(게인·공분산·예측보정 없음) ② 좋은/나쁜 샘플 라벨을 **참값 오라클**로 만듦(실전 불가).
→ 우리는 그 오라클 라벨을 **실데이터 관측(z)** 으로 대체하고, 필터의 **적응게인+공분산+수축**을 살린다.

## 아이디어 (KF 프레이밍)
| KF 요소 | 합성데이터 학습에서 | 역할 |
|---|---|---|
| 예측 x⁻, P⁻=P+Q | 모델이 자기 믿음에서 합성 생성 | 새 정보 없음 + 불확실성 Q 증가 |
| 관측 z, R | 소량 실데이터 배치 평균 | 진실로 **앵커**(오라클 대체) |
| 게인 K=P⁻/(P⁻+R) | **적응적 신뢰** | 불확실↑/drift↑ → 실데이터 더 믿음 |
| (1-K)<1 | **수축=소산성(#39)** | 오차 유계 = 붕괴 없음 증명 |
| 혁신기반 Q 팽창 | **적응 KF** | 큰 분포이동 감지 → 게인 급상승 → 빠른 회복 |

## toy (src/toy_kf_synthetic_collapse.py)
재귀 추정(θ*=2.0, σ_d=1, 세대당 실샘플 n_real=5, 합성배치 m=50, T=120세대, 300시드).
비교 — `naive`(자기생성만)·`mix`(고정혼합)·`kf`(최적고정게인)·`kf_ad`(적응게인). **동일 real 예산.**

### 결과
**Part 1 — 평균 붕괴 (final |err|, 300시드)**
- naive **0.704** (최대 6.55, 붕괴율 22%) ← 앵커 없어 랜덤워크 발산
- mix-real 0.230 · **KF 0.146** · adaptive-KF 0.287
- → 동일 예산에서 **KF 가 mix 보다 37%↓** (최적게인이 자기예측의 노이즈를 올바르게 다운웨이트).

**수축인자 (1-K)** — <1 이어야 오차 유계
- naive **1.000**(수축 없음→발산) · mix 0.909 · **KF 0.730**(최강 수축=최타이트 유계, #39).

**Part 2 — 분산(다양성) 붕괴 (최종 분산/σ_d²)**
- naive **0.12**(꼬리 소멸=붕괴) · mix 0.92 · KF 1.04 (보존)
- → 유한표본 자기학습은 분산이 (m-1)/m 배씩 수축→0. 실관측 보정이 차단.

**Part 3 — 분포이동 회복 (gen 50에서 +3.0, 동일 예산)**
- 회복세대수: mix **35** · KF **7** · adaptive-KF **3** (5~10× 빠름)
- 누적오차: mix 41.2 · KF **16.4** · adaptive-KF 20.0
- → 적응게인은 혁신 감지→게인↑→최속 회복. (단 adaptive 는 평상시 과반응으로 누적오차는 plain KF보다 약간↑ — "최속 회복 vs 최저 정상오차" 교환.)

## 차별점 / 가치
- 근접논문 2512.00757의 **오라클 라벨 약점 제거**(실데이터 관측 보정) + 필터의 **적응게인·공분산·수축** 복원.
- **동일 real 예산에서 고정혼합(가장 강한 기존책)을 정량적으로 능가** + 분포이동 강건 + 교정된 불확실성.
- 통합: #32(KF≈학습 update) + #39(수축/소산성) + #33(데이터·피처 큐레이션) + 모델붕괴. 🧭 나침반(샘플효율·안정·학계 toy) 정중앙.

## 정직한 한계
- R 추정·근사 선형가우시안 가정. **딥넷 확장**은 KalmanNet식 학습게인 + 대각 공분산 필요(비용).
- 베이스라인 `mix-real`이 더 단순 — 우리 이득은 **적응성·붕괴 없음 보증·불확실성 교정**이 커지는 레짐(제한된 real 예산·분포이동)에서 가장 큼.
