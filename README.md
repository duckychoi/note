# Reliability-Gated Filtering (#63) — raw 관측 품질 → 게인 + 수축 증명

칼만/PF의 게인은 "예측 vs 관측" 한 축만 조절한다. "이 관측이 유독 좋으니 더 가중"을 하려면
**raw 관측에서 측정 가능한 품질 함수 $q(z)$** 가 **게인에 수식적으로 들어가고**, 그래도 **발산 안 함이 증명**되어야 한다.

> 상태: proof-of-concept. "품질(잔차 아님) 게이트가 robust/VB KF의 순환성·증명 공백을 메운다"를 numpy toy로 실증.

## robust/VB KF에 있나? (정직한 분해)
1. **raw 관측에서 goodness 측정** — ✅ 있으나 한 종류: 정규화 혁신 $\nu^\top S^{-1}\nu$. **모델 예측 대비**(관측 고유 품질 아님).
2. **게인 기여** — ✅ Student-t 변분 KF가 $\lambda\to R_{\text{eff}}=R/\lambda\to K$.
3. **증명** — △ 추론 수렴(ELBO)은 있으나 **적응게인 전역 균일 수축**은 전면에 없음.

**공백 2개 = #63:**
- **(A) 순환성**: goodness가 잔차라서, 자신만만하게 틀린 필터가 '맞지만 놀라운' 좋은 관측을 이상치로 버림.
- **(B) 증명**: "더 믿되 발산 안 함"의 균일 수축이 잔차기반엔 안 묶임.

## 아이디어
- **품질 함수** $q(z)$: SNR·선명도·교차뷰/교차태스크 일관성(#43)·confidence — **모델 잔차와 독립**. 보정맵 $R_{\text{eff}}=h_\theta(q)$ (학습가능), 클램프 $R_{\text{eff}}\in[R_{\min},R_{\max}]$.
- **게인 기여**: $K(q)=P^-H^\top(HP^-H^\top+R_{\text{eff}}(q))^{-1}$. $q\uparrow\Rightarrow R_{\text{eff}}\downarrow\Rightarrow K\uparrow$.
- **명제(수축·bounded influence)**: $H$ 가역·$R_{\text{eff}}\succeq R_{\min}\succ0$ 이면 $A_{cl}=I-K(q)H$ 가 $\|A_{cl}\|\le\rho<1$ 균일(게인이 의사역 도달 못함=동역학 무시 못함) **동시에** $\|K\|\le\kappa$(단일관측 주입 유계). → **robust + stable 동시**. 잔차게이트엔 없던 결합 보증.

## toy (src/toy_reliability_gate.py)
1D 추적, 이질 노이즈(품질 covariate $c$가 관측분산과 상관) + 이상치 + 점프(순환성). 200시드.
비교 — **A** 고정R / **B** 잔차게이트(robust/VB, Student-t) / **C** 품질게이트(ours) / **D** 결합.

### 결과
**Part 1 — 이질노이즈 정상 RMSE**: A 1.126 · **B 2.035**(고정R보다 나쁨!) · **C 0.498** · D 0.497
→ 품질 가중이 유리. 잔차게이트는 '놀라움=나쁨'으로 혼동해 오히려 손해.

**Part 2 — 점프 직후 회복오차 = 순환성 ★핵심**: A 3.101 · **B 4.604(최악)** · **C 1.376** · D 1.382
→ 잔차게이트 B가 '맞지만 놀라운' 좋은 관측을 이상치로 버려 가장 느림. 품질게이트는 2.3× 빠른 회복.

**Part 3 — 이상치 최대오차(평균)**: A 3.74 · B 4.26 · C 1.75 · **D 1.55**
→ B는 잔차로, C는 품질로 강건, D는 둘 다. (최대값은 점프+이상치 겹침 시 공통 17.89 — 공유 최악사례.)

**Part 4 — bounded influence & 수축**: 전 방법 $K<1$ 균일 → $(1-K)>0$ 수축 보장. 품질게이트는 좋은 관측에 $K\!\le\!0.95$(의도적 고신뢰)이나 클램프로 유계. B는 주입 0.38로 과보수적 → 그게 순환성 실패의 원인.

## 차별점 / 가치 (정직)
- **있는 것**: 마할라노비스 게이팅·Student-t VB KF·적응 R·Huber KF — 전부 **잔차기반**.
- **빈 땅(#63)**: ①goodness를 **raw/일관성 품질**(잔차 아님)로 → **순환성 해소**, ②**클램프 균일 수축 증명**(robust+stable 동시), ③#42/#43 **합성데이터 '샘플 신뢰'로 이식**(2512.00757이 오라클로 때운 가중을 품질함수로 엄밀화).
- 한계: C는 품질→노이즈 보정맵이 **교정/학습**되어 있다고 가정(실제 $q$는 confidence/SNR/일관성으로 학습). 품질신호가 틀리면 손해 → D(품질+잔차 백업)가 안전.

## toy#2 — 학습형 게이트 (오라클 제거) `src/toy_learned_reliability.py`
1차 toy의 약점(품질→노이즈 맵을 안다고 가정)을 제거: 맵 $h(c)$ 를 **데이터에서 학습**.
- 원리: $E[\nu^2-P^-\mid c]=E[r\mid c]$ (현재 잔차 안 씀 → 순환성 회피). 보정/테스트 시드 분리.
- **정직한 반복**: 1차 최소제곱 적합은 **실패**(이상치·점프의 거대 $\nu^2$ 가 지배 → 계수 폭발, 맵 포화, E가 A보다 나쁨). → **c-빈별 median** 로버스트 모멘트매칭으로 교체 → 성공.
- 결과(ρ=0.8, 테스트 200시드): 학습맵 c=0.1→2.41 / c=0.9→0.09 로 $E[r|c]$ 복원. **정상 RMSE E 0.563** vs A 1.148·B 2.043, 천장 C* 0.481 근접. 순환성 회복 E 1.72 vs B 4.60.
- **안전성(ρ 스윕)**: ρ 1.0→0.0 에서 E 0.58→1.12≈A(1.15) — 품질신호 무정보면 자동 고정R화, **절대 A보다 나빠지지 않음**. B(잔차)는 ρ 무관 2.04로 계속 나쁨.
- → 학습형 품질게이트가 오라클 없이 robust/VB(잔차)의 두 공백(순환성·안전성)을 동시 해결.
