# 톡트립 TalkTrip — AI 여행 플래너 랜딩 (오리지널 데모)

rockpin.ai(록핀/코르딕스)의 **기능·정보구조를 분석**해, 동일한 기능을 하는 **오리지널 랜딩페이지**로 재구현한 단일 HTML.

> ⚠️ 저작권: 특정 상용 서비스의 디자인·문구·이미지·상호·회사정보를 **복제하지 않음**. 브랜드명(톡트립)·카피·색상·레이아웃 모두 자작, 모든 비주얼은 **CSS/SVG로 직접 그림**(외부 이미지 핫링크 없음). "AI 여행 일정 플래너" 콘셉트의 기능 동등 데모.

## 재현한 기능/섹션 (분석 → 구현)
1. 히어로: 대화 입력창 + 예시 칩 + 폰 목업(일자별 일정 미리보기)
2. 기능 6종 카드: ①링크로 장소 추출 ②AI 챗 일정 생성 ③저장 폴더 자동정리 ④지도 동선(SVG 경로) ⑤내 주변 추천+제휴 할인 ⑥PC↔앱 동기화
3. 3단계 사용법(말하기→받기→고쳐 떠나기)
4. 앱 동기화 + 스토어 배지(텍스트형, 공식 로고 미사용)
5. 최종 CTA + 푸터(언어 전환, 데모 고지)

## 기술
- 순수 HTML/CSS/JS 단일 파일(`index.html`), 의존성 0, 반응형.
- 인터랙션: 칩→입력 채움, CTA 데모 alert, IntersectionObserver 등장 애니메이션.
- 비주얼: CSS 그라디언트·SVG 지도경로·이모지(저작권 자산 없음).

## 실행
`index.html` 을 브라우저로 열면 끝. (정적)
