# #68–70 점 추적(TAPNext++) × 깊이 추정 → 4DGS · 모캡 · Visual SLAM

출발점은 두 자료다.
- Threads 글: 픽셀별 깊이 추정. 글에 나온 "Apple Depth Pro 2"는 존재하지 않는다(이전 확인).
- 인스타 릴스(@index.opensource): Google DeepMind TAPNext++(arXiv 2604.10582). 프레임 단위 온라인 점 추적으로 위치와 가시성을 예측한다. Apache-2.0.

질문은 "이 두 모델을 도입하면 모캡, 4DGS, visual SLAM 성능이 오르나"이다.

## 공통 원칙 (연구 검증 12규칙 적용)
- **사전등록:** 가설, 지표, 판정 관문을 실행 전에 이 문서에 고정한다. 바꿀 때는 이력을 남긴다.
- **튜닝된 비교군:** 기존 사전정보(원 논문 설정)에도 같은 튜닝 예산을 준다.
- **오라클 금지:** 정답 깊이나 정답 추적은 상한(upper bound)으로만 보고하고, 제안법 입력에는 쓰지 않는다.
- **시드와 신뢰구간:** 시드 ≥3, 장면별로 짝지은 비교를 한다. 부트스트랩 95% 신뢰구간이 0을 넘어야 "개선"이라고 판정한다.
- **절제:** 추적만 교체, 깊이만 교체, 둘 다 교체, 신뢰도 가중 유무를 각각 돌린다.
- **분포 이동:** 합성(디지털 스튜디오) 결과와 실영상 결과를 따로 보고한다.
- **선행연구:** 각 문서의 "가장 가까운 연구"를 정독하기 전에는 새롭다고 주장하지 않는다.

## 공통 부품
- 추적: TAPNext++ 체크포인트(BootsTAPNext 파인튜닝판). 비교로 CoTracker3와 BootsTAPIR를 쓴다.
- 깊이: 비디오 깊이 모델 1종, 미터 깊이 모델 1종(정확한 선택은 실행 시점의 공개 모델로 고정하고 여기 기록).
- 점별 신뢰도: 추적 가시성 확률 × 깊이 불확실성(또는 시간 일관성 잔차)이다. #63 신뢰도 게이트 필터링과 연결된다.
