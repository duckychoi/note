# Quantum-inspired KF (#41) — 복소/텐서넷 상태를 가진 샘플프리 세계모델 필터

"양자 파티클 필터"는 양자를 **샘플링(줄여야 할 부분)** 에 붙인 미스매치. 같은 직감을 **표현(복소/텐서넷 상태)** 에 붙이고 필터는 **샘플프리 KF/SSM**(#39)로 돌리면 — **샘플프리 + 간섭 + 안정 = 나침반 정중앙**. #28·#39·#40이 한 몸.

> 상태: proof-of-concept. 두 핵심(샘플프리 다봉 / 위상 간섭)을 toy로 실증.

## 논제
- PF의 다봉성을 **샘플 없이**: 복소 진폭 상태(파동함수형)의 $|\psi|^2$ 가 다봉 사후를 **단일 복소벡터**로 표현. 실수 KF(단일 가우시안)는 모드 사이 갭으로 붕괴.
- **위상 간섭**($|a+b|^2$ 의 cross term $2|a||b|\cos\Delta\phi$) = 고전 확률 합 $|a|^2+|b|^2$ 이 못 하는 추가 표현력(#28·#40의 그 수학).

## toy (src/toy_complex_vs_real_kf.py)
- **Part 1 (샘플프리 다봉)**: 모호관측 $y=\cos x$ → 사후 bimodal(±1.2). **복소/그리드 모드질량 0.97**(양 모드) vs **실수 KF μ=0(갭)·모드질량 0.25**. → 샘플 없이 다봉 보존.
- **Part 2 (위상 간섭)**: 겹침 질량 — 복소 Δφ=0 **0.782**(보강) / Δφ=π **0.494**(상쇄) vs 고전 **0.714 고정**(위상 블라인드). → 간섭 = 고전 넘는 표현력.

## 설계
상태 = 복소 진폭(저차원 그리드) 또는 **텐서네트워크 MPS(고차원, #40)**. 갱신 = 복소 KF 예측–보정(샘플프리, #39) + **소산성(#39·#32)으로 안정**. → "quantum PF" 대신 **"quantum-inspired KF"**.
- 참고 실증 도구: 복소 KF(통신 I/Q)·텐서네트워크 KF(고차원 상태추정) 이미 존재 → 다리 탄탄.

## 왜 "양자 PF"가 아니라 이것인가
양자 PF = 간섭을 샘플링(무거운 가지)에 붙임 + 고전 사후는 비음(간섭 자리 없음)이라 미스매치. 간섭은 **표현**에서 이득 → 샘플프리 필터의 **상태 표현**에 붙이는 게 맞음. (양자 PF가 맞는 유일한 곳 = 추정대상이 진짜 양자상태일 때 = #40의 C.)
