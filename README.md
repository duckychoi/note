# Spectral Diffusion × Beamspace — 빔포밍 생성 사전확률 (#14)

빔 가중치 $w\in\mathbb C^N$ → 빔패턴 $P(\theta)=|w^H a(\theta)|^2$ = 조향벡터와의 내적 = **각도영역(DFT dual)=beam-space=스펙트럴**.
논제: **"좋은 빔포머 분포"를 학습한 생성 사전**이 ill-posed 빔 설계/복구를 해결한다. (완전 디퓨전은 torch 필요 → 여기선 선형-가우시안 프록시로 가치·한계 규명.)

> 상태: proof-of-concept. 사전의 가치(inpainting)와 선형의 한계(방향 비선형)를 실증 → 디퓨전 당위.

## toy (src/toy_generative_beam_prior.py, ULA N=16, 데이터 600)
- **매니폴드 저차원**: '좋은 빔포머(Hamming·임의 조향)' 공분산 유효차원 **10/16** → beam-space 저차원 구조(스펙트럴).
- **(A) 게인제약만 ill-posed — 선형사전 실패**: 생성사전 MAP PSL −7dB로 **매칭필터(−13dB)보다 나쁨**. 원인: 전 방향 데이터라 평균≈0, 전역 2차통계가 **특정 방향 위상 비선형성**을 못 담음.
- **(B) inpainting(소자 고장 복구) — 사전 유효**: 가우시안사전 PSL이 영채움을 일관 우위.
  - k=2: −12.1 vs −11.0 / k=4: −11.7 vs −9.2 / k=6: −9.8 vs −7.1 / **k=8: −8.6 vs −5.8** (진리 −12dB).

## 결론 (정직)
- **사전은 유효**(역문제 복구에서 이김) **그러나 선형-가우시안은 약함**(방향 위상 비선형성 못 담음).
- → **빔포머 매니폴드는 방향에 비선형 → 비선형·조건부 생성사전 = "스펙트럴 디퓨전"이 필요**. 선형 프록시의 한계가 곧 디퓨전의 당위.

## 🟢 연구 각도
1. **빔-space 조건부 디퓨전**: 각도영역에서 패턴 생성/인페인팅(저사이드로브·널 제약 조건부). 선형이 못 한 방향 비선형 해결.
2. **스펙트럴 표현**: 빔패턴이 각도에서 sparse(메인로브+제어된 사이드로브) → 디퓨전을 sparse 도메인에서.
3. **생성형 빔 설계**: 시나리오(유저 방향·널)로 조건부 샘플 → per-scenario 최적화 대체(빠름·강인).
