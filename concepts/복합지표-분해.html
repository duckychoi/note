🆕 보조 사례 — 열거형 결론의 부분 인용. On-Policy-or-Off-Policy-Distillation 결론은 “objective, evaluation setting, and optimisation hyperparameters” 3가지에 의존한다고 적는데 수집기는 1가지(목적함수)만 전했다. ⚖️ 열거형 결론은 항목 수를 함께 적는다 → 표-부분인용. 🆕 규모 ≠ 성능 재확인: impeccable “결정론적 검출 규칙 61개” 는 규모이고 효과가 아니다(효과 수치 0개). 📌 같은 형태가 Sharpening-Tax “42케이스” 에도 있다 — 케이스 수는 규모이고 tax 값이 성능이다(그림 매장).

정의

헤드라인 지표 하나가 실제로는 성질이 다른 두 모집단의 합일 때, 그 지표로 만든 비율·순위·“이례성” 판정이 전부 오염된다. 핵심은 값이 틀린 게 아니라는 점이다. open_issues_count 는 정확하다 — 다만 그것이 세는 대상이 “이슈” 가 아니라 “이슈 + 풀리퀘스트” 다. 드리프트 검증은 통과하고, 자릿수도 맞고, 재현도 된다. 그래서 5배치 동안 아무도 막지 못했다.

🔴 이 페이지는 볼트의 자기정정이다 — 볼트가 5배치 동안 쓴 "이슈 비율" 은 이슈 비율이 아니었다

볼트는 09-26~09-30 다섯 배치에 걸쳐 open_issues_count / stars 를 “이슈 비율” 로 적고, 그 값으로 레포 간 건강도를 비교했으며, 09-30 에는 paperclip 6.46% 를 “이례적까지는 확정” 이라고 결론했다. ✅ 2026-10-01 실측: open_issues_count = 공개이슈 + 공개PR 이 6개 레포에서 자릿수까지 완전 일치.

검증식: is:issue is:open + is:pr is:open (GitHub Search API) = open_issues_count 오차 0. PR 비중 범위 29.1% ~ 66.1% — 즉 레포마다 오염 정도가 다르다. 이것이 왜 순위를 뒤집는지의 원인이다.

결과 1 — 순위가 뒤집힌다 (상수 보정이 아니다)

수집기 주장 "VoiceStudio 0.20% — 오늘 5건 중 최저" 는 정정 대상이다

  • 수집기식(이슈+PR): PageIndex 0.28% > VoiceStudio 0.20% → VoiceStudio 최저
  • 순수 이슈: VoiceStudio 0.12% > PageIndex 0.10% → PageIndex 최저

PR 비중이 66.1% vs 41.0% 로 25%p 차이나기 때문에 두 레포의 순서가 교환된다. 오염이 균일하지 않으므로 “어차피 다 같이 부풀었으니 비교는 유효하다” 는 변명이 성립하지 않는다.

결과 2 — 5배치 미해결 문항 paperclip 의 “이례성” 이 대부분 사라진다

  • 수집기·볼트 공동 결론(09-30): paperclip 6.46% 는 “2위의 1.4배 · 최저의 46배” → “이례적 확정”
  • 순수 이슈 실측(10-01): 2,643 / ★95,507 = 2.77%
    • 2위 OpenShell 순수 2.49% 대비 → 1.11배 (주장 1.4배)
    • 최저 PageIndex 순수 0.10% 대비 → 27.7배 (주장 46배)
  • 🎯 paperclip 이 유별나 보였던 이유의 큰 몫은 “PR 비중이 6건 중 가장 높다(57.4%)” 였다. 즉 관측된 것은 이슈 적체 가 아니라 PR 유입량이었다.

결과 3 — 그래도 적체는 실재한다 (문항의 나머지 절반)

4배치 미해결 문항은 “유입이냐 적체냐” 였다. 분해 후 이슈 쪽은 적체가 확정된다.

  • sort:created-asc 로 수집한 공개이슈 300건이 전부 91일+, 최고령 210일(2026-03-04 · “feat: project-scoped issue identifiers”)
  • 라벨 24종 실조회 — questionable solution · unclear value · maintainer opinions requested · revisions requested 처럼 판정 보류를 명시적으로 표현하는 라벨이 4종 존재한다. 적체를 라벨 체계가 이미 인정하고 있다.
  • 🔴 단, 300건은 created-asc 정렬 표본이므로 “오래된 것이 있다” 는 확정이고 “전체 분포” 는 아니다. 전수 연령 히스토그램은 미수행 → 표-부분인용 경계.

왜 이 오류가 5배치를 버텼는가 — 측정도구-먼저-반증 의 빈틈

드리프트 검증은 같은 질문을 두 번 묻는다. 복합지표는 질문 자체가 틀렸을 때 통과한다

볼트의 검증 루틴은 “수집기 값 ↔ 볼트 재측정” 의 일치를 본다. open_issues_count 는 양쪽에서 같은 필드를 읽으므로 항상 일치한다. 일치는 “같은 것을 재고 있다” 를 증명하지만 “재려던 것을 재고 있다” 는 증명하지 않는다. ⚖️ 규칙 추가: 비율의 분자·분모를 처음 쓸 때, 그 필드가 세는 모집단을 한 번은 분해해 본다. 분해 비용은 질의 2회였고, 미분해 비용은 5배치였다.

계측 오류 계보에서의 위치

  • 구조적-영값 — 값이 과소(0으로 보임)
  • 캐치올-200 — 응답이 과대(200 OK 인데 내용 없음)
  • 무응답-오귀속 — 빈 결과를 대상 속성으로 오귀속
  • 복합지표 분해(본 페이지) — 값은 맞고 대상이 다름. 🎯 앞 셋은 “못 받았다” 계열이고 이것은 “받았는데 다른 것” 계열이다. 네 번째 축이다.
