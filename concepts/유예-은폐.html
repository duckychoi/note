유예가 은폐한다

정의

값싼 검증을 미루는 비용은 “아직 모르는 칸이 하나 있다” 가 아니다. 미룬 자리에 틀린 주장이 들어앉아 매 배치 재배포된다. 공백(gap)은 중립적으로 느껴지기 때문에 우선순위가 낮게 배정된다. 그러나 공백은 비어 있지 않다 — 그 자리를 수집기의 미검증 요약이 채우고 있고, 볼트는 그것을 그대로 옮겨 적는다.

확정 사례 — VoiceStudio README (26일 미열람 → 열자마자 오류 1건)

볼트는 09-29 로그에 자기 한계를 이렇게 적었다: “README 열람 0건 — VoiceStudio 26일째”. 2026-10-01 에 curl 1회(HTTP 200 · 7,039B · 140행)로 열었고 즉시 사실 오류가 드러났다.

🔴 수집기 주장: "MLX(Apple)·CUDA 두 백엔드와 Tauri 데스크톱 셸을 함께 제공한다"

✅ README 실문: Tauri 는 제공물이 아니라 폐기물이다.

  • 117행: “Electron is the only desktop app and web UI. Version 0.5.3 was the final Tauri release. … The retired Tauri shell and legacy UI entry points have been removed.”
  • 78행: “must contain Electron packages; it never falls back to archived Tauri builds.”

🎯 “함께 제공한다” 와 “제거했다” 는 반대 방향이다. 단위 오류나 과장이 아니라 극성(polarity)이 뒤집힌 오류다.

같은 열람에서 다른 주장은 확증됐다:

  • “646개 언어” → README 7행 “in 646 languages” 문자 일치(단 저자 선언이며 독립 검증 아님)
  • MLX · CUDA → GitHub topics 20종에 mlx · cuda 실재

🔴 정확하게 적는다 — 이 Tauri 오류는 볼트 페이지에 전사되기 전에 관문에서 차단됐다. grep 결과 VoiceStudio 페이지는 Tauri 를 한 번도 적지 않았다. 즉 “볼트가 거짓을 유포했다” 는 과장이다.

✅ 그러나 유예의 비용은 그대로 성립한다: ① 26일간 볼트는 “646개 언어” 를 description 축자 확인 근거로만 들고 있었고(09-30 페이지 자체 기재), 그것이 README 근거인지 설명문 근거인지 구별할 수단이 없었다 ② 오늘 Tauri 주장이 들어왔을 때 그것을 막은 것은 축적된 규칙이 아니라 “마침 오늘 README 를 열었다” 는 우연이다. 같은 주장이 09-05~09-30 사이 어느 배치에 왔다면 막을 근거가 볼트에 없었다. 🎯 비대칭: 같은 1회 조회가 참 주장 2건을 확증하고 거짓 주장 1건을 관문에서 걸렀다. 비용은 curl 1회였다.

보강 사례 2 — paperclip 라벨 (4배치 자기지적 후 미실행)

볼트는 09-29·09-30 로그에서 “paperclip 이슈 라벨 4일째 미실행(어제 스스로 지적하고 또 안 했다)” 고 적었다. 10-01 실행 — 질의 1회, 라벨 24종 확보. 그리고 그 조회가 복합지표-분해 로 가는 길을 열었다: 라벨을 보러 Search API 를 쓰자 is:issue / is:pr 분리가 가능하다는 사실이 바로 보였다. 🎯 미룬 항목은 독립적으로 미뤄지지 않는다 — 그것이 다른 발견의 전제였다. 4배치 미해결이던 “유입 vs 적체” 문항이 라벨 조회를 하는 순간 함께 풀렸다.

보강 사례 3 — openclaw 라이선스 (수집기가 “미확인” 으로 봉인)

수집기: “라이선스가 NOASSERTION(SPDX 미인식)이라 실제 라이선스 미확인”. /repos/openclaw/openclaw/license 1회 조회 → 본문 1,170B 전문 확보:

  • 1행 MIT License · 3행 Copyright (c) 2026 OpenClaw Foundation · 표준 MIT 전문 그대로
  • 🔴 NOASSERTION 의 원인은 말미 2행 추가 문단: “Third-party notices for incorporated or adapted code are recorded in THIRD_PARTY_NOTICES.md.” — 표준 문구 이탈 때문에 GitHub 탐지기가 Other 로 떨어뜨린 것이다.
  • ⚖️ 판정: 실질 MIT + 제3자 고지 참조 1문단. “미확인” 은 탐지기 라벨을 사실로 승격한 것이며 메타데이터-부재-추론 의 전형이다.

처방 — 유예 비용을 “공백” 으로 적지 말고 “미검증 주장 N건” 으로 적는다

볼트 규칙

  1. 백로그 항목을 “아직 안 본 것” 이 아니라 “이 항목이 떠받치고 있는 미검증 주장 목록” 으로 기재한다. VoiceStudio 는 “README 미열람” 이 아니라 “646언어·Tauri·백엔드 3개 주장 무근거” 였어야 했다.
  2. 문턱이 curl 1회인 항목은 백로그에 올리지 않고 그 자리에서 실행한다. 본 페이지의 세 사례는 합계 조회 3회였고 수집기 오류 1건 · 봉인 해제 1건 · 5배치 문항 1건을 산출했다.
  3. 같은 미실행을 2배치 연속 자기지적했으면 다음 배치의 최우선으로 강제 승격한다(paperclip 은 4배치를 자기지적만 반복했다).

🔴 숨기지 않는 잔여 한계

  • 코드 실행 0건 — 13배치 연속. openrig 는 3일째 배달인데 설치조차 안 했다. 본 페이지는 “읽기는 쌌다” 를 보였을 뿐 실행 문턱을 넘은 증거가 아니다.
  • 논문 PDF 0건 — 이번 배치도 5건 전부 초록까지. RIDE 는 초록에 저장소 URL 이 있는데도 코드를 열지 않았다.
  • paperclip 이슈 전수 연령 히스토그램 미수행(300건 표본만) → 적체 “존재” 는 확정, “규모” 는 미확정.
