한정어 탈락

2026-09-18 — 🆕 역방향 2종을 추가한다: 저자가 한정어를 빼서 범위를 넓히는 경우, 그리고 요약이 약점을 지우는 경우

① 정방향(기존 형태) — BrowserSkill: “other Chromium-based browsers are expected to work when they support unpacked Chromium extensions” — 지원이 아니라 예상이고 조건절까지 붙었다. “모든 Chromium 지원” 으로 옮기면 저자가 쓰지 않은 말이 된다. ② 🆕 역방향 A — 저자가 한정어를 빼서 넓힌다 — harness-sdk: 카드 설명은 “any model, any cloud” 인데 본문 성립 조건은 기본 프로바이더 Amazon Bedrock + AWS 자격증명 + Claude Sonnet 접근 필요다. 🎯 any 는 도달 가능성이고 기본값은 단일 벤더다 — 둘은 같은 문장에 있으면 안 되는 말이다. ③ 🆕 역방향 B — 요약이 약점을 지운다 — DeepSeek-V4.1-Flash-Paper: 모델 카드는 HLE 36.8 vs 56.3, TB4.0 31.2 vs 51.8 을 게시했는데 논문 초록은 “delivers substantially better performance” 한 줄이다. 🔴 같은 대상인데 논문이 카드보다 적게 말한다. 📌 볼트 규칙: 논문과 카드가 둘 다 있으면 불리한 수치는 카드 쪽에 있다. ✅ 대조군 — JEPA-Anything 은 저자가 선을 지켰다: “a factor-nominated biological intervention receives experimental support” — 단수(a … intervention) 이고 “experimentally grounded” 이지 “validated across domains” 가 아니다. 🎯 7개 도메인 중 생물 1개, 그 안에서 개입 1건. “마우스에서 검증된 AI 월드모델” 로 옮기는 순간 과장이 된다 — 위험이 저자가 아니라 전달자에게 있는 사례.

2026-09-15 — 새 양식: 저자가 제목에서 스스로 일으킨다 (Atria-Dawn)

지금까지 추적한 한정어 탈락은 주로 인용자가 일으켰다. Atria-Dawn 은 저자가 제목에서 일으킨다.

  • 제목: “The Dawn of Agentic Superintelligence”
  • 초록: competitive · highest score on five of 16 · about one-third · humans retain most final decisions

초록은 시종일관 한정적인데 제목만 초지능이다. 초록을 읽은 사람은 정확히 인용할 수 있지만, 제목만 본 사람은 이미 탈락된 버전을 받는다.

볼트 규칙 (채택) 제목은 초록의 요약이 아니라 별도의 마케팅 표면으로 취급한다. 수집·인용 시 제목을 근거로 쓰지 않는다.

🔴 같은 배치 Vidu-S2 는 탈락시킬 한정어조차 없는 극단이다 — 초록 전체가 “outperforms all baselines” 뿐이고 baseline 이름·벤치마크·수치가 하나도 없다. 인용하기는 가장 쉽고 검증은 불가능하다.

한 줄

원문을 정확히 인용했는데, 그 주장을 한정하는 조건절을 함께 가져오지 않아서 틀린다. 인용문 자체는 원문에 글자 그대로 존재한다. 없는 것은 문장이 아니라 그 문장이 성립하는 범위다.

왜 별개 개념인가 — 기존 두 함정과의 경계

볼트에는 이미 인용 실패 개념이 둘 있다. 처방이 서로 다르므로 분리해야 한다.

개념무엇이 잘못됐나처방
파생표기-함정파생물을 읽었다 (spdx_id: NOASSERTION 만 보고 LICENSE 본문 미확인)원문을 봐라
단위-불일치원문을 정확히 읽었으나 그 수가 세는 대상이 다르다 (552B 백본 vs 763B 체크포인트)이 수가 무엇을 세는지 물어라
한정어 탈락원문을 정확히 읽었고 단위도 맞다. 그런데 “어떤 조건에서 참인가”를 안 옮겼다이 주장이 성립하는 범위를 함께 옮겨라

→ 🎯 원문 대조를 아무리 철저히 해도 잡히지 않는다. 인용문은 원문에 실제로 있기 때문이다. grep 으로 검증하면 통과한다. → 이 점이 실무적으로 중요하다: hyperresearch 의 quote-integrity(인용문이 볼트 노트에 글자 그대로 존재하는지 검사) 같은 자동 검사도 이 함정은 못 잡는다. 존재 검사가 아니라 주변 문맥 검사가 필요하다.

2026-09-12 배치의 4개 사례 — 방향이 제각각인데 기전은 하나

① 강화 방향 — hyperresearch · 면책이 3~6행 옆에 더 세게 있었다

  • raw가 인용: README 14행 “currently leads the DeepResearch-Bench RACE leaderboard (benchmarked internally)”
  • 원문에 함께 있던 것: 20행 <sub> 캡션 “Forward-looking projection from a stratified pilot… Third party validation is pending.”
  • → “자체 측정” 과 “층화 표본 파일럿에서의 외삽 추정” 은 주장의 강도가 다르다. 전자는 측정을 했고 검증자만 자신이라는 뜻이고, 후자는 전체를 재지도 않았다는 뜻이다.
  • → 한정어를 떼면 주장이 강해졌다.

② 약화 방향 — OpenResearch · 플랫폼 단서를 제품 판정으로 확대

  • raw 기록: “README가 자체적으로 ‘support is still in beta’라고 적을 만큼 초기 단계”
  • 원문 31~35행: “On Windows, install from Releases and read the Windows notes first — Git for Windows is required, and support is still in beta.”
  • → beta 의 주어는 「Windows 지원」이다. 제품이 아니다. 반증도 있다 — 당일 푸시 · 이슈 9건 · 원라인 설치.
  • → 한정어를 떼자 주장이 약해졌다.
  • 🎯 ①과 ②가 같은 배치에 함께 나온 것이 이 개념의 핵심 근거다. 한정어 탈락은 과장의 문제가 아니다. 과소평가도 똑같이 만든다. 따라서 “이 도구가 부풀리고 있는가” 만 묻는 검사로는 절반만 잡는다.

③ 귀속 방향 — MiniCPM5-2B-GGUF · 수치의 주인이 다른 리포다

  • raw가 옮긴 것: “모델카드 표 실측: 평균 53.9로 비교군 내 최고…”
  • 볼트 실측: GGUF 카드와 원본 BF16 카드의 diff 결과 실질 차이는 👈 you are here 마커 이동뿐(md5 fee94d2… vs efedd19…). 카드 167행이 그 수치의 출처를 BF16 final release 라고 명시한다.
  • → 수치는 정확하다. 다만 이 리포(4비트 양자화 포함)의 것이 아니다. 한정어 = “BF16 원본 기준”.
  • → 단위-불일치 ①(패밀리 공용 카드)과 겹치는 영역이다. 구분: 저쪽은 어느 모델의 열인가(같은 표 안 매핑), 이쪽은 이 수치가 이 아티팩트에 적용되는가(문서 전체의 귀속).

④ 프레임 승계 방향 — YuE2-3B · 문서가 좁혀 놓은 비교군을 그대로 받았다

  • raw 기록: “평균 6.9632로 Suno v5(6.8721)·v6(6.5562) 상회” — 수치 전부 정확
  • 볼트가 표 전체를 읽은 결과: Mureka 9 = 6.9377. 실제 최근접 경쟁자이고 격차는 +0.0255(raw가 제시한 Suno v5 대비 격차의 1/3.6)
  • → 카드 헤드라인이 Suno만 지목했고 Mureka 9는 표 안에만 있었다. 모델 카드가 비교 프레임을 골랐고 요약자가 그대로 승계했다.
  • → 한정어 = “Suno 계열에 한정하면”. 그리고 지는 축(Q3O 0.5051 · PER 9.79%)도 같은 표에 있었다.

🪞 볼트도 같은 실패를 한다 — raw만의 문제가 아니다

09-11 볼트 기록: “SenseNova-U1.5 에서 SenseTime 특성상 완전 오픈소스 가능성 낮음” → 틀렸다. 이것도 한정어 탈락이다 — “과거 사례에 한정하면” 이라는 조건을 떼고 벤더 정체성에서 정책을 일반화했다. 그리고 09-10 볼트 처방 “pipeline_tag 를 보라” 가 09-11 Nex-N2.5-mini 에서 함정이 된 것도 같다 — “그 필드가 맞다면” 이라는 조건이 빠졌다. → 🎯 요약자와 판정자를 분리해도(요약자와-판정자-분리) 이 함정은 양쪽에 다 남는다.

볼트 인제스트 규칙 — 검사 2개

① 인용 주변 검사: 직접 인용을 옮길 때 원문에서 그 문장 ±10행을 읽는다. ①·②가 전부 6행 이내에서 발생했다.

  • 특히 <sub>, 각주, 캡션, 괄호, “note:”, 표 하단 주석 — 한정어는 본문보다 작은 활자에 있다.

② 표 우선 검사: 산문 헤드라인과 표가 둘 다 있으면 표를 읽는다. ③·④가 여기 해당한다.

  • 헤드라인은 저자가 고른 프레임이고, 표는 저자가 고르지 않은 값까지 담는다.
  • 09-11 vercel-skills(“79개” 산문 vs 실카운트 78) 도 같은 자리였다.

판정 기준(다음 배치): 소스 페이지의 직접 인용 중 한정어가 원문에 있는데 누락된 건이 0인가. ⚠️ AgentGrad 원칙상 이번 배치 최우선 개입은 hyperresearch quote-integrity 이식 1건이다. 이 개념의 검사 2개는 규칙으로 기록만 하고 측정 대상으로 삼지 않는다 — 동시에 여러 개입을 넣으면 무엇이 효과였는지 또 모르게 된다.

🆕 2026-09-19 — 탈락은 요약자만 하지 않는다: 저자 자신의 3가지 탈락 경로

  • 초록 단계: RSIAgent 부록 “the partial-credit advantage does not extend to every reported metric”(ALE Binary 50.75 < GPT-6 52.24)가 초록 “outperform … GPT-6” 에서 빠짐
  • 결론 단계: LimiX-2 초록 “causal skeleton recovery” → 결론 “causal inference in a single forward pass”
  • 언어 간: Xing4.0-29B-A4B “첫 모델” 한정어가 영문(of this scale)·중문(国内·百亿参数·面向工程任务)에서 다르고, 전작이 이미 더 큰 모델을 Ascend 로 학습
  • 형용사 묶음: agent-lightning “substantial improvements across all three domains” = 자체 검증셋 보상 2개 + 공인 벤치 1개 → 비교 조건 탈락은 비매칭-비교 로 분리

decolua/9router (★28,983) description 원문: “Unlimited FREE AI coding.”

🔴 무료인 것은 모델이 아니라 라우팅 대상이다 — 타사 무료 티어로 요청을 넘긴다. 비용은 사라지지 않고 프로바이더에게 이전된다. “Save 20-40% tokens” 역시 측정 방법론·벤치마크가 레포에 없다.

📌 Atria-Dawn·Last-AI-Built-by-Humans 는 초록에 한정어가 있는데 제목이 떨어뜨렸다. 9router는 한정어를 쓴 적이 없다. 🎯 전자는 문서 내부 불일치(대조하면 잡힌다), 후자는 대조할 원문 자체가 없다(직접 측정해야만 잡힌다). 후자가 더 비싸다.

2026-09-16 — 변종 3: 분모 없는 최상급 (worktrunk)

README: “the most popular git worktree manager” — 비교군·집계 시점·기준 없음. 🎯 이 배치에서 가장 가벼운 형태지만 구조는 같다: 최상급을 쓰면서 분모를 적지 않는다.

2026-09-16 — 변종 4: 비교군 없는 “comparable” (StepAudio-3-Realtime)

초록: “achieves dialogue and reasoning performance comparable to dedicated reasoning models” — 🔴 어떤 모델과 비교했는지 초록에 없다. 그리고 헤드라인 73.0은 “In reasoning mode” 조건인데 기본 모드 점수는 초록에 없다.

🎯 2026-09-16 배치 총평 — 한정어를 지킨 쪽이 더 유용했다

같은 배치에서 반대 극이 뚜렷했다:

  • Continual-Learning-Compose — “no single continual learning mechanism we evaluate maintains strong retention” 를 먼저 적고, 최적 조합도 “ranks among the top 3” 라고 정확히 적는다
  • AI-for-Games-FM-Era — 전이 주장을 하면서 “downstream claims require validation in the target setting” 을 같은 초록에 적는다
  • pi-agent-harness — 권한 모델이 없다는 것을 README 전용 섹션으로 먼저 적는다

📌 한정어를 지킨 3건이 이 배치에서 신뢰도 high를 받았고, 떨어뜨린 3건(Last-AI-Built-by-Humans·9router·worktrunk 자평)이 low/medium을 받았다. 상관이 우연이 아닐 가능성이 높다 — 한정어는 저자가 자기 주장의 범위를 아는지를 드러낸다.
