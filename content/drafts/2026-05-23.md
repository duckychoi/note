## 당신이 자리를 비운 사이, AI가 업무를 끝내놓는다

출근해서 컴퓨터를 켰더니 어젯밤에 맡긴 리서치 보고서가 완성돼 있다. 경쟁사 10개의 가격 정책을 웹에서 긁어모아 표로 정리하고, PDF로 저장하고, 이메일 초안까지 작성해 뒀다. 사람이 한 게 아니다. AI가 브라우저를 열고, 직접 마우스를 클릭하고, 검색창에 타이핑하고, 결과를 복사해서 문서에 붙여 넣은 것이다.

이게 공상과학 이야기가 아니다. 2026년 현재, **Computer Use Agent(컴퓨터 사용 에이전트)**는 이미 수백만 명의 일상 업무에 녹아들고 있다. AI가 텍스트를 '생성'하던 시대에서, 직접 '행동'하는 시대로 전환점이 찾아왔다.

---

## Computer Use AI란 무엇인가?

**Computer Use Agent**는 AI 모델이 사람처럼 컴퓨터 화면을 보고, 마우스·키보드를 조작해 실제 작업을 수행하는 기술이다. 단순히 코드를 작성하거나 텍스트를 요약하는 것과는 차원이 다르다. 다음과 같은 일을 **자율적으로** 처리한다.

- 웹 브라우저를 열고 특정 사이트에 로그인
- 검색 결과를 순서대로 탐색하고 필요한 데이터 추출
- 스프레드시트·문서 작업 앱에서 데이터 입력·수정
- 양식 작성, 파일 업로드, 이메일 발송
- 여러 탭을 넘나들며 멀티태스킹 처리

핵심은 **Vision 모델**이다. AI가 화면 스크린샷을 실시간으로 해석해 "지금 이 버튼을 클릭해야 한다"고 판단하고 실행한다. 텍스트 명령어가 아닌, 실제 GUI를 '눈으로 보고' 반응하는 것이다.

## 빅테크 3사의 전략: 누가 가장 앞서 있나?

### 1. Anthropic — Claude Computer Use

Anthropic은 2024년 말 **Claude Computer Use**를 연구 프리뷰로 공개하며 이 시장의 문을 열었다. 2025년 8월 Chrome 확장 프로그램 형태로 출시해 Max 플랜 구독자에게 먼저 제공했고, 2025년 12월 Pro·Team·Enterprise 플랜으로 확대됐다.

2026년 4월에는 기업용 클라우드 서비스 **Claude Managed Agents**를 런칭했다. 요금은 런타임 1시간당 $0.08 + API 토큰 비용이며, Notion·Rakuten·Asana 등이 얼리어답터로 합류했다. 벤치마크 성능도 눈에 띄게 향상됐다. OSWorld(컴퓨터 작업 자동화 테스트) 기준, 2024년 14%였던 태스크 완료율이 2026년 현재 44%로 **3배 이상** 뛰었다.

### 2. OpenAI — Operator → ChatGPT Agent

OpenAI는 2025년 1월 **Operator**라는 독립형 브라우저 에이전트를 출시했지만, 불과 7개월 만인 2025년 8월 서비스를 종료하고 **ChatGPT Agent**로 통합했다. 복잡한 브라우저 작업 기준 성공률 87%를 기록하며 기술 경쟁력은 증명했지만, UX와 가격 정책 문제로 독립 서비스 유지를 포기한 것으로 분석된다.

현재 ChatGPT Agent는 ChatGPT Plus·Pro 구독자에게 기본 제공되며, 웹 탐색·코드 실행·파일 처리를 하나의 대화 흐름에서 처리할 수 있다. OpenAI는 차기 모델을 '에이전트 네이티브(Agent-Native)' 구조로 설계 중이다.

### 3. Google — Project Mariner의 종말과 Gemini Spark

Google은 2024년 Project Mariner를 선보이며 브라우저 에이전트 경쟁에 참전했다. WebVoyager 벤치마크 83.5% 달성, 클라우드 VM에서 최대 10개 동시 태스크 처리라는 인상적인 성과를 냈다. 하지만 2026년 5월 4일, Google은 공식적으로 **Project Mariner를 종료**했다. 기술은 다른 Google 제품군에 흡수됐다.

대신 Google I/O 2026에서는 **Gemini Spark**를 발표했다. "사용자의 디지털 삶을 24시간 관리하는 개인 AI 에이전트"라는 설명처럼, 스마트폰과 PC 전반을 아우르는 퍼스널 에이전트 전략으로 방향을 전환한 것이다.

## 시장 규모: 이제 시작에 불과하다

Andreessen Horowitz에 따르면 AI 브라우저 에이전트 시장 규모는 2026년 **120억 달러(약 16조 원)**에 달하며, 전년 대비 200% 이상 성장하고 있다. Gartner는 2026년 말까지 전체 기업 애플리케이션의 **40%**가 작업 특화 AI 에이전트를 통합할 것으로 예측했다. 2025년 기준 통합률이 5% 미만이었다는 점을 감안하면, 1년 사이 8배 급증이다.

인력 비용 절감 효과도 실증되고 있다. 기업들이 Computer Use Agent를 도입한 후 데이터 입력·조사 업무에서 **개인 생산성이 최대 200% 향상**된 사례가 보고되고 있다.

## 실전 활용 사례: 지금 당장 쓸 수 있는 업무들

### 마케팅·리서치 팀
- 경쟁사 웹사이트를 순회하며 가격·기능 비교표 자동 작성
- SNS 플랫폼에서 특정 키워드 게시물 수집 및 감성 분석용 데이터 정리
- 광고 플랫폼(구글 애즈, 메타 애즈)에 반복 캠페인 셋업 자동화

### 영업·고객 관리 팀
- CRM에 신규 리드 정보를 여러 소스에서 취합해 일괄 입력
- 고객 계약서 PDF를 열어 특정 조항 확인 및 요약 보고서 작성
- 견적 의뢰 이메일이 오면 내부 시스템에서 자동으로 견적서 생성

### 개발·운영 팀
- CI/CD 대시보드를 주기적으로 모니터링하고 이상 감지 시 슬랙 알림
- 클라우드 콘솔에서 리소스 현황을 조회해 비용 분석 리포트 생성
- 반복적인 QA 클릭 테스트를 에이전트가 대신 수행

## 핵심 기반 기술: Vision + MCP + 오픈소스 프레임워크

### Vision 모델의 도약
Computer Use가 실용적으로 쓰이게 된 결정적 이유는 **비전 모델 성능의 임계점 돌파**다. 2025년 말부터 AI가 UI 요소를 식별하는 정확도가 극적으로 높아지면서, "버튼 A를 클릭하라"는 지시를 화면에서 정확히 찾아 실행하는 것이 가능해졌다.

### MCP (Model Context Protocol)의 역할
AI 에이전트끼리, 그리고 에이전트와 다양한 도구 사이의 표준 통신 규약인 **MCP**는 Computer Use 생태계의 확장을 가속했다. 현재 MCP 서버는 10,000개 이상, 월간 SDK 다운로드는 9,700만 회에 달한다. 덕분에 브라우저 에이전트가 CRM·ERP·이메일·캘린더 등 기존 업무 도구와 원활하게 연결된다.

### 주목할 오픈소스 도구들
- **Browserbase**: 클라우드 기반 브라우저 인프라. 에이전트가 안정적으로 수천 개 탭을 병렬 처리할 수 있게 지원
- **Stagehand**: Playwright 위에 구축된 AI 브라우저 자동화 프레임워크. 자연어로 브라우저 조작 명령 가능
- **Browser-Use**: Python 기반 오픈소스 브라우저 에이전트 라이브러리. GitHub Star 5만+ 돌파

## 한계와 주의사항: 맹목적 신뢰는 금물

아직 완벽하지 않다. 현재 최고 수준인 Claude Computer Use조차 OSWorld 기준 태스크 완료율이 44%다. 즉, **절반 이상의 복잡한 작업은 여전히 실패하거나 재시도가 필요**하다.

보안 리스크도 있다. AI 에이전트에 로그인 권한을 부여하면 인증 정보 노출·의도치 않은 데이터 접근 등의 위험이 생긴다. 기업 도입 시에는 반드시 **최소 권한 원칙(Least Privilege)** 적용과 감사 로그 설정이 필요하다.

또한 CAPTCHA·2FA·봇 탐지 시스템이 에이전트 작동을 방해할 수 있어, 실제 업무 적용 전 충분한 테스트가 필수다.

## 지금 시작하는 방법

1. **Claude.ai Pro/Max 구독** → Claude for Chrome 확장 프로그램 설치 → 간단한 반복 업무부터 실험
2. **ChatGPT Plus** → ChatGPT Agent 탭에서 브라우저 자동화 기능 체험
3. **개발자라면** → `browser-use` 라이브러리(Python)를 설치해 로컬 환경에서 커스텀 에이전트 구축
4. **기업 도입 검토** → Claude Managed Agents ($0.08/시간)로 파일럿 프로젝트 운영 후 ROI 측정

## 결론: AI는 이제 '생각'이 아니라 '행동'한다

텍스트를 생성하는 AI는 이미 익숙하다. 이제 다음 단계는 AI가 **직접 행동하는 세상**이다. 마우스 클릭, 폼 입력, 데이터 수집, 예약, 보고서 작성 — 지금 당신이 컴퓨터 앞에서 반복적으로 하는 모든 일이 자동화의 대상이다.

Gartner가 예측했듯, 2026년 말이면 기업 앱의 40%에 에이전트가 내장된다. 이 변화에 올라타느냐, 아니면 뒤처지느냐의 차이가 이미 벌어지고 있다. 지금 당장 한 가지 반복 업무를 골라 에이전트에게 맡겨보자. 첫 번째 성공 경험이 업무 방식 전체를 바꿔놓을 것이다.
