# ByteDance (바이트댄스)

> [!insight] 핵심 인사이트
> TikTok/Douyin 모회사인 중국 빅테크로, 이 위키에는 **에이전트 하네스**·**영상 AI**·**에이전트 메모리 인프라** 세 축으로 등장한다. ①**[[deer-flow]]**(DeerFlow 2.0, GitHub ⭐76,695) — 서브에이전트·장기 메모리·샌드박스를 갖춘 **롱호라이즌 슈퍼에이전트 하네스**(리서치·코딩·창작), 완전 재작성으로 "딥리서치 툴 → 범용 슈퍼에이전트"로 전환. ②**[[Seedance]]** — 할리우드급 VFX를 저비용으로 표방하는 영상 AI. ③**[[OpenViking]]**(클라우드 자회사 Volcengine 명의, ⭐26,604) — `viking://` 파일시스템 패러다임 **에이전트 컨텍스트 DB**(메모리+RAG+스킬 통합). 즉 ByteDance는 "**에이전트 인프라(하네스+메모리, 오픈)** + **영상 생성(제품)**"을 나란히 미는 포지션 — deer-flow는 위키 자동수집 오케스트레이터 후보, OpenViking은 [[에이전트-메모리-레이어]] 최신 후보, Seedance는 video-saas 경쟁 축.
