# 00 — 리서치 로그 (대화 기반 정리)

빔포밍 재발명 주제로 나눈 논의의 타임라인. 조사한 내용·제시한 아이디어·교정 사항을 순서대로 정리한다.

## 발단
- 출발 트리거: 한 릴스(실제 내용은 TAPNet/TAPNext++ 점 추적)에서 촉발된 질문 —
  "바이브 코딩 이전에 나온 알고리즘(예: 빔포밍)을, AI-native 관점에서 *방법론 자체*로 업그레이드할 수 있는가?
   딥러닝으로 빔포밍을 하는 걸 넘어 빔포밍이라는 방법론을 더 최적으로 만들 수 있지 않을까?"

## 1라운드 — 지형 정리 (→ `01_ai_native_beamforming_landscape.md`)
- "빔포밍을 DL로 하기 vs 방법론을 재발명하기"를 **6단계 사다리**로 구조화:
  1. 솔버만 교체(CNN/LSTM이 CSI→가중치 매핑)
  2. 알고리즘 언폴딩(WMMSE unfold + GNN)
  3. 엔드투엔드 재정의(**Neural Beamforming Transformer, NBT**, 2026 — 보편근사 증명)
  4. 목적함수 재발명(task-oriented / semantic / ISAC)
  5. 하드웨어 공동설계(배열 기하·sparse array·RIS/메타표면 역설계)
  6. AI 알고리즘 발견(AlphaEvolve/FunSearch — 무선 알고리즘 자율 발견, 2026)
- 핵심 인사이트: 레버리지는 (1) 사람이 그은 블록 경계(채널추정→빔포밍→스케줄링→센싱)를 녹이는 joint 설계, (2) "무엇을 최적화하나"를 SINR→과제가치로 바꾸는 것. 물리(Maxwell)는 하드 제약이라 physics-informed가 스윗스팟.

## 2라운드 — 아이디어 신규성 판정
사용자 제안 3개를 신규성 기준으로 판정:
- **MoE+트랜스포머 빔선택** → 🟡 이미 나옴: **CAT-MoEformer**(2026, 장면조건부 MoE-FFN). 단 "전문가=빔/타겟", 물리레짐 라우팅 등 차별화 여지.
- **슬라이딩모드/슈퍼트위스팅으로 빔 전달** → 🟢 **빈 땅**: SMC는 제어(로봇·UAV·위성안테나)엔 많지만 *전자적 빔포밍 가중치 적응법*으론 거의 없음. 단 "전달력(이득)↑"이 아니라 **강인성·유한시간 추적**이 이기는 지점(교정).
- **멀티빔 동시조준** → 🟡 성숙(MU-MIMO)이나 "점 조준"=근거리장 **Volumetric Beam Focusing**(Nature 2026)은 최신.

## 3라운드 — 두 "twist/slide" 결혼 (→ `04_physical_twist_slide_beams.md`)
- "빔 자체를 진짜 꼬아서(twist)·미끄러뜨려(slide) 쏠 수 있나?" → **실재**:
  - TWIST = **OAM 보텍스 빔**(나선 위상, 토폴로지 전하 ℓ). ISAC×OAM(2026.9).
  - SLIDE = **Airy 자동집속/자가치유**, **FDA**(거리-시간 의존 초점).
- 1차 결혼안("슈퍼트위스팅 제어로 OAM 빔 추적")은 **응용**임을 인정. 진짜 융합 필요.

## 4라운드 — 갱신식 vs loss 정리
- SMC를 가중치 갱신에 쓰면 "옵티마이저 교체"라 매력 낮음(인정).
- 갱신식과 학습 loss는 다른 객체지만 **슬라이딩 변수 s := ∇J** 로 두면 동일 객체가 됨("SMC as optimization", 2026). → 통합형이 더 깔끔.

## 5라운드 — 진짜 이론 융합 (→ `03_spatial_supertwisting_aperture.md`)
- 통일 원리: **"설계된 불연속/특이점으로 얻는 강인성"**.
  - SMC: 슬라이딩면의 `sign` 스위칭 → 외란 불변성.
  - 빔: **1-bit 코딩 메타표면 = 공간 sign(cosΦ)**, OAM=위상특이점, 급격자동집속=유한거리 수렴.
- 진짜 융합 3안:
  - 🟢 ① **공간 슈퍼트위스팅 개구**(1-bit 메타표면을 슈퍼트위스팅으로 설계; ΔΣ↔슬라이딩, 슈퍼트위스팅=2차 ΔΣ; 양자화 로브=채터링) — 개발가능.
  - 🟡 ② 터미널 슬라이딩=유한거리 집속 ↔ 급격자동집속 빔.
  - 🔴 ③ 슬라이딩-불변 빔=지정 외란에 맞춘 자가치유.

## 6라운드 — 아키텍처 융합 제안 (→ `02_vf_monbt.md`)
- 사용자 제안: NBT + CAT-MoEformer + 멀티빔 동시조준 + Volumetric Focusing 융합.
- 결과: 네 조각이 직교 레이어라 융합 성립 → **VF-MoNBT** 설계. (근접 선행연구 있으나 넷 동시 융합은 미발표)

## 7라운드 — 수식·시뮬 (→ `03` + `sim/`)
- 공간 슈퍼트위스팅 개구의 전체 수식 유도(1-bit 로브 -9.5 dB, NTF (1-z⁻¹)ᵖ, 보호대역 전력 ∝ Ω_b^{2p+1}) + 시뮬 설계 + 코드 뼈대 작성.

## 교정·정직성 메모
- SMC "전달력↑"은 틀림 → **강인성·유한시간 추적**이 본질.
- OAM은 원거리 P2P 용량에서 MIMO를 못 이김 → "강인성·ISAC·다중화 단순화"로 포지셔닝.
- 실수 ±1 개구는 미러빔 불가피 → 복소 1-bit/오프셋 임계 필요.
- 초록·메타데이터 기반 조사가 다수 → 본문 미검증 부분은 실험으로 확인 필요.
