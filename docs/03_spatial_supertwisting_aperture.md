# 03 — 플래그십 B: 공간 슈퍼트위스팅 개구

**Spatial Super-Twisting Aperture** — SMC/슈퍼트위스팅의 *이론 구조 자체*를 빔합성 수식에 내재시킨다.
(응용이 아니라 융합: 외부 제어루프도, 가중치 갱신도 아니며, 빔의 정적 공간장 자체가 SMC의 구조법칙으로 합성된다.)

## 핵심 주장

> 1-bit 양자화 로브는 SMC의 채터링과 같은 수학적 객체이고, 슈퍼트위스팅은 "리야프노프로 안정성이 보장되고
> 유한스텝에 수렴하는 비선형 2차 ΔΣ 변조기"라서, 양자화 로브를 메인빔 근방에서 40 dB/decade로 셰이핑하면서도
> 선형 2차 ΔΣ의 불안정·톤 문제를 없앤다.

## 통일 원리: "설계된 불연속/특이점 = 강인성"

- **SMC**: 슬라이딩면을 가로지르는 `sign(s)` 불연속 → 외란 불변성·유한시간·위상적 ±1.
- **빔**:
  - **1-bit 코딩 메타표면 = 공간 sign(cosΦ)** (문헌: 이상 위상자를 실수부 부호로 {+1,−1} 매핑).
  - **OAM = 위상 특이점**(토폴로지 전하 ℓ).
  - **급격 자동집속(circular Airy) = 유한거리 수렴**.
- SMC는 시간축에서, 빔은 공간/전파거리축에서 같은 수학을 쓴다.

## 1. 문제 설정 & 표기

ULA, 소자 N개, 간격 d=λ/2, k=2π/λ, 소자 n=0..N-1.

이상(연속위상) 가중치(단위모듈러스):
    a(n) = exp(jΦ(n)),   Φ(n) = ω0 n,   ω0 = -k d sin(θ0)

배열인자(관측 공간주파수 ω = k d sinθ):
    AF(ω) = Σ_{n=0}^{N-1} c(n) exp(jω n)

1-bit 코드북 C = {+1,-1}(위상 0/π), 메모리 없는 양자화기:
    Q(x) = sign(Re x) ∈ {±1}

## 2. 왜 순진한 1-bit가 실패하나 — 양자화 로브 유도

순진하게 c(n) = sign(cos Φ(n)). 사각파 푸리에 급수:
    sign(cos ψ) = (4/π) Σ_{m≥0} (-1)^m/(2m+1) cos((2m+1)ψ)

ψ = Φ(n) = ω0 n 대입:
    c(n) = (2/π)(e^{jω0 n}+e^{-jω0 n})      ← 메인 θ0 + 미러 -θ0
         - (2/3π)(e^{j3ω0 n}+e^{-j3ω0 n})   ← 양자화 로브 @ 3ω0
         + ...

3차 고조파 로브의 메인 대비 진폭비 = 1/3:
    L_quant = 20·log10(1/3) ≈ -9.5 dB      (문헌 1-bit "-8~-10 dB" 바닥과 일치)

원인: 메모리 없는 sign의 양자화 오차 스펙트럼이 백색 → 로브가 각도영역에 그대로 남음 (= SMC의 채터링과 동일).

주의(미러빔): 실수 ±1 개구는 |AF(ω)|=|AF(-ω)| 대칭이라 미러빔이 원천적으로 생김.
→ 복소 1-bit {±1,±j}(2-bit) 또는 오프셋/디더 임계로 별도 처리(§7). 아래 셰이핑은 분산된 양자화 오차 로브를 공략.

## 3. 공간 ΔΣ = 1차 슬라이딩 (워밍업)

개구를 n=0→N-1 훑으며 오차귀환:
    u(n) = a(n) - e(n-1)
    c(n) = Q(u(n))
    e(n) = c(n) - u(n)
정리:
    c(n) = a(n) + (e(n) - e(n-1))
    C(z) = A(z) + (1 - z^{-1}) E(z)        → NTF_1 = 1 - z^{-1} (고역통과)

양자화 오차가 공간주파수 고역(개구 가장자리/비가시영역)으로 밀려 메인빔 근방 로브 억제.

슬라이딩 해석: 누적오차 σ(n)=Σ_{m≤n}(c(m)-a(m))를 슬라이딩 변수로 보면 루프가 σ≈0(슬라이딩면) 강제,
sign 양자화가 스위칭. → ΔΣ ≡ 1차 슬라이딩모드.

## 4. 코어 — 슈퍼트위스팅 = 2차 슬라이딩 변조기

연속 슈퍼트위스팅(STA):
    σ̇ = -k1 |σ|^{1/2} sign(σ) + z
    ż  = -k2 sign(σ)

적분기 2개 → 2차 노이즈 셰이핑. 개구를 "시간"으로 보고 (수치 채터링 방지 위해 암시적/투영 오일러) 이산화:
    σ(n) = σ(n-1) + (c(n-1) - a(n-1))
    z(n) = z(n-1) - k2 sign(σ(n))
    u(n) = a(n) - k1 |σ(n)|^{1/2} sign(σ(n)) - z(n)
    c(n) = Q(u(n)) = sign(Re u(n))

→ NTF_2 ≈ (1 - z^{-1})^2 (40 dB/decade).

왜 "그냥 2차 ΔΣ"가 아니라 슈퍼트위스팅이어야 하나 (= 과학적 기여):
- 선형 2차 ΔΣ는 불안정·극한주기(톤/패턴노이즈) 위험.
- 슈퍼트위스팅의 분수멱 항 |σ|^{1/2}이
  (ⅰ) σ의 유한스텝 붕괴(작은 N에서도 평균오차가 유한 소자수 안에 락온),
  (ⅱ) 리야프노프 보장 강인안정성으로 톤 억제.
- 안정성(Moreno–Osorio): V = ζ^T P ζ, ζ = [|σ|^{1/2}sign(σ), z]^T 로 유한시간 수렴 증명.
  충분이득(교란상한 L): k1 = 1.5√L, k2 = 1.1 L.

→ 슈퍼트위스팅 = 리야프노프-안정 + 유한정착 비선형 2차 ΔΣ. 빔합성 수식에 SMC 이론이 내재되는 지점.

## 5. 노이즈 셰이핑 로브 분석 (정량 주장)

양자화 오차 e(n)을 근사 백색(분산 σ_e²)으로 보면, 차수 p NTF의 잔류 스펙트럼:
    S_res(Ω) = |(1-e^{-jΩ})^p|² σ_e² = (2 sin(Ω/2))^{2p} σ_e²
(Ω = 메인빔 기준 공간주파수 오프셋)

보호대역 [0, Ω_b] 내 잔류 양자화 전력:
    P_in(p) = (σ_e²/π) ∫_0^{Ω_b} (2 sin(Ω/2))^{2p} dΩ ≈ (σ_e²/π) · Ω_b^{2p+1}/(2p+1)

    p=0: ∝ Ω_b   (로브 잔존)
    p=1: ∝ Ω_b³  (ΔΣ)
    p=2: ∝ Ω_b⁵  (슈퍼트위스팅)

→ 차수 1당 메인빔 근방 로브를 +20 dB/decade씩 추가 억제. 순진 -9.5 dB → 보호대역 내 ≪ -25~-30 dB.
대가: 가장자리(고 Ω, 비가시영역)로의 오차 전이.

## 6. 시뮬레이션 설계

배열: ULA N∈{16,32,64,128}, d=λ/2. (+ 2D 32×32 메타표면, 근거리장 집속 변형 → "조준타격"/Volumetric 연결)
시나리오: 원거리 조향 θ0=30° 기본, θ0∈[0°,60°] 스윕. 근거리장 구면위상 집속 변형.
비교군: (a) 이상 연속 (b) 순진 1-bit (c) 1차 ΔΣ (d) 선형 2차 ΔΣ(대조군) (e) 슈퍼트위스팅 2차(제안).
지표:
  ① 메인/미러 제외 피크 양자화 로브(dB)
  ② 메인 지향성·스캔손실
  ③ SLL·보호대역 적분전력(§5 검증)
  ④ 강인성(소자 위상오차 N(0,σ²), 고장률 p_fail, 1-bit 상태오류): 제안 우아한 저하 vs 선형 2차 ΔΣ 톤/발산
  ⑤ 정착: |σ(n)|<ε 도달 소자수(유한정착) vs ΔΣ 점근
  ⑥ θ0 스윕 로브
핵심 어블레이션(= 주장): |σ|^{1/2} 항 on/off(슈퍼트위스팅 vs 선형 2차) → 분수멱 항 기여 분리.
반증가능 예측:
  (a) 보호대역 전력 ∝ Ω_b^{2p+1}(로그-로그 기울기)
  (b) 제안이 선형 2차와 같은 셰이핑인데 스퓨리어스/톤 더 낮음
  (c) 정착 소자수 N 무관
몬테카를로 1000회로 신뢰구간.

구현: `sim/spatial_supertwisting.py` 참조.

## 7. 정직한 한계 & 처방

1. 미러빔: 실수 ±1은 ±θ0 대칭 → 복소 1-bit {±1,±j} 또는 오프셋/디더 임계.
2. 엔드파이어: 조향 커지면 비가시영역 축소 → 오차 버릴 공간 부족 → 큰 θ0에서 억제 저하(지표 ⑥).
3. 2D 경로의존성: 래스터 훑기 방향 아티팩트 → 힐베르트곡선/2D 오차확산(Floyd–Steinberg 유사).
4. 강력한 앵커 — 하프토닝: 1-bit 개구합성 ≡ 디지털 하프토닝, ΔΣ ≡ 오차확산,
   슈퍼트위스팅 ≡ 강인 2차 오차확산. 성숙분야에 뿌리 → 신뢰도↑, 리뷰 방어.

## 한 줄 결론
sign(cosΦ) 1-bit 로브(-9.5 dB)는 백색 양자화 오차 = 채터링. 1차 ΔΣ(=1-sliding)는 (1-z⁻¹),
슈퍼트위스팅(=2-sliding)은 (1-z⁻¹)²로 셰이핑하되 |σ|^{1/2} 덕에 리야프노프-안정·유한정착
→ 메인빔 근방 양자화 로브를 40 dB/decade 제거. 비유가 아니라 빔합성에 SMC 이론이 수식으로 내재.
