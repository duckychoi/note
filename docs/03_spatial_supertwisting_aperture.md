# 03 — 플래그십 B: 공간 슈퍼트위스팅 개구

**Spatial Super-Twisting Aperture** — SMC/슈퍼트위스팅의 *이론 구조 자체*를 빔합성 수식에 내재시킨다.
(응용이 아니라 융합: 외부 제어루프도, 가중치 갱신도 아니며, 빔의 정적 공간장 자체가 SMC의 구조법칙으로 합성된다.)

## 핵심 주장

> 1-bit 양자화 로브는 SMC의 채터링과 같은 수학적 객체이고, 슈퍼트위스팅은 "리야프노프로 안정성이 보장되고
> 유한스텝에 수렴하는 비선형 2차 ΔΣ 변조기"라서, 양자화 로브를 메인빔 근방에서 40 dB/decade로 셰이핑하면서도
> 선형 2차 ΔΣ의 불안정·톤 문제를 없앤다.

> **rev2 정정 (2026-10-19, `sim/NOTES.md` 실험 E1–E4):**
> - **확인:** §2 의 −9.5 dB.
> - **확인:** 영점을 메인빔(±ω0)에 둔 *대역통과* 1차 셰이핑. 근방 잔차가 −23~−28 dB, 기울기 ≈3.
> - **정정:** rev1 의 (1−z⁻¹)ᵖ 는 영점이 broadside 라서 조향빔에서는 노이즈를 오히려 키울 수 있다(§3·§5).
> - **정정:** §4 이산화의 z 부호 오류(양의 피드백).
> - **미검증 가설:** 위 인용의 "슈퍼트위스팅 = 40 dB/decade + 안정" 은 아직 검증되지 않았다.

## 통일 원리: "설계된 불연속/특이점 = 강인성"

- **SMC**: 슬라이딩면을 가로지르는 `sign(s)` 불연속 → 외란 불변성·유한시간·위상적 ±1.
- **빔**:
  - **1-bit 코딩 메타표면 = 공간 sign(cosΦ)** (문헌: 이상 위상자를 실수부 부호로 {+1,−1} 매핑).
  - **OAM = 위상 특이점**(토폴로지 전하 ℓ).
  - **급격 자동집속(circular Airy) = 유한거리 수렴**.
- SMC는 시간축에서, 빔은 공간/전파거리축에서 같은 수학을 쓴다.

## 1. 문제 설정 & 표기

ULA, 소자 N개, 간격 d=λ/2, k=2π/λ, 소자 n=0..N-1.

이상(연속위상) 가중치(단위모듈러스):
    a(n) = exp(jΦ(n)),   Φ(n) = ω0 n,   ω0 = -k d sin(θ0)

배열인자(관측 공간주파수 ω = k d sinθ):
    AF(ω) = Σ_{n=0}^{N-1} c(n) exp(jω n)

1-bit 코드북 C = {+1,-1}(위상 0/π), 메모리 없는 양자화기:
    Q(x) = sign(Re x) ∈ {±1}

## 2. 왜 순진한 1-bit가 실패하나 — 양자화 로브 유도

순진하게 c(n) = sign(cos Φ(n)). 사각파 푸리에 급수:
    sign(cos ψ) = (4/π) Σ_{m≥0} (-1)^m/(2m+1) cos((2m+1)ψ)

ψ = Φ(n) = ω0 n 대입:
    c(n) = (2/π)(e^{jω0 n}+e^{-jω0 n})      ← 메인 θ0 + 미러 -θ0
         - (2/3π)(e^{j3ω0 n}+e^{-j3ω0 n})   ← 양자화 로브 @ 3ω0
         + ...

3차 고조파 로브의 메인 대비 진폭비 = 1/3:
    L_quant = 20·log10(1/3) ≈ -9.5 dB      (문헌 1-bit "-8~-10 dB" 바닥과 일치)

원인: 메모리 없는 sign 의 양자화 오차가 메인빔 근방에서 줄어들지 않고 각도영역에 그대로 남는다(= SMC 의 채터링과 동일).
정확히 말하면 순진 1-bit 의 오차는 백색이 아니라 고조파 **톤**((2m+1)ω0 의 선 스펙트럼)이다. §5 의 백색 가정은 디더나 위상 앙상블이 있을 때만 성립한다.

주의(고조파 접힘, 검증 E1): 소자 간격으로 샘플링하므로 (2m+1)ω0 는 2π 로 접혀서(mod 2π) 나타난다.
- ω0 가 π 의 유리수배이면(예: θ0=30°, d=λ/2 → ω0=π/2) 3ω0 ≡ −ω0 가 되어 3차 로브가 **미러빔 위에 정확히 겹친다.**
  그래서 −9.5 dB 로브가 미러 guard 에 가려지고 피크가 −19 dB 처럼 보인다. 검증 각도로 쓰면 안 된다.
- d<λ/2 이면 접힌 고조파가 비가시영역(|ω|>kd)에 떨어져 사라질 수도 있다.
- 일반 각도(20°, 23.7°, 35°, 45°, N=64)에서 측정한 피크 로브는 −8.8~−9.5 dB 로, 이론값 −9.54 dB 와 일치한다.

주의(미러빔): 실수 ±1 개구는 |AF(ω)|=|AF(-ω)| 대칭이라 미러빔이 원천적으로 생김.
→ 복소 1-bit {±1,±j}(2-bit) 또는 오프셋/디더 임계로 별도 처리(§7). 아래 셰이핑은 분산된 양자화 오차 로브를 공략.

## 3. 공간 ΔΣ = 1차 슬라이딩 (워밍업)

개구를 n=0→N-1 훑으며 오차귀환:
    u(n) = a(n) - e(n-1)
    c(n) = Q(u(n))
    e(n) = c(n) - u(n)
정리:
    c(n) = a(n) + (e(n) - e(n-1))
    C(z) = A(z) + (1 - z^{-1}) E(z)        → NTF_1 = 1 - z^{-1} (고역통과)

~~양자화 오차가 공간주파수 고역(개구 가장자리/비가시영역)으로 밀려 메인빔 근방 로브 억제.~~ **(rev2 정정)**
NTF_1 = 1 − z⁻¹ 의 영점은 ω=0, 즉 **broadside(θ=0)** 에 있다. 메인빔 ω0 에서의 노이즈 이득은
    |NTF_1(e^{jω0})|² = (2 sin(ω0/2))²
이고, d=λ/2 에서 sinθ0 > 1/3 (θ0 > 19.47°) 이면 1 보다 커진다. 즉 조향빔 근방 노이즈를 **오히려 키운다.**
검증 E2(디더, N=1024): 측정치가 이 예측을 1.2~1.6 dB 차이로 추종한다(5°: −12.9 dB, 45°: +3.9 dB).
또 d=λ/2 에서는 가시영역이 ω∈[−π,π] 전체라 "비가시영역"이 없다. 밀어낸 노이즈는 결국 보이는 사이드로브로 나온다.

**조향빔용 올바른 형태 — 영점을 ±ω0 에:**
    실수 1-bit {±1}:   NTF_1^BP(z) = 1 − 2cos(ω0) z⁻¹ + z⁻²      (실수 코드라 ±ω0 쌍. 미러빔은 원래 대칭이라 함께 셰이핑된다)
    복소 2-bit {±1,±j}: NTF_1^C(z)  = 1 − e^{jω0} z⁻¹            (미러 없음, §7)
오차귀환 구현: u(n) = x(n) + [(NTF−1)e](n),  c(n) = Q(u(n)),  e(n) = c(n) − u(n)  ⇒  C = X + NTF·E.
검증 E2: 대역통과 1차는 전 각도(5°–60°)에서 메인빔 근방 잔차가 p=0 보다 23~28 dB 낮다.

슬라이딩 해석: 누적오차 σ(n)=Σ_{m≤n}(c(m)-a(m))를 슬라이딩 변수로 보면 루프가 σ≈0(슬라이딩면) 강제,
sign 양자화가 스위칭. → ΔΣ ≡ 1차 슬라이딩모드.

## 4. 코어 — 슈퍼트위스팅 = 2차 슬라이딩 변조기

연속 슈퍼트위스팅(STA):
    σ̇ = -k1 |σ|^{1/2} sign(σ) + z
    ż  = -k2 sign(σ)

적분기 2개 → 2차 노이즈 셰이핑. 개구를 "시간"으로 보고 (수치 채터링 방지 위해 암시적/투영 오일러) 이산화:
    σ(n) = σ(n-1) + (c(n-1) - a(n-1))
    z(n) = z(n-1) - k2 sign(σ(n))
    u(n) = a(n) - k1 |σ(n)|^{1/2} sign(σ(n)) + z(n)      ← rev2: rev1 의 "- z(n)" 은 부호 오류
    c(n) = Q(u(n)) = sign(Re u(n))

부호 근거: σ 는 c−a 의 누적이므로 σ>0 이면 다음 c 를 낮춰야 한다.
연속 STA 의 제어는 v = −k1|σ|^½sgnσ + z 이고 ż = −k2 sgnσ 이다. 따라서 z 는 **+** 로 들어가야 한다.
rev1 의 −z 는 σ>0 일 때 u 를 키우는 양의 피드백이다. 검증 E4: σ 가 발산하고 코드의 98% 가 +1 로 고착, broadside 에 0 dB 가짜 빔.

→ ~~NTF_2 ≈ (1 - z^{-1})^2 (40 dB/decade).~~ **(rev2: 미검증 가설로 강등)**
- 이 루프는 적분기 기반이라 영점이 있다면 broadside 에 있다(§3 정정과 같은 문제). 조향빔용으로는 적분기를 ω0 공진기로 바꾼 대역통과 STW 가 필요하며, 아직 유도하지 않았다.
- 부호를 고친 루프도 문서 게인(k1=1.5, k2=1.1)에서는 피크 로브가 −0.0~−2.1 dB 로 순진 1-bit(−9.5)보다 나쁘다.
  게인을 낮추면(k1=0.2, k2=0.02) −10.0~−11.2 dB 로, 순진보다 1~2 dB 나은 수준이다(E4, N=64).
- 1-bit 2차 루프의 안정성은 리야프노프 증명(연속시간, 비포화 제어 가정)만으로는 보장되지 않는다. 양자화기 포화 아래에서 이산 루프를 따로 분석해야 한다.
  참고로 선형 순수 2차 NTF(|NTF|max ≥ 4)는 1-bit 에서 과부하·발산한다. 극점을 넣어 |NTF|max 를 약 1.85 로 낮춘 선형 BP2 는 안정적이다(E3).

왜 "그냥 2차 ΔΣ"가 아니라 슈퍼트위스팅이어야 하나 (= 과학적 기여):
- 선형 2차 ΔΣ는 불안정·극한주기(톤/패턴노이즈) 위험.
- 슈퍼트위스팅의 분수멱 항 |σ|^{1/2}이
  (ⅰ) σ의 유한스텝 붕괴(작은 N에서도 평균오차가 유한 소자수 안에 락온),
  (ⅱ) 리야프노프 보장 강인안정성으로 톤 억제.
- 안정성(Moreno–Osorio): V = ζ^T P ζ, ζ = [|σ|^{1/2}sign(σ), z]^T 로 유한시간 수렴 증명.
  충분이득(교란상한 L): k1 = 1.5√L, k2 = 1.1 L.

→ (가설) 슈퍼트위스팅 = 리야프노프-안정 + 유한정착 비선형 2차 ΔΣ. 빔합성 수식에 SMC 이론이 내재되는 지점.
  위 근거들은 연속시간 STA 의 성질이다. 1-bit 양자화 루프와 조향빔(대역통과)에서 그대로 성립하는지는 미검증이다(§4 rev2 주석).

## 5. 노이즈 셰이핑 로브 분석 (정량 주장)

양자화 오차 e(n)을 근사 백색(분산 σ_e²)으로 보면, 차수 p NTF의 잔류 스펙트럼:
    S_res(Ω) = |(1-e^{-jΩ})^p|² σ_e² = (2 sin(Ω/2))^{2p} σ_e²
(Ω = **NTF 영점** 기준 공간주파수 오프셋. rev2 정정: (1−z⁻¹)ᵖ 의 영점은 broadside 다.
 Ω 를 "메인빔 기준"으로 읽으려면 영점이 ω0 에 있는 대역통과 NTF(§3)가 필요하다. 영점 근방에서 그 NTF 의 크기는 ∝ Ω 로 같은 꼴이다.)

성립 전제 (rev2, 검증 E3):
- (i) 오차가 백색이어야 한다(디더 또는 위상 앙상블). 단일 정현의 순진 1-bit 는 오차가 톤이라 p=0 기울기가 1 이 아니라 3.2 로 나온다.
- (ii) Ω_b ≫ 2π/N (빔폭보다 넓은 보호대역).
- (iii) 개구 누설: 1-bit 는 진폭 테이퍼가 불가능한 **균일 개구**다. 대역 밖으로 밀어낸 노이즈가 sinc 사이드로브로 대역 안에 다시 샌다.
  그래서 고차 기울기가 깎인다. 측정(N=4096) 결과 직사각은 p=1 2.63, p=2 2.70 이고, Hann 테이퍼(진단용)는 p=1 2.97, p=2 4.12 다.
  즉 균일 1-bit 개구에서는 p=2 의 기울기 이점이 사라진다.

보호대역 [0, Ω_b] 내 잔류 양자화 전력:
    P_in(p) = (σ_e²/π) ∫_0^{Ω_b} (2 sin(Ω/2))^{2p} dΩ ≈ (σ_e²/π) · Ω_b^{2p+1}/(2p+1)

    p=0: ∝ Ω_b   (로브 잔존)
    p=1: ∝ Ω_b³  (ΔΣ)
    p=2: ∝ Ω_b⁵  (슈퍼트위스팅)

→ 차수 1당 영점 근방 로브를 +20 dB/decade 씩 추가 억제한다(전제 (i)–(iii) 하에서).
  - 확인된 수치: 대역통과 1차가 메인빔 근방(|ω−ω0|<0.05) 잔차를 p=0 대비 −23~−28 dB 낮춘다(E2).
  - "순진 −9.5 dB → ≪ −25~−30 dB" 는 *보호대역 내 잔차* 기준이다. 보호대역 밖 피크 로브는 그만큼 내려가지 않는다(다음 줄).
대가: 대역 밖으로의 오차 전이. d=λ/2 는 비가시영역이 없어서, 옮겨진 오차가 보이는 먼 사이드로브로 나온다.
  검증 E5: 보호대역 밖 피크 로브는 대역통과 1차 기준 N=64 에서 −7.2 dB(순진 −9.5 보다 **악화**), N=256 에서 −11.6 dB(약 2 dB 개선)다.
  피크 로브까지 크게 낮추려면 d<λ/2(공간 오버샘플링)로 비가시영역을 확보해야 할 가능성이 크다. 이 부분은 미검증이다.

## 6. 시뮬레이션 설계

배열: ULA N∈{16,32,64,128}, d=λ/2. (+ 2D 32×32 메타표면, 근거리장 집속 변형 → "조준타격"/Volumetric 연결)
시나리오: 원거리 조향 θ0=23.7° 기본(rev2: 30° 는 ω0=π/2 퇴화 각도라 §2 검증에 부적합), θ0∈[0°,60°] 스윕. 근거리장 구면위상 집속 변형.
비교군: (a) 이상 연속 (b) 순진 1-bit (c) 1차 ΔΣ — 저역(영점 broadside) vs 대역통과(영점 ±ω0)
        (d) 선형 2차 대역통과 ΔΣ(대조군, 극점으로 |NTF|max 제한) (e) 슈퍼트위스팅 2차(제안, 대역통과형은 미정식화).
지표:
  ① 메인/미러 제외 피크 양자화 로브(dB)
  ② 메인 지향성·스캔손실
  ③ SLL·보호대역 적분전력(§5 검증)
  ④ 강인성(소자 위상오차 N(0,σ²), 고장률 p_fail, 1-bit 상태오류): 제안 우아한 저하 vs 선형 2차 ΔΣ 톤/발산
  ⑤ 정착: |σ(n)|<ε 도달 소자수(유한정착) vs ΔΣ 점근
  ⑥ θ0 스윕 로브
핵심 어블레이션(= 주장): |σ|^{1/2} 항 on/off(슈퍼트위스팅 vs 선형 2차) → 분수멱 항 기여 분리.

  (c) 정착 소자수 N 무관

## 7. 정직한 한계 & 처방

1. 미러빔: 실수 ±1은 ±θ0 대칭 → 복소 1-bit {±1,±j} 또는 오프셋/디더 임계.
2. 엔드파이어: 조향 커지면 비가시영역 축소 → 오차 버릴 공간 부족 → 큰 θ0에서 억제 저하(지표 ⑥).
3. 2D 경로의존성: 래스터 훑기 방향 아티팩트 → 힐베르트곡선/2D 오차확산(Floyd–Steinberg 유사).
4. 강력한 앵커 — 하프토닝: 1-bit 개구합성 ≡ 디지털 하프토닝, ΔΣ ≡ 오차확산,
   슈퍼트위스팅 ≡ 강인 2차 오차확산. 성숙분야에 뿌리 → 신뢰도↑, 리뷰 방어.

## 한 줄 결론 (rev2)
- **확인:** sign(cosΦ) 1-bit 로브(−9.5 dB, 일반 각도)는 메인빔 근방에서 줄지 않는 양자화 오차(= 채터링)다.
- **확인:** 1차 ΔΣ(=1-sliding)가 조향빔 근방을 실제로 깎으려면, 영점이 ±ω0 에 있는 대역통과 NTF (1−2cosω0 z⁻¹+z⁻²) 여야 한다. 측정 −23~−28 dB, 기울기 ≈3. 저역 (1−z⁻¹) 은 θ0>19.47° 에서 오히려 악화시킨다.
- **가설(미검증):** 슈퍼트위스팅(=2-sliding)이 대역통과형으로 정식화되어 1-bit 루프에서 안정적으로 40 dB/decade 셰이핑을 낸다는 주장.
  균일 개구 누설 때문에 2차 기울기 이점은 직사각 개구에서 측정되지 않았다(2.7).
