# 03 — 플래그십 B: 공간 슈퍼트위스팅 개구

**Spatial Super-Twisting Aperture** — SMC/슈퍼트위스팅의 *이론 구조 자체*를 빔합성 수식에 내재시킨다.
(응용이 아니라 융합: 외부 제어루프도, 가중치 갱신도 아니며, 빔의 정적 공간장 자체가 SMC의 구조법칙으로 합성된다.)

> **rev2 (2026-10-19).** rev1 은 시뮬레이션이 이론과 맞지 않았다. 원인을 실험 E0–E5(`sim/NOTES.md`)로 분리하고 이 문서를 고쳤다.
> 표기: **[확인]** = rev2 시뮬로 재현됨, **[정정]** = rev1 수식·서술 오류를 고침, **[가설]** = 아직 검증 안 됨.

## 핵심 주장 — [가설]

> 1-bit 양자화 로브는 SMC의 채터링과 같은 수학적 객체이고, 슈퍼트위스팅은 "리야프노프로 안정성이 보장되고
> 유한스텝에 수렴하는 비선형 2차 ΔΣ 변조기"라서, 양자화 로브를 메인빔 근방에서 40 dB/decade로 셰이핑하면서도
> 선형 2차 ΔΣ의 불안정·톤 문제를 없앤다.

위 인용은 rev1 의 연구 가설이다. 이 문장 중 rev2 에서 확인된 것은 다음뿐이다.
- [확인] 순진 1-bit 로브 −9.5 dB (§2).
- [확인] 영점을 메인빔 ±ω0 에 둔 *대역통과* 선형 ΔΣ 가 메인빔 근방 노이즈를 차수에 맞게 셰이핑한다(§3·§5). 1차는 기울기 ≈3, 2차는 Hann 측정 4.89 대 정확 예측 4.88.

슈퍼트위스팅이 이것을 더 잘한다는 부분(안정성·톤 제거·40 dB/decade)은 **검증되지 않았다**(§4).

## 통일 원리: "설계된 불연속/특이점 = 강인성"

- **SMC**: 슬라이딩면을 가로지르는 `sign(s)` 불연속 → 외란 불변성·유한시간·위상적 ±1.
- **빔**:
  - **1-bit 코딩 메타표면 = 공간 sign(cosΦ)** (문헌: 이상 위상자를 실수부 부호로 {+1,−1} 매핑).
  - **OAM = 위상 특이점**(토폴로지 전하 ℓ).
  - **급격 자동집속(circular Airy) = 유한거리 수렴**.
- SMC는 시간축에서, 빔은 공간/전파거리축에서 같은 수학을 쓴다.

## 1. 문제 설정 & 표기

ULA, 소자 N개, 간격 d=λ/2, k=2π/λ, 소자 n=0..N-1.

이상(연속위상) 가중치(단위모듈러스):
    a(n) = exp(jΦ(n)),   Φ(n) = ω0 n,   ω0 = -k d sin(θ0)

배열인자(관측 공간주파수 ω = k d sinθ):
    AF(ω) = Σ_{n=0}^{N-1} c(n) exp(jω n)

1-bit 코드북 C = {+1,-1}(위상 0/π). 실수 코드가 맞추는 **실수 목표**:
    x(n) = amp · Re a(n) = amp · cos(ω0 n)        (amp ≤ 1, 이하 모든 변조기의 입력)
메모리 없는 양자화기: Q(v) = sign(v) ∈ {±1}.
실수 코드는 AF(−ω) = AF(ω)* 이므로 |AF| 가 ±ω0 에서 같다. 메인과 미러는 구분할 수 없고, 아래의 ±ω0 표기는 둘을 함께 가리킨다.

## 2. 왜 순진한 1-bit가 실패하나 — 양자화 로브 유도 [확인]

순진하게 c(n) = sign(cos Φ(n)). 사각파 푸리에 급수:
    sign(cos ψ) = (4/π) Σ_{m≥0} (-1)^m/(2m+1) cos((2m+1)ψ)

ψ = Φ(n) = ω0 n 대입:
    c(n) = (2/π)(e^{jω0 n}+e^{-jω0 n})      ← 메인 θ0 + 미러 -θ0
         - (2/3π)(e^{j3ω0 n}+e^{-j3ω0 n})   ← 양자화 로브 @ 3ω0
         + ...

3차 고조파 로브의 메인 대비 진폭비 = 1/3:
    L_quant = 20·log10(1/3) ≈ -9.5 dB      (문헌 1-bit "-8~-10 dB" 바닥과 일치)

원인: 메모리 없는 sign 의 양자화 오차가 메인빔 근방에서 셰이핑되지 않고 각도영역에 남는다(= SMC 의 채터링).
이 오차는 백색이 아니라 고조파 **선 스펙트럼**((2m+1)ω0 의 톤)이다. 위상을 무작위로 바꿔도 톤의 위상만 평균될 뿐 백색이 되지는 않는다.
백색 오차 모델(§5)은 디더를 넣어야 근사적으로 맞는다.

고조파 접힘(검증 E1): 소자 간격으로 샘플링하므로 (2m+1)ω0 는 mod 2π 로 접혀 나타난다.
- 3ω0 ≡ −ω0 (mod 2π), 즉 **4ω0 ∈ 2πℤ** 이면 3차 로브가 미러빔 위에 정확히 겹친다.
  예: θ0=30°, d=λ/2 → ω0=π/2. 이때 −9.5 dB 로브가 미러 guard 에 가려져 피크가 −19.4 dB 로 측정된다. rev1 의 −21 dB 가 이것이다. 이 각도는 검증에 쓰면 안 된다.
- d<λ/2 이면 접힌 고조파가 비가시영역(|ω|>kd)에 떨어져 사라질 수도 있다.
- 일반 각도(20°, 23.7°, 35°, 45°, N=64, 위상 앙상블)에서 측정한 피크 로브는 −9.0~−9.5 dB 로, 이론값 −9.54 dB 와 맞는다.

주의(미러빔): 실수 ±1 출력이면 임계값을 어떻게 바꾸든(오프셋·디더 포함) AF(−ω)=AF(ω)* 가 유지된다. 따라서 미러빔을 없앨 수 없다.
미러를 없애려면 복소 코드(예: 2-bit {±1,±j})처럼 출력 자체가 복소인 모델이 필요하다(§7). 아래의 셰이핑은 미러와 무관하게 양자화 오차 로브를 공략한다.

## 3. 공간 ΔΣ = 1차 슬라이딩 (워밍업)

개구를 n=0→N-1 훑으며 오차귀환(실수 목표 x):
    u(n) = x(n) - e(n-1)
    c(n) = Q(u(n))
    e(n) = c(n) - u(n)
정리:
    c(n) = x(n) + (e(n) - e(n-1))
    C(z) = X(z) + (1 - z^{-1}) E(z)        → NTF_1 = 1 - z^{-1}

**[정정] rev1 서술 "오차가 고역(비가시영역)으로 밀려 메인빔 근방 로브 억제" 는 조향빔에서 틀렸다.**
NTF_1 = 1 − z⁻¹ 의 영점은 ω=0, 즉 **broadside(θ=0)** 에 있다. 메인빔 ω0 에서의 노이즈 이득은
    |NTF_1(e^{jω0})|² = (2 sin(ω0/2))²
이다. d=λ/2 에서 sinθ0 > 1/3 (θ0 > 19.47°) 이면 이 값이 1 보다 커서, 조향빔 근방 노이즈를 **오히려 키운다.**
- 검증 E2(N=1024, 디더): 예측에 오차 분산 차이를 보정한 값(|NTF|²·σ²_e,LP/σ²_e,p0)과 측정이 1 dB 안에서 맞는다(5°·10°·25°·45°·60°).
- 단 θ0=19.47°(ω0=π/3, 6ω0∈2πℤ) 에서는 +3.3 dB 벗어난다. 유리수 각도에서 생기는 주기 톤 때문으로 보이며, 원인은 미확인이다.
- 또 d=λ/2 에서는 가시영역이 ω∈[−π,π] 전체라 비가시영역이 없다. 밀려난 노이즈는 보이는 사이드로브로 나온다.

**조향빔용 형태 — 영점을 ±ω0 에 [확인]:**
    실수 1-bit {±1}:    NTF_1^BP(z) = 1 − 2cos(ω0) z⁻¹ + z⁻²     (±ω0 영점 쌍)
    복소 코드 {±1,±j}:  NTF_1^C(z)  = 1 − e^{jω0} z⁻¹            (미러 없음, §7; 미검증)
일반 오차귀환 구현: u(n) = x(n) + [(NTF−1)e](n), c(n) = Q(u(n)), e(n) = c(n) − u(n) ⇒ C = X + NTF·E (STF = 1).
- 검증 E2: 대역통과 1차의 메인빔 근방(|ω−ω0|<0.05) 잔차 PSD 는 디더 p=0 대비 −25.8 ~ −30.9 dB 다.
- 메인빔 피크 |AF(ω0)|² 대비로는 −44 ~ −50 dB 다. 이것은 대역 평균 잔차이며, §2 의 피크 로브 −9.5 dB 와는 다른 지표다.

**[정정] rev1 `dsm2_linear` 는 구조 자체가 불안정했다(E0).**
i1 += x − c(n−1), i2 += i1, u = 2·i1 + i2 를 선형화하면 (q=z⁻¹):
    NTF = (1−q)² / (1+q−q²),   STF = (3−2q) / (1+q−q²)
극점 z ∈ {0.618, −1.618} 중 하나가 단위원 밖이다. 1-bit 포화 덕에 |u| 는 유계(≤16)지만, 영점도 broadside 다.
측정 피크 로브는 −11.4/−6.9/−3.1 dB(10°/23.7°/45°)로, 각도가 클수록 순진 1-bit 보다 나빠진다.

슬라이딩 해석: 누적오차 σ(n)=Σ_{m≤n}(c(m)−x(m)) 를 슬라이딩 변수로 보면 루프가 σ≈0(슬라이딩면)을 강제하고,
sign 양자화가 스위칭이다. → 저역 ΔΣ ≡ 1차 슬라이딩모드. 이 대응은 broadside 영점의 저역형에서만 문자 그대로 성립한다.

## 4. 코어 — 슈퍼트위스팅 = 2차 슬라이딩 변조기 [가설]

연속 슈퍼트위스팅(STA):
    σ̇ = -k1 |σ|^{1/2} sign(σ) + z
    ż  = -k2 sign(σ)

개구를 "시간"으로 보고 **명시적(전진) 갱신**으로 이산화한다. rev1 은 "암시적/투영 오일러"라고 적었지만 실제 식과 코드는 명시적이다. 암시적 방식은 미구현.
    u(n) = x(n) - k1 |σ(n-1)|^{1/2} sign(σ(n-1)) + z(n-1)      ← [정정] rev1 은 "− z" (부호 오류)
    c(n) = Q(u(n))
    σ(n) = σ(n-1) + (c(n) - x(n))
    z(n) = z(n-1) - k2 sign(σ(n))

부호 근거: σ 는 c−x 의 누적이므로 σ>0 이면 다음 c 를 낮춰야 한다.
연속 STA 의 제어는 v = −k1|σ|^½sgnσ + z 이고 ż = −k2 sgnσ 이므로, z 는 **+** 로 들어가야 한다.
rev1 의 −z 는 σ 와 같은 부호로 u 를 미는 양의 피드백이다.
- 검증 E4(θ0=23.7°, φ=0, N=64): 초기 과도 뒤 코드가 한 부호로 고착된다. 입력 부호 +면 +1 이 63/64 개, −면 1/64 개다.
- 그 결과 broadside 에 메인빔보다 **+26 dB** 큰 가짜 빔이 생긴다(위상 앙상블 평균 +25~+30 dB).

부호를 고쳐도 남는 문제:
- 이 루프는 적분기 기반이라, 셰이핑이 있다면 영점은 broadside 다(§3 과 같은 문제). 조향빔용으로는 적분기를 ω0 공진기로 바꾼 대역통과 STW 가 필요하며, 아직 유도하지 않았다.
- 부호를 고친 루프(E4, N=64, 피크 로브는 메인 대비):
  - 문서 게인(k1=1.5, k2=1.1): +2.4 ~ +9.9 dB. 메인보다 큰 로브가 생긴다.
  - 게인을 크게 낮추면(k1=0.2, k2=0.02): −10.1 ~ −11.0 dB. 같은 각도의 순진 1-bit(−8.8~−9.5)보다 0.6~2.1 dB 낫다.
- 리야프노프 유한시간 증명은 연속시간·비포화 제어를 가정한다. 1-bit 포화 이산 루프의 안정성은 따로 분석해야 한다.
- 선형 2차의 1-bit 과부하 판정은 |NTF|max 경험칙(~1.5, 설계 지침이지 정리가 아님)과 실측으로만 했다.
  - 순수 BP² (|NTF|max=6.8) 는 실측에서 발산했다(rev2 첫 실행, max|u| ≈ 3e5).
  - 극점 반경 r=0.7 로 |NTF|max=1.85 까지 낮춘 BP2 는 유계다(max|u| ≈ 3).

왜 "그냥 2차 ΔΣ"가 아니라 슈퍼트위스팅이어야 하나 — rev1 의 논거(모두 [가설]):
- 선형 2차 ΔΣ는 불안정·극한주기(톤/패턴노이즈) 위험.
- 슈퍼트위스팅의 분수멱 항 |σ|^{1/2}이
  (ⅰ) σ의 유한스텝 붕괴(작은 N에서도 평균오차가 유한 소자수 안에 락온),
  (ⅱ) 리야프노프 보장 강인안정성으로 톤 억제.
- 안정성(Moreno–Osorio): V = ζ^T P ζ, ζ = [|σ|^{1/2}sign(σ), z]^T 로 유한시간 수렴 증명(연속시간).
  충분이득(교란상한 L): k1 = 1.5√L, k2 = 1.1 L.

이 논거들은 연속시간 STA 의 성질이다. 1-bit 양자화 루프·조향빔(대역통과)에서 그대로 성립하는지는 미검증이고, E4 의 현재 수치는 오히려 반대 방향이다.

## 5. 노이즈 셰이핑 로브 분석 (정량 주장)

양자화 오차 e(n)을 근사 백색(분산 σ_e²)으로 보면, 영점이 Ω=0 에 p 개 겹친 저역 NTF 의 잔류 스펙트럼:
    S_res(Ω) = |(1-e^{-jΩ})^p|² σ_e² = (2 sin(Ω/2))^{2p} σ_e²
(Ω = **NTF 영점 기준** 공간주파수 오프셋. [정정] rev1 은 "메인빔 기준"이라 적었지만, (1−z⁻¹)ᵖ 의 영점은 broadside 다.)

대역통과 NTF (영점 ±ω0, 극점 반경 r) 에서는 Ω = ω − ω0 로 두고 영점 근방을 근사한다.
    |NTF_p^BP(e^{j(ω0+Ω)})|² ≈ K^{2p} Ω^{2p},   K = 2|sin ω0| / [ (1−r)·|1 − r e^{−2jω0}| ]
즉 지수는 같고 계수가 각도·극점에 따라 달라진다. 예: θ0=23.7°, p=2, r=0.7 이면 K⁴ ≈ 235.

보호대역 |Ω|<Ω_b 내 잔류 양자화 전력(점근):
    P_in(p) ≈ (σ_e²/π) · K^{2p} · Ω_b^{2p+1}/(2p+1)      (저역형은 K=1)

    p=0: ∝ Ω_b    (셰이핑 없음)
    p=1: ∝ Ω_b³   (단일 영점 ΔΣ)
    p=2: ∝ Ω_b⁵   (이중 영점 NTF. 슈퍼트위스팅이 이 차수를 낸다는 것은 [가설])

성립 전제와 검증(E3, θ0=23.7°, Ω_b ∈ {0.02, …, 0.16}, 잔차 r=c−x):
- (i) 백색 오차. 디더 p=0 은 기울기 1.01~1.06 이다. 디더 없는 순진 1-bit 는 오차가 톤이라 이 모델이 맞지 않는다.
- (ii) 2p+1 은 Ω_b→0 의 점근 지수다. 실제 대역 범위에서 정확히 적분한 기울기는 p=1 2.97, p=2 4.88 이다.
- (iii) 개구 누설. 1-bit 는 진폭 테이퍼를 줄 수 없는 균일(직사각) 개구다. 대역 밖으로 밀린 노이즈가 sinc 사이드로브로 대역 안에 새어 고차 기울기가 깎인다.
  독립 백색 e 를 NTF 로 거른 선형모델에서도 같은 감소가 재현되고, Hann 창을 씌우면 회복된다. 그래서 누설이 원인임을 확인했다.

  | 기울기 | 측정, 직사각 | 측정, Hann(진단용) | 선형모델, 직사각 | 정확 |
  |---|---|---|---|---|
  | p=1, N=4096 | 2.74 | 2.91 | 2.73 | 2.97 |
  | p=2, N=4096 | 3.01 | 4.89 | 2.44 | 4.88 |
  | p=2, N=65536 | 4.48 | 4.89 | 3.84 | 4.88 |

  누설에 의한 감소는 N 이 커질수록 줄어든다. 결론은 "N=4096 균일 개구에서는 p=2 의 기울기 이점이 대부분 깎인다"로 한정한다.

→ 전제 (i)–(iii) 하에서 차수 1당 영점 근방 로브를 약 +20 dB/decade 씩 추가로 억제한다(선형 대역통과 NTF 기준 [확인]).
- 보호대역 내 잔차(E2): 메인빔 피크 대비 −44 ~ −50 dB(대역통과 1차).
- 보호대역 밖 피크 로브(E5): 사정이 다르다. rev1 의 "순진 −9.5 dB → ≪ −25~−30 dB" 는 피크 로브로 읽으면 근거가 없다.

대가: 대역 밖으로의 오차 전이. d=λ/2 는 비가시영역이 없어서 옮겨진 오차가 보이는 먼 사이드로브로 나온다.
- 검증 E5(대역통과 1차, 입력 amp=1, 피크 로브는 메인 대비): N=64 에서 −6.9 ~ −7.0 dB 로 순진 −9.5 보다 **악화**, N=256 에서 −11.5 ~ −12.0 dB 로 2~2.5 dB 개선.
- amp=0.5 로 줄이면 메인빔이 약해져 피크 로브가 −1.1 ~ +3.7 dB 가 된다.
- 피크 로브까지 낮추려면 d<λ/2(공간 오버샘플링)로 비가시영역을 확보해야 할 수 있다. [가설]

## 7. 정직한 한계 & 처방

1. 미러빔: 실수 ±1 출력은 임계값과 무관하게 AF(−ω)=AF(ω)* 다. 대칭을 깨려면 복소 출력 코드(2-bit {±1,±j} 등)가 필요하다. 오프셋·디더 임계로는 해결되지 않는다(rev2 정정).
2. 엔드파이어: 조향 커지면 비가시영역 축소 → 오차 버릴 공간 부족 → 큰 θ0에서 억제 저하(지표 ⑥). d=λ/2 는 처음부터 비가시영역이 없다(§5 E5).
3. 2D 경로의존성: 래스터 훑기 방향 아티팩트 → 힐베르트곡선/2D 오차확산(Floyd–Steinberg 유사).
4. 강력한 앵커 — 하프토닝: 1-bit 개구합성 ≡ 디지털 하프토닝, ΔΣ ≡ 오차확산,
   슈퍼트위스팅 ≡ 강인 2차 오차확산([가설]). 성숙분야에 뿌리 → 신뢰도↑, 리뷰 방어.

## 한 줄 결론 (rev2)
- [확인] sign(cosΦ) 1-bit 로브(−9.5 dB, 일반 각도)는 메인빔 근방에서 셰이핑되지 않는 톤성 양자화 오차(= 채터링)다.
- [확인·정정] 조향빔 근방을 깎는 것은 영점이 ±ω0 에 있는 대역통과 NTF (1−2cosω0 z⁻¹+z⁻²)ᵖ 다.
  - 1차: 메인 근방 잔차가 −44 ~ −50 dB(메인 피크 대비), 기울기 ≈3.
  - 2차(극점 r=0.7): 기울기가 Hann 측정 4.89 로 정확 예측 4.88 과 일치.
  - 저역 (1−z⁻¹) 은 θ0>19.47° 에서 오히려 악화시킨다.
- [한계] 균일 개구 누설 때문에 N=4096 에서 2차 기울기 이점이 대부분 깎인다. d=λ/2 에서는 대역 밖 피크 로브가 거의 개선되지 않는다.
- [가설] 슈퍼트위스팅(=2-sliding)이 대역통과형으로 정식화되어 1-bit 루프에서 안정적으로 이 셰이핑을 더 낫게 낸다는 주장. 현재 수치(E4)는 이를 지지하지 않는다.
