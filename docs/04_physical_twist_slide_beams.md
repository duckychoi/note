# 04 — 물리적으로 꼬인/미끄러지는 빔 & SMC-as-optimization

"빔 자체를 진짜 sliding·twisting하게 쏠 수 있나?"에 대한 물리적 답과, 갱신식/loss 관계 정리.

## A. 갱신식 vs 학습 loss — 다른 객체지만 일부러 같게 만들 수 있다

- (a) 런타임 갱신식 `w_{k+1}=w_k + 슈퍼트위스팅(s_k)` = 온라인 동역학(스냅샷마다, 학습 아님, 랴푸노프 수렴).
- (b) 학습 loss = 오프라인 메타목표(여러 채널 실현의 sum-rate·추적오차)로 (a)의 자유 파라미터(곡면·게인) 학습.
- **둘은 다른 물건.** 그러나 슬라이딩 변수를 목적함수 그래디언트로 두면:
      s := ∇_w J(w)
  → 슈퍼트위스팅이 ∇J→0을 유한시간·채터링없이·외란강인하게 모는 **최적화기 그 자체**("SMC as optimization", 2026).
  → 분리형(SMC가 기준빔 추종 + NN이 별도 loss로 곡면 학습)보다 통합형(s=∇J, NN은 프리컨디셔너 P(x)만)이 깔끔:
      ẇ = -P(x) ∇J    (랴푸노프 V=J-J*로 단조감소 보장)

주의: A·B처럼 "가중치 갱신에 SMC" 자체는 옵티마이저 교체라 점진적. 더 매력적인 건 §03(수식 내재) 또는 아래 물리빔.

## B. 물리적으로 꼬인/미끄러지는 빔 (실재)

### TWIST = OAM 보텍스 빔
- 나선형 위상전면 exp(jℓφ), 위상 특이점(토폴로지 전하 ℓ), 가운데가 도넛처럼 빔.
- ℓ 직교 → OAM 모드분할다중화(MDM): 같은 주파수에 여러 꼬임 중첩 = "조준타격 여러 개"의 또 다른 축.
- ISAC×OAM: "Twisting Signals for Joint Radar-Communications: OAM Vortex Beam"(2026.9).

### SLIDE = 미끄러지는 빔
- **Airy 빔**: 자기가속(self-accelerating) — 곡선으로 옆으로 미끄러짐 + 자가치유(장애물 지나면 복원).
- **급격 자동집속(circular Airy)**: 유한거리에서 확 집속(§03의 유한시간 수렴과 동형), 난류 강인.
- **FDA(주파수 다이버시티 배열)**: 안테나별 주파수 증분 → 초점이 거리-각도-시간에 따라 스스로 스캔/미끄러짐. FDA로 OAM 보텍스까지 방사.
- **시공간 코딩 메타표면**: 움직이는/미끄러지는 빔 패턴.

## C. 두 "twist"의 결혼 — 응용 vs 진짜 융합

- 1차 결혼안: "슈퍼트위스팅 제어로 OAM 빔을 강인 생성·추적" → **응용(application)**. SMC를 꼬인 빔에 갖다 붙인 것.
  - 가치: OAM은 정렬 어긋남·난류·이동에 취약 → 고속 이동/난류에서 OAM 모드 유한시간 락온·유지엔 유용.
- 진짜 융합: SMC 이론 구조를 빔합성 수식에 내재 → **§03 공간 슈퍼트위스팅 개구**가 그 답.
  - 보조안: 터미널 슬라이딩=유한거리 집속↔급격자동집속 / 슬라이딩-불변 빔=지정 외란 맞춤 자가치유.

## D. 정직한 한계
- **OAM은 만능 아님**: 원거리 점대점(far-field P2P)에선 기존 MIMO 용량을 못 이김(OAM은 MIMO의 특수해). 이기는 데는 LoS·단거리·구조광·ISAC·다중화 단순성. → "용량 초월"로 포장 금지, "정렬·이동 강인성 / ISAC / 다중화 단순화"로.
- Airy는 꼬리에 에너지 샘, FDA는 거리-각도 결합 복잡.
- 제어의 "슈퍼트위스팅"(알고리즘 이름)과 물리의 "트위스트"(OAM 위상 나선)는 다른 twist — 네이밍 다리일 뿐, 공학적 결합은 §03처럼 수식 레벨에서 정당화해야.
