# #69 조밀 표면 추적 + 깊이를 신뢰도 가중 제약으로 쓰는 단안 모캡

## 문제
단안 모캡(HMR, SMPL 피팅)은 주로 2D 관절 키포인트에 의존한다. 그래서 다음이 약하다.
- 팔다리 축 방향 회전(twist)
- 전역 이동과 스케일 드리프트
- 발 미끄러짐
- 키포인트가 없는 표면의 움직임

## 아이디어
1. 사람 마스크 안에서 조밀한 질의점을 뽑고 TAPNext++로 추적한다. 출력은 위치 `u_i(t)`와 가시성 `v_i(t)`다.
2. 각 질의점을 첫 프레임 SMPL 표면의 정점(무게중심 좌표)에 대응시킨다. 이후 프레임에서 그 표면점의 투영이 추적점과 맞도록 하는 **조밀 재투영 제약**을 건다.
3. 비디오 깊이(스케일·시프트를 사람 영역 밖 정적 배경으로 정렬)에서 표면점 깊이 관측을 얻어 **깊이 제약**을 건다.
4. 각 제약은 점별 신뢰도 `w_i(t)`로 가중한다(#63).
   - 가시성 확률
   - 추적의 시간 일관성 잔차
   - 깊이 불확실성
   - 옷처럼 몸에 고정되지 않은 점은 잔차가 크므로 자동으로 가중이 낮아져야 한다.

목적함수(피팅 또는 학습 미세조정):
```
L = L_kp2d + Σ_i,t w_i(t) · ρ(π(S(θ_t,β,T_t)[b_i]) − u_i(t))      # 조밀 재투영
      + λ_d Σ_i,t w_i(t) · ρ(depth(S[b_i]) − d̂_i(t))                # 깊이
      + L_prior(θ) + L_smooth + L_contact
```
ρ는 강인 손실(Geman-McClure 등)이고, b_i는 표면 무게중심 좌표다.

## 가장 가까운 연구 (정독 필요)
- **AnthroTAP (2507.06233):** 방향이 반대다. SMPL을 투영해서 추적 학습 데이터를 만든다.
- **깊이 기반 시간 일관성 HMR (2602.04257):** 깊이로 스케일 드리프트와 깊이 모호성을 잡는다. 깊이 쪽 기여가 겹칠 수 있다.
- **WHAM, TRAM, GVHMR 류:** 전역 궤적 추정의 기준선이다.
- 조밀 대응 계열(DensePose / CSE 기반 피팅)과 겹침도 확인해야 한다.
- **새로움 주장 범위(잠정):** 범용 점 추적의 가시성 확률을 신뢰도로 쓰는 조밀 제약, 그리고 옷처럼 몸에 고정되지 않은 점의 자동 배제다. 위 연구 정독 후 다시 판정한다.

## 가설 (사전등록)
- **H69-1:** 조밀 재투영 제약을 추가하면 키포인트만 쓸 때보다 PA-MPJPE와 PVE가 낮아진다. 개선은 특히 회전이 큰 동작에서 나타난다.
- **H69-2:** 깊이 제약을 추가하면 W-MPJPE(전역)와 발 미끄러짐이 감소한다.
- **H69-3:** 신뢰도 가중 없이 같은 제약을 넣으면 헐렁한 옷 장면에서 성능이 악화된다. 이게 신뢰도 가중이 필요하다는 근거가 된다.
- **H69-4:** 추적 오차를 인위적으로 키울수록 가중 있는 버전이 가중 없는 버전보다 완만하게 나빠진다.

## 설계
- **toy (먼저 실행)**
  - 합성 SMPL 시퀀스를 렌더링하고 표면점에 정답 궤적을 둔다.
  - 추적·깊이 관측에 제어된 잡음, 이탈, 가림을 넣는다.
  - 옷을 흉내내기 위해 표면에서 떨어져 미끄러지는 점을 일부 섞는다.
  - 비교 팔은 키포인트만 / +조밀(가중 없음) / +조밀(가중) / +깊이 / 전체 / 오라클 상한이다.
- **실영상:** 3DPW, EMDB(전역 궤적 정답), RICH. 디지털 스튜디오 합성 사람 장면도 쓴다.
- **양성 대조:** 정답 추적을 쓴 상한이 키포인트만 쓴 경우보다 확실히 좋아야 한다. 아니면 제약 설계를 재검토한다.
- **비교군:** 같은 최적화 예산으로 튜닝한 키포인트 피팅, 그리고 공개 HMR 모델 출력.
- **지표:** MPJPE, PA-MPJPE, PVE, W-MPJPE, 가속도 오차, 발 미끄러짐.

## 판정 관문
- **toy 관문:** H69-1과 H69-3이 시드 3, 95% 신뢰구간에서 성립해야 실영상으로 간다.
- **중단:** 실제 TAPNext++ 추적 잡음 수준에서 조밀 제약의 이득이 신뢰구간 안이면 종료하고 음성 결과로 기록한다.

## 상태
등재만 함. 실험 없음. 우선순위 1(새로움 가능성이 가장 큼).
