# #70 동적 장면 Visual SLAM: TAPNext++ 장기 추적 + 깊이 사전정보

## 가장 가까운 연구 (이미 같은 조합)
- **LEAP-VO (2401.01887):** CoTracker 기반 장기 추적을 VO 프런트엔드로 쓴다. 궤적으로 움직이는 점을 추정하고, 점별 불확실성을 둔다.
- **MegaSaM (2412.04463):** 단안 깊이 사전정보와 움직임 확률 맵을 DROID-SLAM에 통합한다.
- **ParticleSfM:** 장기 궤적으로 움직임 마스크를 만든 뒤 번들조정에서 가중치를 낮춘다.
- **새로움:** 낮다. 의미 있는 질문은 두 가지로 좁혀진다.
  - (a) 온라인 추적기(TAPNext++)로 바꾸면 **실시간 제약 아래에서** 정확도를 잃지 않는가?
  - (b) 가시성 확률을 번들조정 가중치로 직접 쓰는 게 별도 움직임 분할보다 나은가?

## 가설 (사전등록)
- **H70-1:** LEAP-VO의 추적기를 TAPNext++로 교체하면 동적 장면 ATE가 같거나 낮고, 처리 지연은 줄어든다.
- **H70-2:** 번들조정 가중치 = 가시성 × 정적 확률(궤적 기반)로 두면 MegaSaM 대비 동적 장면 ATE가 낮다. 정적 장면에서는 차이가 신뢰구간 안이다.
- **H70-3:** 깊이 사전정보는 시차가 작은 구간에서 스케일 드리프트를 줄인다.

## 설계
- **데이터:** MPI Sintel(동적), TartanAir-Shibuya, Bonn RGB-D Dynamic, TUM RGB-D dynamic 시퀀스. 정적 대조군으로 TUM 정적과 ETH3D를 쓴다.
- **기준선:** 공개 코드 기준 DROID-SLAM, LEAP-VO, MegaSaM이다.
- **팔:** 추적기 교체, 가중 방식 교체, 깊이 사전정보 유무.
- **양성 대조:** 정답 움직임 마스크(합성)를 쓴 상한이 마스크 없는 기준선보다 좋아야 한다.
- **지표:** ATE, RPE, 처리 FPS. 시퀀스별로 짝지은 비교를 하고 시드 3을 쓴다.

## 판정 관문
- **진행 조건:** #68 또는 #69에서 TAPNext++ 추적 품질이 실영상에서 확인된 뒤 착수한다(조건부).
- **통과:** 동적 장면 ATE 개선의 95% 신뢰구간 > 0이면서 FPS가 기준선 이상이다.
- **중단:** MegaSaM 대비 개선이 신뢰구간 안이면 음성 결과로 기록하고 종료한다.

## 상태
등재만 함. 실험 없음. 우선순위 3.
