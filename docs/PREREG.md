# 사전등록 — MAI RL 레시피 소규모 LLM 재현 (GPU 필요, 미실행)

작성 2026-11-24, 실행 전. 결과를 본 뒤 아래 기준을 바꾸지 않는다. 검증 규칙: lab 원장 "🔒 연구 아이디어 검증 규칙" 12항.

## 질문
MAI의 두 수정(엔트로피 적분제어 상한 + 외부 비율 클립)과 top-p 마스크 재생이, **같은 계산량에서 튜닝된 기준선**보다 소규모 추론 RL의 (a) 최종 정확도 (b) 학습 안정성을 개선하는가.

## 무대
- 정책: Qwen2.5-Math-1.5B 또는 동급 1–2B base(추론 trace 미노출). 보상: 정답 일치(0/1), 언어·길이 항은 끔(1차).
- 데이터: 학습 = MATH 훈련셋 + DeepScaleR류 공개 문제(오염 검사). 평가 = MATH-500, AIME 2024/2025(avg@16, T=1, top-p 0.97 — 원문 평가 설정과 동일).
- 비동기 근사: 롤아웃 1회당 그래디언트 4–5 스텝, staleness 상한 8 갱신 — **모든 팔 동일**.
- 예산: 팔마다 같은 롤아웃 토큰 수와 같은 학습 스텝, 같은 벽시계 상한. 시드 3 이상.

## 팔
1. **GRPO 대칭 클립**(ε=0.2) — 기준선.
2. **DAPO clip-higher 고정**(ε_low=0.2, ε_high를 검증셋에서 {0.24, 0.28, 0.35} 튜닝) — 가장 강한 근접 기준선.
3. **엔트로피 보너스**(계수 {1e-4, 1e-3, 3e-3} 튜닝) — 원문이 "못하다"고 한 대안.
4. **MAI 전체**: ε=0.6, k 적분제어(δ=0.25, k_max 2.5, H* ∈ {0.2, 0.3, 0.5} 튜닝) + 외부 클립 r_max=50.
5. 절제: 4에서 외부 클립 제거 / 4에서 k 고정 0 / 4에서 top-p 마스크 재생 제거.
- 모든 팔에 early-exit·통과율 필터 동일 적용(필터 효과와 손실 효과를 섞지 않기 위해). 필터 자체 효과는 별도 팔(필터 끔)로.
- 튜닝은 같은 검증 예산(팔당 3후보 × 짧은 런)으로, 선택 후 새 시드로 본실험.

## 양성 대조 / 식별가능성
- 시작 전: 기준선이 MATH-500에서 의미 있게 오르는지(+5%p 이상) 확인. 안 오르면 무대 부적합으로 중단.
- 엔트로피 제어가 개입하는지: 팔 4에서 상한 클립률이 0.1% 미만이고 k가 계속 0이면 "제어기 미개입 무대"로 기록하고 손실 비교 결론을 내지 않음(우리 표 toy에서 실제로 일어난 일).

## 관문 (주지표 = MATH-500 최종 정확도, 보조 = AIME avg@16, 안정성)
- 통과: 팔 4가 **튜닝된 팔 2 대비** 시드 짝 차이 95% 구간 하한 > 0 이고 평균 +1.5%p 이상.
- 안정성: 그래디언트 노름 스파이크(중앙값의 10배 초과) 횟수, 엔트로피 붕괴(H<0.05) 여부, 학습–추론 로그확률 평균 절대차 추이. 외부 클립 절제에서 스파이크가 유의하게 늘어야 "외부 클립 기여" 인정.
- 중단: 2회 연속 모든 팔이 발산하면 구현 결함으로 보고 중단·디버깅.
