- MoGe-2: A100 32장 × 120시간, 12만 스텝, LR 1e-5/1e-4(2.5만마다 반감), 24개 데이터셋 가중 샘플링.
- UniDepthV2: RTX 4090 16장 6일, 30만 스텝, 배치 128, fp16.
- Metric3D v2: A100 48장, 80만 스텝, 배치 192.

**표준 절차**: 출력 형태 결정 → DINOv2/v3 ViT-L↑ + DPT, 인코더 LR = 디코더의 0.1배 → 데이터(합성 10~20종 + 실측 + 무라벨 실사진 수천만, 초점거리 다양성) → **합성 전용 교사**(SSI L1 + 기울기 정합 + 국소 정렬 + 법선 + 하늘 마스크) → 실사진 **가짜 라벨**(상위 10% 무시 / RANSAC 스케일 정렬 / 국소 필터+푸아송 보완) → **학생**(다해상도·다종횡비, 특징 정렬) → **미터 단위**(CSTM / 화각 헤드 / 스케일 MLP / 광선 조건; 상대 모델 미세조정이 처음부터보다 나음) → **합성 전용 경계 다듬기** → 평가(제로샷 AbsRel·δ1, 경계 F1, 화각 오차; 프로토콜 고정).
**불일치**: 실데이터 순서(Depth Pro 실→합성 / DA2 학생은 가짜 라벨 실사진만 / Marigold 합성만), 목표(역깊이·깊이·포인트맵), 미터 획득 방식.

- HunyuanVideo: VAE 손실 L1 + 0.1 LPIPS + 0.05 적대 + 1e-6 KL, 추론 시프트 t′ = s·t/(1+(s−1)t). 단일 고해상도만 미세조정하면 저해상도 품질 저하 → 혼합 스케일. CFG 증류 ~1.9배.
- Movie Gen: 256px T2I 21만 스텝·배치 9216·LR 1e-4·1536 GPU → 256px T2I/V 18.5만 스텝·LR 6e-5 → 768px LR 6e-5→1e-5. SFT 모델 여러 개 **평균**.
- Seedance 1.0: 단계 T2I → 이미지+영상(3~12초, 12fps) → 640px → 24fps·I2V 20% → 연속학습 I2V 40% → 카테고리별 SFT 후 병합 → RLHF(보상 3종, x₀ 보상 직접 최대화, DPO·PPO·GRPO보다 낫다고 주장) → 증류로 1080p 5초 41.4초(L20).
- LongCat: 다중 보상 GRPO(HPSv3·움직임·정합), 고정 잡음·특정 타임스텝만 SDE·절단 스케줄·그룹 최대 표준편차 정규화.

**표준 절차**: 인프라(FSDP+문맥병렬, 잠재·텍스트 사전계산, bf16+QK정규화, 길이×종횡비 버킷) → 데이터(샷 분할 4~12초 → 저렴한 필터 → 임베딩 중복제거·군집 재균형 → 사람 라벨 점수기 → 단계별 기준 상승) → VLM 재캡셔너 + 프롬프트 재작성기 → 3D 인과 VAE(2D→3D, L1+KL+LPIPS → +GAN) → 텍스트 인코더(+드롭아웃) → rectified flow(속도, logit-normal, 해상도·길이 비례 시프트) → 커리큘럼(256px T2I → 이미지+저해상도 영상 → 해상도·길이·fps↑, 이미지 계속 혼합, LR·배치↓) → 고품질 어닐링 → SFT(부분집합별 모델 병합) → 다중 보상 RL/DPO → 증류(CFG·소수 스텝·정제기·FP8) → 평가(VBench·사람 상관 가중 벤치·Arena Elo; FVD/FID 단독 금지).

- **데이터**: 수십억 쌍(QI·Seedream). Seedream 3.0은 결함 영역을 손실에서 마스킹해 쓸 데이터 +21.7%. 분류체계 균형: WordNet(QI) · 위키 지식그래프+BM25(Z-Image) · TF-IDF+군집(Seedream 3.0).

- **사전학습**: rectified flow, logit-normal + 해상도 시프트(Seedream 3.0·Z-Image). 해상도 256→640→1328 ✔(QI) / 256·512→512·1024·2048(QI2) / 512→1K~4K(Seedream 4.0). **저해상도에 연산 절반**: Z-Image 256² 단계 147.5K / 전체 사전학습 290K H800 GPU시간 ✔. 편집 데이터를 일찍 혼합(QI2 T2I:편집 0.9:0.1 → 0.7:0.3). REPA(DINOv2-L, λ=0.5 ✔, Seedream 3.0). 유일한 공개 하이퍼파라미터(QI2 ✔): Adam, wd 0.001, clip 1.0, 무조건 드롭 0.1, 사전학습 700K 스텝·LR 1e-4·배치 32K/16K → 연속학습 250K·2e-5 → SFT 10K·1e-5. 인프라: Megatron TP4(QI, activation checkpointing 끔: 메모리 −11% 대신 3.75배 느림) / HSDP(Seedream) / FSDP2(Z-Image).

- **선호·RL**: DPO 먼저(QI 사람 선택 / Z-Image는 텍스트·개수 같은 객관 차원만) → Flow-GRPO 다중 보상. QI2-RL 교훈 ✔: **전 40 타임스텝에서 학습하면 몇 반복 만에 보상 해킹** → 고잡음 타임스텝만 학습 / **CFG는 롤아웃에만**(양쪽 다 쓰면 붕괴, 아예 안 쓰면 스타일·지식 손실) / 보상별·그룹별 정규화 / 점수형(pointwise) VLM 보상모델이 쌍비교보다 나음(정성) / 그룹 내 보상 범위가 작은 프롬프트 제거 / 범주별 보상 가중 / 과제별 RL 정책을 온폴리시 증류(OPD)로 통합.

## 5. 세 분야 공통 패턴
1. 데이터 큐레이션이 성능을 가장 크게 좌우(필터·중복제거·점수기·재캡션/재작성·오염 제거).
2. 쉬운 설정에서 시작해 단계적으로 확장(합성→실 / 저해상도·짧은 길이→고해상도·긴 길이 / 4K→128K 문맥).
3. 마지막에 소량 고품질로 다듬기(경계 다듬기 · SFT·병합 · 어닐링).
4. 큰 모델이 작은 모델을 가르침(교사→학생 가짜 라벨 · 증류).
5. 대규모 RL은 학습–추론 수치 일치가 안정성의 핵심(라우팅·마스크 재사용, 오프폴리시 마스킹, 비트 일치 — #64 Rocket과 같은 흐름).
