§3

새 방향(v2, codex 검수 반영): 위상 간섭의 가치는 "채점식"이 아니라 "제한된 기억 안에서 모든 경로를 한 번에 더하는 것"이다

한 문장: 기억 하나에 사실들을 겹쳐 두고, 관계를 한 번 걸 때마다 "갈 수 있는 모든 곳"이 겹친 채로 나옵니다. 두세 번 걸면 모든 경로가 저절로 더해지고, 맞는 답은 쌓이며 잡음은 서로 지워집니다.
R1

v1 채점식 \(|\sum_p z_p|\)는 철회한다. 경로들이 서로 맞는지만 읽고, 어느 답을 지지하는지는 읽지 못한다

유도
codex 검수(review/SM28_독립검수_20261122.txt:15) · 직접 검산

목표 방향이 +1일 때 경로 화살표 [+1,+1,+1], [−1,−1,−1], [i,i,i]는 모두 \(|\sum z|=3\)입니다. 참·반대·무관을 구별하지 못합니다. 목표 방향으로 투영하면 각각 3, −3, 0으로 구별됩니다. 그런데 투영하면 선형성 때문에 아래 등식이 성립합니다.

\[ \mathrm{Re}\Big\langle \sum_p \hat t_p,\; t\Big\rangle=\sum_p \mathrm{Re}\langle \hat t_p,\,t\rangle \]

즉 경로를 하나씩 나열해 채점하는 한, "위상 간섭" = "부호 있는 경로 합"이고 둘은 같은 점수입니다. 경로를 원본 그래프에서 읽는 실험에서는 간섭에 고유한 이점이 없습니다.

또 하나: 성분별 복소곱은 순서를 바꿔도 같습니다("부모의 배우자" = "배우자의 부모"). 그래서 관계를 순서가 남는 연산으로 바꿉니다. \(R_r(x)=\Pi(x)\odot\theta_r\)에서 \(\Pi\)는 고정 순환이동입니다. 이렇게 하면 \(R_aR_b\neq R_bR_a\)가 됩니다(DihEdral 등의 비가환 합성과 같은 목적).

M2

남는 주장: 중첩 기억에 관계를 연달아 걸면 경로를 나열하지 않고도 모든 경로가 더해진다

유도

관계 \(r\)의 사실들을 한 벡터에 겹쳐 둡니다: \(M_r=\sum_{(h,r,t)}\overline{h}\odot \Pi^{-1}(t\odot\overline{\theta_r})\). 질의 개체 \(q\)에 이 기억을 걸면 \(q\)의 \(r\)-이웃 전체가 겹친 벡터가 나오고, 누화는 무작위 위상이라 작게 남습니다. 여기에 관계를 두세 번 연달아 걸면 다단 경로가 모두 겹친 채로 한 번에 계산됩니다. 경로 수가 늘어도 계산량은 같습니다. 답 쪽 신호는 경로 수만큼 쌓이고, 누화는 \(\sqrt{\cdot}\)으로만 자랍니다(보강 vs 상쇄).

이것이 교수님 발상의 구체형입니다. 긴 기억(감쇠 α, 오래된 사실까지 중첩 유지) + 위상 보강간섭(경로들이 같은 답에서 쌓임) → 저장된 적 없는 답.
