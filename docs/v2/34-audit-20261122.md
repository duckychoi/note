# #34 점검 (2026-11-22, codex gpt-6.2-sol r1–r3 검수 반영판)

## 결론
개념노트의 박스 리워드 $r(x)=-\mathbb E_{t\sim U[0,1]}\|v^*(x_t,t)-(x-x_0)\|^2$ 는 **max-ent RL과 합쳐도 데이터분포로 가지 않는 경우가 있다** — E1 의 다봉 GMM 과 E2 의 링 MDP 에서 정확 계산으로 확인(예외는 1차원 또는 등방 단일 가우시안뿐: 온도 하나로 복원. **비등방 단일 가우시안은 봉우리가 하나여도 순위가 뒤집힌다** — P3′). 원인은 (1) 시간 가중이 균등이라는 것, (2) RL의 엔트로피가 행동 엔트로피라 상태방문 엔트로피가 빠진다는 것. 두 설정에서 재현했고, 둘 다 고칠 수 있다.
선행: 고정 diffusion prior 리워드로 AMP 대체 = **SMP**(TOG, arXiv 2512.03028, 균등 가중), 전문가−학습자 손실 차 = **SMILING**(ICLR 2025, 2410.13855). 기여 후보: **(가) 고정 prior 리워드의 고정점 편향 진단과 값싼 보정, (나) 위상조건 prior 로 타이밍 강제.**

## 2. 바로잡은 결과 (선형 보간 $x_t=(1-t)x_0+tx_1$, $x_0\sim N(0,I)$ 독립)
**보조정리 1.** $0<t<1$, 임의 끝점분포에서 $m=\mathbb E[x_1|x_t=x]$ 일 때 $u=(m-x)/(1-t)$, $s=-(x-tm)/(1-t)^2$ ⇒ $\Delta s=\tfrac{t}{1-t}\Delta u$.

**정리 1 (KL 등식).** $p,q$ 가 유한 2차 모멘트를 가지면
$$\mathrm{KL}(q\|p)=\int_0^1\frac{t}{1-t}\,\mathbb E_{x\sim q_t}\|u_q(x,t)-u_p(x,t)\|^2dt\quad(\text{계수 1, 등식; KL}=\infty\text{ 포함}).$$
증명: $y=x_t/t$ 는 $x_1+\sqrt\tau Z$, $\tau=((1-t)/t)^2$. 상대 de Bruijn $\tfrac{d}{d\tau}\mathrm{KL}(q_\tau\|p_\tau)=-\tfrac12\mathbb E\|\nabla\log q_\tau-\nabla\log p_\tau\|^2$, $y$-좌표 score 차 $=t^2\Delta u/(1-t)$, $|d\tau/dt|=2(1-t)/t^3$ ⇒ 피적분 $t/(1-t)\|\Delta u\|^2$. 양끝: $t\downarrow0$ 에서 $\mathrm{KL}(q_\tau\|p_\tau)\le W_2^2(q,p)/(2\tau)\to0$, $t\uparrow1$ 에서 데이터처리+하반연속성으로 원 KL 에 수렴. (Song 2021 likelihood weighting · Kingma&Gao 2023 의 FM 좌표판 — 독립 기여 아님, 도구.)

**명제 2 (샘플별 리워드, 정확식).** 절단 $\delta$, $\tau_\delta=(\delta/(1-\delta))^2$, $p_\tau=p*N(0,\tau I)$:
$$\ell_w(x)=\int_0^{1-\delta}\tfrac{t}{1-t}\mathbb E_{x_0}\|u_p(x_t,t)-(x-x_0)\|^2dt=\mathrm{KL}\big(N(x,\tau_\delta I)\,\|\,p_{\tau_\delta}\big)=-\tfrac d2\log(2\pi e\tau_\delta)-\mathbb E_Z\log p_{\tau_\delta}(x+\sqrt{\tau_\delta}Z).$$
$K_\delta=-\tfrac d2\log(2\pi e\tau_\delta)$ 를 뺀 $g_\tau(x)=\exp[-(\ell_w(x)-K_\delta)]=\exp\mathbb E_Z\log p_\tau(x+\sqrt\tau Z)$ 는 **정규화돼 있지 않다**(Jensen 으로 $g_\tau\le p_{2\tau}$, $\int g_\tau\le1$; 표준정규·$\tau=1$ 이면 $e^{-1/4}\approx0.779$). 표본분포 $q$ 를 $\mathbb E_q\ell_w<\infty$, $|h(q)|<\infty$ 인 밀도 중에서 자유롭게 골라 $\mathbb E_q[-\ell_w]+h(q)=\text{상수}-\mathrm{KL}(q\|q^*_\tau)$ ($h$ = **표본분포의 미분 엔트로피**) 를 최대화하면 해는 $q^*_\tau=g_\tau/\int g_\tau$ (두 항이 무한인 $q$ 는 목적식을 $\text{상수}-\mathrm{KL}(q\|q^*_\tau)$ 로 정의해 포함). 점별로 $g_\tau\to p$ (**$p$ 가 양의 연속 밀도일 때**; 점질량이 있으면 깨진다 — 원점 50% + 표준정규 50% 이면 극한의 원점 질량이 37.75%), Fatou 로 $\int g_\tau\to1$ ⇒ $q^*_\tau\to p$ ($\delta\downarrow0$). **RL 은 표본분포를 자유롭게 고르지 못하고 행동 엔트로피를 쓰므로, 이 결론이 정책 점유분포로 넘어가려면 명제 4 의 조건이 필요하다** (E2: 정확한 $\log p$ 를 줘도 일대일 링 A 의 KL 0.485). 오차 전개 $\ell_w-K_\delta+\log p=-\tau(\Delta\log p+\tfrac12\|\nabla\log p\|^2)+O_x(\tau^2)$ 는 매끄러운 양의 밀도(E1 GMM)에서 **고정 $x$ 마다** 성립. ($\exp(-\ell_w)$ 자체는 $(2\pi e\tau)^{d/2}$ 배라 정규화 필요.)

**명제 3 (균등 가중의 실패, E1 GMM 한정).** 균등 잔차 Gibbs 밀도 $\propto\exp(-\ell_u/\alpha)$ 는 **모든 $\alpha>0$ 에서 중심점 밀도 순서를 뒤집음**: $\log p(2.5)-\log p(0)=+0.780$ 인데 $\ell_u(2.5)-\ell_u(0)=+1.558$(필요 온도 −2.00). **수치 관찰이며 오차 상계는 없다**: 절단 $\delta$ 1e-6→1e-8, 시간노드 240→480, Gauss–Hermite 120→200 으로 바꿔도 차이 1.557773418 이 9자리까지 같다(`prop3_sign_robustness`). 다른 쌍의 필요 온도는 3.82, 0.74 로 하나의 $\alpha$ 로 맞출 수 없음. **모드 창 질량의 역전은 실측값($\alpha$=1, 1.624)에 한정**: 아래 E1. 예외: $p=N(\mu,s^2)$ 이면 $\ell_u=\pi(x-\mu)^2/(4s)+C$ 라 $\alpha=\pi s/2$ 에서 정확 복원 — 실패는 이 다봉 설정에서 확인한 것.

**명제 4 (점유분포, 이산 결정론 MDP; 전문가 점유분포가 실현 가능하고 리워드가 정확한 $\log p$ 라고 가정).** 유한 절단 P2 리워드($\tau>0$)를 쓰면 정확한 상태보정으로도 편향이 남는다(codex r7: 두 상태 좌표 0·1, $\tau=1$ 에서 방문 확률 0.800→0.564; $\tau\to0$ 에서 사라짐). 창 $=(s,s')$, 정확 리워드 $\log p(s,s')$, 행동엔트로피 $\alpha$=1:
$J=-\mathrm{KL}(d\|p)-H(S)+H(A|S,S')$. 상태보정 $-\log d_\pi(s)$ 가 $H(S)$ 를 지움. (단일 스텝에서도 같다: 행동 셋 중 둘이 도착점 0, 하나가 1 로 가고 전문가가 (1/2,1/2) 이면 균등 정책은 (2/3,1/3) 을 만든다.) **$H(A|S,S')$ 가 점유분포와 무관한 상수이면**(충분조건 예: 상태별 행동→다음상태 일대일이면 0. 모든 전이에 같은 수 $m$ 의 복제 행동이 있으면, 각 점유분포에서 복제 행동 배분을 먼저 최적화(균등 배분)한 뒤에 $\log m$ 이 공통 상수가 된다 — 90:10 배분이면 0.325 nats, 50:50 이면 0.693) $J=-\mathrm{KL}+$상수. 일반 이산 결정론 MDP 는 행동엔트로피 대신 $H(S'|S)$(같은 도착점 확률 합산). **확률적 전이에서는** $-H(S'|S,A)$ 항이 더 남아 $H(A|S,S')=0$ 이어도 복원이 깨질 수 있다(codex r6 반례: 3상태, 목적값 −0.347 → 학습자 −0.317). 또한 이것은 실패 **가능성**이다: $H(S)$ 항이 최적점을 옮기지 않으면 보정 없이도 복원된다(예: 두 상태, 두 행동이 각각 0·1 로 보내고 전문가가 반반 — 반반이 아니라 0.8 이면 무보정 최적은 0.941 로 옮겨 감). E2 링은 옮기는 사례.
**연속 제어(미검증, 한계):** 행동·상태 동차원의 매끄러운 가역 $a\mapsto f(s,a)$ 이면 상태보정 목적은 $-\mathrm{KL}-\mathbb E\log|\det D_af|$ — 리워드에 $+\log|\det D_af|$ 가 필요. 행동 차원이 더 작으면(MuJoCo) 다음상태 분포는 $f(s,\cdot)$ 의 상 위에 놓인다. 상이 매끄러운 다양체인지는 차원 차이만으로 정해지지 않는다(자기교차 가능). 매장(단사 몰입 + 상으로의 위상동형)은 **충분조건**이지 필요조건이 아니다($f(a)=(a^3,0)$ 은 상이 직선이지만 $a=0$ 에서 몰입이 아님). 이 경우 면적 야코비안 $\sqrt{\det(D_af^\top D_af)}$ 와 다양체 위 기준측도를 따로 정해야 한다. **전문가 밀도만 평활하면** $a\mapsto(a,0)$ 에서 학습자 분포는 직선 위에 남아 평면 밀도에 대한 KL 이 무한이다. 양쪽을 평활하면(폭이 달라도) 둘 다 르베그 밀도를 갖는다. 같은 폭이면 평활 KL 의 최소점이 $q=p$ 로 보존된다(충분조건; 폭이 달라도 보존되는 경우가 있다 — 예: 위치족 $N(\mu,1)$).

**평활은 목적식 자체를 바꾼다 (codex r4·r5, 손계산 검산).** 전문가 행동 $N(0,1)$, 학습자 $N(0,v)$, $f(s,a)=a$ (또는 $(a,0)$), 평활 폭 $\tau$. 리워드는 $+\mathbb E_Z\log p_\tau(a+\sqrt\tau Z)$ (= $-\ell_w$ + 상수):

| 목적식 | 최적 분산 ($\tau=1$) |
|---|---|
| 양쪽을 평활한 KL | $1$ |
| 리워드 + 행동 엔트로피: $-\frac{v+\tau}{2(1+\tau)}+\frac12\log v$ | $1+\tau$ (=2) |
| 정상분포 창 리워드 + 평활 상태밀도 보정 + 행동 엔트로피: $-\frac{v+\tau}{1+\tau}+\frac12\log(v+\tau)+\frac12\log v$ | $v^2-v-1=0$ → $1.618$ |

편차는 $\tau$ 의 차수지만 **좌표 눈금에 좌우된다**: $f(s,a)=10^{-3}a$ 이면 같은 $\tau=10^{-6}$ 에서도 최적 분산이 1→2. MuJoCo 실험은 특징을 전문가 평균·표준편차로 표준화해(`src/v2/il/common.py` `load_expert`) 눈금이 1 근처이므로 $\tau\approx10^{-6}$ 의 영향은 작을 것으로 보지만, **재지 않았고 보장도 없다**. 실험은 야코비안 항과 평활 편향을 모두 무시한 실증적 근사다.

## P3′ (11-22 추가, GPT 독립분석 제안 · 우리 코드로 재검산) 봉우리 하나인 타원 가우시안에서도 균등 가중은 순위를 뒤집는다

가정: 시작점 $N(0,I)$, 선형 보간, $t\sim U(0,1)$, 정확한 속도장, 전문가 $N(\mu,\Sigma)$. 고유축 좌표 $z_i$, 축 표준편차 $s_i$ 이면 축마다 1차원 문제로 분리되어

$$\ell_u(x)=C+\frac{\pi}{4}\sum_i\frac{z_i^2}{s_i},\qquad \ell_w(x)=C'+\sum_i\frac{z_i^2}{2s_i^2}\;(=-\log p+\text{const}).$$

(축 계수 $\int_0^1\frac{(1-t)^2}{[(1-t)^2+t^2s^2]^2}dt=\int_0^\infty(1+s^2u^2)^{-2}du=\pi/(4s)$, 우도 가중은 $u$ 를 곱해 $1/(2s^2)$.)
균등 잔차가 유도하는 분포 $q_\alpha\propto e^{-\ell_u/\alpha}$ 의 공분산은 $\tfrac{2\alpha}{\pi}\Sigma^{1/2}$ — 분산비가 $\kappa$ 에서 $\sqrt\kappa$ 로 줄고, 어떤 온도도 이를 고치지 못한다.
예: $s=(1,4)$, $A=(1,0)$, $B=(0,3)$. 참 $-\log p$: A 0.5, B 0.281 (B가 더 흔함). 균등 잔차: A 0.785, B 1.767 (A를 더 전문가답다고 채점). 모든 $\alpha>0$ 에서 역전.
검산: `gmm_flow.GMM` 1성분 1차원 + Gauss–Hermite 60점 + quad 로 A/B 차분 = 균등 0.7854/1.7671, 우도 0.5/0.2812 (11-22 실행).
