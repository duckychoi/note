연구주제 원장 #35 · Particle Filter × Flow Matching · 점검·전환 노트

PF(SMC)는 생성 샘플러로는 한계, 가치(Q)로 기울인 FM 정책 샘플러로는 유망하다

원래 주장("확산·flow ODE를 PF로 대체해 few-step에서 Euler보다 13배")은 NFE를 정직하게 세면 성립하지 않습니다. 정답 에너지를 줘도 가중치가 차원에 비례해 흔들려 무너집니다. 반면 FM 정책을 Q로 기울이는 문제 \(\pi^*\propto\pi_{FM}e^{Q/\beta}\)에서는 가중치에 쓸 진짜 신호(Q)가 있습니다. toy에서 SMC가 같은 예산의 best-of-N보다 약 4.5배 정확했고, 근사 Q 기울기 유도의 편향도 고쳤습니다.

기술별: 무엇을 풀려 했고, 점검 후 어떻게 됐나

기술 1예측–보정–리샘플(SMC) = 샘플러 교체풀려던 문제: 적은 스텝의 ODE 적분(Euler)은 휘어진 길을 놓쳐 분포가 틀어진다
작업 전입자를 굵은 스텝으로 움직이고(예측), 정답 분포에 맞는 정도로 가중해(보정), 맞는 입자를 복제합니다(리샘플). 스텝이 굵어도 오차가 교정된다고 봤습니다.
작업 후교정은 되지만, 같은 계산량이면 더 좋은 적분기(Heun)가 더 싸게 같은 일을 합니다. 가중의 흔들림이 차원에 비례해 커져서 고차원에서는 무너집니다(§3).
구현: 원본 src/toy_pf_vs_euler.py, 재현 note/src/v2/pf/e35_audit.py:51. · 철학: "길을 정확히 계산하는 대신, 여러 명을 보내고 잘 간 사람을 따라간다."
기술 2가중치의 근거풀려던 문제: 어느 입자가 "맞는 곳"에 있는지 판정할 기준이 필요하다
작업 전toy GMM의 정답 밀도 \(p_t\)를 그대로 썼습니다. 시험 보면서 정답지를 본 셈입니다.
작업 후근거를 바꿨습니다. 정책 문제에서는 가치 \(Q\)가 "얼마나 좋은 행동인가"라는 진짜 신호입니다. 목표는 \(\pi_{FM}e^{Q/\beta}\)이고, 가중에는 \(p_t\)가 필요 없고 \(Q\)(와 중간 가치 \(Q_t\))만 있으면 됩니다(§5).
구현: note/src/v2/pf/e35p_twist.py · 철학: "정답지를 훔쳐보지 말고, 실제로 받을 점수로 고른다."
기술 3중간 가치 twist \(Q_t\)풀려던 문제: 결승선에서만 고르면(best-of-N) 드문 좋은 행동을 찾으려고 입자가 많이 든다
작업 전없었습니다. 원 연구는 rejuvenation(score 방향으로 흔들기)으로 다양성만 되살렸습니다.
작업 후flow 시간 \(t\)마다 "이 중간 행동이 결국 얼마나 좋을지"를 \(Q_t\)로 매기고, 그 차이로 중간 가중을 줍니다. 구간마다 중간 기록으로 유망한 선수를 남기는 방식입니다. \(Q_t\)가 정확할수록 적은 예산으로 정답에 갑니다(§5 E4).
구현: 정확 \(Q_t\)는 닫힌형(e35p_twist.py:45 Qt_exact), 근사는 Tweedie 추정 \(Q(\hat a_1(a_t))\). 학습 \(Q_t\)는 아직 안 했습니다 미확인.

판정

생성 샘플러 버전은 종료하고, 가치로 기울인 FM 정책 샘플러(후보 A)로 전환을 제안합니다

  • 생성 버전은 한계입니다. 같은 NFE에서 Heun을 이기지 못하고(§2), 정확한 에너지를 줘도 \(\mathrm{Var}\log w\)가 차원에 비례해 커집니다. 입자를 늘리거나 2차 커널, 노이즈 조정을 써도 역전되지 않았습니다(§3). 코드
  • 정책 버전(후보 A)은 유망합니다. 같은 예산 512, d=8에서 SMC(근사 중간 가치)의 오차는 0.026입니다. best-of-N은 0.118, 근사 Q 기울기 유도(QPILOTS류)는 0.123에서 멈췄습니다. 정확한 \(Q_t\)를 쓰면 예산 32에서 이미 0.03입니다(§5). 코드
  • 후보 B(Q 과대평가 증폭)는 현상을 확인했지만 새롭지 않아서 A의 부록으로 둡니다. 후보 C(PF belief + FM 정책)는 범위가 커서 보류합니다.
  • 아직 증명되지 않은 것: 학습한 \(Q_t\)로 같은 우위가 나오는지, 실제 offline RL 벤치마크에서 나오는지. 미확인

E2·E3 생성 버전의 이론적 한계: 정확한 에너지를 줘도 차원이 이긴다

이론

가중의 흔들림은 차원에 비례하고, 필요한 입자 수는 그 지수로 늘어난다

유도
e35_theory.py 머리말
\[ w=\frac{p_{t'}(x')\,L(x\mid x')}{p_t(x)\,q(x'\mid x)},\qquad \mathrm{Var}\log w_{\text{step}}\sim \frac{d\,e^2}{g^2h},\qquad K_{\text{필요}}\sim e^{\mathrm{Var}\log w} \]

\(e\)는 커널 평균의 한 스텝 오차, \(g\)는 노이즈 크기입니다. 정규화 상수는 약분되므로 에너지만 있으면 가중은 정확합니다. 그래도 \(d\)가 크면 입자가 지수적으로 필요합니다(중요도 샘플링의 차원의 저주).
