로봇 SLAM / 3DGS / 카메라 누적 인사이트

목표: SLAM 기술 이해 + 3DGS 렌더링 + 카메라 파이프라인

최근 흐름 (2026-09-14 배치) — 시각을 더 쓰는 게 아니라 통로를 좁힌다

🎯 신규 1건 — LIT (raw ai-news → slam-3dgs 재판정)

재판정 근거: 이득이 미학습 카메라 구성·조명 변화·방해물에서 나오고 감독 신호가 SE(3) 말단 자세다. 09-13에 FreeFlow·RCWM·World-in-World 에 적용한 기준과 동일.

진단: 로봇 파운데이션 모델은 학습 분포 안에서 행동과 우연히 상관된 과제 무관 시각 단서를 이용하고, 그 상관이 깨지면 무너진다(“vision-action shortcuts”). 해법의 방향이 특이하다 — 시각을 더 잘 쓰게 만드는 게 아니라 시각이 지나갈 통로를 하나로 좁힌다.

  • 1단계: 이미지 없이 언어·로봇 상태·시연 청크의 종료 SE(3) 자세로 행동 사전분포 학습 → 지름길이 생길 수 없는 조건
  • 2단계: 그 자세를 복원하도록 감독된 잠재 인터페이스가 유일한 시각 조건 경로

🎯 1단계의 조건이 2단계의 감독 타깃이 된다. 통로를 좁히는 것과 통로에 무엇을 흘릴지 정하는 것이 같은 장치로 해결된다. 프레임워크 무관 — Pi0.5·MolmoAct2·FAST-WAM·ImageWAM 4종 전건 개선.

🎯 이 도메인에 "인터페이스만 설계한다" 계보가 쌓이고 있다

  • World-in-World(09-13) — 동결 비디오 모델에 어댑터 없이 “카메라·시간 라벨 붙은 시각 상태” 로 입력 형식만 번역
  • LIT(09-14) — 백본을 바꾸지 않고 시각 조건 경로 하나만 끼운다 둘 다 모델을 재학습하지 않고 모델이 보는 것의 형태를 바꾼다. RCWM 의 “코드 표현은 있었고 없던 것은 짓는 절차” 와 같은 태도다.

🔴 성립 조건 — 이득은 분포 외에서만 난다

실로봇 +13.30~16.70%p 의 조건은 “unseen camera configurations, lighting variations, and distractors” 이고, 통상 LIBERO는 “preserving or improving” 수준이다. “LIT가 로봇을 더 잘하게 만든다”로 읽으면 틀린다. 지름길을 끊었으니 분포 내는 유지되고 분포 외가 살아나는 게 예측되는 결과다 → 분포내-우위 의 거울상. 🔴 절대 성공률 없음(%p 증분만) · 실로봇 3과제 이름·개별 수치 없음 · LIBERO-Plus 3.87~10.70%p(2.8배 범위) 의 아키텍처별 배분 없음.

최근 흐름 (2026-09-13 배치) — 3건 이관 입고

raw가 ai-news 로 분류한 3건을 주제 기준으로 이 도메인에 이관했다(FreeFlow·RCWM·World-in-World). 09-11/09-12에 적용한 “주제가 도메인을 정한다” 기준의 일관 적용이다.

🎯 세 논문이 같은 방향을 본다 — 전용 부품을 빼고 범용 구조에 맡긴다

  • FreeFlow: 옵티컬 플로우에서 상관볼륨·워핑·반복정제를 전부 제거, 어텐션 3종만 남김. 얻은 것은 스케일링(키우면 오른다)
  • World-in-World: 태스크별 모듈·추가 학습 없이 동결 비디오 모델에 입력 형식만 번역해 넣음
  • RCWM: 표현(코드)은 이미 있었고 없던 것은 짓는 절차 — 솔버 재귀로 해결

공통: 특수 부품 대신 범용 구조 + 좋은 입력/절차. 볼트가 08-31에 세운 국소-수리-원리 의 연장선이고, 특히 RCWM은 그 원리에 빠져 있던 조각(국소 수리 뒤 전역 정합의 책임 주체 = 부모 호출)을 채운다.

🔴 셋 다 실시간 판단이 불가능하다

  • FreeFlow: FPS·지연 수치 없음(“memory efficient at 1080p” 는 메모리 얘기다)
  • RCWM: VLM 에이전트 재귀 렌더-비교 → 호출 수가 장면 복잡도에 비례. 오프라인 복원 경로
  • World-in-World: 디노이징 + 캐시 밖 검색 + 기하 렌더링 전처리 → 이 배치에서 30fps 후보는 없다.

파이프라인 관점의 실익 — 하류 소비처가 생긴다

World-in-World 는 목표시점 투영과 기하 렌더링을 “증거”로 받는다. 기존 SLAM/3DGS 산출물을 비디오 모델 입력으로 재사용하는 경로다. RCWM 은 출력이 실행 가능한 코드(RSP)다. 3DGS 산출물은 고치기 어렵지만 코드는 국소 수정과 diff가 된다 → 검사가능성-공사 노선과 정합.

월드모델 × 엣지 로보틱스 (2026-07-12 synthesis)

slam-3dgs ↔ world-model 접점

JEPA효율화-로컬추론에서 도출 — SLAM/3DGS = “지금 어디에 무엇이 있나”(명시적 기하·현재), 월드모델 = “다음에 무엇이 일어날까”(암묵적 예측·미래). 엣지 로봇(Jetson)엔 둘 다 필요하며 같은 하드웨어 예산 안에서 경쟁·협력.

  • 가능한 합성: 3DGS를 월드모델의 렌더러/타깃으로, 또는 JEPA 월드모델을 SLAM의 예측 사전(prior)으로.
  • 연결: 임바디드-AI · Embodied-cpp(온디바이스 런타임) · RoboDojo(sim-and-real 평가) · JEPA · Mamba4(선형 롤아웃)

[2026-09-04] 배치 — 통합 월드모델과 의미 분할이 만나는 지점

🌍 Puffin-World — 물리·기하·외형을 한 모델의 네이티브 상태로 (업보트 31, ACE Robotics)

볼트에 월드모델 소스가 28건 쌓였지만 대부분 “미래 프레임을 그럴듯하게 그린다” 쪽이다. Puffin-World의 차이는 무엇을 상태로 두는가에 있다 — 물리(중력장·위도) · 기하(깊이) · 외형(이미지) 을 네이티브 월드 상태 3종으로 함께 모델링하고 외부 오프라인 모듈에 의존하지 않는다.

  • Omni-Camera 표현으로 카메라를 통일, 절대 카메라 속성을 실세계에 접지(grounding) → 물리적 일관·시각적 안정 주장
  • 외형과 기하를 단일 생성 과정에 결합 — 미래 뷰를 합성하면서 그 뷰의 기하를 동시에 복원 → 닫힌 루프(mimic·자기 보정 월드 탐색)
  • Puffin-16M: 1,500만 vision-language-camera 트리플렛 + 100만 궤적
  • “외부 모듈 없이”가 실질 주장이다 — 기존 파이프라인은 깊이 추정기·포즈 추정기·물리 엔진을 따로 붙이고, 모듈 경계는 곧 드리프트 발생 지점이다(LIO-SAM 계열 고전 문제)
  • 🚨 정량 수치 0건: 벤치마크·비교군·SOTA 주장 전부 없음. “physically consistent and visually stable” 은 주장이다. 코드·모델·데이터셋을 “released” 라 했으나 HF 페이지에 링크 없음. PAWBench 교훈(월드모델 11개 시스템 전멸)을 감안해 특히 보수적으로 읽을 것
  • → 우선순위는 데이터 > 모델: Puffin-16M의 실재·라이선스만 먼저 확인한다. 사실이면 이 축 최대 획득물

🔗 sam3와의 교차 — 의미가 붙은 3D 재구성

Puffin-World가 깊이·기하를 생성하고 sam3가 개방 어휘 의미 분할(텍스트로 모든 인스턴스, 비디오 추적)을 붙이면 의미가 붙은 3D 재구성으로 간다. X2SAM·4D-Human-Scene-Reconstruction 축과 직결되며, SAM 3는 🤗 Transformers 정식 통합이라 실험 진입 비용이 낮다.

축 관측

Puffin-World가 중력·위도·깊이를 암묵적 학습에 맡기지 않고 상태 변수로 승격시킨 것은, 이번 배치 5건에서 반복된 암묵을-명시로 패턴의 3D판이다. 방향은 JEPA-vs-Diffusion-월드모델의 “무엇을 예측 대상으로 삼는가” 논점의 확장.

📦 2026-09-07 배치 — WorldSculpt (재분류: ai-news → slam-3dgs)

통짜 재구성에서 분해 가능성(decomposability) 으로

목표 표현이 “공유 월드 프레임에 배치된 개별 오브젝트 메시들의 집합” 이고, 초록이 이유를 명시한다 — 게임·AR/VR·시뮬레이션·로보틱스가 그걸 요구하기 때문이다.

기존 두 갈래의 실패를 논문이 직접 짚는다:

  • 기하 기반: 장면을 하나의 표현으로 재구성 → 가려진 영역의 기하가 미완성
  • 기존 조합적 방법: 비교적 단순한 장면에 한정

→ 볼트의 3DGS 축(GlobalSplat·anyrecon·Beyond-Pixels-4D)이 대체로 통짜 표현이었다면 이건 분해 축이다. 로보틱스에 쓰려면 물체 단위로 잡히지 않으면 쓸모가 없다는 요구가 표현 방식을 결정한다.

학습 분포와 추론 복잡도가 분리됐다

초록 원문: “the model is finetuned entirely on single objects in canonical space, it generalizes to large scenes with severe occlusion without any scene-level training.” 밀집 장면을 생성하기 위해 밀집 장면을 학습할 필요가 없었다. 단일 오브젝트 prior(Pixal3D)에 multi-view conditioning 경로만 달면 된다. 그리고 주장의 형태가 좋다 — “격차가 장면 복잡도와 가림이 커질수록 벌어진다”. 평균 우위가 아니라 겨냥한 실패 모드를 실제로 푼다는 증거 형태.

🔗 월드모델 축과 slam-3dgs 축이 여기서 연결된다

초록 마지막: “생성된 3DGS 월드(Marble, HY-World 2.0)를 compositional mesh scenes로 변환”. → 볼트가 따로 추적하던 두 축 사이에 변환 경로가 생겼다. 3DGS로 만든 월드를 게임/시뮬레이터에 넣을 수 있는 형식으로 내리는 다리다.

벤치마크: UE-MeshyScene

수백 오브젝트 · 오브젝트별 주석 · GT 메시 를 갖춘 포토리얼 밀집 장면. → 검사가능성-공사

확인 안 된 것

  • 절대 수치 전무 — “일관되게 상회” 이상 인용 금지
  • 실시간성 판정 불가 — 생성 시간이 초록에 없다. 오브젝트 수백 개를 개별 생성하면 오브젝트 수에 선형 이상일 가능성
  • 코드·모델 공개 미확인 · 저자 소속 미확인
  • 🔴 오브젝트 경계를 누가 정하는가 — “grounded video” 는 분할이 이미 주어졌음을 시사한다. 그렇다면 실사용 난이도가 분할 품질에 종속되고 X2SAM 계열이 전처리로 붙는다

추적 공백 (신규 3건)

Pixal3D(기반 prior · 읽어야 할 1순위) · Marble · HY-World 2.0 — 셋 다 볼트에 페이지 없음.

[2026-09-08] 배치 — 검증 루프를 지었더니 메모리 부재가 드러났다

신규 1건: EmbodiedSkills(HF 논문 · 업보트 5 · 저자 17인 · 코드 공개)

구조 — 모델 출력을 “결정”이 아니라 “제안”으로 격하시킨다

“행동 예측이나 모델이 생성한 스킬 결정은 그 자체로는 제안된 조작이 현재 상태에서 유효한지, 결과가 검증될지를 보장하지 않는다.” → 제안 → 사전조건 검사 → 실행 → 사후 검증을 고정된 실행가능 스킬 인터페이스로 강제한다.

고정 인터페이스의 효과: 저수준 VLA 정책을 에이전트 루프를 안 바꾸고 교체할 수 있다. VLA 모델의 교체 주기가 짧다는 점(볼트 관측: 파운데이션 모델 세대 교체가 timesfm-3.0-pytorch 사례에서 4일)을 고려하면 실질적 이득이다. 소프트웨어 공학의 의존성 역전을 로봇 스택에 적용한 형태.

부수 효과가 더 중요하다: 인터페이스가 계획·실행·검증·복구를 구조화된 궤적으로 기록하고, 그 기록이 다시 각 구성요소의 감독 신호가 된다. → 검사 창을 지으면 로그가 남고, 로그는 학습 데이터가 된다(검사가능성-공사 확장).

실측 — 그리고 저자가 자기 한계를 먼저 썼다

벤치마크성공률
RoboTwin 2.0 50태스크 평균86.20%
LIBERO 4스위트97.40%
RMBench 기억의존 4태스크🔴 12.5%

구성: Qwen3-VL(고수준) + OpenPI/pi0.5(저수준).

📌 12.5%를 초록에 쓴 것, 그리고 “이 결과들은 태스크 적응된 저수준 VLA 정책의 실행 성능을 확립한다” 며 86.20%를 프레임워크의 공으로 주장하지 않은 것 — 둘 다 신뢰도를 올린다. 볼트가 Thinkingbox·apache-maka 에서 경고한 “중간 지표 ≠ 최종 결과” 의 역방향 사례다.

🔴 12.5%가 말하는 것 — 검증 루프를 잘 지어도 메모리는 별도 문제다

사전조건 검사 → 실행 → 사후 검증은 전부 현재 상태에 대한 판단이다. 과거에 무엇을 했는지는 이 루프에 들어갈 자리가 없다. → 에이전트-메모리-레이어 축과 정확히 만난다. 구조적 검사는 “지금 유효한가” 를 답하지 “아까 뭘 했나” 를 답하지 않는다. ⚠️ RMBench 태스크가 4개뿐이라 표본이 작고, 저자도 실패 원인을 분해하지 않았다.

도메인 템플릿 미답 항목

  • 실시간 가능성: 미확인. 초록에 지연시간·주기 수치가 전혀 없다. 매 스킬마다 사전·사후 검증을 돌리면 오버헤드가 있을 수밖에 없는데 그 값이 없다 — 로봇에서 이건 결정적이다.
  • 카메라 파이프라인: Qwen3-VL이 시각 입력 처리, 구체 형식 미기재.
  • 필수 레퍼런스: RoboTwin 2.0 · LIBERO · RMBench — 볼트에 페이지가 없다. 추적 공백 3건 등록.

📌 도메인 간 수렴 — 이번 배치 최대 신호

EmbodiedSkills(로봇 제어)와 TGOPD(LLM 학습)가 서로를 인용하지 않고 같은 골격에 도달했다: “신뢰할 수 있는지 먼저 검증하고, 통과할 때만 쓴다.” 도메인이 최대한 멀리 떨어져 있는데 처방이 같다 → 검사가능성-공사 가 도메인 특수적 유행이 아니라는 지금까지 중 가장 강한 근거.

[2026-09-09] 배치 — 단안 깊이추정이 1-step으로 내려왔다

Marigold-V2 — HF 데일리 1위(업보트 24)

raw는 ai-news 로 보냈지만 단안 깊이추정은 이 도메인의 입력단이다. 기여는 새 모델이 아니라 레시피: 사전학습된 다단계 flow-matching DiT를 1-step 추론으로 돌려 SOTA 깊이추정기로 전환.

처방 두 가지 (순진한 학습의 아티팩트 진단 후)

  1. 모델 내부 표현을 GT에서 추출한 의미 피처와 정렬
  2. Sinkhorn 기반 신규 손실을 축으로 한 2단계 파인튜닝 필요시 양자화를 적용해 모델 용량은 보존하면서 실행 비용을 낮춘다.

현재 SOTA 수치

  • KITTI · ETH3D에서 AbsRel 기존 최고 대비 16–26% 개선
  • 표면 법선 추정 · 본질 이미지 분해 등 다른 밀집 회귀 과제에서도 SOTA
  • 정성: “fur, foliage, and hair-thin edges” — 기존 모델이 놓치던 머리카락 두께 경계를 해결

즉시 할 것

HF Space에서 내 소스 이미지로 먼저 돌린다(설치 0): https://hf.co/spaces/huawei-bayerlab/marigold-v2-web 판단 기준은 벤치마크가 아니라 내 데이터에서 경계 디테일이 실제로 살아나는가. 3DGS 초기화·깊이 프라이어에서 경계 품질이 병목이었다면 직접적 개선.

미확인

fps 수치가 논문에 없다. 1-step + 양자화로 “cheap to run”이라 주장하지만 30fps+ 실시간 가능 여부는 판정 불가 — DiT 백본 크기가 지배할 것으로 보인다. 실측 필요.

[2026-09-11] 교차 참조 — SpatialBlock (도메인은 ai-news, 축은 여기)

도메인 판정 기록

raw는 ai-news 로 보냈고 볼트도 ai-news 유지로 판정했다. 근거: 이 논문은 재구성 파이프라인이 아니라 LVLM 학습 데이터셋이라, 이 도메인 템플릿(실시간성·카메라 파이프라인·재구성 SOTA)에 답할 항목이 거의 없다. 2026-09-10 Pascal-Editor 판정(“slam-3dgs는 깊이추정·재구성 계열”)과 일관된 기준 적용이다. 다만 주제가 이 도메인의 관심사와 직결되므로 교차 참조를 남긴다.

이 도메인에 주는 함의 — 공간지능 학습에 실데이터가 필수가 아닐 수 있다

SpatialBlock 초록이 지적하는 기존 방식의 문제: “constructing such labels is costly, time-consuming, and often noisy due to reliance on external perception modules” → 🎯 ②가 이 도메인에 특히 아프다. 실장면 공간 QA 라벨을 만들 때 깊이추정·SLAM 같은 외부 인지 모듈을 쓰는데, 그 모듈의 오차가 라벨에 그대로 섞인다. 정답을 만드는 도구가 피학습자와 같은 실패 모드를 갖는 구조 → 검사가능성-공사. 우회로: 합성 블록쌓기 15,000문제(3D→2D 투영 · 시점 변환 · 구조 결합 + 앵커 추론 유도용 통제 색 변조). 정답이 생성 규칙에서 직접 나오므로 인지 모듈이 개입할 여지가 없다. 결과: “generalize to real-world spatial tasks, despite the dataset’s synthetic and compact nature” — 직답 학습·추론기반 학습 둘 다 효과(견고성 신호).

정량 수치 부재

“significantly outperform”이라는 정성 서술뿐, 벤치 점수가 초록에 없다. 저자 3명·업보트 35의 소규모 논문. 코드·데이터는 공개(github.com/rsoohyun/SpatialBlock)되어 검증 가능하나 미검증.

이 도메인 관점의 액션

공간 인지 라벨을 만들 일이 생기면 “외부 인지 모듈로 라벨을 만들 것인가, 정답이 생성 규칙에서 나오는 합성 과제를 만들 것인가” 를 먼저 묻는다. 후자가 가능하면 비용과 오염을 동시에 없앤다.

🆕 2026-09-17 — 액션 토크나이저의 평가 관행을 반증했다 (ActionPiece · raw ai-news → 재판정 slam-3dgs)

🎯 MSE가 낮은데 동작 방향이 뒤집힐 수 있다

VLA(vision-language-action) 모델의 액션 토크나이저는 통상 MSE 같은 점별 복원 오차로 평가된다. 초록 원문:

“small individual errors do not fully characterize how faithfully action adjustments across demonstrations are preserved. After compression, similar actions may still cluster around a representative motion, while the adjustments needed for different contexts are diminished, distorted, or even reversed.”

🎯 or even reversed — MSE가 낮은 토크나이저가 로봇을 반대로 움직이게 만들 수 있다. 📌 원인: 압축이 유사 동작을 대표 모션으로 뭉치면 각 점은 대표값에 가까워져 MSE가 작아진다. 무너지는 것은 점이 아니라 점들 사이의 관계다.

새 지표 PRC — 구현 비종속으로 설계됐다

PRC(physical rank consistency): 복원 후에도 국소 물리 거리의 순위가 보존되는지 잰다. ✅ “Evaluating decoded actions provides a common reference across token vocabularies and decoder architectures” — 디코딩된 액션에서 재므로 토큰 어휘·디코더 구조가 달라도 비교 가능하다. 방법: 표현학습과 양자화를 공동 감독(인코더/양자화 특징의 가까움-멂 순서 + 코드워드 할당 분포에 같은 순서). 복원 손실을 대체하지 않고 증강한다.

도메인 템플릿 답 (ActionPiece)

  • 현재 SOTA: 동일 Qwen3-VL-4B 정책 학습 설정에서 LIBERO 94.8% · 미학습 LIBERO-Plus 68.8% · SimplerEnv 71.9% · VLA-Arena L0–L2 51.5%. ⚠️ 토크나이저 비교 실험이므로 전역 SOTA 주장이 아니다
  • 실시간 가능성: 🔴 초록에 지연시간·주파수 수치 없음 — 확인 불가. 구조상(이산 토큰 자기회귀 + frozen decoder) 기존 VLA와 동급 비용
  • 카메라 파이프라인: 입력 시각+언어 → 이산 액션 토큰 → frozen decoder → 실행 명령
  • 응용 가능성: 🔴 직접 응용 경로 없음(로봇 하드웨어 미보유). 🎯 발상은 이식 가능 — “압축 후 관계 순위가 보존되는가” 는 임베딩·양자화 평가 전반에 적용된다
  • 필수 레퍼런스: 🔴 코드 링크 초록에 없음. LIBERO · LIBERO-Plus · SimplerEnv · VLA-Arena 가 비교 기준선

🔴 지는 축이 크다 — 일반화는 해결되지 않았다

학습 분포 94.8% vs 미학습 68.8% = −26.0점 격차 · VLA-Arena L0–L2 51.5% = 절반 수준. 🎯 토크나이저를 고쳐 얻은 것은 분포 내 충실도이고, 분포 밖 일반화는 여전히 미해결이다 → 분포내-우위 의 로보틱스 판본. 🔗 같은 배치 ProgramDistill 의 “프런티어 에이전트 최고 49.2%” 와 같은 메시지 — 2026 하반기 에이전트/로봇 벤치가 절반 근처에서 막혀 있다. 🔴 볼트 미확인: PRC 수식 · 비교 토크나이저 목록 · 어블레이션 수치 · PRC 값 자체가 초록에 없다(“jointly improve PRC” 까지만). 베이스라인 성능이 없어 94.8%가 얼마나 개선된 것인지 알 수 없다
