왜 지금 JEPA이고
왜 월드모델이 미래인가

Yann LeCun은 "생성형·자기회귀(LLM)만으로는 진짜 지능에 도달할 수 없고, 세계를 예측하는 월드모델이 필요하다"고 말합니다. 그 핵심 설계가 바로 JEPA(Joint Embedding Predictive Architecture) — 픽셀이 아니라 표현(representation) 공간에서 예측하는 아키텍처입니다.

"AI 시스템은 관찰로부터 세계가 어떻게 작동하는지 배우고, 예측하고, 계획할 수 있어야 한다. 그러려면 픽셀을 재생성하는 대신 추상적 표현 공간에서 예측해야 한다." — Yann LeCun, A Path Towards Autonomous Machine Intelligence (2022) 요지

PART 1 · 개념과 철학

01JEPA란 무엇인가

JEPA = Joint Embedding Predictive Architecture. "입력의 일부(context)를 보고, 가려진 나머지(target)의 표현을 예측"하는 자기지도학습(SSL) 아키텍처입니다. 핵심은 "픽셀·토큰을 복원하지 않는다"는 점이에요.

🧭철학

세상은 픽셀 단위로는 예측 불가능하다(잎사귀의 정확한 흔들림, 군중의 개별 얼굴…). 그래서 예측 불가능한 디테일은 버리고, 추상적 표현 공간에서 예측한다. 이것이 인간이 세계를 이해하는 방식에 가깝다.

⚡핵심 기여

생성형(재구성)·대조학습(negative pair)의 한계를 우회. 손으로 만든 데이터 증강 없이, 표현 공간의 예측 오차만으로 의미론적·물리적으로 유용한 특징을 학습한다.

🎯왜 미래인가

학습된 월드모델 안에서 행동을 상상하며 계획(planning)할 수 있다. 로봇 제어·자율주행·에이전트가 "머릿속 시뮬레이션"으로 미래를 내다보는 길을 연다.

3가지 패러다임 비교

🎨 Generative

입력 공간에서 복원. 오토리그레시브 LLM, 디퓨전. 모든 디테일을 예측하려다 예측 불가능한 정보에 용량을 낭비. x → 모든 픽셀/토큰 재생성

🔗 Contrastive

양성/음성 쌍 비교. SimCLR 등. 강력하지만 대량의 negative pair·증강 트릭에 의존, 붕괴(collapse) 방지가 까다로움.

🧠 JEPA 이 리포트

표현 공간에서 예측. target 인코더(EMA)의 표현을 predictor가 맞힘. 복원도 negative pair도 불필요. enc(x) → 예측 → enc(y)

PART 1 · 구현

02어떻게 구현되는가 — 인터랙티브

아래 탭을 눌러 세 아키텍처의 데이터 흐름을 비교해 보세요. JEPA의 핵심은 Predictor가 context 표현으로부터 target 표현을 맞히고, 손실은 임베딩 공간의 거리라는 점입니다.

구성 요소

  • Context Encoder — 보이는 부분 x를 표현으로 인코딩
  • Target Encoder — 가려진 부분 y를 표현으로 인코딩 (보통 context 인코더의 EMA 사본, stop-gradient)
  • Predictor — context 표현 + 위치/latent z → target 표현을 예측
  • Loss — 예측 표현과 실제 target 표현의 L2 거리 최소화

붕괴(collapse) 방지

자기 표현을 예측하면 "모두 상수"로 무너질 수 있음. 이를 막는 장치:

  • 비대칭 + EMA target + stop-gradient (BYOL·I-JEPA 방식)
  • VICReg류 정규화 — 분산(variance)·공분산(covariance) 제약으로 표현 다양성 유지 (MC-JEPA)
  • 마스킹 설계 — 충분히 큰/의미 있는 블록을 가려 shortcut 차단

PART 2 · 심층 분석

04C-JEPA 뜯어보기

제공해주신 논문. Causal-JEPA: Learning World Models through Object-Level Latent Interventions — JEPA의 마스킹을 "이미지 패치"에서 "객체(object) 단위"로 끌어올려, 상호작용·인과 추론을 강제합니다.

arXiv 2602.11389 Object-centric Causal / Counterfactual World Model

저자: Heejeong Nam(Brown) · Quentin Le Lidec(NYU) · Lucas Maes(Mila) · Yann LeCun(NYU) · Randall Balestriero(Brown)

"World models require robust relational understanding… object-centric representations are not sufficient to capture interaction-dependent dynamics. We propose C-JEPA, which extends masked joint embedding prediction from image patches to object-centric representations… creating counterfactual-like prediction queries that discourage shortcut solutions." — Abstract

+20%반사실적(counterfactual) 추론 정확도 (CLEVRER)
1%패치기반 월드모델 대비 latent 입력 특징만 사용
8×Push-T 제어에서 더 빠른 플래닝

🧭 철학 · 동기

객체를 슬롯으로 분리해도 "객체들이 어떻게 상호작용하는지"는 잘 못 배운다. C-JEPA는 객체 하나의 상태를 가리고(mask) 나머지 객체들로부터 추론하게 만든다 → "만약 이 객체가 없었다면?"에 가까운 latent intervention(잠재 개입) 효과가 생겨 shortcut을 막고 인과·상호작용 학습을 강제한다.

⚡ 핵심 기여

  • 객체 단위 마스킹 — 패치가 아닌 객체 슬롯을 가려 인과적 귀납 편향 부여
  • 효율 — 패치 월드모델의 1% 특징으로 유사 성능, 훨씬 빠른 플래닝
  • 추론력 — 반사실 추론 +20% (동일 구조 대비)
  • 이론 — 객체 마스킹이 관측성(observability) 제어를 통해 유용한 귀납 편향을 만든다는 형식적 분석

🔧 구현 방식

  • 객체중심 인코더: VideoSAUR 또는 SAVi로 슬롯 표현 추출 (CLEVRER 7슬롯 중 0~4개 마스킹)
  • 가려진 history 슬롯을 다른 슬롯들로부터 예측: ẑτⁱ = Φ(z₀ⁱ) + eτ, history/future 창에 걸쳐 L2 거리 최소화
  • 인프라: Stable-WorldModel + Stable-Pretraining 프레임워크 기반
  • 벤치마크: CLEVRER(시각 추론 VQA), Push-T(로봇 제어)

📊 결과 · 추후 과제

  • Push-T: 88.67% 성공(6×128 토큰 ≈ 패치의 1%) vs DINO-WM 91.33%(196×384) — 근접 성능 + 8× 빠름
  • CLEVRER: 전체 83.88% / 반사실 60.19% — SlotFormer·OCVP-Seq 상회
  • 최적 마스킹: VideoSAUR 4/7, SAVi 2/7
  • Future work: (repo 공지 '26.6.30) 최신 stable-worldmodel/pretraining으로 사용성 개선 예정. 더 복잡한 실세계 상호작용·장기 플래닝으로 확장 여지.

PART 3 · 생성형 축

05World Model × Diffusion

JEPA가 "잠재 공간에서 예측(비생성)"이라면, Diffusion 월드모델은 정반대 축 — 다음 프레임의 전체 분포를 학습하고 반복적 디노이징으로 실제 픽셀을 렌더링합니다. 그래서 직접 플레이하거나 운전할 수 있는 시뮬레이터가 나옵니다(GameNGen·Genie·GAIA·Cosmos).

🧠 JEPA (예측형 · 비생성)

I-JEPA · V-JEPA 2 · C-JEPA
  • 미래의 잠재 임베딩을 예측 (픽셀 복원 X)
  • 예측 불가능한 디테일은 버림 → 효율·추상화
  • 손실 = 표현 공간 거리 (에너지기반/회귀)
  • 강점: 샘플효율 RL·플래닝·견고한 표현
  • 약점: 렌더링 불가(사람이 볼 영상 X)

🎨 Diffusion (생성형 · 픽셀공간)

DIAMOND · Genie 3 · GAIA-2 · Cosmos
  • 다음 프레임의 전체 분포를 학습·샘플링
  • 반복 디노이징으로 실제 영상 렌더링
  • "시각 디테일이 성능을 좌우"(DIAMOND)
  • 강점: 인터랙티브·고충실·데이터 생성
  • 약점: 무거움·느린 롤아웃·오차 누적

디퓨전 월드모델의 5대 분야

🧪Core · Theory

DIAMOND(WM 안에서 RL), Diffusion Forcing(next-token+디퓨전 통합), History Guidance(장기 일관성). 오차 누적을 길들이는 기반 레시피.

🎮Gaming · Interactive

GameNGen(DOOM 20FPS), Genie 1/2/3, Oasis·Matrix-Game·Hunyuan-GameCraft — 직접 플레이 가능한 뉴럴 게임엔진.

🚗Autonomous Driving

GAIA-2(Wayve), Vista·GenAD·Drive-WM·MagicDriveDiT·DriveLaW(CVPR’26) — 멀티뷰 주행 시나리오 생성·플래닝.

🤖Robotics · Planning

iVideoGPT·AdaWorld·VPP·Dreamer 4·NWM — 영상 예측을 정책·플래닝으로. (NWM은 LeCun팀의 디퓨전판 월드모델)

🌍Foundation Models

NVIDIA Cosmos, UniSim, Sora(as world simulator), Pandora — 범용 물리세계 시뮬레이터 파운데이션.

🔀수렴하는 흐름

두 축은 경쟁이 아니라 상보적. 같은 Meta팀이 JEPA와 디퓨전(NWM) 둘 다 만들고, 하이브리드(Pandora)·잠재 디퓨전 WM(GAIA-2)이 그 사이를 메우는 중.

PART 5 · 전망

07앞으로의 Future Work

🏗 계층적 · 다중시간 예측 (H-JEPA)

여러 추상화 수준·시간 스케일에서 예측하는 계층 JEPA로 장기 플래닝. LeCun의 원래 청사진에서 아직 완전히 실현되지 않은 부분.

🤖 행동조건 월드모델 · 로봇

V-JEPA 2-AC, DINO-WM, VLA-JEPA 흐름 — latent action·제로샷 플래닝을 실세계 조작·자율주행으로 확장.

🎲 불확실성 · 확률적 JEPA

latent z를 통한 다봉(multimodal) 미래 표현. Var-JEPA·VJEPA(변분) 등 생성-예측 SSL을 잇는 이론화.

🧩 객체중심 · 인과

C-JEPA가 연 방향 — 개입·반사실을 통한 상호작용 추론. 더 복잡한 장면·장기 인과로 확장.

💬 언어 · 멀티모달 통합

LLM-JEPA·VL-JEPA — 임베딩 공간 학습을 언어/비전-언어로 이식. 토큰 생성 없이 예측만으로 표현 학습.

📐 이론적 보장

JEPA 월드모델의 일반화 바운드·식별가능성(identifiability) — LeJEPA, generalization theory 논문들이 "언제 진짜 월드모델을 배우는가"를 규명 중.
