분기 미래: z = c ± 2.0 (좌/우). context c = [-1.  0.  1.]

결정론 JEPA(회귀 평균) 예측 ẑ:
  c=-1.0 → ẑ=-1.01 (최근접 모드까지 1.99) ← 갭(무효)
  c=+0.0 → ẑ=+0.04 (최근접 모드까지 1.96) ← 갭(무효)
  c=+1.0 → ẑ=+0.93 (최근접 모드까지 1.93) ← 갭(무효)

생성형 JEPA(flow) 샘플 분포:
  c=-1.0 → 우모드(c+2) 0.35 / 좌모드(c-2) 0.38 / 갭(c) 0.01
  c=+0.0 → 우모드(c+2) 0.36 / 좌모드(c-2) 0.41 / 갭(c) 0.01
  c=+1.0 → 우모드(c+2) 0.34 / 좌모드(c-2) 0.43 / 갭(c) 0.01

해석:
 - 결정론 JEPA: 양 모드를 평균 → c 근처(모드 사이 '갭')에 떨어짐 = 무효 예측(붕괴).
 - 생성형 JEPA(flow): 좌·우 모드를 둘 다 복원(각 ~0.5), 갭엔 거의 안 감 → 다봉 미래 보존.
 → '표현공간에서 flow로 조건부 미래분포 예측' 이 JEPA 모드평균 약점을 해결(#37).
