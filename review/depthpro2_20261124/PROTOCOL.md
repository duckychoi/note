# Depth Pro 2와 #43의 연결을 확인하는 소규모 진단

2026-11-24. 이전 ROBI 연구에서 정한 크롬 나사·기어, 장면 4·5·8·9의 Ensenso 출발 자세 두 개씩을 사용한다. 출발 자세는 각 장면의 정렬된 시점 목록에서 1/4과 1/2 위치다. 원래 정해진 16쌍이며 새 오류를 찾아서 장면을 고르지 않는다. 동일 장비·시점에서 얻은 일반 좌영상과 패턴 투사 좌영상에 대해 공개 Depth Pro 2-S를 학습 없이 별도로 실행한다. 허용된 입력은 원본 해상도 흑백의 RGB 3채널 복제와 고정된 보정 초점거리다. 각 쌍의 공개 카메라 자세, 해상도, 기준 깊이 좌표가 맞는지 검사한다. 이는 산업용 카메라의 촬영 모드 차이이므로 일반 스튜디오 광원 위치·재질을 독립 조작한 결과로 해석하지 않는다.

중앙 가로·세로 50% 영역, 4픽셀 간격의 기존 격자 중 코팅 기준 깊이가 있는 곳을 평가한다. 첫 지표는 패턴 유무에 따른 두 예측 거리 차이의 중앙값(mm)이다. 두 번째는 각 시점 전체에서 일정한 배율 차이를 뺀 후에도 남는 모양 차이(절대 로그깊이 차이의 중앙값, 백분율 환산)다. 각 영상의 기준 대비 절대오차, 기준 대비 중앙 배율, 전역 배율을 사후 정답으로 맞춘 후의 절대오차도 계산한다. 후자는 원인 분리용이며 제출할 수 있는 예측이 아니다. 같은 입력을 비교하는 음성 대조의 차이는 0이어야 한다. 장면 통계에서는 물체별 네 장면을 같은 비중으로 두고, 각 장면 두 시점에 같은 비중을 준다. 성능 우위, 모든 재질에 대한 강건성, 학습 전이, 제품 속도는 이 작은 실험의 판정 대상 밖이다.

추론 전 추가한 4점 비교. 각 사분면에 1개씩 총 4회의 거리 조회 기회를 준다. 중앙 격자에서 16픽셀 간격인 격점은 질의 전용이고 나머지만 평가한다. 고정 중심점, 층화 무작위(고정 난수 128회 평균), 두 조명 예측의 절대 로그비가 가장 큰 점, 가장 작은 점을 비교한다. 동률은 중심 근접점이 우선이다. 처음 결정을 내릴 때 후보 위치의 원시 깊이·정답을 보지 않는다. 정한 지점에서 센서가 실제 반환한 거리만 쓰며 실패한 질의는 교체하지 않는다. 일반 영상의 예측을 성공한 거리점들의 중앙 로그 배율로 보정한다. 전부 실패하면 원본을 쓴다. 이 비교는 한 개의 공통 배율 추정으로 한정한다. 반사·가림이 만드는 국소 오차 교정까지 시험했다고 주장하지 않는다. 앞뒤 두 사진을 쓰는 정책은 한 장만 필요한 고정·무작위와 총 촬영비가 다르며, 두 사진이 이미 주어진 상황의 4점 비교로 해석한다.

작은 S 모델 실행 후 논문의 주 비교 모델인 H+도 같은 16쌍에 적용한다. 모델 크기에 따른 민감도 점검이며 영상, 평가점, 보정 규칙을 바꾸지 않는다.

S 결과를 본 후 단순 기준을 하나 더 둔다. 각 모델별로 나사 개발 장면 4·8의 두 시점씩에서 사분면 중앙을 4회씩 질의한다(개발 총 16회, 실패 포함). 성공 측정의 로그 배율 중앙값을 고정하고 나사 5·9와 기어 전체에 적용한다. 이 기준은 시험 때 거리 조회가 0회이며 개발에서 얻은 정보를 사용한다.
