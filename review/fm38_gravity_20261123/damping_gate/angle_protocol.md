# 각도 오차를 직접 학습하는 보조 시험

주 시험 첫 시드의 결과를 본 뒤 설계했다. 예측 대상의 차이가 있는지 별도로 점검한다. 원 관문 판정은 바꾸지 않는다. 강감쇠의 미사용 512개 상태(53819)에 모든 행동을 실행한다. 학습·검증 자료와 관측, 각도 판독기, 물리 기준, 성공 기준은 주 시험과 같다.

모델 입력은 원래 ridge가 보는 시작·연습 관측 각도, 추정 복원 계수, 본 동작 세기, 기준 궤적이다. 목표는 실제 미래 사진에서 읽은 다섯 각도와 기준 궤적의 차이다. 5차원 조건부 rectified flow와 결정론적 MLP를 같은 폭 128·은닉층 2개, 1,600회 갱신, 같은 미니배치·세 시드로 학습한다. Flow는 표준 정규에서 시작해 8회 Euler 적분으로 32표본을 뽑는다. 검증 궤적 MAE로 체크포인트를 선택하고, 주 시험과 같은 규칙으로 보정 세기를 정한다.

새 시험에서 물리 기준, 단순 ridge, 결정론적 MLP 대비 각도 Flow의 행동 성공률과 궤적 MAE를 비교한다(6개 동시 구간). 같은 시드의 예측을 상태별로 평균한다. 이것은 공개 Flow-JEPA를 바꿔 다시 투입한 결과가 아니라 작은 별도 모델을 쓴 보조 분석이다. 단순 보정과 Flow를 같은 각도 출력에서 비교한다.
