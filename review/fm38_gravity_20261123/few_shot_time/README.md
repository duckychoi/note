# #38 · 새 그네에서 4·8·16회 연습해 촬영 시점 고르기

강한 저항에서 고정 0.48초보다 성공률이 높았던 최소 관측 예산은 요청한 세 예산 중 4회, 추가로 잰 2회까지 포함하면 2회였다. 강한 저항에 맞춰 미리 고른 고정 0.32초가 더 좋았고, 두 저항을 반반 섞으면 연습 없는 고정 0.40초가 더 좋았다.

경사와 감쇠가 고정된 시뮬레이터 장치 192개를 새로 생성했다. 장치별 시험 128개로 총 24,576개의 미사용 장면이다. 출발 사진은 공통이고, 각 시험 정책은 탐색 밀기 후 사진을 한 장만 본다. 각 장치에서 시작각과 목표각을 같게 맞춰 0.32초와 0.48초를 한 번씩 시험했다. 각 회에 약한 탐색 밀기와 선택한 본 밀기가 든다. 자신의 성패만 세어 0.32초가 더 많이 성공하면 전환하고 동점이면 0.48초를 유지한다. 모델 3개와 독립 연습 기록 8개는 별도 실험을 반복한 것이고 한 정책에 합쳐 주지 않았다.

## 강한 저항에서 고정 0.48초와 비교

| 연습 횟수 (실제 밀기) | 고정 → 연습 후 성공률 | 차이와 동시 95% 구간 (%p) | 0.32초 선택 빈도 |
|---|---:|---:|---:|
| 2회 (4번) | 49.03% → 49.13% | +0.11 [+0.05, +0.18] | 4.51% |
| 4회 (8번) | 49.03% → 49.20% | +0.17 [+0.09, +0.29] | 7.25% |
| 8회 (16번) | 49.03% → 49.34% | +0.31 [+0.19, +0.47] | 12.54% |
| 16회 (32번) | 49.03% → 49.56% | +0.53 [+0.34, +0.76] | 20.14% |

## 어떤 기준과 비교하느냐에 따른 판정

| 새 장치 분포 | 고정 0.48초 | 고정 0.40초 | 고정 0.32초 | 16회 연습 |
|---|---:|---:|---:|---:|
| 원래 저항 | 79.41% | 78.87% | 76.60% | 79.29% |
| 강한 저항 | 49.03% | 50.88% | 51.29% | 49.56% |
| 두 범위 반반 | 64.22% | 64.87% | 63.95% | 64.42% |

두 분포를 반반 섞었을 때 고정 0.48초 대비 4회·8회·16회 차이(%p)는 +0.06 [-0.01, +0.13], +0.11 [+0.03, +0.20], +0.20 [+0.09, +0.33]다. 강한 저항에서 16회 보정은 고정 0.32초와 비교해 -1.74 [-2.14, -1.35]%p였다. 혼합 분포의 16회 보정과 고정 0.40초의 차이는 -0.45 [-0.81, -0.09]%p였다.

강한 저항에서 같은 출발·목표의 연습 한 쌍이 서로 다른 성패를 준 비율은 3.31%다. 16회 뒤에도 누적 성패가 동점인 비율은 77.52%였다. 고정 0.48초에 대한 차이가 양수인지와 사전에 정한 +3%p 실용 기준을 구분했다. 강한 저항에서 시험한 예산 중 +3%p에 도달한 경우는 없었다.

## 해석 범위와 재현

실험 때마다 같은 장치로 리셋할 수 있고 각 후보를 같은 시작·목표에서 비교할 수 있다는 가정이다. 0.32초는 이전 강감쇠 대규모 실험에서 골랐다. 총성공률은 모든 새 목표를 포함하며 시험 성공률에 연습 비용을 차감하지 않았다. 구간은 장치 간 변동을 기준으로 36개 비교를 동시 보정했으며, 새로 모델을 다시 학습할 때의 변동까지 다루지 않는다. 이 작은 차이를 모든 센서·물성이나 공개 최고 성능에 일반화할 수 없다.

기존 그네 비교는 공개 Flow-JEPA를 개조한 영상 보정기를 평가했다. 원 논문의 공개 과제와 별개이며, 비슷한 연구인 JEPA-TTT도 새 물성 장면에서 동작하며 예측기를 갱신한다. 두 연구와 동일한 자료·횟수·평가에서 승리한 실험은 없다. [기존 Flow 비교](../damping_gate/README.md) · [Flow-JEPA 원 논문](https://arxiv.org/abs/2608.29029) · [JEPA-TTT 원 논문](https://arxiv.org/abs/2610.00722)

MuJoCo 환경에서 devices.py로 장치를 만든 뒤 기존 CUDA 학습 환경에서 predict.py calibration → choose.py → predict.py test → analyse.py → report.py 순서로 실행한다. report.py --check는 원래 최고점과 고른 힘에서 성패·예산별 선택·시험 성공률을 다시 계산하고 연구노트와 대조한다.
