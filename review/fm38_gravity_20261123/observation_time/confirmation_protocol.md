# 강한 저항에서 시점을 다시 고를 수 있는 경우

원 범위 검증에서 0.48초를 고른 후, 첫 미사용 시험 결과를 열기 전에 추가로 정한 확인 시험이다. 원 범위에서 미리 정한 시점의 주 검정은 그대로 실시한다.

첫 강감쇠 평가 2,048개에서 주 회귀법의 평균 성공률이 가장 높은 시점을 하나 고른다. 동률은 빠른 시점이다. 이 조건은 강한 저항의 행동 결과가 이미 주어진 환경을 가정한다. 가중치는 다시 학습하지 않는다. 이 시점을 잠근 뒤, 서로 독립인 새 강감쇠 1,024개 묶음 두 개(58421, 58422)에서 ①기존 0.55초, ②원 범위에서 고른 시점과 각각 비교한다. 두 차이는 한 가족으로 보정한 짝지은 95% 구간을 사용한다. 같은 후보가 선택됐으면 같은 결정끼리의 차이는 0이다. 주 시험과 같은 개선·시간단축 기준을 적용한다. 새 확인 시험에서 다시 시점을 고르지 않는다.
