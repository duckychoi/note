# #38 구현 · 탐색 동작이 다음 힘 선택을 바꾸는 경로

**연습 동작의 반응은 시각 인코더 다음에서 읽고, 행동 조건부 월드모델이 네 후보의 미래를 만들기 전에 사용한다.** 같은 그네에는 후보 네 개가 복원 계수 하나를 공유한다. 목표각은 예측한 궤적을 비교하는 마지막 단계에서 사용한다.

## 수식과 학습 신호

시각 인코더 E는 공개 Reacher 가중치로 고정했다. 각도 판독기 D는 이전 실험에서 원 물성 시범의 각도 표지로 학습한 것을 그대로 썼다. q₀=D(E(시작 사진)), qₚ=D(E(연습 후 사진))이다. 수치 적분 함수 S는 단진자식 q″=−k sin(q)를 따른다. 연습 세기 uₚ와 시간 Δt를 알고 있을 때, `|S(q₀,uₚ,k,Δt)−qₚ|`가 가장 작은 k를 후보 2~32 s⁻² 중에서 고른다. k는 복원 가속도의 계수여서 중력과 진자의 관성 효과를 함께 담는다. 그네 세계의 운동식과 명령한 초기 각속도는 알고 있다. 학습 또는 시험에서 기울기·중력 정답을 모델에 주지 않았다.

행동 a의 시간별 기준 각도 q*는 S로 계산한다. 학습 시범의 각도에 대응하는 사진 표현을 보간해 기준 표현 b를 얻는다. 공개 Flow-JEPA는 다음 형태의 잔차를 조건부 flow matching으로 학습한다.

```text
조건      = 행동 인코더(a) + 학습형 투영([b, 정규화한 k])
학습 목표 = (실제 미래 사진 표현 − b) / 원 물성 잔차 표준편차
추론 각도 = q* + D(b + 표준편차 × 예측 잔차) − D(b)
```

마지막 뺄셈으로 예측 잔차가 0이면 물리 각도가 정확히 복원된다. flow는 영 중심 정규 잡음에서 잔차를 뽑아 8회 적분한다. 본 행동은 원위치로 되돌린 후 시작한다. 기본 액션은 네 개라 전수 비교했고, 위치 인코딩이나 보상 함수를 바꾸는 연산은 추가하지 않았다. 원 물성 훈련 시범은 2,048개다. 3개 시드마다 1,000회 학습하며 원 물성 검증 손실이 가장 낮은 체크포인트를 썼다. [공개 Flow-JEPA 구현](https://github.com/HuoYanchen/Flow-JEPA/tree/6b6a88b45a93ba1bcb2ce65af6c2003e771fe376)

## 같은 새 장면에서 분리한 효과

과거 시험과 독립인 512개 시작점에서 네 행동의 실제 최고점을 두 물성으로 각각 계산했다. 수치는 포기 없이 선택한 행동의 성공률이다.

| 무엇을 모델에 넣었나 | 익숙한 그네 | 더 강하게 되돌아오는 그네 |
|---|---:|---:|
| 기존 Flow에 시작·연습 사진을 모두 입력 | 24.2% | 15.9% |
| 물리 기준만 사용, 연습 관측을 가리고 훈련 중앙 계수를 적용 | 62.7% | 17.8% |
| 실제 연습 응답으로 계수를 추정하고 물리 기준으로 선택 | **82.6%** | **71.5%** |
| 같은 물리 기준 + 학습한 Flow 보정 전량 | 46.2% | 38.0% |
| 같은 시작점의 반대 물성 연습 사진을 입력, 물리 기준만 적용 | 21.3% | 17.8% |
| 네 후보 중 성공하는 후보가 있는 비율 | 82.8% | 77.0% |

강한 물성에서 같은 물리 모형에 실제 탐색 정보를 추가한 차이는 +53.7%p [47.9, 59.6]였다. 그 상태에서 Flow 보정까지 켠 차이는 −33.5%p [−38.9, −28.1]였다. 전체 모델과 기존 Flow의 차이는 +22.1%p [16.9, 27.4]였다. 구간은 같은 시작점에서 세 시드의 결과를 먼저 평균해 짝지은 부트스트랩을 하고 사전에 정한 6개 차이를 동시 보정한 값이다. 계수의 평균 절대 오차는 원 범위 0.28, 새 범위 1.86 s⁻²였다. [전체 결과와 시드별 값](results.json)

목표가 59.97도인 410번 장면에서 같은 연습 밀기 후 진자의 실제 각도는 31.2도와 10.6도였다. 카메라를 본 추정기는 k=11.6, 14.8 s⁻²를 냈다. 물리 기준 정책은 각각 2단, 3단을 골라 두 경우 모두 맞혔다. 잔차 보정을 강제로 켜면 세 시드가 모두 두 조건에서 2단을 골라 두 번째를 놓쳤다.

## 무엇이 확인됐나

이상적인 단진자에서 실질적인 기여는 **탐색 동작을 물성 추정 문제로 바꾸고 그 값을 모든 행동 후보의 전개에 공유한 것**이었다. 원 물성 시범으로 학습한 이번 Flow의 보정량은 두 물성 모두 행동 점수를 악화시켰다. 실제 복원 계수를 주면 사용한 운동식은 두 물성의 MuJoCo 궤적을 최대 0.000004도 이내로 설명한다. 마찰·외부 접촉이 있는 다른 장치에서도 같은 성능이 나오는지는 이번 결과로 알 수 없다. 매번 동일한 탐색을 하고 리셋했으므로 언제 어떤 실험 동작을 고를지도 남은 질문이다.

관측한 움직임으로 동역학 파라미터를 추정해 정책에 조건을 주는 연구와, 불완전한 물리 예측의 오차를 학습하는 연구에는 선행이 있다. 이번 결과는 #38에 실제로 연결한 두 경로의 효과를 같은 행동·같은 장면에서 따로 확인한 것이다. [온라인 시스템 식별 연구](https://arxiv.org/abs/1702.02453) · [물리 모형과 학습 보정 연구](https://arxiv.org/abs/2010.04456)

주 시험의 첫 학습 시드 결과를 본 뒤, 실제 기본값을 원 물성 검증으로 고르는 추가 시험을 설계했다. 192개 검증 장면에서 물리 기준 84.9%, 전체 보정 52.6~54.7%여서 세 시드 모두 보정 끄기를 선택했다. 이 선택을 고정한 뒤 별도의 새 256개 시작점으로 확인했을 때 원 물성 85.2%, 새 물성 64.8%였다. 같은 새 물성에서 보정을 강제로 켜면 39.5~41.0%였다. 주 시험과 이 추가 시험은 서로 다른 상태 집합이라 두 표본의 절대 성공률에는 차이가 있다. [추가 설계](gate_protocol.md) · [검증 선택과 재시험 수치](deployment.json)

## 실제 사용

아래 명령은 작업 폴더의 실제 RGB 파일 두 개를 넣어서 네 세기 중 하나를 반환한다. 촬영 장치·배경·막대와 추의 모양은 이번 96×96 시뮬레이터에서 학습한 카메라 조건을 전제로 한다. 두 사진 대신 `--demo 0`을 사용하면 보관한 첫 시험 장면으로 확인할 수 있다.

```powershell
python experiment.py --images before.png after.png --goal-degrees 60
```

기본 실행은 원 물성 검증에서 선택한 보정 설정을 읽는다. `--full-flow`는 학습된 보정을 켜고 `--prior-only`는 물리 추정만으로 행동을 선택한다. 사용한 시드 4821의 완전한 배포 가중치는 FM38_DATA 아래의 swing/probe_planner/planner_4821.pt다. 코드 API는 `ProbePlanner.select_action`이며 네 후보 확률, 예상 각도 오차, 선택한 강도, 추정한 k도 반환한다. [검증에서 선택한 설정](deployment.json)

## 재현

이전 그네 실험의 학습·검증 자료, 각도 판독기, 기존 Flow 비교군 가중치를 재사용한다. 원 실험을 만드는 방법은 상위 폴더에 있다. 이 후속의 MuJoCo 새 시험은 generate.py, 모델 학습과 비교는 experiment.py, 저장된 점수로 재집계하는 작업은 summary.py가 담당한다. [기존 자료 생성법](../README.md#재현)

```powershell
python generate.py
python experiment.py
python summary.py
python generate.py --gate
python deployment.py
```

물리 생성은 MuJoCo 4.0.1, 학습·모델 실행은 CUDA PyTorch 2.11.0과 Transformers 5.5.4에서 했다. LEWAM_SOURCE로 #38 작업트리의 위치, FLOW_JEPA_SOURCE로 공개 모델 소스의 위치, FM38_DATA로 큰 자료 저장 위치를 지정할 수 있다. 작업공간의 기본 위치에서는 별도 지정이 필요 없다. [검증 수치](results.json) · [보관된 예측과 정답](forecasts.npz)
