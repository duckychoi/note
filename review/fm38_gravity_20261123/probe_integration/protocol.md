# #38 탐색 관찰을 월드모델에 연결하는 실험

기존 그네 시험을 보고 설계한 후속이다. 새 시험을 열기 전에 아래 기준을 정했다.

- 그네를 되돌리는 계수 k를 탐색 전후 RGB의 학습된 각도 판독값, 알려 준 탐색 세기와 경과 시간으로 추정한다. 운동식은 q'' = −k sin(q)다. 계수 후보 2~32 s⁻²를 양쪽 물성에 공통 사용한다. 정지 사진만 있으면 원 물성 시범으로 추정한 k의 중앙값을 사용한다. 훈련·추론에서 중력·판 기울기 라벨을 쓰지 않는다. 기존 시각 판독기와 아래 각도→표현 대응표는 원 물성의 각도 라벨을 사용한다.
- 후보별 물리 궤적을 다섯 시점에서 예측한다. 각도를 원 물성 시범의 사진 표현으로 대응시키고 실제 사진 표현과의 잔차로 공개 Reacher Flow-JEPA를 미세조정한다. 시작 장면과 탐색 장면은 이력으로, 후보 행동·물리 기준 궤적·계수는 미래 시점별 조건으로 준다. 보정 세기를 시험 자료로 선택하지 않는다. 잔차 0과 학습된 잔차 전량을 둘 다 평가한다.
- 학습은 이전 원 물성 시범 2,048개, 검증 192개, 학습 시드 4821~4823이다. 같은 초기 장면과 목표로 두 물성에서 분기하는 새 시험 512개(시드 49211)를 생성한다. 본 밀기 전 원상 복귀, 네 후보와 32표본, 8회 적분, 5개 미래 시점, ±7.5도 성공 기준은 기존과 같다. 원본 후보 비교기도 같은 새 장면에서 다시 평가한다.
- 행동별 성공 확률, 동률이면 평균 절대 각도 오차, 그마저 같으면 약한 행동 순으로 고른다. 실패 회피용 포기는 없다. 주 비교는 원래 Flow 대비 새 전체 경로, 탐색을 끈 물리 경로 대비 탐색을 켠 물리 경로, 물리 경로 대비 전체 경로이다. 각각 두 물성, 총 6개 차이에 동시 95% 구간을 쓴다. 사진을 반대 물성의 짝으로 바꾼 추가 대조에서는 시작점과 목표가 그대로인 상태에서 탐색 응답만 바뀐다.
