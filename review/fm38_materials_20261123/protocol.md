# #38 물성 변화와 행동 선택 · 시험 결과를 열기 전 정한 비교

목적은 서로 다른 두 가지 순위 반전을 구분하는 것이다.

- 같은 모델이 예측한 시간별 성공 확률을 고정하고 마지막 세 장면의 성공을 공동 궤적으로 계산할 때와 독립 곱으로 계산할 때의 정책 가치 차이가 물성 이동 전후로 부호를 바꾸는가?
- 세 방법 중 두 방법의 실제 정책 가치 순서가 뒤집히는가?

| 설계 | 고정 값 |
|---|---|
| 밀기 | MuJoCo T자 물체를 네 가지 속도로 밀고 손을 뗀다. 마지막 세 장면 모두 물체 중심이 색 띠 안에 들어야 성공한다. 바닥 마찰 0.32~0.52 → 0.85~1.05. |
| 시각 접촉 | 네 힘 중 하나로 스프링 버튼을 누른다. 마지막 세 장면 모두 실제 접촉과 표시한 눌림 구간을 충족해야 한다. 스프링 강성 42~58 → 85~105 N/m. |
| 데이터 | 과제당 원 물성의 무작위 시범 2,048개. 검증 192개 시작 상태 × 네 행동, 미사용 시험 384개 × 네 행동 × 두 물성. 같은 시험 상태와 목표·행동으로 두 물성을 짝짓고 물성 값은 모델 입력에서 제외한다. 훈련·검증·시험 시드는 분리한다. 과제 개발에는 별도 원 물성 파일럿만 쓴다. |
| 입력 | 96 × 96 RGB, 목표 표시 포함. 과제별 저자 공개 체크포인트의 ViT와 projector를 세 방법이 공유한다. 현재 한 장면, 행동 조건부 미래 다섯 장면. 동일한 원 물성 장면으로 맞춘 성공 판독기를 공유한다. |
| 세 방법 | 공개 Push-T·Cube Flow-JEPA에서 시각부를 고정하고 원 물성 시범으로 예측부 미세조정. 동일 시각 표현에서 가우시안 혼합 궤적 예측기, 행동별 시범 검색. 원 체크포인트 그대로의 전이 성능도 별도 측정한다. 세 방법의 학습 이력·구조는 다르다. |
| 예산 | 네 후보, 후보당 미래 32표본, Flow-JEPA 8 Euler 단계. 모든 방법에 동일한 단일 결정의 지연시간 상한 1초. 실제 GPU 동기화 지연시간을 별도 측정한다. 더 많은 표본을 쓰는 민감도 실험은 별도로 표시한다. |
| 결정 | 성공 시 1, 포기 시 0.1·0.3·0.5·0.7. 각 포기 값에서 추정 기대 보상이 가장 큰 행동 또는 포기를 택하고 네 값을 동일 비중으로 평균한다. 항상 포기=0.4. 같은 확률이면 먼저 나오는 행동, 포기와 같으면 포기. 실제 성공은 물리 엔진에서 판정한다. |
| 불확실성 | 같은 시작 상태로 방법과 물성을 짝지어 부트스트랩한다. 학습 시드 3개의 정책 가치를 상태별로 먼저 평균한다. 원 물성과 새 물성에서 차이의 부호가 반대며 양쪽 동시 구간이 모두 0을 제외할 때 순위 반전을 확인한다. 두 과제에서 모형 내 3쌍·모형 간 공동 점수 3쌍과 두 물성, 총 24개 차이를 한 검정 가족으로 묶는다. |

공 받기 연구와 달리 이 시험은 두 새로운 과제의 한 번 행동 선택에서 물성 이동을 묻는다. 저자 논문의 원래 데이터셋 성능 재현과 구분한다. 이미지 판독 정확도, 후보별·포기 점수별 결과, 사후 최선 행동의 가치, 원 물성 검증에서 정한 상수 행동 기준도 확인한다.
