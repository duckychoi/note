# #42 × #43 두 시점 게인 검증 — 시험 예측 전 고정

질문은 두 번째 시점이 깊이를 확인해 주는 곳에 지도학습 비중을 더 주면 실제 단안 영상에 전이되는가이다. 새 학생은 이전 #43 소형 CNN을 난수 초기화하며 모든 조건에서 사전학습이 없다. 첫 실험의 ETH3D와 다른 YCB-Video 공개 실촬영을 사용한다.

## 자료와 예산

- BOP YCB-V 12개 공식 시험 비디오 중 번호가 가장 작은 48·49는 개발 전용이다. 각 비디오 중간 키프레임의 4×8 격자에서 깊이 32개씩 총 64회 조회한다. 유효점은 반복 학습할 수 있지만 다른 점을 조회하지 않는다. 소량 조건은 본학습 매 8회째 같은 두 사진의 유효점에서 로그 깊이 L1에 0.25 가중치를 준다. 0개 조건은 두 사진도 사전학습도 사용하지 않는다. 시험 시 모든 방법은 RGB 한 장과 공개 초점거리만 사용한다.
- 비디오 50–59에서 각 12개 키프레임을 시간순 균등 간격으로 뽑는다. 320×240으로 줄이고 유효 깊이 0.20–5.0m를 사용한다. 1차 지표는 (1) 유효한 전체 깊이 MAE, (2) 가위·마커·클램프 두 종류의 가는 부분 윤곽에서 양쪽 2픽셀 이내 유효 깊이 MAE다. 개체의 공개 가시 마스크에서 국소 두께를 판정한다. 반경 5픽셀의 원이 들어가는 중심부에서 7픽셀 넘게 떨어진 윤곽을 가는 부분으로 정의한다. 경계 양쪽을 포함하되 유효 픽셀이 16 미만인 프레임은 해당 지표에서만 제외한다. 사용 영상 수, 유효 위치 수 및 물체 안쪽만의 민감도 지표를 기록한다.
- 예비 48쌍, 게인 학습 24쌍, 게인 점검 16쌍, 본학습 128쌍을 각 방법에 전액 청구한다. 네 단계에 각 8개 원본을 두고 원본당 1,1,2,2,4,4,8,10개 변형을 만든다. 두 시점 모두 독립적으로 같은 장면을 렌더하고 두 RGB 모두 학습에 사용한다. 렌더·초기화 시드 4211, 4217, 4229, 4231, 4241. 동일 초기학생에서 예비 80회, 본학습 4×48회, 배치 4. 실제 이미지를 쓰는 조건끼리 실측 조회·반복·갱신 횟수가 같다. 게인 보정 연산은 모든 방법이 같은 결과를 공유하고 사용 유무만 바꾼다.

## 처치와 대조

두 카메라의 가로 이동량 B와 초점거리 f를 알면 역깊이 u=1/z와 시차 d의 관계는 d=fBu다. 스테레오 매칭으로 얻은 v=d/(fB)를 두 번째 추정으로 사용한다. 합성 정답을 다른 카메라로 재투영해 실제로 보이는지 확인하고, 좌우 매칭이 일치한 곳만 허용한다. 같은 렌더러가 만든 두 시점의 오차가 독립이라는 가정을 두지 않는다.

예비 단안 추정 m의 오차를 e₁=m−u, 스테레오 오차를 e₂=v−u라 한다. 보정용 합성 데이터에서 영상 경사와 혁신 크기 빈별로 K=clip(E[e₁(e₁−e₂)]/E[(e₁−e₂)²],0,1)를 구한다. 이 값은 같은 빈에서 m+K(v−m)의 평균 제곱오차를 최소화하는 스칼라 선형 결합이다. 따로 작은 신경망이 혁신·영상 경사·양방향 일치도로 같은 결합 오차를 직접 최소화하는 게인도 시험한다. 게인의 최적성은 합성 분포의 결합 오차까지다. 학생은 정확한 렌더 깊이를 정답으로 사용하며, 확인된 곳의 손실을 1+2K배로 하고 이미지별 평균 비중을 1로 맞춘다. 신경망 게인으로 얻을 실제 깊이 개선은 탐색이다.

균등 학습은 전체 묶음에서 표본 균등, 출처별 균등은 전체 묶음에서 원본 장면을 균등 추출한다. 과거 누적은 일정마다 새 32쌍을 추가하고 지금까지 모인 전체에서 균등 추출한다. 주 방법은 정확히 같은 누적 배치의 같은 픽셀 정답에 산식 게인을 적용한다. 대조로 확인 여부만 쓴 비중, 같은 이미지 안에서 위치를 섞은 게인, 신경망으로 학습한 게인을 같은 배치에서 비교한다. 훈련 도중 학생이 바뀌더라도 현재 실험에서는 예비 모델로 보정한 게인 표·지도를 고정한다. 모든 방법에 학습률·손실식·최종 체크포인트 선택을 고정하고 시험 결과로 튜닝하지 않는다.

## 판단

설계 검수 후, 실행 전에 구현 세부를 명시한다. 원본 8개에 1,1,2,2,4,4,8,10쌍을 배분하는 규칙은 본학습의 32쌍 블록 네 개에만 적용한다. 예비·게인 학습·합성 점검은 각 쌍마다 서로 다른 원본이며 모든 집합의 원본 난수 공간을 분리한다. 빈에 유효 근거가 없으면 전역 상수 게인, 분모가 0이면 0을 쓴다. 같은 영상의 확인된 픽셀 안에서만 게인을 섞고 단순 확인 가중은 해당 영상의 확인 픽셀 평균 게인을 사용한다. 독립 점검 원본에서 예비 단안, 스테레오, 전역 상수, 빈별 산식, 신경망의 결합 MSE를 같은 위치에서 비교한다.

실측 0개와 소량을 따로 판단한다. 시드 및 프레임을 먼저 평균해 비디오를 같은 비중으로 집계한다. 주 방법과 세 기준의 짝 차이를 계산한다. 두 지표와 세 기준 모두에서 차이와 비디오 짝 재표집 20,000회의 단측 95% 상한이 음수여야 해당 실측 조건의 관문을 넘는다. 평가 가능한 비디오가 한 개뿐이면 그 지표의 일반화 판정을 유보한다. 시드별·비디오별 결과, 검증 가능한 픽셀 비율, 격리된 합성 점검에서 실제 필터 결합의 역깊이 MSE를 공개한다. 시간 일관성·광학 흐림·학회 수준의 신규성은 이번 종점에 포함하지 않는다.
