# 단안 미터 깊이 합성 학습 비교

## 비교 질문

11월 25일 교차검수 뒤의 실험 순서와 판정 규칙은 [학습 설계 검수와 실험 순서](#학습-설계-검수와-실험-순서)에 있다. 아래 날짜별 보유량·미실행 기록은 해당 시점의 상태다.

조명과 카메라 시점이 바뀐 독립 실사에서, 합성 데이터로 학습한 제안법이 현재 강한 합성 학습법보다 정확한가. 실사 깊이 정답을 충분히 사용한 모델까지 얼마나 따라잡거나 넘는가. 추론은 사진 한 장으로 한다. 다른 시점, 스테레오, 정답 깊이와 조명 정보는 학습에만 사용한다.

## 같은 모델에서 비교할 학습법

| 역할 | 학습 조건 |
|---|---|
| 기본 대조 | 기존 합성 정답 지도학습. 어떤 손실과 데이터 처리가 이득을 냈는지 확인한다. |
| 공개 합성 학습법 재현 | Depth Pro 2의 합성 학습 D2를 참고한다. 초점거리 정규화 역깊이 오차, 스케일·이동에 무관한 형상 손실, 3스케일 경계 기울기, 카메라와 가시성으로 대응시킨 시점 간 일관성을 적용한다. 정답을 보간하지 않는 크롭·간격 서브샘플링을 공유한다. 같은 Depth Pro 2-S에서 재구현하고, 추가 합성 자료나 내부 데이터가 다른 Apple 원실험의 직접 재현과 구분한다. |
| 강한 합성 대조 | 위 레시피와 함께 공식 Depth Anything V2 미터 학습의 SiLog를 같은 모델에서 튜닝해 비교한다. 조명·카메라 노출·재질·노이즈를 바꾼 RGB와 형상을 보존하는 기본 증강을 각 조건에 동일하게 제공한다. 시점 간 관측을 쓰는 자료에는 고정 가중 기준을 둔다. |
| 제안법 | 같은 강한 합성 레시피 위에서 깊이 출력 보정, 파라미터 갱신, 결합을 각각 시험한다. 보조 관측을 사용하는 조건들 사이에 관측 원천·수·추가 라벨 권한을 맞춘다. 초점거리와 렌더 정답, 보조 관측의 신뢰도 가중을 구분한다. |
| 실사 지도학습 | 동일 모델을 실측 깊이 정답으로 학습한다. NYU Depth V2와 SUN RGB-D의 공식 학습 자료 또는 장면이 분리된 실측 RGB-D로 한다. 학습 이미지와 계산량을 맞춘 결과 및 가능한 전체 실사 자료를 사용한 결과를 함께 보고한다. 같은 장면·프레임이 중복된 NYU와 SUN 자료는 합산 전에 제거한다. |
| 실사·합성 혼합 지도학습 | 동일 모델에 양쪽 정답을 넣고 혼합 비율을 개발 자료로 고른다. 실사 센서의 신뢰할 수 없는 경계와 결측은 렌더 정답의 경계와 같은 방식으로 감독하지 않는다. 이 조건의 관측된 최고 성능은 실사·합성 혼합으로 닿은 실용 기준이다. |

현재 Apple 체크포인트에서 시작하는 실험은 합성 또는 실사로 **추가 학습**한 비교다. 합성 자료만으로 깊이를 학습했다는 주장을 검증할 때는 모든 조건을 같은 DINOv3 이미지 사전학습 인코더와 새 깊이 디코더·헤드에서 시작한다. 합성 조건에는 실사 RGB-D, 실사 RGB의 의사 깊이와 실사 정답 기반 교사를 추가하지 않는다. 모델 크기·크롭·해상도·업데이트 가능한 범위를 맞춘다. 샘플 노출 수를 맞춘 비교와 같은 GPU 시간의 비교를 모두 기록하고, 방법별 학습률·손실 가중치·종료 체크포인트 선택에 동일한 개발 예산을 제공한다. 마지막에는 시드를 반복한다. [Depth Pro 2 §3.2 및 부록 E.1](https://arxiv.org/html/2611.26603v1#A5.SS1) · [Depth Anything V2 미터 손실 구현](https://github.com/DepthAnything/Depth-Anything-V2/blob/main/metric_depth/util/loss.py) · [NYU 공식 분할](https://cs.nyu.edu/~fergus/datasets/nyu_depth_v2.html) · [SUN RGB-D](https://rgbd.cs.princeton.edu/)

## 공개 가중치와의 비교

- **합성 미터 적응.** Depth Anything V2 Metric Hypersim Small과 Large를 공개 가중치 그대로 평가한다. 미터 단계는 Hypersim이지만 선행 모델 학습에는 실사 RGB로 만든 의사 깊이가 쓰였다. Apple의 D2는 합성만 사용한 좋은 문헌 대조다. 공식 저장소에서 D2 가중치는 확인하지 못했다. [Depth Anything V2 §7.3–7.4](https://arxiv.org/html/2406.09414) · [공식 미터 모델](https://github.com/DepthAnything/Depth-Anything-V2/tree/main/metric_depth) · [Depth Pro 2 표 19](https://arxiv.org/html/2611.26603v1#A5.SS1) · [Apple 공식 공개 파일](https://github.com/apple-aiml-research/ml-depth-pro-2)
- **실사·합성 혼합 최신 모델.** Depth Pro 2-H+와 FoundationGeo를 미터 깊이의 공개 모델 기준에 둔다. 모델에 따라 학습 자료와 계산량이 다르므로 가중치 비교의 성능 차이를 학습법 하나의 효과로 해석할 수 없다. [Depth Pro 2](https://arxiv.org/html/2611.26603v1#S4) · [FoundationGeo](https://github.com/mx-liu6/FoundationGeo)
- **합성으로 배운 형상과 경계.** Hypersim과 Virtual KITTI 2로 깊이 학습을 한 Marigold V2를 상대 깊이·경계에서 비교한다. 이 모델의 출력에 실사 정답으로 미터 환산을 맞춰 절대 깊이 표에 넣을 수 없다. [Marigold V2 학습과 평가](https://arxiv.org/html/2609.08084v1)

## 본시험에서 판단할 기준

- 합성 비교는 [기존 프레임 목록](encoder_training_scale.json)의 8,719 → 23,102 → 59,543장을 이용해 학습 곡선을 그린다. 모두 같은 프레임 선택 규칙을 쓴다. 합성 조건의 선택은 공식 합성 개발 분할로 한다. 실사 학습 조건은 평가 세트와 분리된 실사 개발 분할을 쓴다. 검증 오차가 내려가는 동안 최종 학습량을 다시 점검한다.
- 단안 RGB만 쓰는 조건과 카메라 보정값을 함께 쓰는 조건을 따로 평가한다. 실사 시험 정답으로 예측 스케일이나 오프셋을 맞추지 않는다. 미터 AbsRel·δ1과 깊이 경계, 조명만 바꿨을 때의 깊이 변동, 시점별 오차를 기록한다. 주 비교는 새 실사 실내 데이터와 장면별 조명·시점이 교차된 실사에서 각각 한다. iBims-1과 기존 Middlebury는 이미 탐색에 사용했다. 새 시험 후보는 DIODE 실내와 DTU이고 모델별 훈련 중복, 장면·물체 계열, 스캔 가시성 마스크를 고정하기 전에는 확증 세트로 쓰지 않는다. [DIODE](https://diode-dataset.org/) · [DTU](https://roboimagedata.compute.dtu.dk/?page_id=36)
- 가장 강한 동등 조건 합성 레시피를 개발 자료에서 고른다. 이 대조 대비 새 실사 AbsRel의 상대 3% 이상 감소를 실용 기준으로 두고, 장면을 단위로 짝지은 95% 신뢰구간으로 불확실성을 따로 보고한다. 별도로 실사 단독·혼합 기준과의 실제 차이를 보고한다. 예를 들어 강한 합성 0.150, 제안법 0.132, 실사 지도 0.120이면 합성 대조보다 12% 낮고 실사와의 오차 격차는 60% 줄었다. 이 값들은 예시다.

### 확대 합성 데이터의 실제 보유량

목록과 로컬 파일의 장면·카메라·프레임을 대조했다. 8,719장 학습 목록은 34장, 23,102장 학습 목록은 80장, 1,104장 검증 목록은 8장을 보유하고 있었다. 확대 목록을 다운로드 코드에 연결한 뒤 `ai_001_002`의 `cam_00`과 `cam_01`에서 누락된 쌍을 한 장씩 받아 RGB와 HDF5를 열었다. 두 쌍 모두 1024×768이었다. 첫 학습 목록 보유량은 36장이 됐고, 다운로드를 반복 호출했을 때 보유 파일을 다시 받지 않았다.

[확대 데이터 스크립트](encoder_expand_data.py)는 `--stage train_24` 등으로 보유량을 확인하며, `--fetch`를 함께 지정하면 누락분을 받는다. 기존 인코더 학습기는 고정된 파일럿 NPZ를 읽는다. 확대 목록 기반의 학습 로더와 전체 학습 실행은 아직 연결하지 않았다.

## 공개 모델 채점 결과

기존 iBims-1 실사 100장의 RGB를 모두 320×240으로 시작해 각 모델의 공식 전처리를 적용했다. 같은 기준 깊이와 유효 픽셀을 썼으며 정답으로 예측을 보정하지 않았다. AbsRel과 δ1은 이미지별로 계산한 다음 평균했다. Apple의 두 열은 동일한 역깊이에 각기 예측 초점거리와 실제 초점거리를 적용했다. DA V2는 초점거리 입력을 받지 않는다.

| 공개 모델 | RGB만 사용 AbsRel ↓ / δ1 ↑ | 실제 초점거리 추가 AbsRel ↓ / δ1 ↑ |
|---|---:|---:|
| Depth Anything V2 Hypersim Small | 0.16459 / 76.61% | — |
| Depth Anything V2 Hypersim Large | 0.14339 / 85.68% | — |
| Depth Pro 2-S | 0.32391 / 64.23% | 0.28993 / 66.12% |
| Depth Pro 2-H+ | 0.14916 / 83.44% | 0.09834 / 91.79% |

RGB만 사용한 Large와 H+의 AbsRel 차이(Large−H+)는 −0.00577이다. 이미지 단위 짝 재표집 20,000회(시드 4243)의 95% 구간은 −0.03911~0.02351이다. 이 자료에서 두 모델의 순위를 확정하기 어렵다. 공개 모델의 학습 이력과 크기가 다르다. 이전 인코더 실험의 iBims-1은 실제 초점거리를 제공한 조건이다. 이번 비교는 이미 본 실사와 축소 입력에서 얻은 참고치다.

[채점 코드](compare_hypersim_metric.py) · [DA V2 Small 원자료](da2_hypersim_small_ibims.json) · [DA V2 Large 원자료](da2_hypersim_large_ibims.json) · [Apple S 원자료](depthpro2-s_ibims_reference.json) · [Apple H+ 원자료](depthpro2-h_ibims_reference.json)

공개 모델 네 개를 채점했다. 확대 합성 본시험, FoundationGeo와 Marigold V2 채점, 실사 단독 및 실사·합성 혼합 학습은 실행 전이다.

## 11-25 OpenResearch 선행 검토와 구현

OpenResearch의 본문 검색 및 논문 읽기로 확인한 비교 후보는 아래와 같다. 합성에서 학습한 미터 스케일과 정답으로 정렬한 형상 점수를 함께 해석하지 않는다.

| 연구 | 확인한 조건과 비교 역할 |
|---|---|
| [Depth Pro 2](https://arxiv.org/html/2611.26603v1#A5.SS1) | 표 19 D2는 혼합 학습 기준에서 실사 데이터를 제거한 직접 근거다. 이 논문의 §3.2에 따라 미터 역깊이, 정규화 형상, 3단 경계, 가시성 마스크를 적용한 시점 일관성을 같은 S 모델에서 구현했다. 공개 S 가중치에 추가 학습하며 Apple의 내부 학습 자료와 원래 다중 프레임 훈련은 재현 범위 밖이다. |
| [FlowMoDE](https://arxiv.org/html/2610.41190v1) | Hypersim 54K, H100, 640×480, 배치 4, 400K 학습 스텝. DINOv2-B를 고정했다. 학습 깊이는 이미지별 분위수로 정규화하고, 실사 평가는 Marigold 방식을 따르며 정답 스케일을 쓰지 않은 미터 복원 방식이 명시돼 있지 않다. 실사 형상과 디테일의 중요 비교 후보로 둔다. 논문과 프로젝트 페이지에서 실행 가중치는 확인하지 못했다. |
| [Marigold V2](https://arxiv.org/html/2609.08084v1) | Hypersim와 Virtual KITTI 2, 생성 모델 사전학습. 정렬한 깊이와 경계가 비교 대상이다. 노이즈가 있는 경계에서는 분포를 이용한 손실도 유력한 비교다. |
| [Depth Anything V2](https://arxiv.org/html/2406.09414) · [DA3](https://arxiv.org/html/2511.10647v1) | V2는 미터 Hypersim 가중치를 채점했다. V2와 DA3 모두 합성으로 교사를 만들고 실사 자료를 사용하는 학습 단계가 있다. 합성 레이블만 쓴 단계의 공과를 공개 모델 전체와 분리한다. |
| [FoundationGeo](https://arxiv.org/html/2607.11588v1) · [PatchRefiner V2](https://arxiv.org/abs/2501.01121) | 전자는 미터 스케일에 초점거리 분포가 중요한 직접 근거와 혼합 학습 외부 비교다. 후자는 실사 의사 깊이와 고해상도 경계의 관련 비교다. |
| [LangDepth](https://arxiv.org/abs/2611.11763) | NYU와 KITTI 실측 지도학습으로 DIODE 실내 전이를 평가했다. 별도 백본과 스케일 모델의 외부 참고다. 같은 S 모델에 NYU 실측 정답을 준 실험은 별도로 만든다. |
| [Depth Anyviewpoint?](https://arxiv.org/html/2611.02203v1) · [MonoCal](https://arxiv.org/abs/2611.19188) | 단안 시점 간 일관성의 평가 방법과 관측 신뢰도 보정 선행이다. 예측끼리 일치하는 정도와 미터 오차, 가변 게인과 단순 고정 가중의 효과를 각각 검증한다. |

[데이터 로더](depth_full_data.py)는 공식 목록의 RGB·광선 거리·카메라 자세를 스트리밍하며, 거리에서 카메라 축 깊이를 계산한다. [학습기](depth_full_train.py)는 강한 D2 참고 기준, 같은 시점 관측과 고정 게인, 가변 게인, NYU 실측 지도학습을 분리한다. 실사와 합성의 출발 가중치는 같은 Apple 공개 S다. 학습에는 두 사진이 사용될 수 있지만 예측은 각각 단안으로 만든다.

게인은 각 조명 구간의 로그 깊이 오차 두 개의 평균과 공분산을 이전 미니배치에서 추정한다. 두 오차의 편향 차이를 뺀 뒤 중심화 분산을 전개하면 $(1-K)^2P+K^2R+2K(1-K)C$다. 이 식의 두 번째 미분은 $2(P+R-2C)$다. 양수인 경우 구간 $[0,1]$에서 최소로 하는 값은 $(P-C)/(P+R-2C)$를 그 구간에 제한한 값이다. 불일치와 밝기 구간은 출력 예측과 정답의 관계를 검산할 수 있도록 학습 로그에서 별도로 측정한다. 망의 전체 AdamW 갱신에 대한 최적성은 이 유도로 뒷받침되지 않는다.

## 첫 전체 데이터 비교 실행

[비교 실행기](run_full_depth_comparison.ps1)는 RGB·깊이·자세를 전부 받은 Hypersim 공식 학습 59,543장과 고정 개발 1,104장을 사용한다. 첫 패스에서 합성 조건은 59,543회 갱신과 119,086장 노출이다. 동일한 공개 S 초기 가중치에서 인코더와 디코더를 학습한다. NYU 실사 기준은 [공개 RGB-D 묶음](https://huggingface.co/datasets/adams-story/nyu-depthv2-wds)의 학습 47,584장, 개발 654장을 쓴다. 실사 arm을 이미지 노출 수 119,086장까지 실행한다. 두 장을 사용하는 합성 조건과 단일 장을 사용하는 실사 조건은 업데이트 횟수와 실제 시간이 다르다. 아키텍처나 훈련 자료를 달리한 실사 SOTA의 상한으로 해석하지 않는다.

[미터 평가기](depth_full_eval.py)는 [MoGe 전처리 DIODE](https://huggingface.co/datasets/Ruicheng/monocular-geometry-evaluation)의 실내 325장, 3장면을 장면 동일 가중으로 평가한다. 원래 RGB 해상도를 쓰고 정답 스케일 맞춤 없이 사진만 및 실제 초점거리를 준 경우를 각각 잰다. 동결 모델의 AbsRel은 0.28673 및 0.27273이었다. 사진만 사용한 공개 DA V2 Hypersim Small/Large는 0.27907, 0.22854였다. 모델별 공개 전처리를 적용했다. 실사 시험 오차로 학습이나 체크포인트를 선택하지 않는다. 실내 장면 수가 작아 일반화와 3% 추정의 신뢰구간 해석에 한계가 있다. 조명과 시점이 독립적으로 바뀐 실제 실내 데이터 평가가 따로 필요하다.

64회 이하의 초기 실행은 데이터 로더, 기하 마스크, 옵티마이저, 재개 경로를 확인하는 데 쓴다. 6회 실행 중에는 다운로드가 계속돼 arm별로 읽은 데이터도 달랐다. 64회 점검에서는 합성 세 조건이 같은 491개 후보 목록과 시드를 썼으며 목록의 SHA-256이 모두 일치했다. 전체 데이터 비교와 분리한다. 게인 예제에서 $P=.04$, $R=.09$, $C=.02$이면 최적 $K=.22222$이며 격자 탐색도 .22220을 선택했다.

11-25에 NYU 파일과 Hypersim 개발 파일 확보를 완료했다. NYU 실측 지도학습은 RTX 5090에서 시작했다. 개발 AbsRel은 4,000회 0.13793에서 8,000회 0.11890으로 감소했고 δ1은 84.39%에서 84.97%로 올랐다. 재개 파일에서 모델과 최적화기 상태를 확인했다. 합성 배치의 단안 계산은 사진 간 토큰을 공유하지 않는다. TF32를 끈 점검에서 공식 단안 순차 계산과 역깊이 최대 차이가 $1.55\times10^{-6}$였으며 혼합 정밀도 학습의 기울기가 유한함도 확인했다. 00:39 확인 시 공식 학습 59,543장 중 16,330장을 확보했다. 전체 합성 실행과 DIODE 최종 판정은 대기 중이다.

00:57에는 Hypersim 학습 데이터 28,395장과 NYU 23,800회 갱신을 확인했다. 20,000회 NYU 개발 AbsRel은 0.11014였다. 최종 평가기는 각 학습 완료 기록에서 체크포인트 선택 근거를 읽고, 동일 데이터·학습량·시드로 실행한 합성 대조를 확인한다. D2 또는 고정 게인 중 합성 개발 AbsRel이 낮은 조건을 기준으로 고르고, KF의 실사 상대 개선율과 95% 구간, 실사 지도학습과의 절대 오차 격차를 `research_decisions`에 기록한다. 고른 기준이 시험 점수에 따라 바뀌지 않는지 가상 수치로 검산했다.

### 보조 목표의 오차와 실제 기울기

기존 절댓값 손실은 고정된 목표 $t=\mathrm{stopgrad}(x+K\nu)$에 대해 $\partial |x-t|/\partial x=-\mathrm{sign}(K\nu)$였다. 양의 게인 크기가 지워진다. 고정·가변 조건 모두 $\tfrac12(x-t)^2$로 고쳤다. 이제 픽셀당 미분은 $-K\nu$이며 실제 전체 손실에서는 보조 가중치 0.25와 유효 픽셀 평균이 추가된다. 예를 들어 $\nu=2$일 때 $K=0.1,0.9$의 미분은 $-0.2,-1.8$이다. [학습 코드](depth_full_train.py) · [자동미분 회귀 검산](test_fusion_gradient.py)

공개 동결 S로 이웃 단안 예측을 첫 시점에 되돌려 합성 정답과 비교했다. 고정한 학습 48장면 중 47장면에서 공분산을 추정했고, 별도 개발 46장면에서 장면당 한 쌍을 열었다. 가시점이 있는 42장면을 동일 가중으로 평균했다. 분산·편향 추정값은 검증 전에 동결했으며 두 게인은 같은 픽셀과 같은 편향 보정을 사용한다. 아래는 학습 목표의 로그 깊이 제곱오차다.

| 개발 조건 | 고정 0.5 → 밝기 기반 가변 게인 | 해석 |
|---|---:|---|
| 원래 RGB | 0.11876 → 0.12426 | 가변 목표 오차가 4.63% 큼 |
| 같은 영상 쌍에 서로 다른 감마 적용 | 0.11987 → 0.12021 | 가변 목표 오차가 0.28% 큼 |

학습과 개발 쌍의 프레임 간격 중앙값은 3과 13이다. 실제 공간 조명은 바꾸지 않았다. 대상은 합성 정답 대응점에서 이웃 예측이 0.25~30m에 드는 픽셀이며, 장면별 한 쌍과 과거 공분산만으로 얻은 진단이다. 데이터 출처와 두 시점이 동등한 고정·가변 비교에도, 밝기만 쓴 규칙의 우위는 관찰되지 않았다. 다른 보조 목표와의 순위를 일반화하기 전에 양쪽 예측에 같은 범위 마스크를 적용하고 제외율, 양방향 대응, 시점 간격별 결과를 본다. ### 병목을 구분하는 대조

| 확인 순서 | 무엇을 고정하고 바꾸나 | 무엇으로 다음 선택을 하나 |
|---|---|---|
| 두 번째 관측의 정보량 | 같은 초기화·광선·레이블·유효 픽셀에서 첫 예측, 이웃만, 0.5, 학습 분할에서 추정한 최적 상수, 밝기 조건부, 기하 조건부를 비교한다. 기하 조건에는 깊이 경계까지의 거리, 시차와 이동량, 왕복 투영 잔차를 각각 추가한다. 같은 구간 수·표본과 보정값을 쓴다. 구간 표시를 섞은 음성 대조와 학습 분할에서만 추정한 편향을 공유한다. | 밝기와 시점 간격을 교차하여 장면별 보조 목표 MSE, 유효 면적, 부호 있는 편향, 상관을 본다. 같은 유효 면적에서 튜닝한 상수보다 개발 MSE가 낮은 조건을 독립 개발 장면에서 재검한다. 상수보다 이득이 재현되지 않으면 고정 게인을 유지하고 별도 스테레오·렌더 관측을 학습 중에만 대조한다. |
| 광학과 외관 | 같은 장면에서 카메라 중심·방향과 물체를 고정하고 실제 렌더러의 초점거리만 바꾼다. 별도 조명에서는 광원 위치·세기만 바꾸고 카메라와 정답 깊이를 고정한다. 동일 카메라의 원본/감마는 노출 대조다. 시점만 바꾼 대조도 둔다. | 보정행렬과 깊이의 재투영을 검산한 공통 가시점·전체 영상 양쪽에서 결과를 기록한다. 픽셀 크롭에 따른 내부행렬 변화는 $K'=AK$로 반영한다. 좁은 크롭은 보이는 물체와 해상도도 바꾼다. RGB 점수, 실제 초점거리 점수, 상대 형상과 경계 F1을 함께 보고 거리 배율과 형상 손실을 가른다. |
| 특징과 해상도 | 고정 디코더에서 인코더만 업데이트하고, 같은 출발점에서 디코더만·양쪽 학습을 대조한다. 원해상도 크롭과 단계적 해상도는 동일 토큰·계산량에 맞춘다. | 깨끗한 합성 경계와 실사 센서 결측 경계를 구별한다. 조명만 바꾼 특징 거리와 경계 F1을 잰다. 특징 내용 일관성, 색·질감 통계(style), 생성 RGB 편집은 순서대로 하나씩 추가한다. 형상·가림·정답 불변성을 검산한 편집만 학습에 넣고 고전적 광도 증강도 같은 예산으로 비교한다. |
| 출력과 가중치 | 현재 팔은 두 시점의 융합값을 목표로 삼아 AdamW로 학생을 학습한다. 후속은 같은 RGB에서 얻는 추가 관측을 써서 동결망 출력만 보정하는 조건, 같은 단안망에서 최적화기의 파라미터 갱신만 바꾸는 조건, 두 변경을 합친 조건, 둘 다 끈 기준의 2×2다. | 두 번째 머리나 교사를 쓰면 대조군에도 같은 파라미터·계산·감독 권한을 준다. 파라미터용 게인의 목적함수·오차 모형·근사 곡률을 별도로 유도하고 작은 선형 문제에서 먼저 검산한다. 출력의 최소분산 식으로 신경망 가중치 최적성을 주장할 수 없다. |

Apple의 표 19에서 일반 신뢰도 가중(I4)은 일부 미터 정확도를 높였지만 경계 F1을 낮췄다. #42에서 미터와 경계를 동시에 추적하고, #43에서 가시성·범위가 맞는 관측을 만드는 이유다. DA V2식 SiLog는 같은 S와 같은 쌍·시점 일관성을 유지하면서 미터 손실을 교체하는 선택지로 학습기와 평가기에 추가했다. 이 선택지는 DA V2의 전체 사전학습 재현과 구별한다. ### 확증 시험을 열기 전 고정할 사항

- **학습량**. 지금 실행의 합성 한 바퀴·시드 4243은 첫 탐색 곡선이다. 후속에서는 개발 학습률 두 개(기준값과 그 절반), 각 후보에 동일한 검증 횟수와 연산을 준다. 고정 게인도 학습셋에서 맞춘 상수를 포함한다. 같은 이미지 노출과 같은 GPU 시간에서 각각 비교하고 실제 토큰 수·갱신 수·가시점 수를 기록한다. 동일 종료 예산으로 1→2→4바퀴 개발 곡선을 보고 마지막 구간이 계속 내려가면 모든 최종 후보를 같은 추가 예산으로 연장한다. 충분히 학습했다는 판단은 그 곡선을 근거로 한다.
- **강한 대조와 실사 기준**. 같은 S의 D2 참고법·SiLog 미터 학습·튜닝한 상수 융합 중 개발 RGB 점수가 가장 좋은 것을 고른다. 새 KF를 이 승자에도 붙여 같은 레시피 안에서 게인만 바꾼 결과를 별도로 남긴다. NYU 단독은 실사 기준 한 개다. 실사 장면 출처·중복을 복원한 뒤 장면 분리 실사 개발셋을 만들고, 혼합 지도·실사 단독을 별도 튜닝한다. 출처를 복원할 수 없는 분할은 탐색용이다. 지금 실사 119,086회와 합성 59,543회는 통과 이미지 수만 같고 토큰·업데이트·시간은 다르다.
- **데이터 분할과 체크포인트 선택**. 현재 개발 점수는 실제 초점거리·간격 2·영상 평균, 실사 주평가는 예측 초점거리·원해상도·장면 평균이다. 현재 실행은 이 차이를 표기한다. 확증 실험은 공개 화각 추정기를 공통 동결한 상태에서 개발과 시험을 모두 원해상도 단일 RGB, 장면 동일 가중으로 맞춘다. 합성 전용 추가 학습은 합성 개발 장면만으로 모델을 선택한다. 모델·조건을 고르는 개발 장면과 확인 장면을 분리하고 시험 마스크·단위·RGB 전처리·코드 버전·초기 가중치·프레임 목록을 고정한다.
- **독립 실사와 판정**. DIODE 개발 분할 325장은 3장면이고 화각·과거 공개 모델 탐색에도 사용했다. 여기서의 3%와 신뢰구간은 탐색으로 표시한다. 새로운 실사 다장면 데이터에서 동일 물체의 조명×카메라 교차 촬영을 포함하고 관련 합성·실사 학습 장면과 원본 중복을 조사한다. 구체 장면 ID와 유효 깊이 마스크를 사전 고정하고 개발 장면 간 차이로 필요한 독립 장면 수를 추정한다. 사전 고정한 새 시드 4244·4245·4246에서 동일 장면·시드를 짝지어 구간을 추정하며, 실내 장면별 결과와 실패 장면도 남긴다. 주효과는 $100(1-E_{KF}/E_{강한합성})$이며 점추정 ≥3%와 95% 구간 하한 ≥3%를 따로 표시한다. 실사 추월은 $E_{KF}-E_{실사}$의 점추정과 짝지은 구간 상한 ≤0을 따로 본다. 구간이 넓으면 우열 미판정이다.
