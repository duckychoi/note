# 인코더 위상 진단과 단안 깊이 학습

## 구현 확인

Depth Pro 2는 토큰의 위치를 표시하는 2D RoPE를 이미 쓴다. 패치 행·열을 격자의 긴 변으로 정규화하여 어텐션의 query/key를 회전한다. 모델 출력 q는 초점거리 정규화 역깊이다. 코드의 미터 단위 축 깊이는 Z = f_px/(W q)다. 미터 스케일을 RoPE로 계산하지 않는다. 카메라 중심에서 해당 점까지의 광선 길이는 축 깊이와 다르다.

이번 위상 후보는 기존 RoPE를 고정한 상태에서, 동일 카메라의 조명만 바뀐 두 장을 각각 단안 입력으로 넣고 인코더 토큰 맵의 2D 푸리에 위상 일치를 학습에 추가한다. RoPE의 좌표 회전과 특징 맵의 푸리에 위상은 다른 연산이다. 위상이 불안정한 빈도를 줄이기 위해 두 스펙트럼 진폭 곱의 제곱근으로 가중한다. 합성 정답 깊이와 경계 손실은 그대로 둔다. 일반 지도학습과 공간 토큰 코사인 일치 대조를 함께 둔다.

## 첫 실행

동결 Depth Pro 2-S의 3·6·9·12번째 블록을 꺼내 조명 쌍 40개를 비교했다. 코사인 점수에서 같은 위치가 가로 두 토큰 옮긴 위치보다 얼마나 높은지 봤다. 공간 빔 합성에서 격차는 3·6·9·12번째가 약 0.10, 0.17, 0.26, 0.08이었다. 가장 어두운 실사 T0e0에서도 9번째가 0.10으로 비교한 층 중 컸으나, 균일 감광이나 공간 빔 합성보다 위치 구분이 약했다. 위상 거리도 강한 실사 조명에선 0.60~0.67까지 커졌다. 이 실험은 위치 특징의 진단이며 깊이 경계의 검출 정확도를 직접 측정하지 않는다.

기존 4개 합성 학습 장면에서 마지막 인코더 두 블록 총 3,548,160개를 실제로 128회 갱신했다. 디코더와 나머지 인코더는 동결했다. 이미 사용한 Middlebury 실사에서 앞뒤 정확도는 동결 78.64%, 지도학습 78.87%, 토큰 코사인 78.89%, 푸리에 위상 79.27%였다. 위상 손실의 기존 지도학습 대비 차이는 +0.39%p다. 전체 깊이 MAE는 지도학습 4.854m, 위상 4.891m였다. 최소 3% 기준이나 충분한 학습의 판정에 쓰지 않는다.

## 확장 비교

Hypersim 공식 자료에서 이전 6개 장면과 별도의 학습 20장면(120장), 검증 6장면(36장)을 확보했다. 같은 체크포인트와 데이터에서 인코더 단독 지도학습·코사인·위상 대조 후 디코더 단독 지도학습을 실행한다. 512회씩 동일 샘플 순서로 비교하고 합성 검증은 128회마다 기록한다. 단안 실사 평가에는 이전 Middlebury와 이 연구의 신규 iBims-1 100장을 사용한다. 전체 깊이는 이미지별 AbsRel, 정확도는 δ1로 보고한다. iBims-1은 학습·튜닝에 사용하지 않는다. 이전 결정대로 AbsRel은 상대 3% 감소를 실용 기준으로 둔다. 이번 규모에서도 학습 곡선이 안정되지 않으면 충분히 학습했다고 판정하지 않는다.

이 비교는 인코더 위상 후보의 첫 모델 수준 검사다. 깊이값 보정·관측 신뢰도를 넣은 파라미터 갱신·결합의 확대 학습은 별도 비교로 남겨 둔다. 단계적으로 전역 밝기와 조명 위치를 분리하고, 위치별 위상 신뢰도를 고정 계수·코사인 및 기하 재투영 기준과 비교할 수 있다.

## 확장 실행 결과

학습 120장과 검증 36장은 인코더 업데이트·채점 경로를 확인한 파일럿 규모다. 512회 반복과 이 규모의 리더보드는 본실험으로 사용하지 않는다.

| 조건 | 512회 iBims AbsRel | 합성 검증에서 선택한 단계 | 선택된 iBims AbsRel | 선택된 iBims δ1 |
|---|---:|---:|---:|---:|
| 동결 원본 | 0.28993 | — | 0.28993 | 66.12% |
| 인코더 지도학습 | 0.33211 | 256 | 0.21410 | 65.85% |
| 인코더 코사인 | 0.33124 | 256 | 0.21508 | 65.69% |
| 인코더 위상 | 0.31490 | 256 | 0.21235 | 65.82% |
| 디코더 지도학습 | 0.45246 | 384 | 0.20456 | 66.92% |

512회 끝점에서 위상의 인코더 지도학습 대비 상대 AbsRel 감소는 5.18%였다. 그러나 동결 원본보다 오차가 컸으며 두 인코더의 합성 개발 오차도 후반에 악화됐다. 합성 개발 장면 36장으로 각 비교군의 체크포인트를 다시 골랐을 때 위상은 지도학습보다 0.82% 낮았다(이미지 단위 짝 재표집 95% 구간 −1.34~3.02%). 디코더 단독 학습은 이 iBims AbsRel에서 위상보다 낮았으나, Middlebury 전체 오차에는 같은 순위가 나타나지 않았다. 두 번째 비교는 동일한 iBims 자료를 재사용했고 학습 시드는 한 개다. 학습 규모·데이터·학습 순서가 달라질 경우는 미판정이다.

확장 합성 26장면의 공식 카메라 자세도 내려받았다. 후속 교차 시점은 카메라로 같은 표면에 정렬한 뒤, 위상 신뢰도와 독립 스테레오 신뢰도를 비교할 수 있다. 이 시점 간 위상 및 KF 결합은 이번 결과에 포함되지 않는다.

## 본실험 규모 정정

Hypersim 공식 공개 분할에서 학습 365장면 59,543장, 검증 46장면 7,386장, 시험 46장면 7,690장을 재집계했다. 모든 학습 장면을 포함해 장면당 최대 24장인 8,719장으로 학습 곡선을 시작하고, 같은 장면에서 최대 64장인 23,102장과 공식 학습 전체를 비교 가능한 후보로 둔다. 검증은 공식 검증 46장면에서 최대 24장씩 1,104장을 고정한다. 이전 120장으로 고른 파라미터를 본실험 결과에 소급하지 않는다.

8,719장은 확대 비교의 출발량이다. 데이터량·학습량을 늘린 곡선과 고해상도 경계 결과를 확인한 뒤 학습 충분성을 판정한다. 본실험의 주 비교는 같은 모델에서 재구현한 강한 합성 레시피다. 실사 단독 및 실사·합성 혼합 지도학습과의 격차도 잰다. [본실험 프레임 목록](encoder_training_scale.json) · [학습법과 공개 모델 비교 기준](BENCHMARK_PROTOCOL.md)
