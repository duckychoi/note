# 동일 Depth Pro 2-S에서 합성 학습 방법 비교

## 점수 확인 전 고정한 설계

공개 Depth Pro 2-S의 본체와 체크포인트를 고정하고, 동일한 픽셀별 선형 로그 깊이 보정층을 학습한다. 기존 Middlebury 출력은 동일 체크포인트에서 생성한 보관 예측을 사용한다. 모델 간 크기나 사전학습 차이를 만들지 않는다.

Apple Hypersim의 장면 ai_001_001, ai_002_001, ai_003_001, ai_004_001에서 학습하고, ai_005_001과 ai_006_001에서 게인과 합성 검증 점수를 계산한다. 각 cam_00의 프레임 0, 11, 22, 33, 44, 55, 66, 77 중 공식 공개 파일이 있는 프레임을 사용한다. 최종 시험은 기존 Middlebury Mobile의 19시점과 동일한 유효 마스크를 사용한다. Middlebury 정답은 최종 채점에서만 쓴다. Apple 사전학습에 Hypersim이 포함됐으므로 합성 점수는 적응 확인용이다.

RGB 다양성 비교는 원본과 기하를 그대로 둔 노출·감마·색온도 편집을 사용한다. 생성 모델 편집은 실제 샘플의 기하 보존을 검증한 뒤 별도 비교군으로 추가한다. 이번 노출 변형을 생성 모델 데이터로 부르지 않는다.

비교 조건은 동결, 원본 합성 정답 AdamW, 노출 변형을 함께 쓰는 정답 AdamW, 출력 융합 + AdamW, 정답 칼만식 파라미터 갱신, 출력 융합 + 칼만식 갱신이다. 두 옵티마이저는 같은 관측, 같은 초기값, 같은 제곱오차와 약한 수축을 쓴다. AdamW는 전체 자료의 충분통계에서 1,200번 갱신한다. 칼만식은 이미지 블록별로 한 번 갱신한다. 닫힌형 릿지 해를 추가해 선형·고정 공분산에서 칼만식과 같은 해인지 확인한다. 실행 시간의 공정 비교는 이 설계에 포함하지 않는다.

융합 게인은 합성 검증 장면에서 두 노출 추정의 제곱오차가 가장 작아지도록 고정한다. 두 오차가 같은 모델에서 나왔다는 상관을 무시하지 않고 두 예측의 차를 직접 쓴다. 일반 지도학습과 융합 학습 모두 합성 정답을 사용한다. 융합 방식에서만 표준 노출과 변화 노출의 보정된 출력을 보조 목표로 사용한다.

실사 평균 절대 깊이 오차, 깊이 차이 절대오차, 앞뒤 정확도를 장면 계열별 동일 가중으로 비교한다. 기존에 사용한 실사 시험을 다시 쓰는 소규모 탐색이며, 관문 통과나 일반화 증명을 판정하지 않는다.

## 생성형 조명 편집의 별도 검산

첫 학습 장면의 첫 Hypersim 프레임을 내장 ImageGen으로 조명만 바꾸도록 편집했다. 원본 1024×768 크기로 되돌린 뒤 SIFT 양방향 일치와 0.7 비율 검사를 적용했다. 19개 대응 특징 중 15개만 같은 좌표로부터 2픽셀 이내였다. 이동 중앙값은 1.02픽셀, 90분위는 2.95픽셀이었다. 이 수치는 매칭된 희소 점에만 적용된다. 원본의 오른쪽 아래 수납장 위에 없던 접시도 추가됐다. 편집본 전체에 원본 깊이 정답을 붙이지 않았으며 아래 모델 비교에도 사용하지 않았다.

요청 문장:

> Relight the exact reference bathroom from daytime to warm tungsten evening light. Change only illumination, shadows, and color temperature. Preserve the 4:3 uncropped framing, camera roll, perspective, window and blind geometry, all furniture and objects, mirror, sink, tiles, and the exact pixel placement of structural edges. Keep the existing room; do not add, remove, move, or redesign any object. This is a strict geometry-preservation research example.

## 실행 결과

**해석 정정(11-24).** 동결 모델 뒤의 **선형 계수 7개**를 합성 4장면 32장으로 학습한 예비 시험이다. 1,200회 갱신은 주어진 작은 선형 문제의 수렴을 확인한 것이다. Depth Pro 2-S의 디코더나 백본을 충분히 합성 학습했을 때의 성능은 이 결과로 판정할 수 없다.

공식 Hypersim 6개 장면에서 각 8장씩 내려받았다. 32장은 보정층 학습, 나머지 16장은 게인 적합 및 합성 개발 점수 계산에 썼다. 같은 이미지의 원본/변형 96개를 동일한 공개 Depth Pro 2-S 체크포인트로 추론했다. 유효하지 않은 모델 출력은 원본 5픽셀과 변형 7픽셀이다. 어느 한쪽의 예측이 불량한 위치는 모든 학습 조건에서 공통 제외했다. 기존 실사 동결 기준과 체크포인트 해시를 대조했다.

| 학습 조건 | 실사 전체 오차 mm | 실사 단차 오차 mm | 실사 앞뒤 정확도 |
|---|---:|---:|---:|
| Depth Pro 2-S 동결 | 4,908.0 | 777.6 | 78.64% |
| 원본 합성 정답 + AdamW | 4,961.5 | 856.1 | 65.18% |
| 노출 변형 포함 합성 정답 + AdamW | 4,956.2 | 854.1 | 65.44% |
| 출력 융합 + AdamW | 4,951.3 | 840.5 | 66.41% |
| 노출 변형 포함 합성 정답 + 칼만식 갱신 | 4,956.2 | 854.1 | 65.44% |
| 출력 융합 + 칼만식 갱신 | 4,951.3 | 840.5 | 66.41% |

출력 융합의 개발 게인은 1이었다. 이번 구현에서는 보조 깊이가 원본 노출 예측과 같아졌다. 변형 예측과 원본 예측의 개발 로그 깊이 MSE는 각각 0.27769와 0.26407이다. 별도 확증 표본에서 융합이 원본을 개선하는 근거는 얻지 않았다. 원본/노출 변형 기초 학습보다 융합 결합군의 앞뒤 정확도가 0.97%p 높았지만 동결 가중치보다 12.22%p 낮았다.

같은 선형 층과 제곱오차에 대해 칼만식과 AdamW의 최종 파라미터 최대 차이는 두 비교 모두 (4\times10^{-15}) 이내였다. 칼만식의 결과가 닫힌형 릿지 해와 같음을 실행 중 확인했다. 이 조건에서 최적화기만 교체해서 전이 성능이 달라질 근거는 없다. 실제 카메라 이동을 보정한 관측과 위치별 신뢰도는 이번 실험에 포함하지 않았다. 독립 실사 데이터에서의 확증도 남아 있다.

노출 변형을 포함한 지도학습 대비 앞뒤 정확도 차이는 0.97%p(상대 약 1.49%)로 사용자 최소 3% 개선 기준에 미달한다. 동결 기준과의 차이는 이 일곱 계수 적응 결과에 한정된다. 수렴한 해의 일치는 선형·고정 관측 모형에 해당한다. 더 큰 적응층, 제한된 학습 예산, 변하는 신뢰도에서 두 방식의 차이는 미판정이다.

## 충분한 학습 후 비교할 조건

일반 지도학습은 파일럿 대조로 남긴다. 확대 실험의 비교 대상과 실사 지도학습 기준은 [본시험 비교 기준](BENCHMARK_PROTOCOL.md)을 따른다.

최종 과제는 단안 깊이 추정이다. 모든 비교군은 배포·시험에서 RGB 한 장과 같은 조건으로 주어진 카메라 내부 파라미터만 사용한다. 스테레오 또는 다른 시점에서 얻은 관측은 별도의 학습용 교사 후보로만 사용하고, 합성 렌더 정답만으로 학습하는 단안 기준과 비교한다. 이전 시험에서 학습한 것은 모델 밖의 출력 보정 계수 7개다. 디코더·백본을 미세조정한 시험은 아직 없다.

Depth Pro 2 부록 표 19에서 DINOv3를 동결한 H2는 L 기준보다 DynamicReplica 경계 F1이 7.0%p 낮았다. 예측 신뢰도로 역깊이 손실에 가중치를 준 I4도 경계 F1이 6.8%p 낮았다. 42번 후속 비교에서는 확실한 합성 깊이 정답의 경계 손실을 유지하고, 신뢰도는 추가 관측의 영향에만 적용하는 조건을 비교한다. [Depth Pro 2 부록 E.1](https://arxiv.org/html/2611.26603v1#A5.SS1)

- 인코더부터 확인한다(사용자 지시). 같은 장면·카메라의 조명만 바꾼 영상에서 동결 인코더의 여러 층을 꺼내, 대응 위치의 특징이 얼마나 바뀌고 깊이 경계는 얼마나 남는지 비교한다. 다음으로 같은 초기 체크포인트에서 인코더 쪽 학습을 먼저 비교하고, 디코더만 학습한 대조 및 두 부분을 함께 학습한 대조로 확장한다. 공식 공개 합성 자료의 서로 다른 장면 수를 늘리고 프레임 수와 고유 장면 수를 따로 센다. 일반 미세조정은 비교 기준으로 두고, 연구 후보는 조명과 가림에 따라 관측 신뢰도를 추정하고 학습 갱신에 사용하는 방법이다.
- 동결, 일반 지도학습, 출력 보정, 파라미터 갱신, 결합을 유지한다. 학습 가능한 층과 모델 크기가 같은 비교를 포함한다. 방법마다 학습률과 규제를 같은 검증 예산에서 선택한다. 데이터량과 학습량을 늘릴 때 합성 개발 점수가 어떻게 움직이는지 남긴다. 검증 성능이 계속 달라지는 동안에는 학습 예산이 충분했다고 판정하지 않는다.
- 시드를 반복하고 최종 비교는 기존 파일럿에서 쓰지 않은 실사 장면에서 한다. 실용 기준은 앞뒤 정확도 3%p 상승, 깊이 오차는 상대 3% 감소로 우선 정의한다. 앞뒤 정확도의 상대 개선율과 장면별 불확실성도 함께 기록한다.

## 합성 학습과 실사 전이에서 지킬 비교

- **기하와 외관을 분리한다.** 장면과 카메라를 고정하고 물리적으로 재렌더한 RGB 쌍은 깊이·가시성 정답의 재사용을 검산한다. 생성형 편집의 픽셀은 윤곽이나 가려짐이 바뀌면 기존 정답을 폐기한다. Dense 깊이, 경계 기울기, 얇은 구조, 앞뒤 순서를 기하 점검에 사용한다.
- **스타일은 입력과 특징에서 따로 비교한다.** 노출·카메라 응답·센서 잡음·조명 배치·재질을 바꾸는 RGB 증강과, 같은 표면의 중간 특징을 정렬하는 보조 손실을 각각 켜고 끈다. 스타일 통계나 푸리에 진폭 정렬은 후보로 비교한다. 스타일 손실로 기하 손실을 덮지 않는다. 조명에 깊이 기반 감쇠를 쓸 때는 특정 광원과 밝기만으로 정답을 맞히는 지름길을 점검한다.
- **초기화와 학습 단계를 명시한다.** 현재는 공개 체크포인트에서 인코더를 적응시키는 비교다. 처음부터 학습, 합성 사전학습, 혼합 재학습, 특징 정렬, 교사 증류는 서로 다른 실험 조건으로 기록하고 필요한 비교만 실행한다. 실사 RGB로 스타일 통계를 맞추는 경우 실사 비라벨 데이터를 사용했다고 별도로 명시한다. 독립 실사 시험의 이미지·통계·정답은 훈련과 선택에서 분리한다.
- **관측 신뢰도를 분리해 검증한다.** 확실한 렌더 정답에는 기본 지도 손실을 적용한다. 교차 시점·생성 편집에서 얻은 추가 관측에만 신뢰도를 적용한 조건을 기본 혼합, 고정 가중, 가변 가중과 비교한다. 데이터 양, 검증 튜닝, 초기화와 체크포인트 선택 조건을 공유한다.
