# #42 B. 편향 분리 교사의 연속 깊이 검증과 단안 전이

공개 Depth Pro 2-S 특징 위의 기존 합성 사전과 Middlebury 좌우 시차 관측을 사용했다. 보정 계열 4개에서만 참 깊이로 합성 사전의 위치·분산과 반복 시차 중앙값 오차의 경험분포를 따로 적합했다. 온도는 보정 계열을 하나씩 뺀 비교에서 골랐다. 두 사전 모두 0.1이 선택됐다. 보정 시차는 이전과 같은 카메라 배치로 촬영한 네 조명·노출 관측을 중앙값으로 먼저 모아 사용한다. 그 관측들의 일치를 독립 우도의 곱으로 세지 않는다.

이전 보류 4계열·9장면에서 기존 숫자 0.0747을 재현했다. 이전 대조에는 깊이 후보의 범위 제한과 반올림이 들어갔다. 같은 영상·점에서 선을 따라 연속으로 거리 값을 쓰면 직접 중앙값은 0.006064다. 미터 단위의 중앙값은 0.006040이다. 로그 중앙값과 미터 중앙값의 차이는 표본 수가 짝수일 때 가운데 두 값을 기하평균 또는 산술평균하는 데서 온다.

두 편향을 보정한 교사는 연속 로그 중앙값보다 점추정이 0.402% 낮았다. 보류 계열 네 곳의 짝 재표집 구간에는 0이 들어갔다. 미터 단위 중앙값과는 측정된 차이가 작았다. 합성 사전 없이 반복 오차만 보정한 교사도 결합 교사보다 약간 낮았다. 합성 사전 중심의 편향은 실제로 줄었지만, 이 단서의 보정 뒤 로그 RMSE는 시차 중앙값의 약 9배였다. 합성 사전 보정이 직접 중앙값을 넘어서는 이득을 얻었다고 판단할 근거가 없다.

점추정이 잠근 연속 로그 대조를 앞섰으므로 단안 전이도 실행했다. 동일 공개 인코더의 동결 특징, 같은 데이터·초기화·배치와 업데이트 수를 사용했다. 세 시드에서 합성 360회와 합성·실사 혼합 300회를 각각 수행했다. 두 학습군은 하나의 129개 공통 로그 깊이 격자에 연속 타깃을 인접 후보로 분배한다. 직접 감독과 분포 교사의 공통 결정은 AbsRel의 역깊이 가중 중앙값이다. 평가에는 RGB 한 장만 사용했다. 실행 범위는 출력 헤드의 학습이다. 외부 평가는 앞선 PF42의 같은 표본 격자 자료이며, 테스트 영상은 훈련이나 온도 선택에 넣지 않았다.
