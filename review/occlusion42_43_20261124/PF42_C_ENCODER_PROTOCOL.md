# #42 C. 실제 인코더 가중치 방향에서 관측 편향과 갱신 불확실성 분리

## 가정과 바꾸는 성분

이전 C의 두 출력 계수에서 벗어나 공개 Depth Pro 2-S 마지막 네 블록 자체의 가중치 \(\theta\)를 바꾼다. 이전에 똑같은 적응 사진에서 학습한 직접·공유·배율 분리 가중치로, 별도 자료의 깊이 정답을 보기 전에 세 방향 \(V\)를 고정한다. 방향은 Apple 공개 가중치에서 직접 인코더로 간 변화, 직접 인코더에서 공유 인코더로 간 변화, 같은 직접 인코더에서 배율 분리 직접 인코더로 간 변화다. \(\theta=\theta_d+Vu\)이고 \(u\sim N(0,I)\)다. \(J\)는 방향당 ±1에서의 실제 인코더 출력 로그 깊이 차이의 절반이다. 선형화는 \(y\approx Ju\)로 두며 실제 가중치를 합친 인코더의 평가도 따로 한다. 이 세 방향의 검증을 전체 인코더 또는 AdamW의 일반 대체로 해석할 수 없다.

실사 장면 \(g\)의 사진들에서 얻은 광도 시차 중앙값 로그 깊이의 잔차를 \(y_g\), 같은 장면에 공통으로 생기는 시차 편향을 \(b_g\)라 둔다. 기존 독립 점 갱신은 편향을 직접 모형화하지 않는다. C의 관측식은 \(y_g=J_gu+\mathbf1 b_g+\epsilon_g\)다. 실험에서는 가까운 화소를 독립 데이터로 중복 세는 것을 피하기 위해 장면당 관측점 \(n_g\)에 대해 \(\epsilon_g\sim N(0,n_g\sigma^2 I)\)를 고정하고 \(\sigma=.25\)를 쓴다. 장면 편향이 일반적인지 큰지의 사건 \(c_g\)를 \(P(c_g=1)=.20\)으로 둔다. \(b_g\mid c_g\sim N(0,\tau_{c_g}^2)\), \(\tau_0=.08,\tau_1=.60\)으로 두며 정답을 보고 수치를 적합하지 않는다.

## 정리와 대조

\(b_g\)를 적분하면 \(y_g\mid u,c_g\sim N(J_gu,n_g\sigma^2 I+\tau_{c_g}^2\mathbf1\mathbf1^\top)\)이다. 평균 방향과 평균 0 부분을 직교 분해하면 음의 로그우도의 이차항은 상수 배율을 제외하고

$$\frac{\|y_g-\bar y_g\mathbf1-(J_g-\mathbf1\bar J_g)u\|^2}{n_g\sigma^2}
+\frac{(\bar y_g-\bar J_g u)^2}{\sigma^2+\tau_{c_g}^2}$$

이다. 두 부분에 대한 고유값이 각각 \(n_g\sigma^2\), \(n_g(\sigma^2+\tau_{c_g}^2)\)이기 때문이다. 따라서 장면 편향이 클 때 평균 오프셋 정보만 약해지고 상대 형상 잔차의 정보는 유지된다. 어떤 방향 \(v\)가 장면마다 로그 깊이의 공통 배율만 바꾸면 \((J_g-\mathbf1\bar J_g)v=0\)이다. 이 방향의 각 장면 정밀도는 \((\bar J_g v)^2/(\sigma^2+\tau_{c_g}^2)\)이고, 편향 분산이 매우 크면 0으로 수렴한다. 같은 편향을 공유한 화소를 추가한다고 절대 배율이 식별되지는 않는다. \(\tau_0=\tau_1=0\)이면 독립 가우시안 모형으로 환원된다.

각 편향 상태의 조합을 고정하면 제곱 완성으로 \(u\)의 사후분포는 가우시안이다. 전체 분포는 이들의 유한 혼합이며, 각 가중치는 해당 상태 사전확률과 적분 우도의 곱에 비례한다. 여섯 장면은 64상태이므로 정확 열거를 먼저 한다. 단일 가우시안에서 사후 평균과 MAP가 같으므로 이 경우 점 가중치 갱신과 사후 평균 가중치 갱신은 같은 예측을 낸다. 서로 다른 두 상태에서 사후 평균이 각각 \(0,2\)이고 가중치가 \(.75,.25\)이면, 폭이 충분히 좁을 때 MAP는 0 근방이고 평균은 0.5다. 두 결정을 비교하려면 같은 혼합 우도를 써야 한다.

## 비용을 제한한 실제 자료 대조

- 위 세 실제 가중치 방향을 첫 시드의 기존 체크포인트에서 고정한다. `delivery_area, relief, pipes, office, courtyard, kicker`의 RGB·카메라 시차 중앙값만 가중치 갱신에 쓴다. B 때 제공한 LiDAR는 이 업데이트에서는 읽지 않는다. 정답을 학습에 쓰지 않는다.
- 공개 S, 기존 직접 인코더, 독립 가우시안 갱신, 장면 공통 편향 단일 가우시안, 동일 혼합 우도의 다중 초기점 MAP와 사후 평균 가중치를 대조한다. 유한 가우시안 혼합 MAP는 각 성분과 전체 평균에서 시작한 수치 최적화이며, 전역해를 보장하지 않는다. 마지막 팔은 평균 계수를 넣은 단일 인코더다. 여러 인코더의 사후예측 평균이나 AbsRel을 직접 최소화하는 사후예측 결정과는 다르다.
- `playground, terrace`의 9장에 RGB 한 장씩만 넣고 실제 가중치를 합친 인코더로 AbsRel을 채점한다. 이 시험은 C의 가중치 방향과 센서 모형이 식별 가능한지 확인하는 진단이다. 이전 B의 독립 벤치마크 문턱을 이 실험으로 대신하지 않는다. 세 방향의 정보 고유값, 편향 상태의 사후 질량, 선형 근사 오차를 함께 기록한다.
