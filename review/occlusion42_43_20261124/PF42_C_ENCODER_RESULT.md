# #42 C. 실제 인코더 가중치 방향의 정보량 진단

## 실제 인코더의 갱신

기존 Depth Pro 2-S의 마지막 네 블록에서 이미 학습된 변화 방향 세 개를 고정했다. 여섯 DSLR 장면의 15,904개 시차 지점으로 장면 공통 편향을 고려한 가중치 사후분포를 계산했다. 여섯 장면의 두 상태 조합 64개를 정확 합산했다. 이 업데이트에서는 LiDAR를 읽지 않았다. 최종 평가에는 별도 `playground`, `terrace`의 9장, 2,302개 LiDAR가 있는 지점을 사용했다. 사진 한 장만 실제 네트워크에 넣었고, 표의 AbsRel은 두 장면에 같은 가중치를 준다. [관측식과 증명](PF42_C_ENCODER_PROTOCOL.md)

| 실제 단안 인코더 가중치 | AbsRel ↓ |
|---|---:|
| Apple Depth Pro 2-S | 0.291118 |
| 기존 직접 감독 | **0.264611** |
| 독립 가우시안 갱신 | 0.275393 |
| 단일 장면 편향 가우시안 갱신 | 0.275669 |
| 혼합 우도의 수치 MAP | 0.275797 |
| 같은 혼합 우도의 사후 평균 가중치 | 0.275888 |

혼합 사후 평균의 오차는 기존 직접 인코더보다 4.26% 높았다. 다른 갱신도 기존 직접 인코더를 넘지 못했다. 같은 센서 모형에서 MAP와 평균 가중치의 차이는 AbsRel 0.000091이다. 사후 평균은 계수의 평균값으로 한 번 추론한 점 결정이다. 사후예측 앙상블과 구분한다.

가중치 방향의 독립 가우시안 관측 정보 고유값은 0.02590, 0.44144, 1.22027이었다. 적용한 계수 척도와 고정 prior에서 해석하는 수치다. 혼합 사후의 표준편차는 0.710, 0.870, 0.961로 prior의 1과 비교해 일부 방향의 정보가 적었다. 실제 인코더에서 평가한 로그 깊이 갱신과 선형 근사의 영상별 평균 오차는 평균 가중치 기준 0.00262였다. 관측 정보의 방향을 바꾸지 않은 채 적분 방식만 변경해 큰 개선을 기대하기 어렵다는 진단이다. 여섯 입력 장면과 보류의 두 장면은 연구에서 이미 사용한 DSLR 자료이며, 이 C 시험은 독립 장면에서의 재사용 자료 진단이다. 전체 인코더 분포나 입자 추정기의 성능은 평가하지 않았다.

원자료와 가중치 조합은 `research-sources/encoder42_eval/pf42-trials/crossview-b/c-encoder/results.json`에 있고 `pf42_c_encoder.py`로 재현한다.
