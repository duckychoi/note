# #43 광도 스테레오 관측과 #42 단안 전이

## 문제와 식별 조건

카메라와 물체를 고정하면 픽셀 p에서 보는 표면의 카메라 축 깊이 Z(p)는 모든 조명에서 같다. 정면에서 뒤로 갈수록 어두워지는 법칙을 가정하지 않는다. 선형 RGB 밝기에서 광원 없는 프레임의 밝기를 뺀 값 y_k에 대해, 직접광을 받는 이상적 무광 표면은 y_k = s_kᵀg + e_k를 만족한다. s_k는 세기를 포함한 알려진 광원 방향, g = ρn은 반사율 ρ>0과 단위 표면 법선 n의 곱이다. 감마와 톤 맵을 먼저 역변환한다. 그림자, 포화, 거울 반사가 모델 오차 e를 만든다.

고정된 양의 가중치 W에서 A = W^(1/2)S의 열 계수가 3이면 ĝ = A†W^(1/2)y이다. y = Sg + e를 대입하면 A†A = I 이므로 ĝ−g = A†W^(1/2)e이고, 그 길이는 ||W^(1/2)e||₂ / σ_min(A) 이하이다. 이 상한이 ρ보다 작으면 ĝ가 영벡터가 아니며, 법선을 정규화할 수 있다. 잔차가 작아도 반사가 S의 열공간과 같은 방향을 만들면 법선에 편향이 남는다. IRLS에 관해서는 계산 후 얻은 가중치를 고정했을 때의 이 항등식만 사용한다. 실제 e의 상한은 주장하지 않는다.

핀홀 카메라에서 r_p = K⁻¹[u_p,v_p,1]ᵀ, X_p = Z_p r_p이다. 같은 평면 위에 두 점이 있으면 nᵀ(X_q−X_p) = 0이다. 두 광선의 내적이 같은 부호이고 0에서 떨어져 있으면 Z_q/Z_p = (nᵀr_p)/(nᵀr_q)이다. 로그로 쓰면 픽셀 사이의 형상 제약 d_n = log|nᵀr_p|−log|nᵀr_q|이다. 곡면에서는 양 끝 법선을 평균한 국소 근사로 사용한다. 경계를 가로지르면 가정이 깨진다. 같은 법선의 벽을 2m에서 4m로 옮기면 알려진 평행광과 무광 조건에서 픽셀의 밝기는 동일할 수 있다. 모든 Z에 같은 양의 상수를 곱해도 식이 같아 절대 거리에는 별도 기준이 필요하다.

## 관측 시험

기존 재질·광원 실험의 Hypersim 장면 계열 분할을 재사용한다. 합성 학습 32개와 독립 합성 검증 16개다. 고정 카메라에서 기존 표면과 차폐 메시를 8개의 보정된 평행광 및 주변광 단독 조건으로 새로 렌더링한다. 무광과 코팅 재질을 모두 만든다. 교사는 각 재질의 RGB, 광원 방향·세기, 주변광 단독 RGB, 카메라 내참수만 받는다. 참 법선·깊이·재질 ID는 광도 스테레오의 해를 만들 때 사용하지 않는다. 참 깊이는 기하 후보 채점과 단안 감독에, 렌더러의 법선은 각도 채점에 사용한다.

선형화 후 밝기 증가가 0.008 이하인 관측을 제외한다. Huber 가중치로 고정 4회 보정하고, 양의 밝기 관측 ≥5개, 가중 행렬 σ_min≥0.35, 상대 RMS 잔차 ≤0.12인 법선만 통과시킨다. 이 기준은 재렌더 결과를 채점하기 전에 고정한다. 각도 오차와 관측률을 모두 기록한다. 렌더러 법선에는 범프 등 실제 깊이 차분과 다른 요소가 있을 수 있어, 정답으로 별도로 채점한 8픽셀 로그 깊이비를 반드시 보고한다. 두 점 모두 같은 참 렌더 ID이고 실제 깊이비가 1.05 이내인 곳을 형상 진단에 사용한다. RGB 밝기와 법선 각도만으로 미터 오차 감소를 판단하지 않는다.

## 단안 학습

전체 Hypersim에서 학습한 Depth Pro 2-S D2의 같은 체크포인트에서 시작한다. 모든 조건에서 32장면 × 두 재질 × 8 조명 = 512장, RGB를 한 번에 한 장씩 입력한다. 동일한 순서·AdamW 설정·동일한 인코더 마지막 4블록(~710만 개)을 각 1,024번 갱신한다. 복제한 블록 이외의 가중치는 동일하게 고정한다. 다음 표의 보조 손실은 8픽셀 로그 깊이비에 대한 평균 Smooth L1이며, β와 가중치는 모두 0.02와 0.5이다. 1024×768 원래 해상도에서 RGB를 처리하며 GT 감독은 동일한 정규화 역깊이 절사·정규화·기울기 손실(D2 재현)을 4픽셀 간격에서 계산한다.

| 조건 | 동일 RGB 증강·D2 감독 | 보조 목표 |
|---|---|---|
| 조명 증강 | 적용 | 없음 |
| 광도 스테레오 | 적용 | RGB 여러 장으로 푼 광도 법선 → 국소 로그 깊이비 |
| 참 기울기 | 적용 | 광도 조건이 통과시킨 바로 그 위치에서 참 깊이비 |

보조 위치는 교사의 통과와 시선 내적 기준을 써서 정한다. 학습 때는 추가로 같은 참 렌더 ID와 깊이 유효성·연속성으로 경계 횡단을 제한하고, 두 보조 조건의 마스크를 일치시킨다. 참 기울기 조건은 우리가 이미 가진 합성 감독을 같은 위치에 더 주었을 때의 대조다. 실제 깊이비 개선의 이론적 상한으로 쓰지 않는다. 광도 해·광원·참 깊이는 학생의 추론 입력에서 제외한다. 학생이 동일한 로그 깊이비를 실수한다면 광도 교사의 기하 정보가 충분히 전이되었다는 판단을 내리지 않는다.

동결 시작점도 함께 채점한다. 합성 16개 가족에서 별도 검증한다. 실사 HAMMER 775장을 주 평가, DIODE 실내 325장과 iBims-1 100장을 별도 반복 평가로 사용한다. 세 자료 모두 이전 다른 후보에서 열었으며 이번 적합이나 선택에는 사용하지 않는다. 세 실사 평가에는 최종 1,024회 체크포인트만 사용한다. 정답으로 출력 배율을 맞추지 않으며 배포 시 초점 추정기를 동일하게 사용한다. 주 지표는 장면 평균 AbsRel, 보조 지표는 영상별 로그 깊이 오차의 분산 평균이며 장면을 짝지어 재표집한다. 해당 자료의 상대 3%는 점추정과 불확실성 구간을 별도로 판단한다. 기하·재질이 같은 장면을 더 많이 비춘 실험의 결과를 전체 규모 학습이나 최종 SOTA 판정으로 해석하지 않는다. 이 실험은 기존 광도 스테레오 관측이 줄 수 있는 학습 신호를 분리하는 검증이며 신방법의 신규성을 주장하지 않는다.

구현에서 채널별 역변환을 마친 뒤 휘도로 합산한다. 관측에서 제외한 행은 가중치가 0이다. 계산에서는 10⁻⁶ 리지로 비가역 행렬을 처리하지만 관측 채택 기준은 리지 정규화 이전 행렬에 적용한다. 각도·형상 진단은 원래 카메라 내참수를 사용해 4픽셀 간격에서 계산한다. 법선으로만 식별하는 배율은 각 연결성분에서 모호하다.
