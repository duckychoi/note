# #42 동결 D2의 배율·형상 손실 진단과 보존형 순차 학습

## 분해와 검정

같은 RGB와 공통 초점 추정기를 사용한다. 깊이 D, 정답 Z에서 점별 로그 오차 e=log(D/Z)를 두고, 공통 유효 마스크에서 a=mean(e), s=e−a로 정의한다. 합이 0인 s를 대입하면 mean(e²)=a²+mean(s²)이다. exp(a)는 예측과 정답의 기하평균 깊이비다. mean(s²)는 한 장 내 전체 배율을 제외한 형상 오차이고, 별도로 실제 깊이비가 1.05 이내인 가로·세로 8픽셀 간격 점쌍의 로그 깊이비 오차도 측정한다. 이 점쌍은 깊이 연속 영역의 근사다.

원래 AbsRel 손실은 이 두 제곱오차로 쪼개지지 않는다. 동결 0, 기존 입자 학습 1에서 A_ij=mean|exp(a_i+s_j)−1|을 모두 계산한다. 배율 기여를 [(A_10−A_00)+(A_11−A_01)]/2, 형상 기여를 [(A_01−A_00)+(A_11−A_10)]/2라 두면 합이 A_11−A_00이다. 흩어지는 상호작용 변화는 바꾸는 순서 두 개의 평균으로 나눈다. 정답을 본 분해이며 훈련·배포에 전달하지 않는다. 인과적 학습 원인으로 해석하지 않는다.

## 보존과 3% 개선을 보장하는 조건

동결 깊이 D0와 후보 D1 사이의 배포 깊이를 Dλ=(1−λ)D0+λD1로 둔다. λ∈[0,1]이며 RGB 등 추론 때 허용된 정보만으로 고정한다. 실사 Z>0마다 절대값의 볼록성으로

```text
|Dλ/Z−1| ≤ (1−λ)|D0/Z−1| + λ|D1/Z−1|.
R_Q(D0)−R_Q(Dλ) ≥ E_Q[λ (ℓ(D0,Z)−ℓ(D1,Z))].
```

따라서 가중치 λ가 각 검증 조건 g 안에서 λ_g로 일정하고, 실제 평균 이득이 0 이상인 곳에만 가중치를 주면 목표 위험은 증가하지 않는다. 조건부 이득 하한을 b_g라 하면 Σ_g P_Q(g)λ_g b_g ≥ 0.03 R_Q(D0)이 3% 개선의 충분조건이다. 가중치가 그룹 안에서 달라지면 위 식 대신 가중 이득 자체를 검증해야 한다. 이 증명은 전체 장면을 동일 비중으로 뽑고 그 안의 유효 픽셀을 점수로 집계할 때도 동일하다.

하한은 근거 없이 옮기지 않는다. 예를 들어 훈련과 분리한 독립 실사 장면 n개에서 미리 고정한 후보 M개의 이득이 모두 [−B,B] 안에 있고, 검증 장면 분포 P와 배포 장면 분포 Q 사이의 TV 상한 δ가 사전 근거로 주어지면 각 후보의 평균 이득 하한은

```text
mean_P(Δ) − B sqrt(2 log(M/η)/n) − 2Bδ
```

이다. Hoeffding 및 후보 간 합집합 상계로 검증 모평균에 대한 첫 보정항이 나온다. 분포 차이에서 범위 길이 2B에 TV를 곱한 만큼 이득이 움직일 수 있어 둘째 항이 나온다. 이 하한이 양수면 적어도 1−η 확률로 기대 AbsRel이 증가하지 않는다. 3% 보장에는 기준 위험의 적절한 상한을 추가로 써야 한다. 영상 안의 거리점 수를 n으로 쓰면 안 된다. 현재 적응 시험의 730개 NYU 프레임에는 독립 장면 ID와 다른 실사의 TV 상한이 없으므로 이 확률 보장을 주장하지 않는다.

안전성 반례는 간단하다. 학습에서 보지 못한 실사 장면에서 동결 모델이 2m를 맞혔는데 후보가 2.2m를 출력하면, 보정이 아무리 작아도 양의 λ에서 오차가 생긴다. 따라서 기존 출력에 가깝다는 조건은 손해 폭을 제한할 수는 있어도, 모든 미지 분포에서의 무손실을 보장하지 못한다. 로그 보정 |log(D1/D0)|≤τ이면 증가 가능한 절대 상대오차는 평균 부등식으로 (e^τ−1)(1+R_Q(D0)) 이하이지만 이 상한만으로 개선 방향을 결정할 수 없다.

## 동일 예산 비교의 사전 규칙

지난 순차 시험과 같은 D2 초기화, 원해상도, 같은 Hypersim 1,460장과 NYU 730장, 같은 실사 23,360개 지점, 2,190회 갱신, 마지막 네 인코더 블록과 AdamW를 적용한다. 입력 순서와 센서 지점은 이전 manifest 그대로다. 가중치와 입자 난수는 새 고정 시드를 사용한다. 두 팔은 동일 골격이며, 휴리스틱 재선택 없이 마지막 체크포인트를 쓴다.

- **동결 기준에 묶은 보정.** 학습 인코더에서 얻은 로그 깊이의 변경과 후보 분포의 무관측 평균을 더한다. 화면 전체 평균과 평균이 0인 성분으로 나누어 각각 유계화하고, 배포 출력은 깊이 단위에서 정해진 λ=1/2로 동결값과 섞는다. 합성 감독은 정답 깊이의 D2 손실로 입자 제안과 단안 깊이의 형태를 학습시킨다. 실사 같은 거리점에서는 로그 깊이의 직접 감독을 쓴다. 입자 후보 점수층은 RGB 영역 통계를 받아 이전 팔의 9개 구조 상태를 유지한다. 로그 보정의 유계화 전후에 GT 마스크를 사용하지 않는다.
- **보존형 순차 팔.** 같은 모형과 보정으로 시작해 같은 관측점의 순차 입자 음의 로그우도를 추가한다. 합성 32점에도 같은 관측 항이 들어간다. 직접 감독과 합성 D2의 가중치는 두 팔에서 동일하다. 조상은 64개다. 실제 학생 출력은 정확 무관측 순차 가중치에서 얻으며 각 조건에서 실제 입력은 단일 RGB다.
- **순차 팔의 배율·형상 제거 대조.** 한 네트워크 출력에서 찍은 진단이다. 시험 정답 없이 영상 전체 보정의 평균만 남기는 팔과 평균을 없애는 팔을 동시에 채점한다. 시험 점수로 최선의 팔을 골라 주 결과를 바꾸지 않는다.

학습 시 합성 D2 가중치는 .25, 희소 직접 로그 잔차는 .5, 입자 팔의 추가 우도는 .25다. 강도와 전이 비용은 이번 결과를 보기 전에 고정한다. 비교는 같은 시작점 동결 D2, 이전 입자, 같은 영상 수의 밀집 NYU 감독, 전체 NYU 감독이다. 주 평가는 HAMMER다. DIODE 실내와 iBims-1을 학습 분리 외부 자료로, NYU의 동일 배포 분할을 보조 자료로 쓴다. 외부 자료는 여러 후보에서 평가한 반복 시험이다. 새 동결 개선 3%와 실사 기준 격차를 각각 보고한다.
