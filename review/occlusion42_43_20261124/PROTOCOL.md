# 가려진 선으로 거리의 앞뒤를 배우는 실험

실사 점수를 계산하기 전 고정. 주 후보는 가림 장면·선 무늬·명시적 순서 손실을 모두 쓰는 단안 학생이다. 모든 팔에 동일한 소형망, 5개 새 시드(6211, 6221, 6229, 6247, 6257), 시드당 렌더 최대 272쌍·544장, 예비 학습 80회와 누적 본학습 192회, 배치 4를 준다. 이전 모형은 같은 새 시드로 재학습한다. 예비 48쌍, 게인용 32, 효용용 32, 배율용 16, 합성 점검용 16, 본학습 128. 공유 가능한 원본은 한 번 계산한다. 사진 입력 해상도·초점 채널, 배율 적합, 체크포인트 선택 규칙을 고정한다.

## 훈련 대조

기존 쌍 효용 모델은 기존 렌더 128쌍을 그대로 사용한다. 네 대조팔은 본학습 절반 64쌍을 기존 렌더로 유지하고 나머지 64쌍을 불투명한 막대·판이 교차하는 새 장면으로 교체한다. 선을 넣은 경우 뒤쪽 표면의 선이 가려진 부분에서 사라지고 양옆에서 이어진다. 동일한 기하와 바탕색에서 추가 선 무늬만 뺀 경우도 만든다. 서로 반대인 앞뒤 순서를 같은 위치·같은 물체 외양에 균형 있게 배정한다. 모든 팔에 기존 로그 깊이 지도 및 합성 스테레오 보정 쌍의 미터 손실과 효용 가중을 적용한다. 두 팔에는 새 교차의 깊이 순서를 알려 주는 순위 손실을 추가한다. 가중치 0.15, 온도 0.15 로그미터비, softplus를 사용한다. 순위는 같은 단안 출력의 두 깊이 차이에서 읽는다. 별도 분류기가 없다. 진폭만 키워도 손실이 줄 수 있어 실사 진폭 대조를 반드시 채점한다. 각 방법 1회 설정, 실사 튜닝 없음.

합성 점검은 본학습과 다른 8개 기본 장면의 두 순서 상태, 합계 16쌍이다. RGB 동일성에 의한 모호성을 피하기 위해 교차에서 앞에 보이는 두께와 무늬가 물체마다 달라질 수 있지만, 어느 물체가 앞인지는 무작위다. 장면 쌍의 같은 좌표 두 곳에서 정답 순서가 뒤집힌 표본에 양쪽 상태를 모두 맞혔는지 함께 본다. 이 점검용 16쌍도 예산에 포함한다.

## 독립 실사 시험과 세 지표

이전 Middlebury 2014 시험과 다른 2021 Mobile 전체 24시점을 확보한다. 개발은 artroom1·skiboots1의 왼쪽 사진, 각 4×8 격자의 중심 32개를 조회한다. 나머지 artroom·skiboots 시점은 시험에서도 제외한다. 다른 9장면 계열의 19시점을 모두 시험한다. 0점은 합성 16쌍에서만 전역 배율 또는 상수 거리 적합, 소량은 64회 조회 중 유효 값으로 모든 방법에 동일한 MAE 최적 배율 또는 상수 한 개를 준다. 재조회·실사 신경망 갱신 없음. 시험 입력은 폭 320 왼쪽 RGB와 제공된 초점거리다.

점수는 전체 거리 MAE(mm), 얇은 전경과 양옆 배경 사이 부호 있는 단차 MAE(mm), 앞뒤 정답률이다. 동점은 주 순서점수에서 0.5점, 엄격 정답률과 동점률도 기록한다. 상수는 모든 쌍에 동점이다. 데이터셋의 원본 구조광 시차를 카메라 보정으로 m로 바꾼다. 유효범위 0.25–8m, 원본 시차 0.25픽셀에 대한 거리 민감도 5mm 이하. 경계 끝점은 원본 3×3 모두 유효하고 깊이 폭 20mm 이하, 왼쪽과 오른쪽 참 시차가 대응좌표에서 1 원본픽셀 이내. 기존 기하 선별(가로·세로·대각선 각 방향 3·5·8픽셀 양옆이 5cm 이상 뒤, 배경 간 유사, 중심선 연속)을 전체 화면에 고정 적용한다. 시점별 최소 16쌍. 다른 각도는 같은 장면으로 묶고 먼저 장면 안에서, 그다음 시드와 장면에 같은 비중을 준다. 새 장면에서 선 끊김이 선명하다고 따로 고르지 않는다.

## 단차 진폭 대조와 판정

기존 쌍 효용 학생의 예측 지도에서 사진별 중앙값을 중심으로 양의 배율을 곱하면 앞뒤 순서는 그대로다. 배율 적합 후, 추가 깊이 질의 없이 RGB 전체의 가로·세로 4픽셀 이웃에서 후보/기존 예측의 평균 절대단차 비율을 구해 1로 상한 처리한다(실제 적용 가능). 별도 진단은 채점 쌍에서 두 모델 예측의 절대단차 평균을 정확히 일치시킨다. 후보가 더 크면 늘리는 것도 허용하고 그 빈도를 보고한다. 중앙값 기준 확대가 0 아래로 내려가면 지도 전체에 양의 최소 이동량만 더한다. 정확 일치 지도는 채점 좌표를 쓰므로 진단용이다. 해당 쌍이 없는 영상은 전체 거리에 대해 첫 기준을 사용한다. 또 쌍 하나하나에서 후보의 절대 크기와 기존 모델의 부호를 붙인 진단을 둔다. 이는 일관된 전체 깊이 지도를 정의하지 않는다.

후보와 상수·기존·정확 진폭 지도의 차이를 각 예산에서 보고한다. 순서가 우세하고 두 MAE가 모두 낮으며 장면 묶음 20,000회 짝 재표집 단측 95% 범위까지 같은 방향일 때만 동시 개선으로 판정한다. 5개 미만의 적격 장면이면 순서·단차의 일반화 판정을 보류한다. 시드와 장면을 함께 재표집한 민감도, 같은 렌더의 순위 손실 유무와 같은 순위 손실의 선 무늬 유무도 별도 보고한다.

설계 검수 후 점수 열기 전 경계조건을 명시한다. 동점은 같은 지도에서 두 값이 수치상 정확히 같은 경우로 삼는다. 부호·진폭 계산은 float64로 한다. 기존 진폭이 0이고 후보가 양수면 일치 불가능으로 표시한다. 두 진폭이 모두 0이면 배율 1, 후보만 0이면 정확 진단은 0배 및 전부 동점이다. 실용 지도도 배율 0이면 동점으로 채점한다. 정확 일치율·캡이 걸린 빈도와 개별 쌍의 기존 동점을 기록한다. 합성 본학습 매 32쌍 블록의 짝수번째 원본 16쌍을 유지하고 홀수번째 16쌍을 새 기본 기하 8개×두 순서로 채운다. 합성 점검은 모든 팔에 동일한 선 포함 16쌍, 반전 검사는 왼쪽 입력만 사용한다.

원자료 판독 중 장거리 장면 일부에서 고정 5mm 기준의 유효 위치가 0이었다. 실사 예측을 열기 전에 다음 보조 집계를 추가한다. 기본 집계의 세 거리·정확도 기준은 유지한다. 보조 집계는 개발 실측값·배율·모델을 그대로 두고 시험에만 0.25–30m, 시차 변화 0.25픽셀의 거리 민감도 1% 이내를 사용한다. 끝점 3×3 표면 폭은 20mm와 깊이의 0.5% 중 큰 값 이내, 좌우 정답 일치는 동일하다. 두 배경 각각이 앞면보다 적어도 5cm 뒤이고 거리차가 양 끝 민감도 합의 2배 이상이어야 한다. 두 집계 모두 공개한다. 세로형 ladder 좌우 사진과 시차 파일은 실제 네이티브 배열 방향을 쓰며 수평 재투영으로 확인한다.

후보 단차가 더 클 때에도 축소만 허용한 대조를 제공한다. 각 채점 사진에서 양쪽 모델의 평균 절대단차 중 작은 값에 두 지도를 맞춘다. 양 예측의 전체 깊이·순서·단차를 그대로 채점한다. 이를 위의 확장 허용 정확진폭 진단과 구분한다.
