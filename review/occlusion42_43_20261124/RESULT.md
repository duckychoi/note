# 가림으로 끊긴 선에서 앞뒤 순서를 배울 수 있었나

**새 실촬영 자료에서 단차 오차는 줄었지만 어느 쪽이 앞인지 더 잘 판별하게 됐다는 근거는 부족했다.** 기존 모델의 단차 크기를 새 모델만큼 맞춰 주자, 엄격한 시험에서 두 모델의 단차 오차 차이는 1mm 안팎이었다. 장거리까지 포함한 보조 시험에서도 각 경계 쌍의 크기를 일치시키면 부호 선택에 따른 차이는 0.6~1.3mm였다. 상수·기존 모델·같은 진폭 기준을 순서와 두 깊이 지표에서 모두 앞서는 관문은 어느 실측 예산에서도 통과하지 못했다.

## 어떤 모델을 같은 예산에서 비교했나

기존 #42·43 모델은 단안 예측과 양안 관측을 게인으로 결합하고, 이 결합이 오차를 줄여 준 쌍에 학습 비중을 주는 학생이다. 다섯 개의 새 시드에서 이 모델부터 다시 학습했다. 새 실험은 훈련 장면 일부를 교차하는 두 불투명 물체로 교체했다. 뒤쪽 물체에 그려진 선은 교차에서 사라지고 반대쪽에서 다시 보인다. 물체의 위치·방향·색·조명·노이즈를 고정한 채 앞뒤만 바꾼 왼쪽 사진도 같은 수로 만들었다. 오른쪽 사진에는 물리적인 시차 변화가 있다. [기존 쌍 게인](../risk42_43_20261124/paired.py) · [새 렌더러](junctions.py) · [실제 합성 반전 예시](synthetic_reversal.png)

선 무늬의 유무와 순서 손실의 유무를 조합해 4개 팔을 비교했다. 새 장면에서 두 점의 참 로그깊이 차의 부호를 y, 같은 위치에서 단안 학생이 낸 로그깊이 차를 h라 두었다. 보조 손실은 **0.15 × softplus(−yh/0.15)**다. 앞뒤를 바꾸어도 목표는 같고, 정답 방향으로 두 값을 벌리면 손실이 줄어든다. 참 순서는 학습 때의 렌더 정답에서만 읽는다. 측정된 정답이나 렌더 물체 번호는 단안 신경망의 입력에 없다. 4개 팔은 같은 합성 거리 정답, 같은 스테레오 보정 손실, 같은 예비 체크포인트, 같은 누적 배치를 공유한다. 선을 뺀 대조에서도 물체의 겹침과 윤곽선은 남는다. [훈련 코드](learn.py) · [사전 규칙과 자료 판독 때 추가한 보조 시험](PROTOCOL.md)

모델당·시드당 272쌍(544장)이다. 예비 훈련 48쌍, 게인 적합 32쌍, 예상 감소 적합 32쌍, 합성 배율 16쌍, 반전 점검 16쌍, 본학습 128쌍이다. 예비 80회, 본학습 192회, 회당 4장이다. 새 모델의 본학습 128쌍은 이전 렌더 64쌍과 새 기본 배치 32개×두 순서로 구성했다. 기존 기준은 이전 렌더에서 128쌍을 사용했다. 공유 원본을 한 번 세면 시드당 실험 전체의 고유 렌더는 공통 144쌍 + 기존 본학습 128쌍 + 새 선 무늬 두 조건 각 64쌍으로 400쌍이다. 순위 팔에서 만든 12,288개 합성 좌표 질의에는 새 사진이나 실측이 필요하지 않다.

## 새 실촬영에서 측정한 값

이전 2014년판과 다른 Middlebury 2021 Mobile을 사용했다. 저자들이 로봇 팔에 장착한 iPod touch로 촬영하고 구조광으로 시차 정답을 만든 자료다. 개발 두 장면의 관련 시점을 모두 제외한 9개 시험 장면 계열에 19개 시점이 있다. 실측 0점에서는 합성으로만 배율을 맞췄다. 소량에서는 개발 사진 두 장에서 고정 격자 64점을 조회했고, 5mm 정밀도 조건에 맞은 20점이 모두 skiboots1에서 나왔다. 유효점의 깊이 중앙값은 1.18m, 범위는 0.97~1.71m였다. 같은 20점으로 각 모델에 양의 전역 배율 하나만 맞췄다. 실사로 신경망을 재학습한 횟수는 0회다. 오른쪽 사진·좌우 정답은 시험 품질 확인에만 쓰고, 모든 모델은 왼쪽 사진과 초점거리로 예측했다. [공식 자료·거리 환산식](https://vision.middlebury.edu/stereo/data/scenes2021/) · [품질 검사](mobile.py) · [실측 배율](calibration.json)

**기본 시험**은 원본 시차 0.25픽셀에 대한 깊이 변화가 5mm 이하인 영역을 썼다. 전체 깊이는 5계열 10시점의 263,125픽셀, 가는 전경의 앞뒤 순서와 단차는 3계열 7시점의 5,952쌍이 적격이었다. 동일 전경점의 양옆을 두 배경과 비교한다. **경계 5계열 미만이면 일반화 판정을 보류한다는 사전 규칙이 적용된다.**

**거리 범위를 넓힌 보조 시험**은 원자료 판독에서 먼 장면의 정밀도 조건 미달을 발견한 뒤, 모델의 실사 점수를 열기 전에 추가했다. 9계열·19시점의 1,219,306픽셀과 53,402쌍이 적격이었다. 0.25픽셀 변화에 따른 거리 민감도 1% 이내, 좌우 정답 일치, 국소 표면 일관성, 관측된 단차가 양 끝 민감도 합의 두 배 이상인 조건을 사용했다. 범위는 0.25~30m다. 이 기준은 구조광 오차의 절대 보증이 아니다. 계열별로 먼저 평균해 한 사다리 사진에서 쌍이 많이 나와도 결과를 좌우하지 않도록 했다. **전체 수치는 [재생성 가능한 결과표](TABLES.md)에 있다.** 순서 정답률은 동점에 0.5점을 준다. 상수의 50%는 모든 답이 동점이라는 뜻이다. 양의 전역 배율은 순서를 바꾸지 않으므로 실측 예산이 달라도 모델별 순서 정답률은 같다.

- 기본 시험에서 기존 → 후보의 순서 정답률은 46.12 → 47.62%였다. 단차 오차는 0점에서 473.0 → 390.1mm, 20점에서 310.7 → 288.9mm였다. 기존에 후보와 같은 평균 단차를 주면 각각 389.1mm와 288.3mm였다. 상수는 두 조건 모두 136.6mm였다.
- 보조 시험에서 순서는 49.38 → 50.55%였다. 두 방식 차이 +1.17%p의 짝 재표집 하한과 상한은 −0.52~+2.79%p였다(각각 단측 95%, 합치면 중앙 90% 구간). 실측 0·20점의 단차는 각각 1109.3 → 1055.6mm, 1032.0 → 1015.5mm였다. 같은 평균 진폭 기준은 1065.3·1021.5mm였다. 쌍 하나하나의 크기까지 일치시키고 기존 부호를 쓰면 1056.9·1016.1mm였다. 5개 시드까지 함께 재표집해도 이 쌍별 부호 효과 구간은 0을 포함했다.
- 전체 깊이는 기본에서 0점 1680.7 → 1644.1mm, 20점 1610.3 → 1580.8mm였다. 보조에서 0점 5896.7 → 5858.4mm, 20점 6366.0 → 6248.4mm였다. **소량 보정은 같은 예산의 기존 대비 상대적으로 우세했지만, 장거리 포함 후보 자체의 오차는 0점 때보다 390.0mm 커졌다.** 가깝게 찍은 한 장면에서 얻은 20점이라는 배율 적합 조건에 유의해야 한다.
- 선을 넣은 동일 렌더에서 순서 손실을 켜면 보조 시험의 순서 정답률은 50.88 → 50.55%였다. 순서 손실이 있는 동일 조건에서 선 무늬만 추가하면 50.91 → 50.55%였다. 기본 3계열에서는 순서 손실을 켤 때 45.71 → 47.62%였으나, 순서 손실이 있는 상태에서 선을 추가할 때 47.95 → 47.62%였다. 실사 전체에서 끊긴 선 감독의 독립 효과를 주장할 근거는 부족하다.

## 단차만 줄이는 비교가 보여 준 것

기존 지도 p의 중앙값을 c로 잡고 c + a(p−c)로 바꾼다. 두 위치의 예측 차이는 a(p₂−p₁)이므로 a가 양수이면 순서를 보존한다. 예를 들어 +40cm를 +20cm로 만들 수 있지만 −40cm는 −20cm가 된다. 평균 진폭을 정확히 맞추는 a는 후보 예측의 평균 절대단차를 기존 예측의 평균 절대단차로 나눈 값이다. 점별 비교에서는 후보의 절대단차에 기존 모델 부호를 붙였다. 실제 평가 쌍에서 기존 동점과 일치 불가능 사례는 0개였다.

실제 적용할 수 있는 전역 이웃 추정, 평가 위치에 접근하는 정확 일치 진단, 쌍마다 크기를 맞추는 분석을 구별했다. 첫 방법도 두 모델의 예측이 필요하다. 쌍별 진단은 일관된 전체 지도를 만들지 않으므로 전체 거리 오차를 산출하지 않는다. 후보의 단차가 기존 것보다 큰 사진·시드도 있어 정확 일치를 위해 기존 지도를 확대하는 경우가 있었다. 축소만 허용한 별도 비교에서는 둘 중 큰 지도를 작은 진폭에 맞췄다. 보조 시험에서 이 경우의 단차 오차는 기존 → 후보 1061.9 → 1052.5mm(0점), 1016.8 → 1011.3mm(20점)였다. ## 합성 장면 자체에서 단서를 읽었나

독립 합성 장면에서 같은 두 위치의 정답 앞뒤를 반전시켰다. 후보는 사진 하나씩 보면 53.23%를 맞혔지만, **앞뒤를 바꾼 두 사진을 모두 맞힌 위치 쌍은 9.48%**였다. 기존 모델은 7.97%였다. 후보는 실제로 순서가 바뀌었을 때 예측 순서 자체를 바꾼 비율도 12.50%였다.

결과 해석용으로 같은 보관 장면을 다시 그려 단서가 물리적으로 읽히는지도 점검했다. 기하에서 교차 중심과 두 선의 방향만 알려 주고, 중심 색을 각 선을 따라 양옆 12·14픽셀의 색과 비교했다. 두 상태 모두 올바른 쪽을 고른 교차는 **160/160개**였다. 이 계산은 참 거리·앞뒤 정답을 입력받지 않지만 교차의 위치·방향을 제공받는다. 실촬영에서 작동하는 신경망 기준으로 볼 수 없고, 색·질감·윤곽 중 어느 단서만 필요했는지도 분리하지 못한다. 반전 사진에 시각 정보가 존재한다는 합성 양성 대조다. ## 한계와 연구 판단

실촬영은 정지 사진이고, 선 끊김이 눈으로 확인된 실사 경계만 따로 표시하지 않았다. 시험 경계는 거리 기하로 골랐다. 특히 기본 시험의 경계는 체스·의자·스케이트 3계열에 집중됐다. 장거리 보조 시험은 적용 범위를 넓히는 대신 근거리 합성 장면에서 시작한 작은 모델의 절대거리 약점을 크게 드러낸다. 렌더는 3.6m까지인 반면 보조 시험의 일부 장면 중앙값은 10m를 넘었다. 기준 거리는 저자가 제공한 카메라 보정값으로 환산했으며 별도의 실물 거리계로 검증하지 않았다. 이전 2014 자료에서 보고한 동점 처리와 이번 동점 반점 규칙이 다르므로 두 해의 상수 순서 점수를 직접 비교할 수 없다.

현 단계에서는 끊긴 선을 넣거나 순위 손실을 추가하는 것만으로 단안 모델이 가림을 이해했다고 주장하기 어렵다. 연구를 이어간다면 이 결과가 직접 가리키는 과제는 **교차 위치·방향을 영상에서 찾고, 같은 두 물체의 앞뒤가 뒤집힐 때 예측도 함께 뒤집히게 하는 것**이다. 별도 합성 반전 시험에서 두 상태 모두 맞히는 비율이 올라가는지부터 확인할 수 있다. 이번 장면을 다시 사용한 방법 개선은 새로운 실촬영 확증 결과와 구분해야 한다.

## 공개 Depth Pro 2 기준선

Apple 공식 가중치로 기존 Middlebury Mobile 2021 시험 19시점과 보정용 2시점을 추론했다. 입력은 이전과 같은 폭 320픽셀의 단일 RGB와 보정 초점거리다. 전체·경계 유효 마스크와 장면 계열별 집계를 공유한다. 아래의 우리 모델은 기존 가림 순서 모델 다섯 시드 평균이다. 실측 0점 조건의 Apple 모델은 공개 가중치와 직접 출력한 미터 깊이를 사용했고, 우리 모델은 기존처럼 합성 정답에서 정한 배율을 사용했다. 실측 20점 행은 두 모델 모두 같은 개발 위치에 전역 배율을 맞췄다.

| 시험·실측 보정 | 전체 오차 mm, 우리 → H+ | 단차 오차 mm, 우리 → H+ | 앞뒤 정확도, 우리 → H+ |
|---|---:|---:|---:|
| 엄격 · 0점 | 1644.1 → 1478.8 | 390.1 → 43.4 | 47.62% → 97.70% |
| 엄격 · 20점 | 1580.8 → 1497.7 | 288.9 → 42.6 | 47.62% → 97.70% |
| 넓은 · 0점 | 5858.4 → 4604.7 | 1055.6 → 645.9 | 50.55% → 90.38% |
| 넓은 · 20점 | 6248.4 → 4699.3 | 1015.5 → 655.5 | 50.55% → 90.38% |

엄격 시험의 전체 깊이는 5계열, 경계는 3계열이다. 넓은 시험은 양쪽 모두 9계열이다. H+는 두 집계에서 앞뒤 판별 격차가 크다. 소형 S도 앞뒤 순서가 엄격 77.53%, 넓은 시험 78.64%로 높았으나, 전체 깊이 오차는 엄격 0점·20점 및 넓은 20점에서 우리 모델보다 컸다. 이 비교는 해당 입력 해상도에서의 상대 성능이며, 공개 사전학습 모델과 자체 소형 CNN의 구조와 학습 데이터가 다르다. 원본 해상도, 영상 입력, 조명 변화 시험 및 Apple 사전학습에서의 장면 중복은 별도 확인 범위다. ## 재현

기존 프로젝트의 CUDA Python 환경에서 이 폴더를 작업 디렉터리로 삼는다. 원본, 처리 지도, 체크포인트, 실촬영 예측은 작업공간의 research-sources/occlusion42_mobile 안에 있다. 집계에는 보관한 점수 장부만 있으면 된다.

```powershell
$env:CUBLAS_WORKSPACE_CONFIG=':4096:8'
$env:OPENBLAS_NUM_THREADS='1'
$env:PYTHONIOENCODING='utf-8'
python -B mobile.py
python -B learn.py
python -B score.py
python -B summarize.py
python -B diagnose.py
python -B blind_junctions.py
```
