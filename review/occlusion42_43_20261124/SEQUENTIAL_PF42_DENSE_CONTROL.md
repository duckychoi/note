# 동일 영상·갱신 예산의 밀집 실사 대조

희소 관측 직접 감독과 과거 전체 NYU 지도학습 사이를 비교하기 위해 같은 사진과 갱신 수의 밀집 감독 기준을 둔다. 기존 순차 실험의 중간 평가 점수를 선택에 쓰지 않는다.

단안 Depth Pro 2-S의 같은 D2 체크포인트에서 시작해 같은 사진 및 순서를 2,190회 본다. 마지막 인코더 네 블록, AdamW 학습률 3e−6, 가중치 감쇠 .01 및 클리핑 1을 쓴다. 합성은 기존 D2 감독을 그대로 적용한다. 실사는 4픽셀 격자의 유효 Kinect 깊이 전체에 같은 D2 계열의 미터·형상 감독을 적용한다. 실제로 읽은 학습 이미지는 730장으로 희소 조건과 일치하며 라벨 점 수가 더 많다. 따라서 **영상 수와 갱신 예산을 맞춘 밀집 실사 기준**이다. 별도의 전체 NYU 47,584장 참고선도 유지한다.

모델의 첫단은 그대로 공유하며 별도 확률 읽기층 없이 D2 출력의 깊이를 평가한다. 원래 사진 한 장과 공통 초점 추정기를 쓴다. HAMMER·DIODE 실내·iBims-1·NYU의 같은 유효 점과 같은 평균 방식을 사용한다. 마지막 체크포인트만 결과에 넣는다.
