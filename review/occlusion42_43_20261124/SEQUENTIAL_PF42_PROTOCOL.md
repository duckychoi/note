# #42 순차 추정으로 학습하는 단안 깊이

## 상태와 모델

정적 사진 한 장의 네 영역을 인접한 순서(좌상, 우상, 우하, 좌하)로 처리한다. 순서의 인덱스 t는 공간 단계이며 촬영 시간은 아니다. 인코더가 RGB에서 기준 역깊이 q와 영역별 예측 점수를 낸다. 한 상태 s는 영역 안 여러 픽셀의 깊이를 함께 바꾸는 로그 배율과 근거리–원거리 편차의 쌍이다. 각 축에서 3개 값을 사용하여 깊이 후보 9개를 둔다. 보정 깊이는 Z_i(p)=f/[W q(p)] exp(c_i+b_i h(p))이며 h는 같은 RGB의 기준 로그 깊이를 영역에서 중심화한 유계 함수다.

예측 점수 a_t(j)와 보정 좌표 거리 d(i,j)로 K_t(i,j) = softmax_j[a_t(j)−d(i,j)]를 만든다. 합성 정답 깊이에 대한 감독과 관측 예측 우도로 a_t와 인코더를 학습한다. 실사에서는 같은 네트워크와 같은 우도에 희소 센서 깊이를 넣는다. 라벨이 누락된 영역에서는 우도 1이다. 연쇄를 끊고 실사 점에 직접 감독하는 대조, 상태를 지속시켜 고정한 혼합 우도, 같은 전이를 정확 합산하는 유한 상태 대조를 둔다.

## 예측, 관측 보정과 학습

현재 영역 전의 사후 확률을 w⁺_{t−1}라 하면 w⁻_t(j)=Σ_i w⁺_{t−1}(i)K_t(i,j)이다. 독립 측정이라는 작업 모형 하에 영역의 실사 로그 거리 y에서 후보별 Gaussian 잔차 로그 우도 ℓ_t(j)를 계산한다. 관측 수가 달라지면 증거의 크기가 달라지므로 후보별 로그 우도에서 잔차 합을 사용한다. L_t(j)=exp ℓ_t(j), m_t=Σ_j w⁻_t(j)L_t(j), w⁺_t(j)=w⁻_t(j)L_t(j)/m_t이다. 순차 학습은 −Σ_t log m_t를 미분한다. 모든 영역에서 관측이 없는 배포에서는 같은 q, a, K로 예측 단계만 진행하고, 관측 후 확률 없이 RGB 한 장으로 출력한다. 최종 위험 지표에는 동일한 가중 절대오차 베이즈 결정(깊이 후보 z_j의 가중 중앙값, 가중치 w_j/z_j)을 사용한다.

실제 PF는 각 단계에서 직전 사후 확률로 조상을 복원추출하고, 뽑힌 조상에 대한 K의 자식 상태를 전부 합산한다. 즉 조상은 입자 표본이고 그 자식 전이는 정확 합산하는 Rao–Blackwell 형태다. 정규화한 예측을 L_t로 갱신한다. 정수 조상에 대한 미분을 끊는 실용 경사는 일반적으로 PF 목적의 불편 경사가 아니다. 같은 전이·우도·모델의 정확 합산 대조가 있으므로 PF 샘플링과 순차 구조의 효과를 구별한다. 우도는 센서 오차뿐 아니라 기준 모델과 유한 상태가 설명하지 못하는 영역 내부 오차를 포함하는 작업 모형이다. 실사 픽셀 오차의 실제 독립성이나 Gaussian 분포 적합을 보장하지 않는다.

## 고정 혼합과 달라지는 조건

첫 영역 관측 전의 행벡터 w₀와 대각행렬 D_t=diag(L_t)를 쓰면 결합 우도는 w₀D₁K₂D₂…K_TD_T1이다. 모든 모델의 첫 확률은 네 영역 점수의 평균을 softmax한 값이다. 식은 정규화하지 않은 전방 벡터를 단계별로 전개한 것이다. K=I이면 대각행렬의 곱이라 Σ_i w₀(i)∏_t L_t(i)이고, 순서가 무관한 한 후보의 고정 혼합 우도가 된다. 각 단계 K의 모든 행이 동일하면 각 단계의 분포가 해당 단계 RGB 점수에만 의존하고 이전 관측으로부터 전달되는 정보가 없다. 다른 전이에서는 항을 곱해 전개할 때 i≠j의 경로가 생긴다. 예를 들어 후보 A,B, 초기 (1/2,1/2), L₁=(1,0), L₂=(0,1)이면 고정 혼합 우도는 0이고 K₂(A,B)>0이면 순차 우도는 K₂(A,B)/2>0이다. 모든 우도를 양수로 교란해도 엄격 차이가 남는 예를 얻는다. 전체 상태 경로를 하나의 새 잠재 변수로 열거하면 순차 모델도 경로 혼합이다. 9개 상태에서는 행렬 전방 합산으로 정확히 푸는 것이 가능하다. 입자 표집은 표본 근사로서 따로 비교한다.

전이를 계산하는 네트워크는 양쪽 도메인에서 하나이며 합성은 세계 기하를 포함한 입자 전이와 후보를 계속 학습시킨다. 실사는 관측 우도로 같은 전이와 인코더에 기여한다. 이는 공간 연쇄를 쓰는 첫 실험이다. 독립 장면에 물리 상태를 이어 붙이거나 물체 시간 추적을 시험한 설정은 아니다.

## 사전 고정 비교

- 동일 기준은 Hypersim 공식 59,543장으로 학습한 D2 Depth Pro 2-S 체크포인트다. 이번 적응은 Hypersim의 각 학습 장면 최대 4장(365장면), NYU의 훈련 전용 샤드에서 고정 난수로 고른 실사 730장이다. 같은 실사 이미지는 8개 지점×4영역, 총 최대 32개 거리만 제공한다. 유효한 점을 고를 때 데이터셋의 유효성 마스크를 사용하며 거리값은 고정된 표집 위치에만 쓴다. 모든 데이터 사용은 기록한다. 다른 테스트 데이터의 정답이나 데이터 선택을 학습에 활용하지 않는다.
- 학습 팔은 합성 D2, 같은 실사 점의 직접 감독, 고정 혼합 우도, 정확 공간 전이, 입자 공간 전이 다섯 개다. 각 팔은 같은 초기 모델, 입력 스케줄, 마지막 4 인코더 블록, AdamW를 쓴다. 관측을 쓰는 네 팔은 동일 실사 목록과 같은 점을 읽는다. 합성 D2는 다른 모든 팔과 동일한 합성 목록과 합성 갱신을 쓰며 추가 정보량 차이를 표에 표시한다. 별도로 이미 완료한 같은 Depth Pro 2-S 전체 NYU 실사 지도학습 체크포인트도 채점한다. 그 학습법과 초기화는 파일럿과 별도다.
- 학습은 AI 생성 RGB가 아닌 원래 물리 기반 Hypersim RGB–깊이를 사용한다. 깊이 후보 특징이 불필요하게 변하지 않도록 원해상도 RGB를 인코더에 넣고 밀집 감독과 구조적 교차엔트로피를 정해진 희소 격자에서 계산한다. 1, 2패스 같은 중간값을 최고점으로 골라 실사에 보고하지 않는다. 완료 지점 하나를 평가한다. 추후 규모와 시드를 늘린 별도 시험을 요구하는 결과와 현재 고정 실험의 판정을 구분한다.
- 절대 상대 거리 오차 AbsRel은 동일 초점 추정기로 재구성한 RGB 한 장의 깊이에서 계산한다. 정답으로 배율이나 오프셋을 맞추지 않는다. HAMMER가 주 실사 판정, DIODE 실내 및 iBims-1이 반복 자료다. NYU 공식 테스트는 실사 감독 수준의 동일 분포 보조 시험이다. 이전 후보에서 결과가 열린 자료이므로 이번 적응 경로와 분리된 반복 시험으로 기록한다. 장면 재표집 구간을 본다. 향상률 3%는 강한 D2 동결과 같은 예산의 실사 감독·혼합 우도 각각에 대해 보고한다.
