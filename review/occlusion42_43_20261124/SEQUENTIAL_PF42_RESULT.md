# #42 순차 입자 학습 실험

Hypersim 365장면에서 1,460장, NYU 훈련 샤드에서 730장과 희소 거리 23,360개를 사용했다. 네 실사 관측 조건의 사진, 위치, 거리값, 갱신 순서를 맞췄다. 실사 정답 깊이의 유효성 마스크에서 표집했다. 실사 사용 조건은 각 2,190회, 합성 D2는 1,460회 갱신했다. 이 중 합성 6장은 사용 거리 범위에 정답이 없어서 자료 손실이 0이었다. 유효 관측이 있는 합성 장면은 364개다. 고정 시작점은 이전에 Hypersim 전체 59,543장을 사용해 학습했다. 전체 NYU 지도 모델은 이전의 47,584장 학습과 다른 초기화·예산을 쓰는 참고선이다. 이 모델은 장면 내 공통 초점 추정기를 사용해 다른 모델과 같은 단안 입력으로 평가했다.

숫자 검산에서 동일 상태·우도의 고정 혼합 0.00888854과 정확 전이 0.01375974가 달랐다. 조상 50,000개에서 PF 추정값은 0.01373479였다. 본 학습은 64개다.
독립 수치 검산의 전이 로짓 경사 최대 오차는 1.388e-16다. 20,000번의 64입자 실험에서 정확 결합 우도 0.05954216, 입자 우도 평균 0.05952059, 평균의 표준오차 0.00003000였다.

## 구현과 주장 범위

- 배포에는 관측을 주지 않았다. 입자를 쓰는 것은 훈련 경로다. 배포는 RGB 한 장에서 9개 전이를 정확히 합산한다.
- 네 영역 점수로 전체 첫 분포를 만든다. 이후 전이는 목적 영역 점수와 고정 거리 벌점이다. 공간 순서를 사용했다. 카메라 시간 전이나 새 입자 상태의 생성 연산을 검증한 시험이 아니다.
- 합성의 보조 학습도 표집 깊이의 가우스 주변우도다. 별도 상태 교차엔트로피를 쓰지 않았다. 순차 음의 로그우도는 유효한 점 개수로 나눈 뒤 .5로 가중했다. 마지막 4블록은 학습률 3e−6, 점수층은 5e−4를 사용했다.
- 직접 감독은 후보 로그 깊이의 가중 평균에 제곱오차를 적용한다. 모든 후보형 모델의 평가는 AbsRel의 가중 중앙값이다. 합성 D2 대조는 표준 지도 손실·영역 헤드 없음·실사 관측 없음의 기준이다. 입자 표집의 추가 효과는 정확 전이와의 대조에 한정된다.
- 기존 규약의 ‘구조적 교차엔트로피’ 표기는 실행 코드를 설명하지 않는다. 코드에 맞춘 합성 보조항의 정의는 위와 같다.
