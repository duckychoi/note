  검색(retrieval)은 라이브러리 2,048 궤적을 한 번 만들고 모든 사례가 공유한다(상각; 사례당 0, 총 2,048). 표에 사례당·총 호출을 둘 다 적는다.

# 관문 3 사전 등록 (2026-11-23, 관문 1·2·2b 결과를 본 뒤, 관문 3 실행 전에 작성. 사용자 승인)

## 과제
- MuJoCo 2-D 구(반지름 .06, 0.25 kg): x 미끄럼 + z 미끄럼 + y축 회전(스핀). 평면 접촉 마찰 μ, 반발은 solref 감쇠 d.
- 과정 잡음: 프레임마다 v_z 가 음→양으로 바뀌면(바운스) v_z ← v_z·exp(N(0, .15²)) (바운스마다 확률적 반발).
- 50프레임(dt .02 s, 10 substeps). 앞 25프레임 관측, 뒤 25프레임 예측. 관측 = (x,z)+N(0,.015²), 앞 25프레임 중 40% 무작위 누락.
- 초기 사전: x0 U[−.2,.2], z0 U[.35,1.0], vx0 U[−.5,1.5], vz0 U[−1,.5], ω0 U[−25,25] rad/s.
- 학습 범위 물성: μ U[.3,.8], d U[.2,.5]. **시험(미사용) 물성**: μ 는 U[.08,.22] 또는 U[.9,1.2] (반반), d 는 U[.07,.17] 또는 U[.55,.8] (반반). 사례마다 연속 물성으로 모델 생성.
- 검증 48사례(학습 범위, seed 51000): 온도 선택 전용. 시험 4 seed × 48 = 192사례 (seed 51200–51203).

## 방법 (시뮬 호출 단위 = 50프레임 궤적 1개 등가 = 500 mj_step)
1. 부트스트랩 PF: MuJoCo 동역학(같은 과정 잡음 포함), 넓은 사전 물성 풀(μ 12단계 geomspace .06–1.3 × d 12단계 .06–.9 = 144모델).
   매 프레임 전파 → 관측 프레임이면 가중 → ESS<N/2 면 계통 재표집 + jitter(위치 σ .002, 속도 σ .02, ω σ .5, 물성 인덱스 각 ±1 확률 .15).
   관측 후 25프레임 무관측 전파로 미래 표본. N ∈ {64,256,1024}, 기준 N=8192. 사례당 호출 ≈ N.
2. 검색: (a) 학습 범위 라이브러리 196,608개(=PF-1024 사례당 1024 × 192사례, 총 호출 동일, 상각), (b) 학습 범위 1,024개(사례당 크기 동일),
   (c) 공정성 추가: 넓은 사전(PF 와 같은 풀) 196,608개. 가중 = 관측 프레임 가우시안 우도^(1/temp).
3. 단일 최적 물리 적합: CEM(인구 64 × 16세대 = 사례당 1,024회, 과정 잡음 없음)으로 관측 SSE 최소화, 최선 궤적 하나로 예측.
4. 평활·외삽: x 는 마지막 관측 ≤8프레임 직선 외삽, z 는 마지막 관측 ≤6프레임에 중력 고정 포물선 적합 후 바닥(.06)에서 반발 .6 고정 반사.
- 온도: 검색은 {.5,1,2,4,8}, PF 는 {1,2,4} (N=1024) 중 검증 에너지 점수 최소.

## 지표
- 미래 에너지 점수(표본 128, 거리 = 미래 25프레임·x,z RMSE), 사건 Brier 두 개: E1 = 미래 창 바운스 ≥2, E2 = x(49)−x(24) > 학습 범위 라이브러리 중앙값.
- 80% 포함률: 최종 프레임 x, z 각각(가중 분위수 10–90%). 점 예측(3,4)은 에너지 = RMSE, 포함률 없음.

## 판정 (조정자 지시 그대로)
- 여유 없음: PF N=256 이 기준 대비 에너지 5% 이내 **그리고** 같은 총 호출 검색 최선(2a,2c)과 차이 5% 미만 → "flow 제안 무의미 → #36 추론 알고리즘 논문 보류", 종료.
- 여유 있음: PF 작은 N(64 또는 256)이 기준 대비 ≥5% 나쁘고 **그리고** 기준 PF 가 검색 최선보다 ≥5% 좋음 → flow 제안분포 설계만 기술(구현 안 함).
- 그 외: 중간 — 숫자 그대로 보고, 원인 기술.

# 4a 사전 등록: 검색 제안 PF (2026-11-23, 관문 3 결과를 본 뒤, 4a 실행 전 작성. 사용자 승인)
코드 `pf36_g4.py`(pf36_g3 import), 결과 `gate4a.json`. CPU ≤16스레드. 과제·사례·지표는 관문 3과 동일(같은 seed로 재생성).

## (i) 검색 공정성 재조정
- 온도 격자 {.5,1,2,4,8,16,32,64,128,256} 을 검증 48사례(seed 51000)로만 선택.
- 적응형: 사례마다 ESS ≥ E* 를 만족하는 가장 작은 온도(같은 격자), E* ∈ {8,32,128,512} 를 검증으로 선택.
- 라이브러리: 학습 범위 196,608 / 넓은 사전 196,608 (관문 3과 동일 seed). 최선 검색 = 둘 × (고정/적응) 중 검증 에너지 최소 1개 → 그 하나만 시험 보고에서 "최선 검색".

## (ii) 검색 제안 PF
- 라이브러리: 넓은 사전(PF 사전과 같은 분포) 앞 L개. 사례마다 관측 prefix 우도(검색 최선 온도)로 상위 k=64 를 뽑아 혼합 제안:
  q(z,i_μ,i_d) = (1−α)·Σ_j π_j N(z; z_j, Σ) K(i_μ|i_μj) K(i_d|i_dj) + α·p(z,i), α=.1, π_j = 상위 k 의 softmax 가중,
  z=(x0,z0,vx0,vz0,ω0), Σ = 상위 k 의 가중 공분산 + diag((상자폭×.005)²), K = 정지 .7 / ±1 각 .15(끝은 정지에 합침) 의 12×12 이산 커널.
  밀도는 정확히 계산(혼합 전부 평가). 초기 로그가중 = log p − log q. 이후는 관문 3 PF 와 같은 순차 가중 + Liu–West(h=.2).
- PF 온도 {1,2,4} 는 검증에서 선택. k, α, Σ 규칙은 고정(튜닝 안 함).
- 예산(라이브러리 L + 사례당 N × 192) ≤ PF-1024 총 196,608 인 세 설정: (L=98,304, N=512), (L=147,456, N=256), (L=184,320, N=64).
  참고로 예산 초과 설정 (L=196,608, N=1024) 도 보고(판정엔 안 씀).

## 판정 (4a)
- 통과: 예산 이내 설정 중 하나라도 에너지가 PF-8192(관문 3, 0.0435) 대비 5% 이내 **그리고** 최선 검색(재조정) 대비 5% 이상 좋음 **그리고** 4개 시드 모두에서 검색보다 좋음.
  → 통과하면 flow(4b) 불필요로 기록하고 종료.
- 불통과 → 4b(조건부 flow 제안) 진행. 80% 포함률·사건 Brier 는 함께 보고(판정 외).

### 4a 실행 전 수정 (스모크 8사례 seed 1, 라이브러리 2만 — 검증·시험 아님)
- 검색 제안 PF 에서 프레임마다 재표집하면, 관측이 하나도 반영되기 전 초기 가중 p/q 만으로 재표집되어 방어 혼합의 사전 입자가 이기고 제안 입자가 소멸(에너지 .46).
  제안이 prefix 전체를 보고 만든 것이므로 **prefix 끝(프레임 24)까지 재표집을 미룸**(가중은 p·L(y_0:24)/q 그대로 정확). 이후 재표집 + Liu–West 는 동일. 수정 후 스모크 .042.

## 4a 결과 요약 (gate4a.json): **불통과** — 예산 내 최선 (L=98,304, N=512) 에너지 .0510: PF-8192(.0435) 대비 +17%, 재조정 최선 검색(넓은 사전·ESS≥8, .0532) 대비 −4.2%, 시드 4개 중 일부만 우세. → 4b 진행.

# 4b 사전 등록: 조건부 normalizing flow 제안 (2026-11-23, 4a 결과 본 뒤, 4b 실행 전)
코드 `pf36_g4b.py`, 결과 `gate4b.json`. torch CPU ≤16스레드, 총 계산 ≤1.5 h.
- 제안 q(z, i | 관측 prefix, 마스크) = Cat(i | 관측) · Flow(z | 관측, i). i = (μ, d) 144 클래스(정확한 pmf), z=(x0,z0,vx0,vz0,ω0) 는
  조건부 affine coupling(RealNVP) 6층, 상자 기준 표준화 → **밀도 정확(log-det 포함)**. 방어 혼합 (1−α)q + α·사전, α=.1 (4a 와 동일).
- 학습 데이터 = 시뮬레이터 궤적 (상태, 물성, 관측 prefix). 관측 잡음과 40% 누락 마스크는 매 에폭 새로 뽑음(추가 시뮬 없음).

  학습 호출 M 은 총 예산에 포함. 설정: (M=98,304, N=512), (M=147,456, N=256). 각 설정당 모델 1개 학습(검증 손실로 조기 종료, 검증 = 학습 데이터 10% 분리).

- 판정: 4a 통과선과 같음(예산 내, PF-8192 대비 5% 이내, 최선 검색 .0532 대비 5% 이상 좋음, 4 시드 모두 검색보다 좋음) **그리고** 4a 예산 내 최선(.0510)보다 좋음.

## FPPF 적응 (arXiv 2607.01012 설계 중 적용 가능한 부분, codex 2항)
- 물성은 계보마다 고정. 바운스 충격은 속도 한 성분에만 들어가는 특이 전이 → 전 상태 flow 대신 **관측 간격(gap) 동안의 가우시안 시뮬레이터 innovation u (최대 8프레임)** 에 대한 조건부 rectified flow q(u | 직전 관측 시점 상태, 물성, 간격 길이, 들어오는 관측), 조건은 연결(concatenation).
- 밀도: Euler 16단계 이산 사상의 **정확한 log|det(I+hJ)|** (8차원 자코비안 전부 계산) — 이산 사상 자체의 정확 밀도. 가중 w·L(o|x)·p(u)/q(u), 사용 안 한 남는 차원은 보조변수로 N(0,1) 목표(확장 공간 IS, 정확). 간격 > 8 이거나 다음 관측 없으면 사전(부트스트랩). ESS<N/2 재표집.
- 1프레임 FPPF 극한: 충격은 그 프레임 위치 계산 **뒤** 속도에 들어가므로 같은 프레임 관측은 충격 분포를 바꾸지 않음 → 최적 제안 = 사전 = 부트스트랩(해석적, 실행 안 함).
- APF: 관측 프레임마다 결정론적 1프레임 예측(재시뮬, 과금) 으로 1단계 가중 λ=N(o; ŷ, σ²+.02²) → 조상 선택 → 사전 전파 → 가중 L/λ.
- 학습 데이터: 넓은 사전 은행 앞 147,456 궤적을 같은 난수열로 재시뮬해 상태·innovation 기록(재시뮬 실제 호출은 장부에 별도 기록), 예 400,000 개(간격 기하분포 p=.6), 20 에폭.
