# #36 독립 감사

관문 5 원자료에서 학습 시드별·시험 묶음별 통과 여부, 분배별 표본 표준편차, 192사례당 호출 회계, 검증/시험 포함률을 재계산한다. 기존 원자료와 가중치는 수정하지 않는다.

별도 미사용 물성 사례를 8묶음 × 24개(난수 56370~56377) 생성한다. 기존 네 시험 묶음과 새 시험은 같은 생성 분포다. 주 분배에서 보관한 세 가중치, α=.1, 각 검증 온도, 넓은 사전 검색 196,608개·기존 ESS 8, PF-8192의 기존 온도와 사건 기준을 고정한다. 보조 분배는 세 가중치가 저장되지 않아 원 로그에서만 검산한다. 모형별 평균과 각 시험 묶음 값을 남긴다.

기존 PF-8192 온도는 입자 1,024개에서 정했다. 공정성 감사를 위해 별도 PF-8192도 기존 검증 48개에서 온도 1·2·4를 고른다. 구형 PF와 조정 PF가 같은 온도를 고르면 같은 결과를 쓴다. 새 시험에 맞춰 다시 고르지 않는다. 검색, 원 PF, 조정 PF의 에너지와 좌표별 마지막 위치의 80% 예측구간 포함률을 같은 사례에서 계산한다.

세 고정 모델의 에너지 점수를 사례별 평균하여 검색보다 5% 이상 낮은지(0.95×검색−flow), 두 PF 대비 5% 이내인지(1.05×PF−flow)를 본다. 8개 독립 시험 묶음별 짝차의 t 구간, 세 비교 Bonferroni 동시 95%로 하한이 양수인지 보고한다. 8묶음이라 구간은 근사치다. 옛 관문의 점 추정 판정과 별도다. 재학습, 다른 환경, 최신 생성 필터 구현은 이 독립 시험에 포함되지 않는다.
