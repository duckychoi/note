# #63 추가 탐색 설계

첫 시험에서 점프를 허용하면 점프 직후에는 유리해도 전체 오차가 더 컸다. 개발 최적 잡음 배율도 전부 탐색 범위의 끝에 걸렸다. 이에 따라 **첫 결과를 본 후** 다음 가설을 세웠다. 큰 관측 오차를 실제 움직임과 센서 이상 두 가지로 설명할 수 있게 하면, 품질표 자체의 추가 가치가 얼마나 남는가. 본 문서는 아래 추가 시험을 돌리기 전에 작성했다.

- 고정·품질·점프 고정·점프 품질·세 품질해석 적응의 기존 다섯 팔 각각에, 측정 잡음의 분산이 64만큼 커지는 성분(사전확률 0.04)을 추가한 판을 둔다. 시뮬레이터의 실제 이상치 분산은 100이다. 가우시안 혼합은 고전 비교군이다. 모델은 점프나 이상치 정답을 입력받지 않는다.
- 각 방법의 정상 잡음 배율 후보는 0.125·0.25·0.5·1·2·4·8·16이다. 추가 학습·개발·시험 난수는 각각 72331·72332·72333이다. 실험군은 생성 때 점프와 좋은 품질을 연동하는 원 조건과, 점프 때에도 다른 프레임과 똑같이 품질·이상치를 뽑는 조건이다. 같은 난수 블록(별도 조건은 +100)을 쓴 방법끼리 비교한다. 첫 생성 조건의 학습 데이터로 품질표를 한 번 추정한다. 개발은 두 생성 조건의 정상 품질 궤적을 같은 비중으로 쓰고 방법별 평균 RMSE로 선택한다. 시험에서 배율을 다시 고르지 않는다.
- 생성 조건마다 새로운 궤적 240개에 정상·무관·반전·중간반전 표시를 적용한다. 전체 RMSE와 점프 후 다섯 프레임 평균절대오차를 보관한다. 센서 이상을 허용한 고정 규칙, 품질 조건부 규칙, 세 해석 적응 규칙을 직접 비교한다. 효과 크기·궤적 단위 95% 짝 구간을 공개한다. 이 탐색으로 새로운 필터·최고 성능·실데이터 성과를 주장할 수 없다.
