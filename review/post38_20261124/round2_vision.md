# 스테레오 관문 독립 2차 검수

**판정은 관문 미통과다.** 두 조건 모두 네 점 일관성 선택이 균등 선택보다 평균 오차를 줄였으나, 미리 정한 상대 10% 개선에는 못 미쳤다. PFM의 배율 처리와 JSON의 집계는 확인됐다.

## 원본과 재계산

`stereo_gate.py`, `protocol.md`, `stereo_results.json`을 대조했다. 두 입력 ZIP의 SHA-256과 15개 GT 헤더를 확인했다. 각 헤더는 `−0.003922`였다. 공식 형식은 부호로 endian을 정하고 절댓값은 무시하며, 파일의 아래쪽 행을 먼저 저장한다. 원본 읽기 방식이 맞다. 공식 설명에서 깊이는 `Z=baseline*f/(d+doffs)`다. SDK ZIP 자체는 직접 가져오기가 막혀 실행하지 않았다. [Middlebury PFM 규격](https://vision.middlebury.edu/stereo/submit3/upload-format.html) · [공식 깊이 변환](https://vision.middlebury.edu/stereo/data/scenes2021/#calib)

| 영상 조건 | 균등 → 일관성 AbsRel | 질감 → 일관성 AbsRel | 평가 픽셀 비율 |
|---|---:|---:|---:|
| 전체 오른쪽 영상 | 0.03690 → 0.03381, 8.37% 감소 | 0.04146 → 0.03381, 18.45% 감소 | 76.36% |
| 오른쪽 중앙 절반 | 0.06072 → 0.05650, 6.95% 감소 | 0.06665 → 0.05650, 15.23% 감소 | 45.48% |

재계산은 15개 장면 점수에서 변형을 묶어 12계열을 동일 가중했다. 10,000회 짝 부트스트랩의 균등 대비 절대 AbsRel 차이 95% 구간은 전체 [0.00024, 0.00694], 중앙 절반 [0.00213, 0.00675]였다. 질감 대비는 각각 [0.00122, 0.01585], [0.00368, 0.01782]다. 모두 원본 JSON과 맞았다. 구간은 절대 차이용이고, 10%는 평균끼리의 상대 개선 기준이다. 계열이 12개여서 좁은 개선 추정까지 일반화하기 어렵다. 원본 테스트 픽셀 평가는 4격자 간격의 모든 질의 후보를 뺀 뒤 SGBM 유효 영역으로 제한됐다. 중앙 절반은 별도의 촬영 중첩률이나 해상도 조건이 아니다.

## 결론을 기록할 때 반영할 사항

- **배율 세 조건은 독립 근거가 아니다.** 기본 예측 깊이를 `D`, 인위 배율을 `s`라 하면, 실측에서 얻은 중앙 로그비는 `median(log(GT/D)+noise)−log(s)`다. 그래서 한 점이라도 성공하면 `sD`에 보정 계수를 곱할 때 `s`가 소거된다. 예를 들어 `D=3`, 측정 2일 때 배율 0.8이면 2.4×(2/2.4)=2, 배율 1.2이면 3.6×(2/3.6)=2다. 0회 또는 모두 실패한 시드는 배율이 남는다. 이 데이터의 4점 집계는 세 배율에서 전부 같다. 따라서 10% 미달 판정은 유지하고, ±20%에서 별개 강건성을 확인했다는 해석은 제외한다.
- **0%에서는 보정할수록 나빠졌다.** 실측 없음 → 일관성 4점은 전체 0.02692 → 0.03381로 약 25.6% 증가, 중앙 절반은 0.05077 → 0.05650으로 약 11.3% 증가했다. 기본 깊이가 이미 잘 맞아도 관측 잡음과 국소 시차 오차가 전체 스케일로 번질 수 있다.
- **관측 모사는 정확히 표시한다.** Middlebury 실제 영상의 변환된 GT에 난수를 얹어 깊이 질의를 모사했다. 별도 깊이 센서는 쏘지 않았다. 코드의 `truth`는 유한 GT 존재 여부를 질의 성공 대리값으로 쓴다. `0.02`는 로그 잡음의 표준편차다. 균등의 후보는 유효 영역의 전체 격자이고, 두 우선 선택법은 각 영역 점수 상위 10%에서 무작위 선택한다. 일관성 점수가 같을 땐 질감으로 정렬한다. 따라서 이 실험은 현재 구현한 두 순위 규칙과 균등 규칙의 비교다.
- **문서 정밀도 수정.** PFM 주석의 “for display”는 공식 제출 설명에서 확인되는 정보가 아니다. 코드 주석에는 “trainingQ header is −0.003922, and Middlebury specifies that its magnitude is ignored” 정도가 정확하다. 프로토콜의 “중앙 50%만 보이는 조건”은 “오른쪽 영상 바깥을 0으로 채우고 예측 대응이 중앙 절반에 있는 픽셀만 평가”로 쓰면 구현과 정확히 맞는다. 평가 범위가 줄어든 두 영상 조건의 AbsRel을 전체 영상 복원 성능으로 해석하지 않는다.

독립 재계산은 보관된 장면별 JSON에서 평균과 짝 구간을 다시 산출했다. 전체 SGBM 점수 생성은 재실행하지 않았다.

## 추가 13장면 선택적 보정 검산

**후속 관문도 미통과다.** Middlebury 2014 공식 추가 장면 13개와 코드·캐시·결과의 이름이 완전히 일치한다. 캐시된 4분의 1 해상도 영상으로 13개 장면을 모두 다시 계산해 JSON의 12시드별 점수, 시드별 유효 질의 수, 평가 범위 및 캐시에 든 원본 해시 문자열이 일치함을 확인했다. 원본 파일은 다시 내려받지 않았다. 평균과 구간은 별도로 재집계했다. 장면 안에서 시드를 평균한 뒤 오차 조건 다섯 개와 장면 13개에 동일 가중했다. 부트스트랩은 다섯 조건을 묶은 장면 전체를 복원 추출한다. [Middlebury 공식 추가 장면 목록](https://vision.middlebury.edu/stereo/data/scenes2014/)

| 기준 → 산포로 선택적 보정 | 5조건 평균 AbsRel | 기준 − 제안 차이의 95% 짝 구간 |
|---|---:|---:|
| 고정 3% 문턱 | 0.026687 → 0.027147, 1.73% 증가 | [−0.00099010, 0.00001737] |
| 연속 축소 | 0.027630 → 0.027147, 1.75% 감소 | [0.00004562, 0.00086448] |

무오차에서는 무보정 0.02017, 항상 보정 0.02730, 산포로 선택적 보정 0.02072였다. 선택적 보정은 무보정 대비 0.00055 증가했고, ±20%에서는 항상 보정과 두 평균이 같았다. 세 안전 하한은 충족했다. 5% 개선과 양의 구간 하한을 두 비교에서 요구한 주 관문은 충족하지 못했다. 평균 평가 범위는 75.58%다. 동일한 네 점을 받은 규칙끼리 비교했으므로 이 결과의 범위는 보정 여부 판단이다. 별도 깊이 센서나 다른 벤치마크로 옮겼을 때의 효과는 미확인이다.
