# #43·44 후속 탐색 — 실측 네 점을 얻은 뒤, 현재 값을 고칠 것인가

첫 15쌍에서 이미 맞는 카메라까지 보정하면 오히려 손해라는 결과를 본 뒤 별도 과제를 정했다. 다음 설계는 추가 영상의 결과를 계산하기 전에 고정했다. Middlebury 2014가 정식 Eval3 훈련·시험 이외로 분류한 13개 장면 전부의 perfect 좌우 영상·왼쪽 시차를 사용한다. 이는 장면만 새로울 뿐 기관·벤치마크 계열은 같다. 실제 카메라에 0%, ±5%, ±20% 전역 거리 설정 오차를 모사한다. 전체 영상에서만 비교한다.

- 같은 SGBM·2% 로그 관측 잡음·사분면 4회·12시드·평가 격자 분리를 유지한다. 최초 실험의 왕복 오차/질감 규칙으로 4점을 선택하고 모든 보정기에 똑같이 제공한다. 위치당 측정값은 정답으로 모사한다. 파일 전송을 줄여 재실행할 수 있도록 4분의 1 해상도로 캐시하고 원본 해시를 남긴다.
- 보정 후보는 네 로그 비율의 중앙값 m이다. 무효 질의는 소비한 것으로 센다. 아무 값도 없으면 현재 보정을 유지한다. 무보정, 항상 m 적용, |m|이 0.03보다 큰 경우만 적용, 0 중심 표준편차 0.10 사전으로 연속 축소, 측정 간 산포에 맞춘 선택적 보정을 비교한다. 유효 수 k, 중앙절대편차 MAD에 대해 s=1.2533·max(0.02,1.4826·MAD)/√k를 사용한다. 연속 축소 계수는 0.10²/(0.10²+s²)다. 선택적 보정은 |m|>1.96s일 때만 m을 적용한다. 네 점에 정규근사를 쓴 **경험적 규칙**이며 보장된 95% 구간이 아니다.
- 장면과 오차 조건에 균등 가중한 AbsRel에서 선택적 보정이 3% 문턱과 연속 축소 모두보다 5% 이상 낮고 장면 단위 95% 짝 차이의 하한도 양수여야 다음 방법 후보로 승격한다. 추가로 무오차에서 무보정 손해 0.003 이하, ±20%에서 항상 보정 대비 손해 각각 0.003 이하를 요구한다. 13장면 성능·관측 가능한 영역과 조건별 수치를 공개한다. 장면마다 전역 스케일 하나만 바뀌며 실제 교정 장비의 절감 효과는 측정하지 않는다.
