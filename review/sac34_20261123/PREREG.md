근거: `../gate34_20261123/PREREG.md`(CEM 라벨 교환 0/9 = 판정 불가), `../salvage_20261123/PREREG_34pc.md`·`gate34pc.json`
(CEM 양성 대조: 과제를 통과한 해는 전부 표적 순서 도달, 실패는 과제·예산), codex v3 규칙(`../FM34_v3_content_style_codex최종_sol_20261123.txt`:
학습·평가 종료 일치, alive 보너스 없음, 정지에서도 신호 있는 속도 보상, 보상 척도 잠금, task-only 먼저, 통과선).
질문: **강한 최적화기(SAC)로, 시범에서 배운 스타일 보상이 같은 속도에서 시범의 착지 순서(앞발 먼저 vs 뒷발 먼저)를 정책에 심을 수 있는가.**
코드(이 폴더, 새 파일): `sac34.py`(S1·S3 학습, `vec.BSAC`·`vec.bmlp`·`phase_util.BPhaseFlow` import), `demos34.py`(S2), `agg34.py`(판정).

## 공통 정의 (S1·S2·S3 동일, 같은 함수)
- 환경: HalfCheetah-v5 모델·`_get_obs`. 스텝은 직접 수행: ctrl=a, `mj_step` 5회(frame_skip 그대로) — **서브스텝(0.01 s)마다 바닥–bfoot/ffoot 실제 접촉** 검사(gate34pc `Feet`와 같은 접촉 정의, 높이 히스테리시스 `FootTD` 안 씀).
- 종료: 학습·평가 모두 1000스텝 시간 제한만. done=0(시간 제한 절단은 부트스트랩). alive 보너스 없음.
- 착지: 발이 **연속 ≥3 서브스텝 공중** 뒤 접촉 시작한 서브스텝. 시각은 서브스텝 단위(스텝=5).
- 뒷발 주기 Tb = 연속 두 뒷발 착지 간격. 유효 범위 **[1.5, 40] 스텝**(7.5–200 서브스텝).
- 순서 지연 ℓ: 앞발 착지 시각 t_f 에서, 직전 뒷발 착지 t_b ≤ t_f 와 그 앞 뒷발 착지로 정한 Tb 가 유효하고 (t_f−t_b)/Tb < 1 이면 ℓ=(t_f−t_b)/Tb ∈[0,1). 아니면 그 착지는 무효.
- **표적: ℓ_R = 0.25(뒷발이 앞섬, 앞발이 ¼주기 뒤), ℓ_F = 0.75(앞발이 ¼주기 앞섬).** 원형거리 d(·,·)∈[0,.5].
- 부호 좌표 s(ℓ) = d(ℓ, ℓ_R) − d(ℓ, ℓ_F) ∈ [−0.5, 0.5] (F 쪽 +).
- 관측(전 팔 동일, 표적과 무관): env obs 17 + [min(뒷발 착지 후 경과,40)/40, min(앞발 착지 후 경과,40)/40, min(Tb,40)/40, cos2πℓ_last, sin2πℓ_last, ℓ_last 유효 여부] = 23.
- 과제 보상: r_task = −|vx − v*| − 0.1‖a‖² − 1·[cos(rooty) < 0]. **v* = 1.0 m/s**(CEM 양성 대조 시범이 이 속도에서 F·R 둘 다 존재). 정지 시 −1 로 신호 있음.
- 순서 점수(오라클·템플릿 공용): 유효 앞발 착지마다 score = 1 − 4·d(ℓ, 표적) ∈[−1,1] 을 갱신·유지, 매 스텝 r_order = 유지 점수. 마지막 유효 앞발 착지가 40스텝보다 오래됐거나 아직 없으면 −1. (이벤트당 보너스 아님 — 발 두드리기 악용 차단)
- 평가 에피소드: 결정적 정책, 1000스텝. **과제 통과** = 스텝 500–1000 변위 속도가 v*±10% 이고 cos(rooty)>0 스텝 ≥90%. **순서**: 스텝 200 이후 유효 ℓ 의 원형평균 ℓ̄(유효 ℓ ≥10개 필요, 아니면 ℓ̄ 정의 안 됨 → 실패, s=0). **순서 도달** = ℓ̄ 정의되고 d(ℓ̄, 표적) < 0.125.
- 집계: **최종 체크포인트만**. 리셋 시드 — S1 평가 500000+e, S2 시범 600000+e, S3 평가 700000+e (서로 안 겹침), 학습 리셋 1000·멤버+seed.
- SAC: `vec.BSAC` 기본값(lr 3e-4, γ .99, τ .005, 배치 256, UTD 1, 무작위 행동 5000스텝), 30만 스텝.

## 스모크 (판정 아님)

## S1 양성 대조 (오라클)
- 팔(멤버): task-only ×3 seed / task + w·r_order(표적 F) / task + w·r_order(표적 R), **w ∈ {0.5, 1.0}** 둘 다 사전 등록(사후 재튜닝 없음) → 3 + 2×2×3 = 15 멤버.
- 평가: 멤버당 10 에피소드. **seed 판정**: 과제 통과 ≥9/10 이고 순서 도달 ≥8/10.
- **S1 통과(w별)**: F 3 seed, R 3 seed 모두 seed 판정 통과. 둘 중 하나라도 통과하면 S1 통과(w 두 개 = 다중비교 표기). 둘 다 통과하면 과제 통과 에피소드 수가 많은 w, 동률이면 0.5 를 **S3 스타일 가중치로 잠금**.
- task-only 는 실패 분해용(과제 실패 / 순서 실패 / ℓ 미정의) + 자발 순서 보고.
- **불통과 → 중단·보고**(오라클로도 SAC 가 못 함).

## S2 시범
- 시범자 = S1 통과 w 의 오라클 정책 seed 0,1,2(표적별). **시범자 단위 held-out**: seed 0·1 = 학습 시범(각 12 에피소드), seed 2 = held-out(20 에피소드). 리셋 600000+.
- 과제 통과 에피소드만 시범으로 쓴다(순서로 거르지 않음). 학습 시범 <20 또는 held-out <20(표적별)이면 중단.
- **통과: held-out 에서 s 로 D_F vs D_R 구분 AUC ≥ 0.9.** 간격 gap = mean s(D_F held-out) − mean s(D_R held-out).
- 보고(판정 아님): 관절별 PSD 상대차이 D_F vs D_R, 같은 표적 안 시범자 간 PSD 차(바닥).

## S3 라벨 교환
- 팔 4개 × 라벨 {D_F, D_R} × seed {0,1,2}(라벨 간 같은 seed 짝) = 24 멤버, 모두 같은 관측·리셋·종료·과제 보상.
  r = r_task + w_lock · r_style, r_style ∈ [−1,1] 로 고정 보정(학습 중 이동 z-score 없음):
  1. `amp_plain`: AMP 판별기(LSGAN+GP10, train_phase 와 같은 형식) on 표준화 (s,s') 34차원. r_style = 2·clamp(1−¼(D−1)²,0)−1.
  2. `amp_phase`: 같은 것 + 접촉 위상 φ_b = 2π·min(뒷발 착지 후 경과/Tb,1) 의 4-고조파.
  3. `fm_phase`: 시범 학습분 (s,s') 의 FM 사전분포 `BPhaseFlow(film4)` (φ_b 조건, 3만 반복, 고정). 우도가중 잔차 res(M=4).
     보정(RL 전 1회): q_D = 학습 시범 창 잔차 중앙값(M=16). r_style = clip(1 − log(1+res/q_D)/log 2, −1, 1) (res=0→1, res=q_D→0, res≥3q_D→−1).
  4. `template`: 학습 시범의 ℓ 원형평균 ℓ_D 를 표적으로 한 순서 점수(오라클과 같은 식, 표적만 시범 추정치).
- 표준화 통계(평균·표준편차)는 학습 시범(두 라벨 합친 것)에서 한 번 계산해 잠근다.
- 진단(RL 전, 판정 아님): FM 보상으로 held-out D_F·D_R 창을 채점한 AUC(각 라벨 사전분포).
- 평가: 멤버당 10 에피소드(리셋 700000+). 에피소드 s 값(ℓ̄ 정의 안 되면 0), 멤버 s̄ = 평균.
- **통과(팔별)**: 모든 seed k 에서 shift_k = s̄(라벨 F 정책) − s̄(라벨 R 정책) ≥ gap/2, 그리고 그 두 멤버 모두 과제 통과 ≥9/10.
  어떤 팔이 하는지, task-only(S1) 대비 과제 비용(과제 통과율·속도오차·제어비용) 보고. 팔 4개 = 다중비교 표기.
- 해석 범위: template 은 손으로 정한 특징(착지 순서)을 시범에서 추정만 하므로 "학습된 스타일" 주장 대상이 아니다 — 학습 보상 주장은 amp_*·fm_phase 로만.

## S4 사전등록 · 다중 스타일 모드 붕괴 (2026-11-23, 사용자 승인 단계, 실행 전 작성 — S3 결과와 무관하게 S1 통과 시 실행)
주장(사용자 가설): 시범이 여러 스타일의 혼합일 때 AMP 판별기 보상은 1–2개 스타일로 붕괴하고, 위상조건 우도(FM) 보상은 스타일을 더 고르게 덮는다.

### 유도 (codex gpt-6.2-sol 검수 대상)
표기: p_D = Σ_k w_k q_k (스타일 k 의 창 분포 q_k, 서로 지지 거의 분리), p_π = 정책이 실제 방문하는 창 분포. 보상은 정책 표본 x~p_π 에서만 평가된다.
가정 A1: 판별기·밀도모델이 최적(무한 용량·무한 표본). A2: 스타일 지지 분리(q_j q_k ≈ 0). A3: 정책이 혼합을 표현할 수 있으면 p_π = Σ_k v_k q_k 꼴(스타일 내부 모양은 시범과 같다고 둠 — 순수하게 '비율 v' 만 비교).
1. **AMP(LSGAN, 목표 ±1)**: D* = (p_D − p_π)/(p_D + p_π). 표본 보상 r = 1 − ¼(D*−1)². 스타일 k 위에서 비 c_k = v_k/w_k 이면 D* = (1−c_k)/(1+c_k), r_k = 1 − c_k²/(1+c_k)².
   기대보상 J = Σ_k v_k r_k(c_k). 예(w = ⅓ 셋, 덮은 스타일엔 고르게): 셋 다 덮음 c=1 → r=.75 / 둘만 c=1.5 → r=.64 / 하나 c=3 → r=.4375. **판별기가 p_π 를 보고 있으므로 덮지 않은 스타일이 있으면 덮은 쪽 c_k>1 → 표본 보상이 떨어진다 = 덮기 압력이 존재.** 이 게임의 균형은 p_π=p_D(LSGAN 은 엄밀히 JS 가 아니라 χ² 계열 발산; 아래 3의 JS 수치는 GAN 계열의 대표 비교용).
2. **고정 우도 보상 (S3 의 fm_phase 와 같음)**: r(x) = log p_D(x)(보정된 단조변환 포함). p_π 와 무관 → J = Σ_k v_k E_{q_k}[log p_D] 는 v 에 선형 → **최적은 기대 로그밀도가 가장 큰 단일 스타일(꼭짓점 해)**. 엔트로피 정칙화(max-ent SAC)는 행동 엔트로피일 뿐 스타일 비율 v 의 엔트로피가 아니므로(메모리 11-22: 행동엔트로피≠상태방문엔트로피) 이를 바꾸지 못한다. **즉 고정 우도 보상은 모드 '추구'(mode-seeking)이며 덮기 압력이 0.** "우도=forward KL=모드 덮기"는 모델을 데이터에 맞출 때(MLE, E_{p_D}[log p_θ])의 성질이고, 정책이 E_{p_π}[log p_D] 를 최대화하는 RL 보상에는 성립하지 않는다(기댓값을 정책 쪽에서 취하므로 reverse 방향).
3. **학습자 밀도 보정 우도 (log p_D − log p_π)**: J = −KL(p_π‖p_D) = −Σ_k v_k log(v_k/w_k) → 최적 v=w(덮음). 스타일 하나를 빠뜨리면 log(1/(1−w_j)), 하나로 붕괴하면 log(1/w_k) 손해. AMP 도 같은 최적(v=w)을 가지며, 분리 지지에서 두 목적의 '빠뜨림 벌점 비'(붕괴/하나 빠뜨림)는 KL 2.71, JS 2.41로 비슷하다 → **모집단 수준에서 FM(보정)이 AMP보다 더 고르게 덮는다는 예측은 나오지 않는다.** 남는 차이는 실천적인 것뿐: 적대 학습의 판별기 과적합·순환(덮은 스타일 보상이 떨어지면 다음 스타일로 '도망'하는 진동) vs 고정/천천히 맞추는 밀도모델의 안정성. 이것은 유도가 아니라 경험적 질문.
4. **정책 클래스 조건(결정적)**: 잠재변수 없는 단일 결정적 정책은 초기상태 잡음(HalfCheetah reset ±0.1)만으로 스타일을 골라야 한다. 이 경우 v 는 사실상 꼭짓점(한 스타일)으로 몰릴 가능성이 높고, 그러면 **어떤 보상이든 붕괴로 측정**된다 → 보상 비교가 판별 불가가 될 수 있다. 그래서 확률적 정책(평가에서 표본 행동) 측정과 잠재조건 변형을 함께 둔다.
**사전 예측(이 유도에 따른 것):** fixed-FM(fm_phase)은 AMP보다 붕괴가 같거나 더 심하다(가설과 반대). 보정-FM(fm_ratio)은 AMP와 비슷. 잠재조건 AMP(amp_latent, ASE/CALM 계열 해법)가 가장 잘 덮는다. 가설이 맞으려면 fm_* 가 amp_phase 보다 KL 이 낮아야 한다(아래 통과선).

### 설정
- 스타일 3개, 같은 과제 v*=1.0: F(ℓ=.75), R(ℓ=.25) = S1 오라클 정책(S1 잠금 w), M(ℓ=.5) = 같은 오라클 보상·같은 w 로 학습한 정책(`s4prep`, S1 과 같은 설정; S1 과 같은 seed 판정 통과가 필요, 미달 seed 는 시범자에서 제외·보고, 시범자 ≥2 필요).
- 시범: 스타일별 같은 에피소드 수(과제 통과만, 시범자 seed 0·1 학습용 12씩 → 스타일당 동수로 잘라 맞춤, seed 2 = held-out 20). S2 시범(F·R)을 재사용, M 은 같은 절차(리셋 600000+).

  가정: (i) 우도가중 잔차 ≈ −log 밀도 + 상수(유한 절단 δ=1e-3 편향 있음), (ii) 위상 조건이므로 최적은 위상별 d_π(s,s'|φ) = p_E(s,s'|φ) — 위상 주변분포 일치는 보장 안 됨, (iii) SAC 엔트로피는 행동 엔트로피이지 상태방문 엔트로피가 아님 → 덮기 압력은 이 대비 항에서만 온다, (iv) 학습자 밀도는 최근 버퍼로 맞추므로 현재 정책 밀도와 시차가 있다, (v) 클리핑 ±1 은 큰 밀도비 차이를 잘라 등식을 깬다. 이 팔은 codex r1 이 지적한 등식 근거 부족을 가정으로 명시하고 탐색적으로만 넣는다.
- 주 비교(fm_phase vs amp_phase)는 그대로 두고 fm_contrast vs amp_phase 는 보조(다중비교 표기).
- 우선순위: S3 가 주 실험. S4 학습은 S3 시작 후 별도 프로세스로 돌린다.
