# #34 양성 대조 사전등록 · 착지 순서만 다른 두 보행 (2026-11-23, 실행 전 작성)

## 보행 쌍 만들기
- 기반 제어기: `gate34_20261123/gaits_v1.0.npz`의 A_inphase_s{2,4,5}(개루프 2-고조파, P=12, v*=1.0)이다. 관절별 진폭은 그대로 둔다.
- **앞발 먼저(F)**: 앞다리 3관절(인덱스 3–5)의 1차 위상 +π/2, 2차 위상 +π.
- **뒷발 먼저(R)**: 같은 관절에 1차 위상 −π/2, 2차 위상 −π(= +π).
- 두 변형은 관절별 진폭이 같고, 뒷다리 대비 앞다리 위상차의 부호만 반대다. 그다음 **상수항 6개만** CEM(8세대×64, 과제 보상)으로 다시 맞춰 v*=1.0에 도달시킨다. 진폭·위상은 고정한다.
- 시범: 변형마다 리셋 8개(F 341000+, R 342000+). 과제 통과분만 쓰며, 앞 2개는 기준·표준화용이고 나머지가 시험이다.

## 착지 순서 지표(단순 기준선이자 오라클 표적)
- 프레임 해상도에서 발 geom 높이 < 반지름 + 0.01 m이면 접지로 본다. 공중 → 접지 전환이 착지다.
- 위상 지연 ℓ = (뒷발 착지 뒤 첫 앞발 착지까지 프레임) / P, 0과 1 사이. 에피소드 값은 마지막 256프레임 착지들의 원형 평균이다.
- 보고: F·R 시험 에피소드 ℓ 분포, 순서 지표의 F/R 구분 AUC, 관절별 PSD 상대거리(F 대 R)로 "스펙트럼이 같다"를 확인.

## (a) 스타일 특징의 구분력
coordination34.features(psd, zero_lag, signed_area, cross_spectrum)로 기반 제어기마다 F 기준(앞 2개)까지의 상대거리를 잰다. AUC = P(R 시험 거리 > F 시험 거리). **통과: cross_spectrum AUC ≥ 0.90**(주 스타일 특징). 나머지 특징과 순서 지표 AUC도 보고한다. 기반 3개 각각과 합산을 보고한다.

## (b) 오라클 보상으로 각 보행에 도달하는가(양성 대조)
- 정책 클래스: 제약 없는 30계수, 무작위 초기화(ladder_pair34와 같은 CEM 초기 분포).
- 예산: **기본 8세대×64**(ladder와 같음), **4배 8세대×256**. 모든 팔에 같은 예산을 준다.
- 팔: task만 / task − 2·d_circ(ℓ, ℓ_F) / task − 2·d_circ(ℓ, ℓ_R) / task − 1·d_cross(F 기준) / task − 1·d_cross(R 기준). ℓ_F, ℓ_R은 각 변형 시범 ℓ의 원형 평균이다. 예측 탐색 리셋 2개, 후보 선택 리셋 4개.
- 평가: 고른 해를 새 리셋 4개에서 384스텝 실행한다. **도달 = 과제 4/4 통과이면서 |ℓ − 표적| < 0.125(원형)**.
- 반복: 기반 3개(표적 ℓ의 출처) × CEM 시드 3 = 표적마다 9회.
- **양성 대조 통과: 오라클 팔이 F·R 각각에서 어떤 예산이든 ≥ 8/9 도달.** 불통과면 이 CEM·정책 클래스로는 표적 보행에 도달할 수 없다는 뜻이다. 그 경우 스타일 보상 라벨 교환 실험(0/9)은 판정 불가로 확정한다.
- 스타일 팔(cross_spectrum)의 도달률은 참고로 보고한다(보상 학습 주장 아님).

- 참고: task만 → F 2·R 3/9(256), cross 팔 → 1/9. 기존 스타일 라벨 교환 0/9는 이 예산에서 **판정 불가**로 확정한다.
