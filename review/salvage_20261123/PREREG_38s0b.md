# #38 0b단계 사전등록 · 원칙으로 정한 행동 격자 (2026-11-23, 실행 전 작성)

근거: 코디네이터 지시와 0단계 한계(행동 간격 0.375 m ≫ 성공창 ±0.10 m). 코드 `gate38s0b.py`. 사후 기계는 0단계 `gate38s0.pf_to_cut`(pf36_g3 PF, N=2048, 온도 4)를 그대로 쓴다. 학습은 없다. 새 시드 **38100–38103**(48사례씩, 총 192). PF_NTH=7.

## 고정 설계(결과를 보기 전에 원칙으로 정함)
- **성공창**: 마지막 프레임(49) x가 x* ± 0.10 m 안. 0단계와 같다.
- **행동 격자**: Δvx ∈ [−1.5, +1.5] m/s, 간격 0.1 m/s, 31개. 남은 비행 시간이 0.5 s이므로, 행동 한 칸이 바꾸는 최종 x는 최대 0.1×0.5 = 0.05 m다. 이는 창 폭(0.20 m)의 1/4이고, 지시한 ≤0.05 m 기준을 맞춘다. 마찰은 이 변화를 줄일 뿐이다. 모든 정책이 같은 격자를 쓴다.
- **목표**: x*는 참 상태·참 물성에 U[−1.5, 1.5]의 연속 무작위 킥을 주고 한 번 굴린 결과다(격자 밖 킥).
- **가치**: 각 정책이 고른 행동의 참 기대 성공 P*(a)로 잰다. P*는 참 상태·참 물성에서 행동마다 64회 굴려 구한다.

## 정책(프레임 24에서 결정, 사후 입자 M=256 재표집)
| 이름 | 상태 | 물성 |
|---|---|---|
| bayes | 사후 입자 | 사후 입자 |
| map | 사후 입자 | MAP 칸 하나 |
| known | 사후 입자 | 참 물성 |
| point_known | 사후 평균 상태 1점(×M, 반발 잡음 있음) | 참 물성 |
| point_map | 사후 평균 상태 1점 | MAP 칸(확실성 등가 계획기) |
| full | 참 상태 | 참 물성 |

- **격차 분해**: full − bayes = (known − bayes)[물성 몫] + (full − known)[상태 몫].
- **상태가 우세하면**(상태 몫 > 물성 몫): 상태에 대한 베이즈 known − point_known, 그리고 bayes − point_map을 보고한다.

## 정보 가치(같은 사례)
- **추가 관측**: 프레임 0–24를 가림 없이 본 PF로 다시 bayes. 차이 = 추가 관측의 가치.
- **탐침 행동 1회**: 프레임 24에 고정 탐침 킥 Δvx=+0.75를 주고, 프레임 25–29를 가림 없이 관측(σ 같음)한다. 그다음 프레임 29에서 같은 31개 격자로 교정 킥을 주고, 20프레임 굴려 같은 x*를 맞춘다.
  - 비교 대상은 같은 탐침 킥을 주되 25–29를 **보지 않고** 예측만 하는 PF(blind)다. 둘 다 같은 실현 참 상태에서 P*_probe로 잰다.
  - 탐침 가치 = bayes_probe_obs − bayes_probe_blind. full_probe도 보고한다.

## 집단과 신호(변경 없음)
- **모호 집단**: MAP 칸 사후 질량 < 0.5(사후만으로 정한다). 보조로 질량 < 0.3 집단도 보고한다(판정 외).
- **진행 신호**: 모호 집단에서 평균(P*(a_bayes) − P*(a_map)) ≥ 3%p이고, 사례 짝 부트스트랩 95% 하한 > 0.
