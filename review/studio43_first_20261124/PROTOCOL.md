# #43 첫 합성 학습 실험 — 결과 확인 전 고정한 조건

실제 영상을 새로 보지 않고 만든 합성 학습법과 실제 개발 영상 2장의 희소 측정으로 렌더 장면을 고른 방법을 시험한다. 실험의 범위는 절대 깊이와 이를 입력으로 한 고정 배경 흐림 렌더러다.

| 조건 | 실측 사용 | 최종 렌더 조건을 고르는 법 |
|---|---|---|
| zero_random | 없음 | 네 조건에서 균등 확률로 장면 생성 |
| zero_synthetic | 없음 | 공통 예비모델의 합성 검증 묶음에서 배율을 맞춘 후 큰 잔차를 보인 영상 영역에 대응하는 조건을 더 생성 |
| few_random | 두 개발 영상에서 각 32점 | 공통 배율을 맞추고 같은 잔차 표를 계산. 최종 장면은 균등 확률로 생성 |
| few_guided | 같은 두 영상과 같은 64점 | 배율을 맞춘 뒤 남은 실제 거리 오류에 따라 조건의 생성 확률을 변경 |

두 모델 계열을 별도로 평가한다. (가) 난수 초기화한 소형 단안 깊이망은 zero 조건에서 실제 RGB·깊이·사전학습 가중치를 전혀 사용하지 않는다. (나) Apple Depth Pro 2-H+를 고정하고 작은 잔차 보정망을 학습한다. 이 계열의 zero는 이번 적응의 실측이 0개라는 뜻이다. Apple 사전학습에는 실사가 포함됐다. 공개 하드웨어와 렌더러에 맞춘 소규모 실험이며 각 계열 내에서만 예산을 맞춘다.

- 합성 장면은 광선과 배경 벽·바닥·입체 도형의 교점을 계산하고 깊이, 조명·재질이 반영된 영상을 함께 만든다. 기본 산란면, 복잡한 실루엣, 어두운 저대비, 고휘도 반사성 표면의 네 생성 조건을 쓴다. RGB만으로 부여하는 진단 영역은 고휘도·저휘도·강한 경사·나머지로 정하고, 해당 생성 조건과 연결한다. 혼합 확률의 절반은 균등분포로 남긴다. 후보 풀을 대량 렌더한 뒤 유리한 것만 고르지 않는다. 최종 조건을 먼저 정한 뒤 장면을 렌더한다.
- 각 정책·학습 시드에 동일하게 예비 64장, 진단 전용 32장, 최종 128장(총 224장)을 배정한다. 동일한 기하 난수·재질 난수·장면 수를 제공하며 조건 선택이 다른 장면만 달라진다. 예비 80회, 최종 160회 경사 갱신, 배치 4, 같은 손실·학습률·초기값 및 학습 순서. 세 고정 시드 431, 433, 439. 예비·진단·균등 장면을 중복 실행하지 않고 공유할 경우 각 정책에 전액 청구한다. 시험 결과를 보고 학습 설정을 고르지 않는다.
- 소량 실측은 ETH3D SLAM의 cables_1, desk_changing_1 중간 프레임 1장씩이다. 영상마다 미리 고른 4×8 구역에서 각 1점, 절반은 공통 로그 배율, 나머지는 오류 분류용이다. 안 나온 깊이값은 재조회 없이 실패로 기록한다. 무작위 기준도 같은 실제 RGB, 64회 질의, 개발용 모델 추론과 배율을 사용한다. 시험 시 새 거리값은 사용하지 않는다.
- 시험은 ETH3D SLAM의 einstein_1, mannequin_1, plant_1, reflective_1, sofa_1, table_1, ceiling_1, sfm_lab_room_1. 시퀀스당 15·50·85% 위치에서 각 4개의 연속 프레임. 공개 RGB-D 거리값 0.2–10m에서 평균 절대오차를 구하고 비디오를 같은 비중으로 합친다. 같은 영상에서 센서 깊이로 만든 기준 흐림과 예측 깊이로 만든 흐림을 같은 렌더러로 비교한다. 유효한 깊이 불연속 주변에서 고주파 밝기의 절대 차이를 사용한다. 이는 광학 실측이 아닌 영상 경계의 대리 지표다.
- 독립 광학 검사는 RealBokeh 공식 test 중 번호 정렬 후 균일 간격 32장면의 실제 f/22 입력, f/2 표적으로 한다. 촬영 메타데이터의 초점·초점거리와 모든 방법에 동일한 원판 흐림 렌더러를 쓴다. 양쪽 **실제 사진**의 국소 고주파 에너지 비로 초점 전이대를 정하고 그 경계에서 렌더/광학 표적의 고주파 밝기 차이를 잰다. 이 사진들은 시간축이 없다. 광학 정답이 짝지어진 동영상 촬영과 구분한다.
- 주 판정은 few_guided 대 few_random. 세 시드 평균에서 깊이 MAE, 같은 영상의 경계 오류, 실조리개 경계 오류가 모두 줄고 각 지표의 장면/영상 짝 부트스트랩 단측 95% 상한(후보−기준)이 0 미만이어야 통과다. 촬영 프레임·픽셀을 독립 사례로 세지 않는다. 엄격한 합성 전용 비교도 같은 세 조건을 쓴다. ‘높은 수준’은 추가로 세 지표 모두 공개 H+ 원본의 1.05배 이내라는 탐색용 기준으로 수치화한다. 측정 잡음, 작은 장면 수, 사전학습 원본의 자료 중복 가능성을 별도로 보고한다.
