# #42 드문 사례의 세대별 소실 시험

기존 평균값 실험과 출처별 단일 갱신을 본 뒤 추가하는 탐색 실험이다. 아래 조건을 결과 계산 전에 정한다.

초기 교사는 드문 사건의 확률을 0.08로 출력하며, 실제 확률은 0.08 또는 0.03이다. 실측 예산은 총 0개 또는 8개로 한 번만 준다. 실측이 있으면 교사의 초기 정보량을 32개로 고정해 모든 방법에 같은 출발값을 준다. 이후 24세대 동안 새 실측은 없다. 고정 초기 교사는 강한 기준이다. 평가 단위는 한 번의 24세대 학습 경로이며 조건당 4,096회 생성한다.

각 세대에 현재 학생이 다시 교사가 되어 8개 출처에서 총 128개 표본을 만든다. 출처당 생성 개수는 2, 3, 5, 8, 12, 20, 30, 48개다. 자식마다 0 또는 0.6의 확률로 같은 출처의 잠재 이진 값을 복사하고, 그 외에는 독립적으로 현재 교사에서 뽑는다. 따라서 부모 내 상관계수는 각각 0 또는 0.36이다. 같은 세대·경로의 부모 및 자식 난수는 방법끼리 공유한다. 방법이 서로 다른 학생을 만들면 다음 세대의 관측값도 달라진다.

비교는 표본별 균등, 출처별 균등, 참 상관을 아는 이론상 가중, 이전 세대까지 누적한 표본별 빈도, 초기 교사를 그대로 유지하는 방법이다. 참 상관 가중은 출처별 가중치의 잠재력을 재는 참고값이다. 세대별 전체 128개를 재학습하는 세 방법에는 같은 산식으로 작은 확률을 그대로 두며 임의의 바닥값을 두지 않는다. 주 지표는 최종 예측 확률이 0.01 아래로 떨어진 비율과 참 확률에 대한 평균 절대오차다. 이진 범주 빈도 실험으로 영상 신경망의 재귀학습 이득을 판정할 수 없다.
