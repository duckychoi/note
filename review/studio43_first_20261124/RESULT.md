# #43 첫 합성 학습 실험

**이번 구현에서는 실제 거리 오차를 참고해 렌더 장면을 고르는 방법이 균등 무작위보다 깊이와 광학 경계를 함께 개선하지 못했다.** 사전학습 없는 작은 모델은 실제 거리 평균 오차가 781.35 → 771.80mm로 줄었지만, 실제 조리개 사진의 경계 오차는 12.208 → 12.263으로 커졌다. 공개 Depth Pro 2-H+ 위에 합성 보정망을 얹은 실험에서도 세 지표 평균이 모두 악화됐다. 사전 기준, 실제 결과, 독립 재집계 기록을 보관했다. [사전 조건](PROTOCOL.md) · [결과 원자료](outcomes.json) · [최종 검수](codex_최종_sol.txt)

## 무엇을 같게 했나

| 역할 | 실제 실행 |
|---|---|
| 무작위 장면 | 산란면, 가늘고 복잡한 윤곽, 어두운 조명, 밝은 반사를 같은 확률로 생성 |
| 오류에 맞춘 장면 | 예비 모델의 배율 보정 후 깊이 잔차를 영상의 보통·강한 경사·어두운·밝은 영역별로 집계. 큰 오차와 연결한 유형의 생성 확률을 올림. 절반의 확률은 균등으로 보존 |
| 학습 모델 | 난수 초기화 CNN, 또는 공개 H+를 고정하고 합성으로 작은 잔차 보정망을 학습. 시험 시 동일한 보정 초점거리를 제공하고 한 프레임씩 추론 |
| 렌더·학습 예산 | 모델 계열·시드·정책마다 예비 64장 + 진단 32장 + 최종 학습 128장, 총 224장. 배치 4로 예비 80회 + 본학습 160회. 시드 431, 433, 439. 공통 장면과 균등 조건의 체크포인트는 공유하고 각 조건에 전액 계산 |
| 실측 0개 | 합성으로만 장면 선택. 처음부터 학습한 CNN은 실사 사전학습도 없음. H+ 보정 계열은 자체 적응에 사용한 실측이 0개이고 H+ 자체는 실사 사전학습 사용 |
| 소량 실측 | 훈련 프레임 2장 × 32점 = 64회 같은 위치 조회. 44개 유효. 배율 21점, 잔차용 23점. 두 실측 조건 모두 같은 영상을 보고 같은 배율 적용. 실사에 역전파한 횟수는 0 |

어두운 화면이나 밝은 픽셀은 재질·깊이 오류의 원인을 유일하게 지시하지 않는다. 렌더러도 구·상자·벽·바닥, 직접 조명, 간단한 광택을 그린다. 실제 장면의 정확한 3차원 구조·반사를 복원한 실험까지 수행한 것은 아니다. 공개 모델의 시야각 예측기는 끄고 제공된 초점거리를 사용했다. 비용은 처리한 장면, 질의, 경사 갱신으로 맞췄고 벽시계 시간을 비교하지 않았다. [장면·재질 코드](studio.py) · [학습·실측 코드](train.py) · [정책별 장부](training.json)

## 처음 보는 실제 촬영에서 얻은 결과

ETH3D SLAM의 개발 동영상 두 개와 별도의 동영상 여덟 개에서 12프레임씩 시험했다. 깊이는 실제 적외선 스테레오 추정값과 비교했다. 동영상 경계는 같은 프레임을 센서 깊이로 흐린 영상과 비교한다. 유효 경계 픽셀이 32개 이상인 62/96프레임이 이 항목에 들어갔다. 독립 광학 검사는 RealBokeh 공식 시험 32장면에서 실제 f/22 사진을 입력으로 사용하고 렌더 결과를 실제 f/2 사진과 비교한다. 경계 지표는 선형 밝기의 고주파 성분 차이 ×1,000이다. 낮을수록 좋다. 이는 논문의 Boundary LPIPS와 다른 수치다. 긴 변 320픽셀에서 모든 예측기를 같은 조건으로 평가했다. [ETH3D 장비와 깊이 설명](https://www.eth3d.net/slam_documentation) · [RealBokeh 원자료](https://huggingface.co/datasets/timseizinger/RealBokeh_3MP) · [Apple 원문](https://arxiv.org/abs/2611.26603)

주 비교에서 처음부터 학습한 모델의 세 지표 차이(실제 잔차 기준 − 무작위)의 단측 95% 상한은 +0.29mm, +0.152, +0.146이다. 세 상한이 모두 0보다 작아야 한다는 기준에 미달했다. 평균 깊이는 8개 영상 중 7개에서 좋아졌고, 실제 광학 경계는 세 학습 시드 모두에서 나빠졌다. H+ 보정 계열에서 같은 상한은 +121.56mm, +0.937, +0.251이다. 실측 0개 비교도 두 모델 계열 모두 관문 미달이다. 학습한 어떤 방법도 세 점수를 모두 공개 H+의 1.05배 안에 들게 하는 탐색 목표를 달성하지 못했다. 부트스트랩은 같은 평가 장면을 쌍으로 묶고 3개 학습 시드를 평균한 뒤 2만 번 계산했다. 새 학습 시드에 대한 불확실성까지 포함하는 구간은 아니다. [장면·시드별 집계](summary.json)

**어디서 개선이 나왔는가.** 처음부터 학습한 균등 모델에 소량 실측의 배율만 적용하면 깊이 오차는 2095.48 → 781.35mm로 약 63% 줄었다. 이때 두 경계 오차는 오히려 커졌다. 같은 배율을 적용한 뒤 장면 분배를 바꿔 생긴 깊이 차이는 9.54mm다. 배율만 맞추는 이득과 합성 학습법의 이득은 이렇게 따로 계산할 수 있다.

## 사후 진단과 한계

사전 판정 후 기존 H+에 같은 위치의 배율 점 21개만 적용했다. 1.0723배 보정 시 깊이는 363.52 → 446.69mm, 동영상 경계는 3.024 → 3.329로 악화됐지만, 실제 광학 경계는 8.926 → 8.898이었다. 실측 중앙값 0.705m를 화면 전체에 주면 깊이 939.84mm, 동영상 경계 6.412, 광학 경계 12.003이었다. 사진을 그대로 두는 무흐림 대조의 광학 경계는 19.907이다. 한 지표만으로 깊이와 광학 품질을 동시에 판단하기 어렵다. 이 진단은 사전 비교·모델 선택에 사용하지 않았다. [대조 코드](controls43.py) · [수치](controls43.json)

- 장면 수가 작고 두 개발 영상 중 유효한 잔차 표본은 총 23점이다. 같은 ETH3D 장비로 얻은 다른 시퀀스이며 제작사 학습자료까지 포함한 장면 중복 여부는 확인하기 어렵다.
- 실제 조리개 정답은 정지 사진이다. 동영상에서는 물리적으로 촬영한 조리개 쌍, 시간에 따른 떨림, 배경 번짐 폭을 직접 측정하지 않았다. 적외선 깊이도 반사·가림 경계에서 빠지거나 틀릴 수 있다. 장면별 경계 유효 프레임은 1–12개다. 한 화면의 밝기 고주파 오차에는 렌더러·노출·미세 정렬 차이도 포함된다.
- 소형 합성 도형과 짧은 학습에서 얻은 결과다. 사전학습의 전체 비용, 두 실장비에서 측정시간 20% 감소, 발표 논문의 원래 해상도·동영상 방식 대비 성능은 이번 실험의 측정 대상 밖이다.
