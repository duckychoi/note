 13 ## 2. 바로잡은 결과 (선형 보간 $x_t=(1-t)x_0+tx_1$, $x_0\sim N(0,I)$ 독립)
 14 **보조정리 1.** $0<t<1$, 임의 끝점분포에서 $m=\mathbb E[x_1|x_t=x]$ 일 때 $u=(m-x)/(1-t)$, $s=-(x-tm)/(1-t)^2$ ⇒ $\Delta s=\tfrac{t}{1-t}\Delta u$.

 16 **정리 1 (KL 등식).** $p,q$ 가 유한 2차 모멘트를 가지면
 17 $$\mathrm{KL}(q\|p)=\int_0^1\frac{t}{1-t}\,\mathbb E_{x\sim q_t}\|u_q(x,t)-u_p(x,t)\|^2dt\quad(\text{계수 1, 등식; KL}=\infty\text{ 포함}).$$
 18 증명: $y=x_t/t$ 는 $x_1+\sqrt\tau Z$, $\tau=((1-t)/t)^2$. 상대 de Bruijn $\tfrac{d}{d\tau}\mathrm{KL}(q_\tau\|p_\tau)=-\tfrac12\mathbb E\|\nabla\log q_\tau-\nabla\log p_\tau\|^2$, $y$-좌표 score 차 $=t^2\Delta u/(1-t)$, $|d\tau/dt|=2(1-t)/t^3$ ⇒ 피적분 $t/(1-t)\|\Delta u\|^2$. 양끝: $t\downarrow0$ 에서 $\mathrm{KL}(q_\tau\|p_\tau)\le W_2^2(q,p)/(2\tau)\to0$, $t\uparrow1$ 에서 데이터처리+하반연속성으로 원 KL 에 수렴. (Song 2021 likelihood weighting · Kingma&Gao 2023 의 FM 좌표판 — 독립 기여 아님, 도구.)
 19 
 20 **명제 2 (샘플별 리워드, 정확식).** 절단 $\delta$, $\tau_\delta=(\delta/(1-\delta))^2$, $p_\tau=p*N(0,\tau I)$:
 21 $$\ell_w(x)=\int_0^{1-\delta}\tfrac{t}{1-t}\mathbb E_{x_0}\|u_p(x_t,t)-(x-x_0)\|^2dt=\mathrm{KL}\big(N(x,\tau_\delta I)\,\|\,p_{\tau_\delta}\big)=-\tfrac d2\log(2\pi e\tau_\delta)-\mathbb E_Z\log p_{\tau_\delta}(x+\sqrt{\tau_\delta}Z).$$
 22 따라서 $K_\delta=-\tfrac d2\log(2\pi e\tau_\delta)$ 를 뺀 정규화 Gibbs 밀도 $g_\tau(x)=\exp[-(\ell_w(x)-K_\delta)]=\exp\mathbb E_Z\log p_\tau(x+\sqrt\tau Z)$ 는 Jensen 으로 $g_\tau\le p_{2\tau}$, 점별로 $g_\tau\to p$ (양의 연속 밀도), Fatou 로 $\int g_\tau\to1$ ⇒ **max-ent($\alpha$=1) 고정점 → $p$** ($\delta\downarrow0$). 오차 전개 $\ell_w-K_\delta+\log p=-\tau(\Delta\log p+\tfrac12\|\nabla\log p\|^2)+O_x(\tau^2)$ 는 매끄러운 양의 밀도(E1 GMM)에서 **고정 $x$ 마다** 성립. ($\exp(-\ell_w)$ 자체는 $(2\pi e\tau)^{d/2}$ 배라 정규화 필요.)

 26 **명제 4 (점유분포, 이산 결정론 MDP).** 창 $=(s,s')$, 정확 리워드 $\log p(s,s')$, 행동엔트로피 $\alpha$=1:

  8 ## 0. 세팅 (가정)
  9 - 기저 $p_0=\mathcal N(0,I)$, 데이터 $p_1=p_{data}$. 선형 보간 $x_t=(1-t)x_0+t x_1$, 독립결합 $x_0\sim p_0,\ x_1\sim p_1$.
 10 - 주변속도장(=CFM 최적장) $u_p(x,t)=\mathbb E[x_1-x_0\mid x_t=x]$ — 연속방정식 $\partial_t p_t+\nabla\!\cdot(p_t u_p)=0$ 으로 $p_t$ 생성.

 13 - (A1) 작은 노이즈 $\sigma>0$ 의 확률보간(stochastic interpolant) SDE 사용. (A2) $v^*$ 가 $x$에 대해 Lipschitz. (A3) 2차 모멘트 유한.

 15 ## 1. 잔차의 바이어스-분산 분해 (정확)
 16 정책 샘플 $x\sim q$ 에 대한 잔차 에너지:
 17 $$\mathcal R(q)=\mathbb E_{t\sim U[0,1]}\,\mathbb E_{x\sim q,\,x_0\sim p_0}\big\|v^*(x_t,t)-(x-x_0)\big\|^2.$$
 18 $y=x_t$ 고정 조건부에서 $u_q(y,t)=\mathbb E_q[(x-x_0)\mid x_t=y]$ 를 더하고 빼면(조건부평균 직교성, 교차항 0):
 19 $$\boxed{\ \mathcal R(q)=\underbrace{\mathbb E_t\,\mathbb E_{y\sim p_t^q}\|v^*(y,t)-u_q(y,t)\|^2}_{\textstyle B(q)\ (\text{바이어스: 장 불일치})}+\underbrace{\mathbb E_t\,\mathbb E\big[\mathrm{Var}_q((x-x_0)\mid x_t)\big]}_{\textstyle C(q)\ (\text{기약 결합분산})}\ }$$
 20 - $B(q)\ge0$, **$B(q)=0\iff u_q\equiv v^*$ (지지 위) $\iff q=p_{data}$** (장이 끝점주변을 결정). → **엄밀 proper discrepancy**.
 21 - $C(q)$: 결합의 기약 잡음(리워드 상수성 offset). 정책경사엔 $B(q)$ 의 $q$-의존만 유효.

 23 ## 2. 주정리 — divergence 상한
 24 **정리.** (A1–A3) 하에서
 25 $$\mathrm{KL}(q\,\|\,p_{data})\ \le\ \frac{1}{2\sigma^2}\int_0^1\mathbb E_{y\sim \rho_t}\|v^*(y,t)-u_q(y,t)\|^2\,dt\ \asymp\ \frac{1}{2\sigma^2}\,B(q).$$
 26 *증명 스케치.* 확률보간 SDE $dX=v^*(X,t)dt+\sigma dW$ 는 $p_0\!\to\!p_{data}$, $dX=u_q(X,t)dt+\sigma dW$ 는 $p_0\!\to\!q$ 를 수송(초기 동일). **Girsanov**: 두 경로측도의 KL $=\frac{1}{2\sigma^2}\int_0^1\mathbb E\|v^*-u_q\|^2dt$. **데이터처리 부등식**으로 끝점 주변의 KL이 경로 KL 이하. $\square$
 27 - 결정론 극한 $\sigma\!\to\!0$: KL 상한은 발산 가능 → 대신 **연속방정식 안정성(Grönwall)** 으로 $W_2^2(q,p_{data})\lesssim \int_0^1\|v^*-u_q\|_{L^2(\rho_t)}^2dt \asymp B(q)$ (Lipschitz $v^*$). 즉 $\sigma{>}0$이면 KL, $\sigma{=}0$이면 $W_2$ 를 상한.
 28 
 29 **따름정리 (리워드 타당성).** $\mathcal R(q)=B(q)+C(q)$ 이므로, $C(q)$ 를 상수화(또는 분산축소)하면 FM 잔차 리워드 $-\mathcal R$ 최대화는 $-\tfrac12\mathrm{KL}$ 의 하한을 밀어올림. max-ent(온도 $\alpha{=}1$) 고정점 $q^*\propto\exp(-\mathcal R/\alpha)$ 는 $B(q)$ 가 지배할 때 $p_{data}$ 로 수렴.

 31 ## 3. $-\log p$ 와의 gap (두 번째 질문)

  9   u(x,t)  = E[x1 - x0 | x_t = x] = (m - x) / (1 - t)          (marginal FM velocity)
 10   s(x,t)  = grad log p_t(x)       = -(x - t m) / (1 - t)^2      (score)
 11 """
 12 import numpy as np

 15 def _lse(a, axis):
 16     m = a.max(axis=axis, keepdims=True)
 17     return (m + np.log(np.exp(a - m).sum(axis=axis, keepdims=True))).squeeze(axis)

 20 class GMM:
 21     def __init__(self, w, mu, s):
 22         self.w = np.asarray(w, float) / np.sum(w)
 23         self.mu = np.atleast_2d(np.asarray(mu, float))          # (K,d)
 24         if self.mu.shape[0] != len(self.w):
 25             self.mu = self.mu.T
 26         self.s = np.broadcast_to(np.asarray(s, float), self.w.shape).copy()
 27         self.d = self.mu.shape[1]
 28 
 29     def _X(self, X):
 30         X = np.asarray(X, float)
 31         if X.ndim not in (1, 2):
 32             raise ValueError(f"expected (n,d) or (n,) input, got shape {X.shape}")
 33         if X.ndim == 1:
 34             # 1-D model: a vector means n points; d-dim model: a vector means one point
 35             X = X[:, None] if self.d == 1 else X[None, :]
 36         if X.shape[-1] != self.d:
 37             raise ValueError(f"last dim {X.shape[-1]} != d={self.d}")
 38         return X
 39 
 40     # ---- marginal of the interpolant at time t (t=1 -> data) ----
 41     def _comp_logpdf_t(self, X, t):
 42         V = t**2 * self.s**2 + (1 - t)**2                       # (K,)
 43         d2 = ((X[:, None, :] - t * self.mu[None]) ** 2).sum(-1)  # (n,K)
 44         return -0.5 * d2 / V - 0.5 * self.d * np.log(2 * np.pi * V) + np.log(self.w), V
 45 
 46     def _resp(self, X, t):
 47         e, V = self._comp_logpdf_t(X, t)
 48         return np.exp(e - _lse(e, 1)[:, None]), V
 49 
 50     def logpdf_t(self, X, t):
 51         X = self._X(X)
 52         e, _ = self._comp_logpdf_t(X, t)
 53         return _lse(e, 1)
 54 
 55     def logpdf(self, X):
 56         return self.logpdf_t(X, 1.0)
 57 
 58     def post_mean(self, X, t):
 59         """m(x,t) = E[x1 | x_t = x]."""
 60         X = self._X(X)
 61         g, V = self._resp(X, t)
 62         gain = t * self.s**2 / V
 63         mk = self.mu[None] + gain[None, :, None] * (X[:, None, :] - t * self.mu[None])
 64         return (g[..., None] * mk).sum(1)
 65 
 66     def velocity(self, X, t):
 67         """Component-wise stable form: u_k = mu_k + (t s_k^2 - (1-t)) (x - t mu_k) / V_k (valid at t->1)."""
 68         X = self._X(X)
 69         g, V = self._resp(X, t)
 70         uk = self.mu[None] + ((t * self.s**2 - (1 - t)) / V)[None, :, None] * (X[:, None, :] - t * self.mu[None])
 71         return (g[..., None] * uk).sum(1)
 72 
 73     def score(self, X, t):
 74         X = self._X(X)
 75         g, V = self._resp(X, t)
 76         sk = -(X[:, None, :] - t * self.mu[None]) / V[None, :, None]
 77         return (g[..., None] * sk).sum(1)
 78 
 79     def sample(self, n, rng):
 80         k = rng.choice(len(self.w), size=n, p=self.w)
 81         return self.mu[k] + self.s[k][:, None] * rng.standard_normal((n, self.d))
 82 
 83     def sample_t(self, n, t, rng):
 84         x1 = self.sample(n, rng)
 85         return (1 - t) * rng.standard_normal((n, self.d)) + t * x1
 86 
 87 
 88 def gl(a, b, n):
 89     """Gauss-Legendre nodes/weights on [a,b]."""
 90     x, w = np.polynomial.legendre.leggauss(n)
 91     return 0.5 * (b - a) * x + 0.5 * (b + a), 0.5 * (b - a) * w
 92 
 93 
 94 def gh(n):
 95     """Probabilists' Gauss-Hermite: E_{z~N(0,1)} f(z) ~= sum w f(z)."""
 96     z, w = np.polynomial.hermite_e.hermegauss(n)
 97     return z, w / np.sqrt(2 * np.pi)

  1 """
  2 E2 - does "max-ent RL + exact log-likelihood reward" match the expert distribution in an MDP?
  3 
  4 Ergodic deterministic MDP (ring, N states, actions {-1,0,+1}); a 'motion window' = transition (s,s').
  5 Expert p(s,s') = stationary transition distribution of a random expert policy (realizable target).
  6 Exact stationary distribution d_pi(s) (differentiable linear solve), exact gradients (torch, float64).
  7 
  8   (A) max-ent RL, reward r = log p(s,s'), alpha=1        J = E_d log p + E_d H(pi(.|s))
  9       Claim:  J = -KL(d||p) - H(d_S) + H(A|S,S')  (last term 0 iff injective) -> biased toward LOW state entropy
 10   (B) learner-density-corrected reward r = log p(s,s') - log d_pi(s,s')   J = -KL(d||p)
 11       (this is what a second, learner-fitted flow supplies; GAIL/SMILING-style)
 12   (C) (A) + state-marginal correction r = log p - log d_pi(s)   == (B) only if action->next-state is injective per state
 13       (general: J_C = -KL - 0 + H(A|S,S');  --noninj adds a duplicate 'stay' action to break injectivity)
 14   (D) next-state entropy H(S'|S) (actions with the same destination summed) + state correction == -KL in any
 15       deterministic finite MDP
 16 Outputs: results/v2/e2_occupancy.json
 17 """
 18 import json, os
 19 import numpy as np
 20 import torch
 21 torch.set_default_dtype(torch.float64)
 22 OUT = os.path.join(os.path.dirname(__file__), "..", "..", "results", "v2")

 24 import sys
 25 N = 12
 26 # injective: actions {-1,0,+1};  non-injective (codex C6 counter-case): {-1,0,0,+1} (two actions -> same s')
 27 MOVES = torch.tensor([-1, 0, 0, 1]) if "--noninj" in sys.argv else torch.tensor([-1, 0, 1])
 28 A = len(MOVES)
 29 NXT = (torch.arange(N)[:, None] + MOVES[None, :]) % N        # (N,A)
 30 ONEHOT = torch.nn.functional.one_hot(NXT, N).double()        # (N,A,N): action -> next state

 33 def stationary(logits):
 34     pi = torch.softmax(logits, -1)                             # (N,A)
 35     P = torch.zeros(N, N)
 36     P = P.index_put((torch.arange(N)[:, None].expand(N, A), NXT), pi, accumulate=True)
 37     M = P.T - torch.eye(N)
 38     M = torch.cat([M[:-1], torch.ones(1, N)], 0)
 39     b = torch.zeros(N); b[-1] = 1
 40     ds = torch.linalg.solve(M, b)
 41     return ds, pi
 42 
 43 
 44 def trans_dist(logits):
 45     """returns d(s,s') (N,N), d(s), pi.  d(s,s') sums actions with the same destination."""
 46     ds, pi = stationary(logits)
 47     Pss = torch.einsum("sa,san->sn", pi, ONEHOT)
 48     return ds[:, None] * Pss, ds, pi
 49

 51 def run(seed, steps=4000):
 52     g = torch.Generator().manual_seed(seed)
 53     exp_logits = 2.0 * torch.randn(N, A, generator=g)
 54     p, ps, _ = trans_dist(exp_logits)
 55     p = p.detach(); logp = torch.log(p.clamp_min(1e-300))
 56     Hps = float(-(ps * ps.log()).sum())
 57     res = {}
 58     for mode in MODES:
 59         th = torch.zeros(N, A, requires_grad=True)
 60         opt = torch.optim.Adam([th], lr=0.05)
 61         for _ in range(steps):
 62             d, ds, pi = trans_dist(th)
 63             Hpi = -(pi * torch.log(pi + 1e-300)).sum(-1)
 64             if mode == "A_maxent_logp":
 65                 J = (d * logp).sum() + (ds * Hpi).sum()
 66             elif mode == "B_logp_minus_logd":
 67                 J = (d * (logp - torch.log(d + 1e-300))).sum()
 68             elif mode == "C_maxent_plus_state_corr":
 69                 J = (d * logp).sum() + (ds * Hpi).sum() - (ds * torch.log(ds + 1e-300)).sum()
 70             else:   # D: next-state entropy H(S'|S) instead of action entropy (general deterministic MDP)
 71                 Pss = d / ds[:, None]
 72                 Hn = -(Pss * torch.log(Pss + 1e-300)).sum(-1)
 73                 J = (d * logp).sum() + (ds * Hn).sum() - (ds * torch.log(ds + 1e-300)).sum()
 74             opt.zero_grad(); (-J).backward(); opt.step()
 75         d, ds, pi = trans_dist(th.detach())
 76         m = d > 0
 77         kl = float((d[m] * (torch.log(d[m]) - logp[m])).sum())
 78         Hds = float(-(ds * ds.log()).sum())
 79         res[mode] = dict(KL=kl, H_state=Hds)
 80     res["H_state_expert"] = Hps
 81     return res
