## rev1 첫 실행 (N=64, θ0=30°) — 기록 보존
```

log-log slope: naive 0.10 / ΔΣ1 0.32 / STW 1.03  (이론 1/3/5)
```

rev1 의 피크 지표는 분모가 전체 최댓값이었다. 그래서 외부 로브가 메인빔보다 커도 0 dB 에서 잘렸다.
위의 30° "0.00" 을 그 조건 그대로 재계산하지는 않았다. 같은 rev1 STW 루프를 별도 조건(E4, θ0=23.7°, φ=0)에서 재면 조향점 |AF(ω0)| 대비 +32.96 dB 의 가짜 빔이 나온다.

### 기울기 2p+1 (§5) 재검증 — E3 (θ0=23.7°, Ω_b ∈ {0.02..0.16}, 잔차 r=c−x, 루프 디더 U(±0.5))
```
                    측정 직사각  측정 Hann  선형모델 직사각  선형모델 Hann  정확(무한개구)  내부e lag2
p=0 디더  N=4096      1.02        1.03        1.05           1.04          1.00
p=1 BP    N=4096      2.72        2.98        2.73           3.05          2.97         +0.157
p=2 BP    N=4096      3.11        4.82        2.36           4.83          4.88         −0.011
p=1 BP    N=65536     2.94        2.99        2.98           3.01          2.97         +0.156
p=2 BP    N=65536     4.17        4.90        3.70           4.90          4.88         −0.012
```
- 잔차는 c−x 로 잰다. STF=1 이므로 이득 추정이 필요 없다.
  - rev2 첫 판은 LS 이득을 제거한 c−α̂x 를 썼는데, 이것이 Hann·p=2 기울기를 4.12 로 깎았다(codex 지적, 수정함).
- **정확** = 백색 오차를 실제 NTF H_p (극점 r 포함)에 통과시켜 이 대역 범위에서 적분한 값이다.
  - 2p+1 은 Ω_b→0 의 점근 지수다(p=2, r=0.7 → 4.88; r=0 다항식이면 5.00). **확인**
- 균일(직사각) 개구에서 기울기가 줄어드는 현상은 독립 백색 e 의 선형모델에서도 재현된다. 같은 표본에 Hann 을 씌우면 회복된다. 따라서 원인은 **개구 누설**이다. **확인**
  - 감소 폭은 N 이 클수록 줄어든다(p=2 직사각: N=4096 3.11 → N=65536 4.17). 결론은 측정한 N 에 한정한다.
- 백색 오차는 *조건부 근사*다.
  - 위상 앙상블은 백색화가 아니다.
  - 디더를 넣어도 루프 내부 오차는 유색일 수 있다(p=1 BP 의 lag-2 자기상관 +0.16, E2 19.2°~19.7° 의 백색지수 +2.8~+3.7 dB).
  - 그래도 이 대역에서의 기울기는 정확 예측과 맞았다.

### 대역 내 셰이핑 ≠ 피크 로브 감소 — E5 (d=λ/2, 메인·미러 ±3빔폭 밖 피크, 조향점 대비)
```
              naive          BP1 입력 amp=1               BP1 입력 amp=0.5
N=64          −8.9~−9.5      −7.0~−7.1 (악화)             +2.4~+3.5 (메인보다 큼)
N=256         −9.5           −11.6~−11.8 (2.0~2.3 dB 개선)  −1.3~−0.0
```
- 대역통과 1차는 메인빔 근방 잔차를 명목 목표 톤 전력 대비 −44~−50 dB 까지 낮춘다(E2). 그러나 밀려난 노이즈가 보이는 먼 사이드로브로 나온다. d=λ/2 는 가시영역이 [−π,π] 전체다.
- 입력을 줄이면 메인빔이 약해져 피크 로브가 메인급 이상이 된다.
- 지표 구분(서로 직접 비교하지 않는다):
  - §2 의 −9.5 dB: **피크 로브 / 조향점 메인**
  - E2 의 −25~−31 dB: **대역 잔차 PSD / 디더 p=0**
  - E2 의 −44~−50 dB: **대역 평균 잔차 / 명목 목표 톤 전력 (amp·N/2)²**

## 슈퍼트위스팅 — 여전히 미검증 가설 (E4, N=64, 피크 로브 조향점 대비, 100회 평균)
```
            naive    rev1(−z)   부호수정 k1=1.5,k2=1.1   부호수정 k1=0.2,k2=0.02
θ0=10°      −9.4     +25.8          +3.4                    −10.0
θ0=23.7°    −8.9     +35.9         +13.6                    −10.5
θ0=45°      −9.5     +28.4          +6.6                    −10.9
```
- 부호를 고치면 σ 는 유계다(max|σ| ≈ 1.5~3.8). 그러나 문서 게인에서는 메인보다 큰 로브가 생긴다. 게인을 크게 낮춰야 순진보다 0.6~1.6 dB 낫다.
- 이 루프는 적분기 구조라 영점이 broadside 다(#2). 조향빔용 대역통과 STW(적분기 → ω0 공진기)는 아직 정식화하지 않았다.
- 결론: "STW = 리야프노프-안정 2차 ΔΣ, 40 dB/decade" 는 **검증되지 않았고, 현재 수치는 지지하지 않는다.** 검증된 2차 기준선은 선형 대역통과 BP2(r=0.7, \|NTF\|max=1.85)뿐이다.
- 1-bit 과부하 판정의 \|NTF\|max ≈ 1.5 는 설계 경험칙이지 정리가 아니다. 순수 BP²(6.8)의 발산은 실측이다(rev2 첫 실행 max|u| ≈ 3e5).
