### 기울기 2p+1 (§5) 재검증 — E3 (θ0=23.7°, Ω_b ∈ {0.02..0.16}, 잔차 r=c−x, 루프 디더 U(±0.5))
```
                    측정 직사각  측정 Hann  선형모델 직사각  선형모델 Hann  정확(무한개구)
p=0 디더  N=4096      1.06        1.06        0.95           0.93          1.00
p=1 BP    N=4096      2.74        2.91        2.73           3.02          2.97
p=2 BP    N=4096      3.01        4.89        2.44           4.94          4.88
p=1 BP    N=65536     2.96        2.97        2.95           2.95          2.97
p=2 BP    N=65536     4.48        4.89        3.84           4.91          4.88
```
- 잔차를 c−x 로 잰다(STF=1 이므로 이득 추정 불필요). rev2 첫 판의 LS 이득 제거(c−α̂x)는 Hann·p=2 기울기를 4.12 로 깎았다(codex 지적, 수정함).
- **정확** = 백색 오차를 실제 NTF 에 통과시켜 이 대역 범위에서 적분한 값이다. 2p+1 은 Ω_b→0 의 점근 지수다(p=2 → 4.88). **확인**
- 균일(직사각) 개구에서의 기울기 감소는 독립 백색 e 의 선형모델에서도 재현되고, 같은 표본에 Hann 을 씌우면 회복된다. 따라서 원인은 **개구 누설**이다. **확인**
  - 감소 폭은 N 이 클수록 줄어든다(p=2: N=4096 3.01 → N=65536 4.48).
  - "균일 개구에서는 p=2 이점이 사라진다"는 일반화는 하지 않는다. N=4096 조건에서만 대부분 깎였다.
- 위상 앙상블은 백색화가 아니다. 백색 근사는 디더로 얻는다. 디더 없는 순진 1-bit 는 오차가 톤이라 이 모델이 맞지 않는다.

### 대역 내 셰이핑 ≠ 피크 로브 감소 — E5 (d=λ/2, 메인·미러 ±3빔폭 밖 피크, 메인 대비)
```
              naive        BP1 입력 amp=1        BP1 입력 amp=0.5
N=64          −9.0~−9.5    −6.9~−7.0 (악화)      +2.5~+3.7 (메인보다 큼)
N=256         −9.5~−9.6    −11.5~−12.0 (2~2.5 dB 개선)   −1.1~+0.1
```
- 대역통과 1차는 메인빔 근방 잔차를 메인 피크 대비 −44~−50 dB 까지 낮춘다(E2). 그러나 밀려난 노이즈가 보이는 먼 사이드로브로 나온다. d=λ/2 는 가시영역이 [−π,π] 전체다.
- 입력을 줄이면 메인빔이 약해져 피크 로브가 메인급 이상이 된다.
- 지표 구분: §2 의 −9.5 dB 는 **피크 로브/메인**, E2 의 −25~−31 dB 는 **대역 잔차 PSD/디더 p=0**, −44~−50 dB 는 **대역 평균 잔차/메인 피크**다. 서로 직접 비교하지 않는다.

## 슈퍼트위스팅 — 여전히 미검증 가설 (E4, N=64, 피크 로브 메인 대비)
```
            naive    rev1(−z)   부호수정 k1=1.5,k2=1.1   부호수정 k1=0.2,k2=0.02
θ0=10°      −9.5     +24.7          +2.4                   −10.1
θ0=23.7°    −8.8     +29.6          +9.9                   −10.9
θ0=45°      −9.5     +27.9          +5.6                   −11.0
```
- 부호를 고치면 σ 는 유계다(max|σ| ≈ 1.5~3.8). 그러나 문서 게인에서는 메인보다 큰 로브가 생긴다. 게인을 크게 낮춰야 순진보다 0.6~2.1 dB 낫다.
- 이 루프는 적분기 구조라 영점이 broadside 다(#2). 조향빔용 대역통과 STW(적분기 → ω0 공진기)는 아직 정식화하지 않았다.
- 결론: "STW = 리야프노프-안정 2차 ΔΣ, 40 dB/decade" 는 **검증되지 않았고, 현재 수치는 지지하지 않는다.** 검증된 2차 기준선은 선형 대역통과 BP2(r=0.7, \|NTF\|max=1.85)뿐이다.
- 1-bit 과부하 판정의 \|NTF\|max ≈ 1.5 는 설계 경험칙이지 정리가 아니다. 순수 BP²(6.8)의 발산은 실측(rev2 첫 실행 max|u| ≈ 3e5)이다.
