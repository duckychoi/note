# sim NOTES — 정직한 상태 보고

`spatial_supertwisting.py` 는 **검증된 결과가 아니라 디버깅이 필요한 스캐폴드**다.
`docs/03` 의 수식 유도는 이론적으로 성립하지만, 아래 첫 실행 수치는 **아직 이론과 불일치**한다.

## 첫 실행 출력 (N=64, θ0=30°) — 이론 불일치
```
naive 1-bit   :  -21.17 dB   보호대역전력=6.55e+01
ΔΣ 1차         :  -15.26 dB   보호대역전력=1.37e+02
ΔΣ 2차(선형)     :   -2.99 dB   보호대역전력=6.65e+01
슈퍼트위스팅        :    0.00 dB   (← 메인급 가짜 로브, 발산)
log-log slope: naive 0.10 / ΔΣ1 0.32 / STW 1.03  (이론: 2p+1 = 1/3/5)
```

## 왜 안 맞나 (디버깅 체크리스트)
1. **복소 vs 실수 혼동**: 변조기를 실수 Re 축에만 적용 → 위상 ramp의 복소 구조가 깨짐.
   올바른 설계는 복소 ΔΣ(오차를 복소로 피드백) 또는 위상-도메인 ΔΣ.
2. **STW 이산화 발산**: 명시적 오일러 + 큰 게인 → σ 폭주. 암시적/투영 오일러로 교체,
   게인 k1=1.5√L, k2=1.1L 를 L(국소 교란상한) 추정에 맞춰 스케일.
3. **`dsm2_linear` 피드백 구조 오류**: 코드 피드백 c[n-1] 사용이 표준 CIFB/CRFB 토폴로지와 다름.
   표준 2차 ΔΣ(예: Boser-Wooley) 계수로 재작성 필요.
4. **지표 매핑**: FFT bin→sinθ 매핑과 guard/band 폭이 N·Npad에 민감.
   보호대역 전력은 '선형 파워 적분'으로, dB 피크와 분리 검증.
5. **미러빔**: 실수 ±1 → ±θ0 대칭이라 guard로 가려도 누설. 복소 1-bit{±1,±j} 또는 오프셋 임계 도입.
