핵심 인사이트

이미지 생성 축에서 에이전트-스킬 1층(자산)이 처음으로 트렌딩 상위에 올라온 사례다. 지금까지 볼트에 쌓인 스킬 자산 레포(mattpocock-skills·superpowers·awesome-agent-skills 등)는 코딩 에이전트용 절차 지식이었다. 이 레포는 같은 형식(프롬프트·템플릿·사례를 배포 가능한 텍스트 자산으로 묶고 “Skills”로 추출)을 이미지 생성 프롬프트에 적용한다 — 즉 “스킬=배포 단위” 명제가 코딩 도메인을 넘어 생성형 미디어 도메인으로 확산한 첫 관측이다. 실행 코드가 아니라 자산 레포라는 점이 결정적이다. 언어가 JavaScript로 잡히지만(뷰어·사이트 코드 추정) 본질은 프롬프트 텍스트 묶음이며, 이슈 11건이 이를 뒷받침한다 — 같은 배치 openai-codex(이슈 13,620)·apache-maka(239)와 비교하면 “실행되는 소프트웨어 vs 복사되는 텍스트 자산”의 구조 차이가 이슈 수에서 그대로 드러난다(openai-codex 페이지에 기록한 해석의 재확인 사례).

530+ 사례·20+ 템플릿·"공업급"은 전부 레포 자체 주장 — 미검증 (medium)

⭐14,407·포크 1,545·MIT·푸시 당일은 API 실검증이나, 핵심 가치 주장인 사례 530여 개·템플릿 20여 종·“工业级(공업급)” 품질·“역공학”의 방법론은 전부 레포 설명 자체 주장이며 이번 회차에 내용물을 실측하지 않았다. 프롬프트 자산은 에이전트-스킬 개념 페이지에 기록한 생태계 공통 약점 — 재현성 벤치 부재·스타≠품질 — 이 가장 심하게 적용되는 유형이다. 프롬프트 효과는 모델 버전에 종속되므로, GPT-Image-2가 갱신되면 자산 상당수가 조용히 낡는다(레포에 버전 대응표가 있는지 미확인). 또한 대상 모델 GPT-Image-2 자체가 볼트에 독립 페이지로 없다 — 이 레포는 모델이 아니라 모델 사용법의 2차 자산이며, 원본 모델 능력의 근거로 인용할 수 없다.

생성일이 2026-04-25로 약 4개월 된 레포이며, 이번 트렌딩 2위는 신규 공개가 아니라 축적 후 노출이다. 같은 배치 mattpocock-skills가 푸시 정체 중 스타만 유입된 것과 달리 이 레포는 당일 푸시가 찍혀 있어 실제 갱신은 진행 중이다(“持续更新中” 주장과 정합).
