📌 승격 판정 — 볼트 자체 규칙의 2번째 집행

수집기는 이 건을 ”🆕 신규 후보 — 전용 페이지 없음. Qwen-Image-2.1.md·Qwen-Image-2.1-viggle-turbo.md·ComfyUI.md 3곳에서 파생/연관으로만 언급된다. 볼트가 승격 여부를 판정해야 한다” 로 넘겼다. ⚖️ 승격 확정. 근거는 10-02 에 볼트가 세운 규칙이다 — “파생 DL 이 베이스를 넘으면 독립 페이지를 만든다”. 이 건은 DL 5,674,460 vs 베이스 Qwen-Image-2.1 81,738 로 69.42배다. 규칙이 재량을 남기지 않는다. 📌 선례: 10-02 Qwen-Image-2.1-Uncensored-GGUF 승격(DL 1,303,476 · 베이스의 16.9배). 이 건이 2번째 집행이고 배수가 4배 더 크다. 🔴 그리고 이 승격이 10-02 의 교훈을 그대로 반복 확인한다: 그때 볼트는 “중복검사 실패의 비용은 중복 페이지가 아니라 큰 것을 놓치는 것이다” 라고 적었다. DL 567만짜리가 베이스 페이지 본문의 표 한 줄로만 존재하고 있었다.

핵심 인사이트

재포장이 원본을 69배 압도하지만, 배수는 4회 연속 줄고 있다

Qwen/Qwen-Image-2.1 을 ComfyUI 용 단일 파일로 재포장한 배포본. 관계를 base_model:finetune: 로 선언한다(🔴 실제로는 파인튜닝이 아니라 재포장이므로 선언 어휘와 실체가 어긋난다 → 파생저장소-식별). 🎯 역전이 “설계된 것”이라는 볼트 기존 판정이 이 건의 핵심이다 — 원본 GitHub README 31행이 “[ComfyUI] natively supports Qwen-Image-2.1 from Day 0. Compatible weights at Comfy-Org/Qwen-Image-2.1” 로 원본 제작사가 사용자를 이 레포로 직접 보낸다.

🔴 수집기 오판 적발 — "최대 배수 사례"는 두 겹으로 틀렸다

수집기 주장: “원본-파생-역전 의 최대 배수 사례(볼트 규약대로 소수 첫째 자리까지만 기재)”. ① 볼트 기존 최대는 114.3배다. 원본-파생-역전 에 기록된 배수: 114.3 · 95.6(FastVideo-FastH3-Comfy) · 93.8 · 82.1 · 76.9 · 75.5 · 75.3 · … ⇒ 69.4 는 최대가 아니라 8번째 이하다. ② 같은 쌍의 자기 최고치보다도 낮다. 볼트 실측 시계열:

2026-09-22   535,365 /  6,523  = 82.0734배   (볼트 실측)
2026-09-24                      = 78.17배     (볼트 실측)
2026-09-26  3,266,380 / 42,469 = 76.9121배   (볼트 실측)
2026-10-03  5,674,460 / 81,738 = 69.4225배   (오늘 볼트 실측)

⇒ ⚖️ 4점 단조 감소다. 수집기는 4회 연속 줄어든 수치를 “최대”로 보고했다. 📌 볼트는 이미 09-24 에 “원본이 상대적으로 회복” 이라고 적어 감소를 포착해 뒀다 — 기록이 오판을 막았다. 🔴 수집기 책임 범위 한정: 수집기가 볼트 전체 이력을 조회하지 않고 당일 2건만 비교했다면 이 오판은 구조적이다. ⚖️ “최대/최초” 류의 서열 주장은 수집기가 하지 말고 볼트가 한다(볼트만 이력을 갖는다).

🏆 배수 감소의 원인은 파생의 쇠퇴가 아니라 원본의 성장이다

09-22 → 10-03(11일) 증가율을 볼트가 독립 계산했다:

  • 원본 Qwen/Qwen-Image-2.1: 6,523 → 81,738 = 12.53배
  • 파생 Comfy-Org/Qwen-Image-2.1: 535,365 → 5,674,460 = 10.60배 ⇒ ⚖️ 둘 다 10배 이상 폭발했고 원본이 약간 더 빨랐다. 그래서 비(比)가 줄었다. 📌 이것이 “역전이 해소되는 중”이 아니다. 69배는 여전히 압도적 역전이고, 감소는 분모가 자란 결과다. 🔴 배수 단독 인용은 두 양의 방향을 숨긴다 → 복합지표-분해.

🏆 원본-파생-역전 1:N 구조에서 두 분기가 반대로 움직인다

같은 원본 Qwen-Image-2.1 의 두 파생 분기 시계열:

분기배수 추이방향
abenzerps/…-Uncensored-GGUF12.3 → 16.9 → 16.9증가 후 고정
Comfy-Org/…82.07 → 78.17 → 76.91 → 69.42🔴 단조 감소
⚖️ 10-02 결론 “역전이 수렴하지 않는다. 구조적 격차다” 는 abenzerps 분기에서는 참이고 Comfy-Org 분기에서는 거짓이다.
⇒ 📌 1:N 역전에서 N개 분기는 같은 운명을 갖지 않는다. 역전의 “구조성”은 쌍 단위로 판정해야 하고 원본 단위로 일반화할 수 없다 → 원본-파생-역전 에 분기별 독립 판정 조항 추가.

🔴 파라미터 대조 불가 — 무응답-오귀속 "대체필드 부재형" 확증

볼트 독립 실측: safetensors.total = None · gguf.total = None (둘 다). ⇒ 📌 10-02 에 볼트가 발견한 대체필드-대조 경로가 여기에는 없다. 대체필드형은 “다른 필드를 보면 구제된다” 였으나 볼 다른 필드가 없다. ⚖️ 종전 유형과의 위치: 누락형(필드 부재=신호 있음) · 무효형(HTTP 400=신호 있음) · 대체필드형(신호 없음·도메인 지식으로 구제) · 🆕 부재형(신호 없음·구제 불가) · 그리고 오늘 Qwen3.8-27B 에서 신설한 요청 미지정형(값이 서버에 있는데 안 물어봄). 🔴 중요 — 이 건은 “요청 미지정형”이 아님을 확인했다: ?expand[]= 를 붙여 재조회해도 두 필드가 여전히 None 이다. ⇒ ✅ 진짜 부재다. 수집기 보고가 정확하다. ⚠️ 단 범위 한정: diffusion-single-file 포맷에 다른 메타 키가 있는지는 확인하지 못했다. 부재 확정이 아니라 “표준 2필드 부재 확정 + 포맷 고유 키 미확인” 이다.

도메인별 추출 (video-saas)

도메인 판정 — 수집기 ai-news → 볼트 video-saas

이미지 생성 모델의 배포 경로이고, 베이스 Qwen-Image-2.1 가 video-saas 로 분류돼 있다. ⚖️ 파생은 베이스 도메인을 따른다.

  • 기능 벤치마킹: 🏆 구현이 아니라 배포 전략의 교훈이다. “사용자가 쓰는 툴(ComfyUI)의 포맷으로 Day-0 에 재포장해 올리고, 원본 README 에서 거기로 보낸다” ⇒ 원본 다운로드를 69배 포기하는 대신 실사용자를 얻는 설계. 📌 볼트가 영상 SaaS 를 만들 때 “내 포맷을 고집할 것인가, 사용자 툴 포맷으로 나갈 것인가” 의 실물 사례다.
  • 워크플로우: lib = diffusion-single-file · tags: comfyui ⇒ ComfyUI 에서 파일 1개 드롭으로 끝난다. 원본은 diffusers 파이프라인 구성이 필요하다. ⚖️ 69배의 상당 부분은 성능이 아니라 설치 단계 수 차이다.
  • 라이선스 🔴 주의: license = other · 볼트 기존 확인(Comfy-Org 카드 63행 전문) license_name: qwen-research ⇒ 비상업 제한이 재포장본에서도 유지된다. 📌 볼트 09-24 판정 “Apache-2.0 계보가 비상업으로 바뀌었다” 가 이 레포에서도 참이다. 상업 사용 불가.
  • 경쟁 우위 빈틈: 🔴 이 레포 자체는 빈틈이 아니다(재포장본이다). 빈틈은 “재포장을 공식이 안 해주는 모델” 쪽에 있다.
  • 허와 실: ✅ DL 567만은 실수요다. 🔴 성능은 원본과 동일하다 — 이 레포에 성능 주장이 없다(있을 수 없다). ⚖️ DL 순위를 모델 품질 순위로 읽으면 안 되는 교과서적 사례: HF 다운로드 상위권에 재포장본이 올라온다 → 관심-검증-역상관 과는 다른 축이고, 🆕 “다운로드는 배포 편의를 재고 품질을 재지 않는다”.

당장 할 것

① Qwen-Image-2.1 베이스 페이지의 표에 이 페이지로의 wikilink 추가(완료) + 승격 사실 기록(완료). ② 배수 시계열 5번째 점을 다음 배치에 측정한다. 🎯 가설: 원본 성장률이 파생을 계속 앞서면 배수는 계속 줄고, 역전 해소 여부를 처음으로 관측할 수 있다. 🔴 현재 4점 전부 감소이지만 69배는 해소와 거리가 멀다. ③ diffusion-single-file 포맷의 메타 키 스펙 확인 — 파라미터 대조 경로가 정말 없는지 확정한다(현재 “미확인”).

미해결 질문

  • base_model:finetune: 로 선언됐는데 실체는 재포장이다. HF 의 base_model_relation 어휘에 “repackage” 가 없어서인가, 작성자 실수인가? (전자면 파생저장소-식별 의 구조화 선언 신뢰도에 상한이 생긴다.)
  • 원본 Qwen/Qwen-Image-2.1 의 safetensors.total = 7,115,124,736 인데 재포장본은 None 이다. 같은 가중치인데 왜 메타가 사라지는가? ⇒ 📌 재포장 과정에서 메타가 유실된다는 가설이고, 맞다면 메타데이터-부재-추론 에 “재포장 유실형” 유형이 추가된다. 🔴 미검증.
