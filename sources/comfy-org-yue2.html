새 모델이 아니다 — 카드 전문이 29행이고 본문은 한 문장이다

볼트 카드 전문 대조(29행 전체 확인). 본문 핵심은 문자 그대로 한 줄이다:

“Repackaged model files for ComfyUI.”

그 아래 원본 저장소 2개를 명시한다: m-a-p/YuE2-3B · m-a-p/SheetSage2. 나머지는 ComfyUI 폴더 배치 안내다. ✅ 카드가 파생 관계를 숨기지 않는다 — 원본 링크를 본문에 직접 적었다.

🔴🔴 볼트 최대 발견 — 채택 근거였던 int8_convrot 이 카드에 없다

수집기 채택 논거: ”🎯 그래도 배달하는 이유 — 양자화 축이 새로 생겼다: 원본에 없는 int8_convrot 변형이 여기 있다. 같은 모델을 bf16 / int8 두 점으로 비교할 수 있는 파일이 한 레포에 모여 있다.”

볼트 파일 목록 실측 — 파일은 실재한다 ✅:

.gitattributes · README.md
audio_encoders/sheetsage2_bf16.safetensors
checkpoints/yue2_3b_bf16.safetensors
checkpoints/yue2_3b_int8_convrot.safetensors   ← 실재 확인

🔴 그런데 카드의 배치 안내는 2개만 적는다 (볼트 카드 전문 대조):

ComfyUI/models/audio_encoders/sheetsage2_bf16.safetensors
ComfyUI/models/checkpoints/yue2_3b_bf16.safetensors

🎯 int8_convrot 은 어디에 두는지, convrot 이 무엇인지, 품질 손실이 얼마인지 — 카드에 한 글자도 없다. 📌 따라서 정확한 상태는: “bf16/int8 두 점으로 비교할 수 있다” 가 아니라 “int8 파일이 존재하나 사용법·성능이 미문서화되어 비교점으로 쓸 수 없다” 이다. 🔴 채택 논거가 미문서화 산출물에 기대고 있었다. 파일 존재 ≠ 사용 가능한 축. → 메타데이터-부재-추론 의 역방향 사례: 볼트는 “필드가 비었다고 없는 게 아니다” 를 배웠는데, 이번은 “파일이 있다고 쓸 수 있는 게 아니다” 다.

🔴 base_model 태그와 cardData 가 불일치한다 — 파생 추적의 함정

볼트 API 실측:

  • cardData.base_model = ['m-a-p/YuE2-3B', 'm-a-p/SheetSage2'] ← 둘 다 있다
  • tags = ['base_model:m-a-p/SheetSage2', 'base_model:finetune:m-a-p/SheetSage2'] ← 🔴 SheetSage2만 있다. YuE2-3B가 없다.

🎯 즉 tags 배열만 읽으면 볼트 기보유 YuE2-3B 와의 관계를 놓친다. 음악 생성 본체(YuE2-3B)가 태그에서 빠지고 오디오 인코더(SheetSage2)만 남았다. 🔴 관계 라벨도 틀렸다: 태그는 base_model:finetune: 이라고 적지만 카드는 “Repackaged” 라고 한다. 파인튜닝이 아니라 재포장이다. 📌 → 파생표기-함정 5번째 사례. 계보: description(09-08) → 이름(09-09) → API 계산 필드·표 서식(09-10) → 자동 파싱 arxiv 태그(09-16) → 🆕 불완전·오라벨 base_model 태그(09-17). 🎯 이것이 수집기 질문에 대한 결정적 답이다 — 아래 파생저장소-식별 참조.

🔴 라이선스가 원본과 갈린다 — 상업 사용 차단

이 레포: CC-BY-NC-4.0 (비상업) — 볼트 API 실측 확인. base_model 이 가리키는 원본 2개(m-a-p/YuE2-3B·m-a-p/SheetSage2)의 라이선스는 별도 확인 필요(YuE2-3B 볼트 페이지 기록: 가중치 CC BY-NC). 🎯 재포장이 라이선스를 바꿀 수 있다는 점이 실무적으로 가장 중요하다 — 파일이 같아도 배포 조건이 다른 저장소가 생긴다. 상업 사용 시 원본 라이선스를 별도 확인해야 한다.

🔴 성능 수치 없음 · 생성 후 미수정

카드 29행에 벤치마크 0건. 성능은 원본 YuE2-3B 페이지 참조. pipeline_tag: None. 생성 2026-09-11 · 최종 수정 2026-09-11 — 만든 뒤 한 번도 고치지 않았다. int8 파일 안내 누락이 방치된 상태라는 뜻이다. 🔍 DL:♥ 387:1 — DeepSeek-R1(52:1)의 7.4배, Qwen3.8-27B-TWIN-TURBO-709-GGUF(762:1)의 절반. 재포장 저장소는 사람이 ♥를 누르지 않고 도구가 받아 간다는 해석과 정합하나 확인 불가.
