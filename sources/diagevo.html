DiagEvo: Diagnosis-Guided Self-Evolution via Hierarchical Error Memory

arXiv: 2609.00768 · HF: https://huggingface.co/papers/2609.00768 지표(2026-09-02): 업보트 9(데일리 5위·배치 최저) · 저자 8인(배치 최소) · 공개 2026-09-01 — HF API 실호출 + 초록 원문 대조 드리프트: raw와 완전 일치(9 · 8인)

핵심 인사이트 — 방향 신호를 외부가 아니라 자기 실패에서 뽑는다

셀프플레이의 고질병은 명확하다: 안내 없이 두면 솔버 성능이 정체하거나 하락한다. 기존 해법은 둘 중 하나였다.

  • 무유도(unguided): 난이도·학습가능성·다양성으로 문제 생성을 조종 → 문제는 어렵고 다양해지지만 “어떤 미해결 약점을 겨냥해야 하는지”를 지정하지 못한다
  • 유도(guided): 인간 예제·문서 코퍼스·난이도 지정 등 외부 자원에 의존 → 셀프플레이 루프 바깥의 정보가 필요

DiagEvo의 주장은 제3의 길이다 — 필요한 방향은 솔버 자신의 실패 이력에서 유도할 수 있다. 진단기(diagnostician)가 그 이력에서 반복되는 오류 원인을 추출해 계층적 오류원인 메모리에 저장한다. 메모리는 관련 원인들을 스킬 노드 아래로 묶고, 각 원인을 Active / Mastered로 추적한다(표적 문항에 대한 자기일관성 기준). 챌린저는 이 상태와 재발 횟수를 근거로 원인 표적 생성 ↔ 자유 탐색의 균형을 조절한다.

🎯 국소-수리-원리의 다섯 번째 독립 도달 — 그리고 처음으로 수치가 붙었다

Active / Mastered 라벨은 그 원리의 문자 그대로의 구현이다. Mastered = 이미 잘된 것 = 건드리지 않는다. Active = 틀어진 지점 = 여기만 겨냥한다. 08-31에 이 개념을 세울 때 남긴 약점이 있었다 — 근거 논문 DART-SD가 정량 수치 전무였고, LayerRecall도 절대값이 없었다. 원리는 그럴듯한데 효과 크기를 아무도 제시하지 않았다. DiagEvo가 그 공백을 메운다. 아래 수치는 이 원리 계열에서 볼트가 확보한 첫 정량 근거다.

결과 — 이 배치에서 가장 완전한 수치 보고

기본 설정: 4B 진단기

  • 솔버 3종 전부(Qwen3-4B · Qwen3-8B · OctoThinker-8B)에서 9개 벤치 평균 정확도가 모든 베이스라인 상회 ← “outperforms every baseline … across all nine benchmarks for each of the three solvers” (전칭 주장을 명시적으로 함)
  • Qwen3-8B 기준: 수학 추론 5개 벤치 평균 72.3% = R-Zero 대비 +4.5%p
  • 9개 벤치 전체 평균 57.4% = DARC 대비 +1.1%p
  • 제거 실험(ablation): 계층적 오류원인 메모리와 이중 신뢰도 필터링이 둘 다 이득에 기여

진단기가 4B로 작다는 점이 실용적으로 중요하다 — 진단이 거대 모델을 요구했다면 방법 자체가 비쌌을 텐데, 작은 모델로 되면 자기진화 루프의 비용 구조가 성립한다.

⚠️ 이중 신뢰도 필터링 = 심판 비독립성의 정면 위반 가능성

이중 신뢰도 필터링(Double-confidence filtering): “가장 흔한 솔버 답이 명확한 득표 우위를 가질 때만” 중간 난이도 문항을 유지한다. 그런데 08-31 Agentic-Artifact-Creation(259편 서베이)의 부정적 결론이 정확히 이것을 겨냥했다 — “LLM 심판이 생성기와 선호·맹점을 공유하면 독립 증거가 못 된다.” DiagEvo에서 문항을 걸러내는 판정자는 솔버 자신이다. 생성기와 심판이 같은 정도가 아니라 같은 모델이다. 이 설계에는 구조적 취약점이 따라온다: 솔버가 일관되게 틀리는 오류는 “명확한 득표 우위”를 만들어내므로 필터를 통과해 정답으로 취급될 수 있다. 즉 자신 있게 틀리는 영역이 커리큘럼에서 빠질 위험이다. 초록은 이 위험을 다루지 않는다. 성능이 실제로 올랐다는 사실과, 그 방법이 특정 오류 유형에 구조적으로 눈감을 수 있다는 우려는 양립한다 — 벤치마크 평균 상승은 후자를 반증하지 못한다.

미기재 항목

개별 벤치명·개별 점수가 없다(평균만 제시). 코드/데이터 공개 여부 미기재. R-Zero·DARC의 절대 점수도 없어 +4.5%p·+1.1%p의 기준선 위치를 알 수 없다. 9개 벤치 구성·학습 비용·라운드 수도 미기재. 또한 +1.1%p(9벤치 전체) 는 작은 값이다 — 큰 개선은 수학 5벤치(+4.5%p) 에 몰려 있고, 전체 평균 이득은 그보다 훨씬 완만하다. “모든 베이스라인 상회”라는 전칭 주장과 실제 이득 폭은 구분해서 읽어야 한다.

  • 신뢰도: high — HF API + 초록 대조. 이번 배치 5편 중 유일하게 성능 주장이 검증 가능한 형태(구체 수치 + 비교 대상 명시 + 제거 실험).
  • 즉시 활용: YES(원리). “실패 이력을 구조화해 다음 작업의 방향으로 쓴다” 는 이 볼트가 이미 하는 일이다 — log.md의 정정·철회 기록이 곧 오류원인 메모리이고, Active/Mastered 구분은 볼트의 미해결 질문 추적에 그대로 대응한다. 08-31 철회 건이 지금 Active 상태다.
  • 6개월 영향력: 중~높음. 외부 자원 없는 자기진화는 데이터 확보가 병목인 상황에서 매력적. 단 심판 비독립성 문제가 후속 연구에서 반드시 제기될 것으로 본다.
  • 대체 관계: 인간 큐레이션 커리큘럼 · 외부 코퍼스 기반 유도를 자기 실패 이력으로 대체.
  • 허와 실: 걷어내면 = “틀린 이유를 분류해 저장하고, 아직 못 고친 것만 다시 낸다”. 발상은 단순하고 정직하며, 수치도 과장 없이 제시됐다. 업보트 9로 배치 최저인데 근거는 배치 최강 — 관심과 근거의 괴리를 보여주는 이번 배치 대표 사례.
  • 액션: actionable에 ① 국소-수리-원리 정량 근거 확보로 개념 페이지 갱신(완료) · ② 심판 비독립성 위험 추적 항목 등재.
