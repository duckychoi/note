약관·보안 리스크 — 채택 대상 아님

비공식 브리지이며 각 벤더(Anthropic·OpenAI 등) 약관 위반 소지를 배제할 수 없다. 04월에 기록한 판단을 유지·강화한다 — 프로덕션은 물론 개인 개발에도 권장하지 않는다. 추가 리스크 축이 있다: 이런 브리지는 모델 요청과 응답이 제3자 경로를 통과할 수 있어, 코드·프롬프트가 어디로 흐르는지 사용자가 통제하기 어렵다. 같은 배치 apache-maka가 “세션·설정·실행 기록이 기본적으로 로컬에 남는다” 는 로컬 우선·데이터 소유권을 전면에 내세운 것과 정확히 반대 극에 있다. 이 대비는 이번 배치에서 유용한 축이다 — 접근 비용을 낮추는 방향(free-claude-code) vs 데이터 통제를 높이는 방향(apache-maka). ⭐48,309·포크 7,915은 수요의 크기를 말할 뿐 안전성·합법성의 근거가 전혀 아니다.
