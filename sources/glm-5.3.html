zai-org/GLM-5.3 — 753B 플래그십인데 다운로드는 Flash의 0.29배

HF 모델: https://huggingface.co/zai-org/GLM-5.3 지표(2026-09-03): DL 151,021(30일) · 좋아요 1,548 · HF 트렌딩 1위 · 라이선스 other(glm-5.3 독자) · fp8 · 생성 2026-08-25 · 최종수정 2026-08-31 — HF api/models 실호출 검증 아키텍처: 태그 glm_moe_dsa · 총 파라미터 753,329,940,480(≈753B) · dtype BF16 + F8_E4M3 + F32 · text-generation(멀티모달 아님) 태그(API 원문): transformers safetensors glm_moe_dsa text-generation conversational en zh arxiv:2602.15763 license:other eval-results fp8

📌 raw 대비 API 수치가 크게 다르다 — DL +60.0%

raw.md 기록 94,403 vs API 실측 151,021 → +56,618(+60.0%). 이번 배치 HF 모델 3건 전부 같은 방향으로 어긋났다(GLM-5.3-Flash +17.3% · Qwen3.8-Flash-Next +26.6%). ⚠️ 이는 볼트의 08-30 기록(“HF 8건은 raw와 절대값 완전 일치”)과 정면으로 다르다. GitHub 5건은 이번에도 드리프트 +2~+14(≤0.1%)로 미미했으므로, HF DL 절대값에만 대규모 드리프트가 발생한 것이다. 잠정 해석(미검증): 세 모델 모두 생성 후 9일차의 급상승 구간에 있다. 카운터가 빠르게 움직이는 구간에서는 같은 시간차도 훨씬 큰 상대 오차로 나타난다. 드리프트 크기가 DL 절대 규모와 반비례(GLM-5.3 최소 DL·최대 드리프트)하는 것도 이 가설과 어긋나지 않는다. 단 원인 확정 불가 — 규칙으로 굳히지 않고 다음 회차에 재관측한다. → 채택: API 값. raw의 HF DL 필드는 이제 절대값도 참고치로만 쓴다.

핵심 인사이트 — 베이스를 안 바꾸고 사후학습만으로 올렸다는 주장

raw 수집 메모에 따르면 GLM-5.2와 동일 베이스에서 사후학습(post-training)만으로 성능을 올린 MoE다. 자체 표 기준:

  • Terminal Bench 3.0 28.3 (GLM-5.2 4.6 · Opus 4.8 21.1 · GPT-5.6 Sol 34.6)
  • CyberGym 84.5 · AutomationBench 48.2 · GDPval-AA v2 1769 — 표 내 1위

가장 눈에 띄는 건 Terminal Bench 4.6 → 28.3, 즉 6.2배다. 베이스가 같다면 이 격차는 전부 사후학습 몫이라는 뜻이 된다. 이 주장이 이번 배치 Repo-To-Skill과 정면으로 만난다: 그 논문은 백본을 고정하고 스킬 층만 더해 MLE-bench +134.3%를 얻었다. 여기는 베이스를 고정하고 사후학습만 바꿔 6.2배를 얻었다고 한다. 둘 다 “능력은 베이스 모델 바깥에서 온다”고 말한다. 하나는 그 바깥을 증류된 스킬로, 하나는 사후학습으로 놓는다. 같은 날 상위권에 나란히 올라온 두 주장이 같은 방향을 가리킨다.

⚠️ 벤치 대부분이 벤더 자체 실행이고, 라이선스가 MIT가 아니다

  • raw 메모: 대부분의 벤치가 Claude Code 하네스 위에서 벤더가 직접 돌린 자체 표다. Anthropic 하네스 위에서 Anthropic 모델(Opus 4.8)을 이겼다는 주장이라는 구조를 그대로 읽어야 한다 — 하네스는 통상 자사 모델에 맞춰 튜닝돼 있고, 그 위에서 남의 모델이 이겼다면 하네스 적합성 자체가 교란변수다.
  • 라이선스가 other(glm-5.3 독자 라이선스) 다. 볼트는 Zhipu-AI를 MIT 개방 노선으로 추적해 왔는데(GLM-5.3-Flash는 여전히 MIT), 플래그십만 독자 라이선스로 닫혔다. → “개방 노선”이 계열 전체가 아니라 하위 모델에만 적용된다는 것이 이번 회차의 확정 사항이다.
  • GPT-5.6 Sol(34.6)에는 여전히 진다 — 자체 표에서도 1위가 아니다. 표 내 1위 항목만 골라 요약하면 오독한다.

플래그십이 Flash에 다운로드로 3.4배 진다

  • GLM-5.3-Flash: 517,902
  • GLM-5.3(본 페이지): 151,021 → Flash가 3.43배 많다. (raw 수치로는 4.67배 — 어느 쪽이든 Flash 우세는 동일.) 753B를 로컬에서 돌릴 수 있는 사람은 거의 없다. 321B·활성 18B인 Flash가 실사용 축을 가져간 것은 자연스럽다. 여기에 라이선스 차이(MIT vs 독자) 까지 겹친다. 좋아요는 반대로 Flash 1,990 : 본 모델 1,548로 격차가 1.29배에 불과하다 — 볼트의 08-30 규칙(“사람들은 GGUF를 쓰고 원본을 인정한다”)이 같은 벤더 내 플래그십/경량 쌍에서도 재현된다. 다운로드와 좋아요는 여기서도 다른 것을 잰다.

도메인별 추출 (ai-news · 교차 local-llm)

  • 신뢰도: ⭐⭐⭐ medium — HF API 실검증(지표·파라미터·라이선스 high). 능력 주장은 전량 벤더 자체 표이며 제3자 재현 0건.
  • 즉시 활용: NO. 753B는 로컬 범위 밖이다. fp8이어도 마찬가지다. API 경유라면 가능하나 독자 라이선스 조건 확인이 선행돼야 한다.
  • 6개월 영향력: 중간. 실질적 영향은 이 모델이 아니라 GLM-5.3-Flash 쪽에서 나온다. 본 모델의 의미는 “사후학습만으로 에이전트 벤치를 6배 올렸다” 는 주장의 존재 자체다 — 사실이면 오픈 진영 전체의 자원 배분이 바뀐다.
  • 대체 관계: GLM-5.2를 계열 내에서 대체. 외부적으로는 Opus 4.8·GPT-5.6과 같은 자리를 노리나 자체 표 밖 근거 없음.
  • 허와 실: 걷어내면 “벤더가 자기 하네스에서 자기 표를 만들었다” 이고, 남는 건 753B·fp8·glm_moe_dsa·arxiv 2602.15763 이라는 검증 가능한 사실 네 개다.
  • 액션: arxiv 2602.15763 확인(높음 — GLM-5.3-Flash와 공유 논문이므로 한 번에 두 페이지가 채워진다). glm_moe_dsa의 DSA 정의 확인(중간 — 이번 배치 Declarative-Attention과 직접 비교 대상). 독자 라이선스 원문 확인(중간).

미해결 질문

  • glm_moe_dsa의 DSA는 무엇인가 — sparse attention 계열로 읽히나 미확인. 확정되면 이번 배치의 희소어텐션 3중 관측이 완성된다.
  • 사후학습만으로 6.2배가 사실인가? 베이스 동일성 주장 자체가 벤더 진술이다.
  • arxiv 2602.15763은 5.3과 5.3-Flash 중 무엇을 기술하나, 아니면 둘 다인가?
  • 독자 라이선스 glm-5.3의 제약은? 상용 사용·재배포 조건 미확인. (볼트 09-02 규칙: 라이선스는 배지가 아니라 원문으로 읽는다.)
  • 왜 플래그십만 닫고 Flash는 MIT로 열었나 — 의도적 계층 분리인가?
