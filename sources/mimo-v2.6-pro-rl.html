🎯 이 페이지의 최대 값 — 볼트의 9일 전 미검증 항목이 해소됐다

09-18 MiMo-V2.6-RL-Livestream 은 사용자 지정 소스(Threads 게시물)였고 볼트는 미검증 2건을 명시로 남겨 두었다. 오늘 그 모델이 배달됐다.

① “MiMo-V2.6 Pro: 1조 개 초과 파라미터” → ✅ 실측 확정. 09-18 볼트 판정은 “V2.5-Pro 가 이미 1T급이라는 공식 블로그 제목과 정합” 이었다 — 간접 추론이었다. 🎯 오늘 HF API expand[]=safetensors 실측: total = 1,024,216,603,392 = 약 1.024조. “1조 초과”가 문자 그대로 맞다(1T = 1×10¹²를 2.4% 초과). 정합 → 실측 확정으로 등급이 올랐다.

② “몇 주 내 학습 방식·세부 기술 오픈소스 순차 공개” → ✅ 이행 확인. 09-18 시점 “36kr 보도 방향과 정합하나 공식 문서 원문 미확인”. 🎯 오늘: 모델이 MIT 라이선스로 HF 에 공개돼 있고, 카드가 학습 방법(YORO·비동기 GRPO·GRS·GAR)을 서술한다. 게시물이 “몇 주” 라 했고 9일 만에 왔다.

③ “스텝당 1,568 프롬프트 × 16 롤아웃” → 2차 보도 → 1차 출처로 격상. 09-18 에는 Forkast·36kr·HN 2차 보도 일치로 검증했다. 🎯 오늘 모델카드가 같은 수치를 직접 적는다 — 벤더 1차 출처 확보.

🔴 ④ “한 스텝마다 약 20억 토큰” 는 여전히 미검증이다. ⚠️ 볼트 산술 추정은 가능하다 — 1,568 × 16 = 25,088 시퀀스/스텝이므로 20억 토큰이면 시퀀스당 약 79,700 토큰이다. 1M 컨텍스트 에이전틱 롤아웃으로는 자릿수가 그럴듯하다. 📌 그러나 이것은 볼트의 나눗셈이고 측정이 아니다 — 카드에 토큰 수가 없다. 추정으로 표기 유지. 📌 교훈: 미검증을 미검증으로 적어 둔 것이 9일 뒤에 값을 했다. 만약 09-18에 “1조 파라미터 확인됨” 이라 접어 적었다면 오늘의 등급 상승을 알아볼 수 없었다. 검사가능성-공사 가 볼트 자기 기록에서 작동한 사례다.

🎯 학습 설계 — "You Only RL Once" 가 Rufus-Air와 정반대다

카드가 주장하는 네 가지:

  • ① YORO(You Only RL Once): 도메인별 분리 런이 아니라 코딩·일반 에이전트·비주얼·사이버보안을 한 배치에 섞은 단일 혼합 RL 런. 학습에서 본 적 없는 하니스로도 전략이 전이된다고 주장.
  • ② 비동기 GRPO, 스텝당 1,568 프롬프트 × 16 롤아웃
  • ③ Groupwise Agentic Grading — 이진 pass/fail 로는 통과한 해답들끼리 서열화할 수 없다는 문제의식. GRS(대조 롤아웃으로 과제별 루브릭을 오프라인 구성해 루브릭 품질과 테스트 결과를 융합) + GAR(통과 trajectory 를 온라인 서열화해 advantage 를 고품질 쪽으로 재분배)
  • ④ 자기수정 콜드스타트 + 환경 하드닝·적대적 스크리닝·검증기 교차확인으로 reward hacking 방어 📌 ①이 같은 배치 Rufus-Air와 정면으로 대립한다: Rufus-Air 는 8단계 직렬(리워드 신뢰도 순)이고 이건 단일 혼합 런이다. 🎯 같은 날 배달된 두 레시피가 반대 답을 내놓았고, 둘 다 자기 방식이 낫다고 주장하며 둘 다 상대와 비교하지 않았다. → 이 대립 자체를 개념으로 기록한다(아래 관련 페이지). 🎯 ③이 볼트 관심축과 만난다 — “통과했다”만으로는 순서를 못 정한다는 문제의식은 검사가능성-공사 의 “pass/fail 2값이 부족하다” 와 같은 진단이다. 볼트는 표기 어휘로, MiMo 는 리워드 함수로 답했다.

구조 (카드 실측)

텍스트·이미지·비디오·오디오 단일 모델 + 1M 토큰 컨텍스트. LLM 백본 70층(SWA 60 / GA 10) · hidden 6144 · 라우팅 전문가 384개 중 8개 활성(MoE, 공유 전문가 없음) · MTP 스펙디코더 5 SWA층 · 비전 인코더 681M · 오디오 토크나이저 308M(20 RVQ 코드북) + 오디오 패치 인코더 127M. 🎯 8/384 활성 = 2.08% 로 희소도가 매우 높다. 총 1.024T 중 활성 파라미터는 대략 그 비율 근처일 것이나 🔴 카드가 활성 파라미터 수를 명시하지 않았고 볼트가 계산하지 않았다(공유 전문가 없음·GA층 등 비-MoE 부분을 알 수 없어 단순 비례가 성립하지 않는다). 추정치를 적지 않는다.

🔴 18개 벤치 중 Opus 5 를 넘은 것은 3개 + 동률 1개다

카드 3절에 18개 벤치마크 × 6열 대조표(MiMo-V2.6 Pro/Flash · MiMo-V2.5 Pro · Claude Opus 5 · GPT-5.6 Sol · Claude Fable 5). Pro 가 뒤진 항목: DeepSWE v1.1 71.9(Opus 5 74.0) · ProgramBench 26.5(Opus 5 37.0 — 격차 10.5p) · Toolathlon-Verified 76.9(Opus 5 80.6) · Terminal Bench 4.0 34.9(Opus 5 49.0) · OSWorld-Verified 82.0(Fable 5 86.0) · ExploitBench 47.9(GPT-5.6 78.5 — 격차 30.6p). Pro 가 앞선/동률 항목 4개: AutomationBench v1.0.6 53.1 vs Opus 5 50.3 · Terminal Bench 2.1 89.9 vs 89.1(0.8p) · Agents’ Last Exam 31.6 = 31.6(동률) · MiMo VisualCoding 72.3 vs Opus 5 70.0(단 GPT-5.6 73.4 가 더 높다). 🔴 즉 “앞섰다”의 실제 모양은 3승 1무 + 근소한 차이다. 종합 우위 주장이 아니라 항목별로 갈리는 결과이고, 수집기가 이를 정확히 적었다. ⚠️ 자사 명칭 벤치 3개(MiMo Code Bench · MiMo Cyber Bench · MiMo VisualCoding)가 표에 섞여 있고, 🔴 MiMo Cyber Bench·CyberGym 은 경쟁 모델 열이 -(미측정) 이다 → 자사 벤치에서만 큰 격차가 나는 구조. 분포내-우위·비매칭-비교 동시 해당. 🎯 세대 내 증분은 크고 이건 자기 대조라 상대적으로 믿을 만하다: Terminal Bench 4.0 V2.5 Pro 1.5 → Pro 34.9(23배) · MiMo Cyber Bench 0.0 → 80.2 · CyberGym 40.0 → 94.0. 단 0.0 → 80.2 은 시작점이 0이라 배수가 무의미하고, 이전 세대가 해당 능력을 아예 갖지 않았다는 뜻이다. 🔴 전부 벤더 자기보고 · 독립 재현 미확인.
