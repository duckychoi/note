→ 🎯 즉 카드 본문은 여전히 BF16 모델을 설명한다. 첫 문단부터 “We are releasing MiniCPM5-2B… a dense 2B Transformer” 이고, 모델 목록 167행이 그 수치의 출처를 명시한다: “BF16 final release (post-trained with RL + OPD)”. → 따라서 평균 53.9 · IFEval 86.7 · Multi-IF 71.8 · LiveCodeBench v6 69.1 등은 전부 BF16 무양자화 모델의 점수다. 이 리포가 배포하는 Q4_K_M / Q8_0 의 성능은 카드 어디에도 없다. → Q4_K_M은 4비트 양자화다. 양자화 열화는 실재하고 태스크마다 다르게 나타난다(특히 수학·코드·장문맥에서 크다). 원본이 압도적이라고 기록한 축(LCB-Pro Medium 17.5 등)이 양자화 후에도 유지된다는 근거는 0이다.

raw의 처리 평가 — 절반 맞고 절반 틀렸다:

  • ✅ raw는 “⚠️ 이미 인제스트된 MiniCPM5-2B 의 양자화 변형(별도 리포)” 라고 관계를 정확히 자기 신고했다. 09-11 볼트가 요청한 단 하나의 개선(중복 검사 대상을 wiki/sources/ 로 교체)이 작동한 증거다.
  • 🔴 그런데 바로 다음 문장에서 “모델카드 표 실측: 평균 53.9로 비교군 내 최고…” 라며 그 수치를 이 리포의 성질처럼 서술했다. 관계는 잡았는데 수치의 귀속은 놓쳤다. → 이것이 단위-불일치 ①번(패밀리 공용 카드)의 재발이다. 09-11 Nex-N2.5-Pro·Nex-N2.5-mini 에서 md5 동일로 잡아 개념으로 승격시킨 함정이 하루 만에 다른 형태로 다시 나왔다. 저번엔 카드 1개가 모델 3개를 덮는 형태였고, 이번엔 카드 1개가 원본과 양자화본을 덮는 형태다. → 🎯 규칙 추가: 양자화·변환 리포(GGUF·GPTQ·AWQ·NVFP4·MLX)는 기본적으로 원본 카드를 복사한다고 가정한다. 성능 수치를 옮기기 전에 원본 카드와 md5를 비교하고, 같으면 “수치는 원본 것” 을 명시한다.

형제 리포 — 카드가 알려주는 배포 계보

같은 카드가 나열하는 MiniCPM5-2B 변형(171~183행): GGUF(여기) · GPTQ(4bit) · DSpark-GGUF(드래프트 모델의 GGUF) · 그리고 MiniCPM5-1B-GGUF. → OpenBMB 는 하나의 모델을 배포 형식별 리포로 쪼개고 카드를 공유하는 방식을 쓴다. 볼트가 앞으로 OpenBMB 리포를 만날 때마다 같은 함정이 반복된다는 뜻이므로 벤더 단위로 기억해 둔다. 파라미터 실측(원본 페이지 기록): 2,516,756,480개(2.52B, 비임베딩 1.98B) — ‘2B’는 반올림 표기. raw 일치.

도메인별 추출 (local-llm)

🔀 도메인 판정 — raw의 ai-news 를 local-llm 으로 변경

raw는 ai-news 로 분류했으나 ① 원본 MiniCPM5-2B 가 이미 local-llm 이고 ② GGUF는 정의상 온디바이스 로컬 추론 포맷이며 ③ 09-11 배치의 “HF모델 3건 local-llm 승인” 판정과 일관된다. 양자화 배포판이 원본보다 덜 local-llm 일 수는 없다.

  • 실용성 판단: YES — 오늘 배치에서 가장 즉시 실행 가능한 항목. 2.52B / Q4_K_M 이면 CPU만으로도 돌아가고 Ollama·LM Studio에 바로 올라간다. 다운로드 70,755/30일은 오늘 모델 3건 중 압도적 1위(다음이 2,279)로 실사용 규모의 신호다. ⚠️ 단 지연시간·메모리 수치는 카드에 없다 — 직접 재야 한다.
  • 메모리 아키텍처: 해당 없음(모델 배포 형식). 다만 카드가 장문맥·툴콜링을 태그로 내세우므로 에이전트-메모리-레이어 의 로컬 실행 후보로는 유효.
  • Hermes 적용: 가능성 있음. 로컬 소형 에이전트 백엔드로 실험 가치. 단 원본이 지시따르기(IFEval 86.7 · Multi-IF 71.8)에서 동급 2B에 지는 축이 이미 기록돼 있고(MiniCPM5-2B), 양자화는 그 약한 축을 더 깎을 가능성이 높다. 에이전트는 지시이행 의존도가 크므로 여기가 실패 지점이 될 확률이 가장 높다 — 실험 시 최우선 측정 항목.
  • 트레이드오프: 이 리포에 대해서는 정량화 불가. 카드가 양자화 손실을 측정하지 않았다. 알 수 있는 것은 파일 크기뿐(F16 > Q8_0 > Q4_K_M). 직접 측정 외에 방법이 없다.
  • 오픈소스 구현체: 그 자체가 즉시 실행 가능한 산출물. Apache-2.0 상업 이용 가능.

🟢 낮은 비용 실험 — 양자화 손실을 볼트가 직접 잰다

카드에 없는 수치를 만드는 가장 싼 방법: Q4_K_M 과 F16 을 같은 프롬프트 20개로 돌려 지시이행 실패율만 비교. 벤치 전체는 불필요하다 — 원본이 이미 지는 축(지시이행) 하나만 본다. 근거: AgentGrad 순차 개입 원칙 + 위 경고(양자화 손실 미측정). 볼트가 “수치가 없다”고 적은 자리에 직접 수치를 만드는 첫 사례가 된다. ⚠️ 우선순위 낮음 — 이번 배치 최우선 개입은 hyperresearch quote-integrity 다.
