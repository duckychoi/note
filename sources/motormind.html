MotorMind — 학습 없는 조작, 하네스만으로 13.3% → 66.7%

arXiv/HF: https://huggingface.co/papers/2609.38078 업보트 63 (HF 데일리 1위) · publishedAt 2026-09-29 · 볼트 관측 2026-10-05T09:4x UTC / 18:4x KST 독립 검증: HF API 업보트 63 일치 · 🆕 arXiv HTML 전문 501,242B 열람(초록 아님)

핵심 인사이트

제로샷 조작의 병목이 모델이 아니라 하네스였다. 같은 범용 VLM을 쓰면서 VLA 전용 학습 0 · 코딩 에이전트 0 · SAM3류 그라운딩 도구 0 으로 LIBERO-PRO 66.7% 를 냈고, 기존 제로샷 최대는 13.3% 다 — 5배. 교란 조건에서도 53.8% vs 19.2%(2.8배). 📌 볼트의 하네스-설계-축 에 로보틱스 사례가 처음 들어온다. 지금까지 이 축은 코딩·웹 에이전트에서만 관측됐다.

🏆 구조 — VLM은 "중간 수준 행동"만 내고 저수준은 결정적 제어가 받는다

VLM이 중간 수준(mid-level) 행동을 제안하고, 그것을 결정적 로봇 제어 + 측정된 피드백에 연결한다. 여기에 비동기 모니터링과 백그라운드 메모리 갱신이 붙는다. 🎯 이것은 에이전트-메모리-레이어 의 로보틱스 변종이다 — 메모리를 추론 경로에 넣지 않고 배경 프로세스로 뺀 설계이고, 볼트가 ChinameBot 에 적용 검토해 온 이중 트랙과 같은 형태다.

🆕 본문 전용 수치 — 초록에 없는 상한이 본문에 있다

백본을 더 강한 VLM(GPT-6 Sol)으로 교체하면 83.3% 평균으로 오른다. 🔴 초록은 이 수치를 적지 않는다 — “Replacing the backbone with a stronger VLM further improves performance” 라고만 쓴다. ⚖️ 즉 초록이 자기 최고 수치를 뺐다. 매체가-숨긴다 의 반대 방향 사례다(→ 숨김유인-부호).

도메인별 추출 (ai-news)

  • 신뢰도: ⭐⭐⭐⭐ — HF 데일리 1위·업보트 63 · 본문 전문 열람 완료 · 시뮬(LIBERO-PRO) + 실기(xArm6) 양쪽 보유. 🔴 단 전부 저자 자가측정이고 외부 재현은 없다.
  • 즉시 활용: NO(로봇 없음) — 그러나 설계 패턴은 즉시 이전 가능하다: VLM은 중간 수준만 결정 · 저수준은 결정적 코드 · 피드백은 측정값 · 메모리는 비동기. 이 4줄은 reat 파이프라인과 ChinameBot 에 그대로 적용된다.
  • 6개월 영향력: VLA 전용 학습의 가치가 재평가된다. “데이터 모아 정책 학습” 대신 “하네스를 짜고 VLM 교체를 기다린다” 가 합리적 선택이 되는 구간이 열렸다(백본 교체만으로 66.7 → 83.3).
  • 대체 관계: 베이스라인 명단이 곧 대체 대상이다 — OpenPI π0.5 · OpenVLA · OpenVLA-OFT · GR00T N1.5 · MolmoAct2(본문 D.2 실측). 이들이 전부 13.3% 이하다.
  • 허와 실: 🔴 “제로샷”의 분모를 봐야 한다. 학습이 없는 대신 프롬프트·역할 분해·그라운딩 절차가 사람이 설계한 자산이다(본문 C.1~C.3: VLM 역할별 프롬프트 · 시각 그라운딩 · 구조화 제안). 학습 비용이 설계 비용으로 이동한 것이고 사라진 것이 아니다.

당장 할 것

본문 부록 C.1(VLM 역할별 프롬프트)을 발췌해 reat 의 장면 계획 단계와 1:1 대조한다. MotorMind가 “제안자/검증자/모니터”를 어떻게 쪼갰는지가 핵심이고, 요약자와-판정자-분리 의 로보틱스 실례다.

남은 실패가 "조기 완료 선언"이다

본문 실패 분석: 잔존 오류는 ① 부정확한 시각 그라운딩 ② 과제 완료를 미리 선언하는 것에 집중된다. 🎯 ②는 로봇 문제가 아니다 — 볼트가 코딩 에이전트에서 반복 관측한 실패와 같은 것이다. 에이전트는 체화돼도 “다 했다”고 먼저 말한다.

미해결

  • LIBERO-PRO 가 LIBERO 와 어떻게 다른지 미확인(본문 D.1 열람 안 함). “PRO” 가 교란 추가판인지 별 벤치인지에 따라 5배의 해석이 달라진다.
  • 실기 95% 의 과제 수 미확인 — 평균이면 분모가 필요하다.
