PAWBench — “그럴듯한 한 편”이 아니라 “가능한 것들의 분포”를 요구한다

HF 논문: https://huggingface.co/papers/2608.27345 · arXiv: 2608.27345 원제: PAWBench: How Far Are We from Probabilistically Aligned World Modeling? 지표(2026-08-28): 업보트 69 · HF 데일리 3위 · 저자 14인 · 공개 2026-08-27 — HF API 실호출 + 초록 원문 대조 검증 규모: 50개 시나리오 × 11개 시스템 · 프로토콜 PAWEval

2026-08-30 갱신 — 업보트 80 → 82(+2) · 데일리 2위 유지 · 초록 3회차 대조 수치 불변

업보트 80 → 82 (2026-08-30 HF API 실호출). 저자 14인 · 공개 2026-08-27 동일. 데일리 2위 유지(3위 → 2위 → 2위). 초록을 3회차 대조했고 50시나리오 · 11시스템 · “일관되게 기준 확률을 맞추면서 유효 행동 범위를 복원한 모델 0개” 는 여전히 한 글자도 바뀌지 않았다. 08-28에 제기한 핵심 공백 — 기준 확률(reference probabilities)의 출처 — 도 여전히 미공개다. 이 질문이 사흘째 답을 얻지 못했으므로, 볼트는 “격차의 존재만 인정하고 크기는 보류” 방침을 유지한다. 증분 +2로 거의 정지. Agentic-Game-Development와의 긴장은 미해소 상태로 이월된다.

2026-08-29 갱신 — 업보트 69 → 80(+11) · 데일리 3위 → 2위 · 초록 재대조 수치 전량 변경 없음

업보트 69(08-28) → 80(2026-08-29 HF API 실호출). 데일리 3위 → 2위 상승. 저자 14인·공개 2026-08-27 동일. 초록 원문을 재대조했고 50시나리오·11시스템·“일관되게 기준 확률을 맞추면서 유효 행동 범위까지 복원하는 모델 0개”라는 핵심 수치·주장은 한 글자도 변하지 않았다. ⚠️ raw 수집 메모는 업보트를 79로 적었으나 API 실측 80 — 볼트는 API 값을 채택한다(시점차 +1).

⚠️ 2026-08-29 신규 긴장 — 같은 날 데일리 1위 Agentic-Game-Development의 처방이 이 벤치 기준으로는 역효과일 수 있다

Agentic-Game-Development는 게임 엔진의 충돌·물리·내비게이션 가능성 검사를 월드모델 RL의 조밀한 보상으로 쓰자고 제안한다. 그런데 이 검사들은 전부 이진 유효성 판정이다 — “이 결과가 가능한가” 는 답하지만 “이 결과가 나올 확률이 맞는가” 는 답하지 못한다. PAWBench가 요구하는 것은 정확히 후자다. 유효성 보상으로 RL을 최적화하면 모델은 가장 안전한 최빈 유효 결과로 수렴하기 쉽고, 유효성은 오르면서 분포 다양성은 붕괴한다 — 즉 RLHEV는 PAWBench 점수를 떨어뜨릴 수 있다. 두 논문은 같은 날 같은 대상(월드모델)에 반대 방향의 압력을 처방하며, 어느 쪽 초록도 이 충돌을 인지하지 않는다. 볼트는 이를 미해결 긴장으로 등재하고, 08-28에 기록한 TTPO와의 긴장(불일치=오답 전제 vs 유효 답 다수 전제)과 함께 묶어 “분포 대 단일 정답”의 두 번째 전선으로 분류한다. → PAWBench의 진짜 기여는 벤치가 아니라 “유효성 ≠ 정렬”이라는 구분일 수 있다. 이 구분이 서면 조밀 보상 설계는 전부 재검토 대상이 된다.

2026-08-29 — OpenMontage·MiniMax-H3 같은 실물 영상 스택에 주는 함의

같은 배치에서 OpenMontage는 산출물 품질 벤치 0건(2개월째)이고 MiniMax-H3는 모델카드에 공개 벤치 0건이다. 두 경우 모두 근거로 제시되는 것은 데모 영상 몇 편이다. PAWBench는 바로 그 증거 형식을 무효화한다 — “그럴듯한 한 편”은 분포에 대해 아무것도 말하지 않는다. 볼트는 영상 스택 평가 시 데모 개수를 신뢰도 근거로 쓰지 않는다는 규칙을 이 페이지에 고정한다.

핵심 인사이트 — 평가의 단위를 영상 하나에서 반복 생성의 분포로 옮긴다

논문의 진단은 한 문장으로 요약된다: 많은 물리 과정은 한 가지 이상의 유효한 방식으로 전개될 수 있다. 따라서 월드모델은 그럴듯한 궤적 하나가 아니라 같은 초기 관측·행동 아래 가능한 행동들의 분포를 재현해야 한다. 논문은 이 분포 수준 요건을 확률적 정렬(probabilistic alignment) 로 형식화한다. 그런데 기존 평가는 대체로 개별 영상의 그럴듯함만 본다 — 반복 생성이 올바른 분포를 복원하는지 시험하지 않는다. PAWEval은 그 공백을 메우는 결과 수준(outcome-level) 프로토콜로, 반복 롤아웃을 가능한 물리적 행동들에 대한 경험 분포로 변환한다.

실측 — 11개 시스템 중 하나도 통과하지 못했다

초록 원문: “Across 50 scenarios and eleven current systems, no model consistently matches the reference probabilities while recovering the range of valid behaviors.” 주목할 것은 두 조건의 결합이다. 모델은 (1) 유효한 행동의 범위를 포괄하면서 동시에 (2) 기준 확률까지 일관되게 맞춰야 한다. 전멸했다는 것은 둘 중 하나만 하는 모델은 있었을 가능성을 시사한다 — 즉 다양하지만 확률이 틀리거나, 확률은 맞지만 한 모드에 붕괴하거나. 어느 쪽이 더 흔한지는 초록에 없다. 논문은 격차 확인에서 멈추지 않고 언어 프롬프트 · 초기 노이즈 샘플링 · 모델 학습 세 가지가 예측 분포를 재형성할 수 있는지까지 시험했다. 결과는 초록에 미기재.

이번 배치 최대 발견 — 세 논문이 같은 날 독립적으로 "분포로 이동"했다

PAWBench · TTPO · ACE-Agentic-Data는 도메인도 저자도 다른데 같은 재구성을 한다:

  • PAWBench: 월드모델 평가를 샘플 품질 → 분포 정렬로
  • TTPO: 의사라벨 학습을 다수결이 맞나 → 불일치 롤아웃의 분포적 비대칭성으로
  • ACE-Agentic-Data: 데이터 생성을 많이 만들기 → 제약된 분포 설계(constrained distribution design) 로

볼트가 08-27에 기록한 발견(FrontierChallenge와 VGI-BENCH가 독립적으로 “최종 상태가 아니라 전개 과정”으로 수렴)의 다음 단계다. 08-27이 “점(結果) → 과정”이었다면 08-28은 “단일 사례 → 분포” 다. 두 이동은 같은 방향의 연속이다.

개별 시스템 점수도, 11개 시스템의 정체도 초록에 없다

어떤 모델이 평가됐는지 목록이 없다. Seedance 2.0(VGI-BENCH에서 51.0%로 최강)이 포함됐는지조차 확인 불가다. 기준 확률(reference probabilities)을 무엇으로 정했는지도 초록에 없다 — 물리 시뮬레이터인가, 실촬영 통계인가, 사람 주석인가? 이게 벤치의 타당성을 좌우하는 유일한 축인데 미공개다. 코드·데이터 공개 여부도 초록 미기재.

도메인별 추출 (ai-news · 교차 video-saas)

  • 신뢰도: ⭐⭐⭐⭐ high — 초록 원문 대조 완료 · 저자 14인 · 규모 명시(50×11). 단 개별 점수·시스템 목록·기준 확률 산출법 전량 미공개로 재현은 불가.
  • 즉시 활용: 부분 YES — 벤치 자체는 못 쓰지만 평가 습관은 지금 바꿀 수 있다. 영상 생성 결과를 판단할 때 한 번 뽑아서 보지 말고 같은 프롬프트로 N회 뽑아 결과 분포를 본다. 비용은 N배지만, 모드 붕괴(항상 같은 전개만 나옴)는 1회 생성으로는 원리적으로 탐지 불가하다.
  • 6개월 영향력: 큼. 영상 생성 마케팅이 체리피킹된 데모 한 편에 의존해 왔는데, 이 논문은 그 관행을 구조적으로 무효화한다. “우리 모델이 이 장면을 잘 만든다”는 주장이 앞으로 반박 가능해진다.
  • 대체 관계: 기존 영상 평가(VGI-BENCH·WBench·WorldExam)를 대체하지 않고 직교로 얹힌다 — 그것들은 한 편의 옳음을, PAWBench는 여러 편의 퍼짐을 잰다.
  • 허와 실: “11개 전멸”은 강한 헤드라인이지만 기준 확률의 정당성에 전적으로 의존한다. 기준이 느슨하면 전멸은 당연하고, 엄격하면 전멸은 무의미하다. 이 부분이 공개되기 전까지는 격차의 존재만 인정하고 크기는 보류한다.
  • 액션: 내 영상 파이프라인 QA에 “동일 프롬프트 N회 생성 후 결과 분포 확인” 단계를 시범 도입(중간) — 특히 물리적 전개가 있는 샷에 한정.

미해결 질문

  • 기준 확률(reference probabilities)의 출처는? 벤치 타당성의 전부가 여기 걸려 있다.
  • 11개 시스템은 무엇이고 개별 점수는? Seedance 2.0 포함 여부.
  • 다양성 실패와 확률 실패 중 어느 쪽이 지배적인가? 처방이 정반대다(전자는 샘플링, 후자는 학습).
  • 초기 노이즈 샘플링으로 분포를 얼마나 교정할 수 있었나 — 저비용 처방의 상한선.
  • VGI-BENCH가 관측한 “후반 디노이징의 자기교정 한계” 와 같은 원인인가? 둘 다 “초기 가설에 갇힌다”를 다르게 본 것일 수 있다.
