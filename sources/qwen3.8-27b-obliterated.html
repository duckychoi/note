Qwen3.8-27B-OBLITERATED — 3포맷 동시 배포로 트렌딩 3위에 오른 가드레일 제거판

HF 모델: https://huggingface.co/OBLITERATUS/Qwen3.8-27B-OBLITERATED 지표: DL 389,747(30일) · 좋아요 770 · HF 트렌딩 3위 · apache-2.0 · text-generation · 공개 2026-08-19 · 최종수정 2026-08-24 — HF API 실호출 검증(2026-08-26) 포맷: safetensors + GGUF + MLX 3종 동시 배포(API 태그 실측) · 베이스: Qwen3.8-27B 태그 실측: abliterated · uncensored · obliteratus · red-team · ai-safety-research

핵심 인사이트

Qwen3.8-27B 파생 생태계에서 “가드레일 제거” 축이 트렌딩 3위까지 올라왔다 — 이 축의 두 번째 상위 진입이다(Qwen3.8-27B-Uncensored-GGUF 이후). 같은 베이스에서 파생 유형별로 수요가 어떻게 갈리는지 이제 세 갈래가 보인다: 양자화(GGUF 733만) ≫ 원본(295만) ≫ 가드레일 제거(39만). 주목할 구조는 3포맷 동시 배포다. safetensors(GPU 추론) + GGUF(llama.cpp/CPU) + MLX(Apple Silicon)를 한 레포에서 낸다는 건, 제작자가 특정 런타임 사용자가 아니라 “로컬에서 굴리는 사람 전부”를 겨냥했다는 뜻이다. 볼트에 쌓인 다른 파생판들이 대개 단일 포맷인 것과 대비된다 — 배포 편의가 곧 채택 속도라는 local-llm 축의 반복 관측과 정합.

low 신뢰도 — 제거 방식·능력 손실·안전성 주장 전부 미검증

이 페이지에서 검증된 것은 오직 API 지표와 태그뿐이다.

  • abliteration 방식이 공개되지 않았다. 거부 방향(refusal direction)을 어떤 층에서 어떻게 제거했는지, 직교화(orthogonalization)인지 다른 기법인지 근거 없음.
  • 능력 손실 벤치마크가 없다. abliteration은 일반적으로 추론·지시 준수 성능을 함께 깎는다고 알려져 있으나, 이 모델의 손실 폭을 보여주는 수치가 제시되지 않았다. “검열만 없애고 능력은 그대로”라는 암묵적 기대는 근거가 없다.
  • red-team·ai-safety-research 태그는 자기 선언일 뿐이다. 안전 연구 용도라는 태그가 붙었다고 해서 안전 연구용으로 검증됐다는 뜻이 아니다 — 오히려 용도 프레이밍으로 배포 정당성을 확보하는 흔한 패턴이며, 실제 연구 산출물(리포트·평가)이 동반되는지 미확인.
  • 라이선스 apache-2.0 표기는 베이스에서 상속된 것이며, 파생물이 원 라이선스 조건과 Qwen 사용 정책을 준수하는지는 별도 문제다(미검증).

Qwen3.8-27B-Uncensored-GGUF 페이지에 기록한 low 판정 사유가 그대로 반복된다 — 이 축은 다운로드가 늘어도 검증 가능한 근거가 함께 늘지 않는다.

39만 다운로드 = 원본의 약 13% — 수요는 있지만 주변부다

DL 389,747은 원본 Qwen3.8-27B 2,945,415의 약 13.2%, Qwen3.8-27B-GGUF 7,334,695의 **약 5.3%**다. 트렌딩 3위라는 순위와 달리 절대 수요는 양자화·원본 축의 한 자릿수 비율에 머문다. 공개 08-19로 일주일 된 신규 모델이라 아직 누적 중이라는 점은 감안해야 하나, 현재로선 “틈새가 상위 노출되는 것”이지 주류 전환이 아니다.

도메인별 추출 (ai-news · 교차 local-llm)

  • 신뢰도: ⭐ low — 지표·포맷·태그는 API 실검증이나 모델의 핵심 주장(거부 제거의 방식과 대가)이 전량 미검증. 볼트 규칙상 스타/다운로드는 품질 근거가 아니다.
  • 즉시 활용: NO — 능력 손실이 정량화되지 않은 모델을 작업 파이프라인에 넣을 이유가 없다. 같은 베이스의 Qwen3.8-27B-GGUF가 검증 가능한 대안으로 이미 있다.
  • 6개월 영향력: 직접 영향은 낮으나 관측 지표로는 유용하다 — 이 축의 다운로드 비율(현재 13%)이 오르는지가 “로컬 사용자가 가드레일을 실제로 얼마나 걷어내는가” 의 대리 지표다. 계속 추적 가치 있음.
  • 대체 관계: 대체 없음. 내 워크플로우에서 Qwen3.8-27B 계열을 쓴다면 원본 또는 양자화판이 우선이다.
  • 허와 실: 실은 3포맷 동시 배포라는 유통 전략과 파생 축 분화의 실측 비율. 허는 ai-safety-research 태그의 정당성과 능력 손실 없음이라는 암묵적 인상.
  • 액션: 추적만 (낮음). 다음 회차에 DL 비율 변화만 확인.

미해결 질문

  • abliteration 이후 벤치 점수가 어디에도 없나 — 모델 카드 본문 실측이 필요(이번 회차 미수행).
  • 3포맷 중 어느 포맷이 다운로드의 다수인가? GGUF가 대부분이면 이 축의 수요도 결국 로컬 CPU 추론 수요의 부분집합이다.
  • 최종수정 08-24에 무엇이 바뀌었나 — 포맷 추가인가 재제거인가.
