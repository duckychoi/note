이 항목은 09-06에 도입한 URL 대조 필터를 통과했다(신규 판정). 그런데 TimesFM 페이지가 09-03에 이미 이 모델을 실측 기록하고 있었다. 원인: TimesFM 의 - 출처: 라인은 arXiv + GitHub URL 이고, 이 항목은 HF 모델 URL 이다. 같은 대상, 다른 URL → 필터가 못 잡는다. → URL 완전 일치 필터는 “같은 대상의 다른 표면”을 놓친다. 09-06에 세운 필터가 첫 회차에 바로 한계를 드러냈다. actionable.md 반영. 처리 판단: 별도 페이지를 생성한다. TimesFM 은 논문·레포 기준 페이지이고 이건 가중치 배포 기준 소스로, 라이선스가 서로 다르다(아래). 두 페이지를 상호 링크한다.

🎯 09-03 미해결 질문이 해소됐다 — 세대 교체는 4일 만에 끝났다

TimesFM 09-03 기록: “신버전이 좋아요는 2.4배 많고 다운로드는 0.85배다. … ⚠️ 3.0 공개 10일차이므로 교체 완료 여부는 다음 회차 판정.” 2026-09-07 실측 (계열 3세대 동시 조회):

모델09-03 DL09-07 DL변화좋아요(09-03→09-07)
timesfm-3.0-pytorch46,862144,455+208.3%315 → 534
timesfm-2.5-200m-transformers55,03660,209+9.4%134 → 136
timesfm-1.0-200m490636+29.8%832 → 835

판정: 교체 완료. 09-03에 3.0은 2.5의 0.85배였는데, 09-07에는 2.40배다. 4일 만에 역전 폭이 2.8배 벌어졌다. 그리고 09-03 관측(“좋아요는 누적되고 다운로드는 이동한다”)이 재확인된다 — 1.0은 좋아요 835로 여전히 계열 최다인데 다운로드는 636이다. 좋아요는 과거의 평판이고 다운로드는 현재의 사용이다.

"공개 직후 DL은 아직 없는 값" 규칙 — 네 번째 독립 사례로 확정

볼트는 09-03에 GLM-5.3-Flash(34→517,902)·Qwen3.8-Flash-Next(4,810→263,287)·본 모델(raw “0”→46,862) 3건으로 규칙을 세웠다. 이번에 같은 모델의 시계열 추적으로 4번째 근거가 붙었다: 46,862(공개 10일) → 144,455(공개 14일). 즉 10일차 값조차 아직 안정값이 아니었다. → 규칙을 강화한다: “생성 10일 이내 DL을 사용량 근거로 쓰지 않는다” → “생성 후 최소 2주, 그리고 전 세대와의 상대비로 읽는다.” 절대값 하나로는 채택 여부를 판정할 수 없다.

🔴 도입 시 결정적 제약 — 상업적 사용 불가

API 실측: license: other / license_name: timesfm-non-commercial-license-v1.0. 09-03 TimesFM 기록은 “라이선스 other(⚠️ GitHub 레포는 Apache-2.0 — 코드와 가중치의 라이선스가 다르다)” 까지만 확인했다. 이번에 그 other 의 정체가 확정됐다: 비상업 라이선스.

  • 코드(google-research/timesfm): Apache-2.0 → 상업 이용 가능
  • 가중치(timesfm-3.0-pytorch): TimesFM Non-Commercial License v1.0 → 상업 이용 불가 → 볼트가 anthropics-skills(레포 레벨 null, 문서 스킬만 source-available)·MiniMax-H3(“오픈 가중치 ≠ 오픈 시스템”)·VoiceStudio(앱 AGPL / 모델 각자)에서 반복 관측한 2층 라이선스 함정의 네 번째 사례이며, 이번엔 방향이 반대다 — 앞선 사례들은 코드가 제약이었는데 여기는 가중치가 제약이다. ⭐30,397짜리 Apache-2.0 레포를 보고 “상업 이용 가능”이라 판단하면 틀린다. 09-03 기록이 갱신을 요구하던 지점이 여기였다.

아키텍처 (raw 기재 · 모델 카드 기준)

  • Stacked Mixing Transformer + Variate Attention + CPM Iterative RevIN
  • 20층 · model dim 1280 · 헤드 16 · 컨텍스트 패치 32 / 예측 호라이즌 패치 64
  • 사전학습 데이터: fev-bench와 겹치는 셋을 제외한 GiftEvalPretrain · Wikipedia Pageviews(2023-11 컷오프) · Google Trends 상위 쿼리(2022년말 컷오프) · 합성·증강 데이터

데이터 오염 회피를 명시한 것은 가점, 그러나 벤치 수치는 없다

“fev-bench와 겹치는 셋을 제외” 는 평가 오염(contamination)을 의식한 서술이다. 검사가능성-공사 축에서 긍정적. ⚠️ 그럼에도 모델 카드 자체에는 벤치마크 수치가 없다(raw 기재 정확). 09-03에 남긴 “정확도 벤치 수치는 이번에도 미확인” 이 09-07에도 미해소다. 오염 회피를 신경 쓴 팀이 성능 수치는 카드에 안 실었다 — 별도 리포트나 논문에 있을 가능성이 높으나 미확인. 데이터 컷오프(2023-11 / 2022년말)는 최근 시계열 예측 시 도메인 드리프트 위험으로 읽어야 한다.

당장 할 것

  1. TimesFM 계열을 상업 용도 후보에서 제외하고, 시계열-예측-파운데이션-모델 에 라이선스 열을 추가한다. 볼트의 시계열 소스들은 지금까지 성능만 비교하고 라이선스를 비교하지 않았다.

미해결

TimesFM 3.0 의 성능이 2.5보다 실제로 나은가. 다운로드 역전은 채택을 증명하지 벤치를 증명하지 않는다. 카드에 수치가 없으므로 여전히 미확인이며, 09-03부터 2회 연속 이월된 질문이다. 다음 회차에는 논문/기술 리포트를 직접 찾아 종결할 것.
