WearableQA

핵심 인사이트

노이즈를 제거하지 않은 것이 설계다. 실제 사용자 200명의 웨어러블 시계열 + 혈액 바이오마커 + 인구통계(1인당 최대 500일)로 만든 4,084문항 10지선다 벤치마크인데, 핵심은 “기기 노이즈와 개인차를 포함한 실제 웨어러블 분포를 보존한다” 는 점이다. → 대부분의 벤치마크는 깨끗하게 만들어서 풀 수 있게 한다. 이건 반대로 더럽게 유지해서 실제 조건을 재현한다.

🎯 이 배치에서 가장 잘 설계된 측정도구

질문 유형 16종을 두 축으로 직교 조직했다:

  • 데이터 추론 vs 건강 추론 — 시계열 위 계산 능력 / 생리학적 해석 능력
  • 단일신호 vs 교차신호 — 개별 신호 / 여러 신호 통합 → 이렇게 축을 나누면 “모델이 못 푼다” 가 아니라 “어느 능력이 없어서 못 푸는지” 가 나온다. 09-09 RoboSPA 에서 배운 “난이도 축으로 펼쳐야 붕괴점이 보인다” 의 정석 구현. 대규모 문항 생성은 이중 접지(dual-grounding) — 문헌 기반 생리학 지식 + 통계 검증된 집단 패턴을 결합. 즉 정답의 근거가 두 겹이다.

📊 평가 결과 (초록 원문 실측)

독점·오픈소스 LLM 14종: 19.6% ~ 72.9% (확률 기준선 10%)

  • 대부분 60% 미만 — 저자 자인 “remains far from solved”
  • 성능 스프레드 53.3%p — 기준선의 2배부터 7배까지 벌어진다 → 변별력이 확보된 벤치마크. 상단이 포화되지 않았고(72.9%) 하단이 기준선에 붙지 않았다(19.6%). 이 두 조건을 동시에 만족하는 벤치마크는 드물다.

왜 이게 볼트에 중요한가 — 좋은 벤치마크의 형태

이번 배치에는 벤치마크가 3건(WearableQA · SAEScientist-Bench · Programmable-World-Model의 CombatStateBench) 있는데, 신뢰도가 갈린다:

  • WearableQA(⭐⭐⭐): 데이터가 외부 실측(실제 200명), 축이 직교 분해, 14종 평가로 스프레드 공개
  • SAEScientist-Bench(⭐⭐⭐): 참조가 외부 앵커(Neuronpedia 전문가 특징), 10구성×20과제
  • CombatStateBench(⭐⭐): 데이터·정답·비교군이 전부 저자 내부, 비교 수치 미공개 → 판별 기준은 “정답의 출처가 저자 밖에 있는가” 다. → 측정도구-먼저-반증

도메인별 추출 (ai-news)

  • 신뢰도: 업보트 24 · 저자 8명 · arXiv 2609.05405 · published 2026-09-04. 업보트는 중간이나 방법론 투명도는 이 배치 최상위.
  • 즉시 활용: NO(주제). 건강·웨어러블은 내 도메인이 아니다. YES(방법론). “두 축 직교 분해 + 이중 접지 + 스프레드 공개” 3종 세트는 내 평가 설계에 그대로 이식 가능.
  • 6개월 영향력: 직접 영향은 낮다. 다만 “실제 분포를 보존한 벤치마크” 가 표준이 되면, 내가 만드는 평가도 깨끗한 합성 입력에서 실제 지저분한 입력으로 옮겨야 한다.
  • 대체 관계: 없음.
  • 허와 실: 과장이 없다. 저자가 “far from solved” 라고 먼저 쓴다 — 자기 벤치마크를 파는 대신 한계를 광고하는 쪽.
  • 액션: 논문의 16종 질문 유형 분류표만 확보해 내 평가 축 설계에 참고.

당장 할 것

09-09 actionable “보장된 null 도입” 의 후속: 내 평가에 축을 2개 넣는다. 지금 내 영상 파이프라인 평가는 “좋다/나쁘다” 1축이라 어디가 깨졌는지 안 나온다. 최소 데이터 처리 vs 의미 해석 2축으로 분해.

미해결 질문

실제 사용자 200명 데이터의 공개 여부와 프라이버시 처리가 초록에 없다. 재현하려면 데이터 접근 조건 확인 필요.
