When EOS Tokens Disagree

핵심 인사이트 — 원인이 학습이 아니라 어휘에 있었다

OPD에서 학생 응답이 생성예산을 소진할 만큼 길어지는 원인 하나를 베이스 학생과 사후학습 교사의 종료 토큰 불일치로 특정했다. 🎯 핵심 관측: Qwen3·Llama·Gemma에서 선언된 정지 집합(declared stopping sets)이 동일해도 정지 확률이 서로 다른 EOS 토큰에 실린다. 기제(초록 원문): 이 불일치가 학생이 선호하는 종료 행동을 억압하면서 교사가 선호하는 대안을 신뢰성 있게 전달하지 못한다 — “suppress the student’s preferred termination action without reliably transferring the teacher-preferred alternative.” 🔴 양쪽을 다 잃는다. 종료가 하나에서 다른 하나로 옮겨가는 게 아니라 둘 다 약해진다. → 온폴리시-증류 계보에 어휘 층 원인이 추가된다. 이 계보의 기존 진단은 전부 신호·가중·교사 동역학이었다(One-Symptom-Three-Levers 의 3레버). 🎯 토큰 ID 수준의 원인은 3레버 어디에도 없다 — 네 번째 층이다.

🔴 저자가 스스로 남긴 한계를 함께 옮긴다 — 이게 이 논문의 신뢰도 근거다

① 정지집합만 맞추는 것으로는 불충분하다(“aligning the decoding stopping set alone is insufficient”). 해법은 기능적으로 동등한 EOS들을 하나의 의미적 정지 행동으로 취급하는 것. ② 종료 정렬로도 사라지지 않는 후기 길이 팽창이 따로 관측됐다 — K2-Horizon 단계별 분석에서 확인. 논문은 종료 불일치를 “important, but not exhaustive” 원인이라고 명시한다. ③ 학습 중 종료 선호가 크게 이동한다(“termination preferences can shift substantially during training”) — 즉 한 번 맞춰놓고 끝나는 문제가 아니다. 🎯 볼트 판정: 이건 자기제한-명시 의 논문 채널 최강 사례다. 원인을 하나 찾은 논문이 “이게 전부는 아니다”를 초록에 적었다. 자기 기여를 스스로 상한 지었다. → 🔴 대조: 같은 배치 harness-sdk 는 “Guardrails catch mistakes” 를 측정 없이 단언했다. 같은 날 배달된 두 문서의 인식론적 품질이 정반대다.

당장 할 것

모델 교체 시 “선언 일치 ≠ 동작 일치” 체크를 규칙으로 넣는다. 🎯 이 논문의 일반형이고, 내가 로컬 모델을 실험할 때 정지 토큰·채팅 템플릿에서 정확히 같은 종류의 함정을 만난다. → 볼트 기보유 Qwen-Fixed-Chat-Templates 가 같은 계열 사고의 사례다.

미해결 질문

“후기 길이 팽창”의 원인이 미규명이다 — 저자가 관측만 하고 설명하지 않았다. 🔴 그리고 그게 남은 절반일 수 있다(종료 정렬로 안 사라지므로). 본문 미확인(초록만). 3개 모델 패밀리 각각의 팽창 크기·완화 폭 수치가 초록에 없다 — “substantially mitigates” 뿐이고 크기가 없다.
