논문: Confidence Comes from Experience: Experiential Confidence Estimation from Reasoning to Agents

URL: https://huggingface.co/papers/2609.17708 지표(2026-09-17 볼트 API 실측): 업보트 44 · HF 데일리 2위 · 게재 2026-09-15 · 저자 6명 드리프트: raw 44 → 볼트 44 = 0 (수집기가 보고한 “페이지 43 → API 44” 드리프트 이후 안정) 🔀 도메인 재판정: raw ai-news → 볼트 local-llm (근거는 아래)

🎯 기존 신뢰도 추정 전부가 공유하는 전제를 지목했다

볼트 초록 전문 대조: “Existing confidence estimators, however, share one design premise: they only read the current inference process, either by introspecting on it, scoring its token probabilities, or resampling it. We argue that the current inference is not a sufficient basis for confidence.” 🎯 내성(introspection)·토큰 확률·리샘플링 — 세 계열이 전부 “지금 이 추론”만 본다. 논문은 그 전제를 부정하고 모델의 누적 경험을 함께 읽는다. 🔗 측정도구-먼저-반증 과 같은 동작이다: 방법을 개선하기 전에 기존 방법 전체가 공유하는 가정을 먼저 무너뜨린다. 같은 배치 ActionPiece 가 VLA 토크나이저에서 동일한 구조를 쓴다.

에피소드에 무엇을 저장하는가 — 5개 필드

과거 에피소드 각각이 담는 것: 태스크 · 모델의 반성(reflection) · 당시 진술한 신뢰도 · 결과 · 채점이 도착한 뒤 작성한 교훈(lesson). 2단계 동작:

  • Recall: 유사 태스크 + 유사한 당시 신뢰도를 가진 과거 에피소드를 검색해 그때의 실제 성공률을 읽는다
  • Reflect: 그 기록을 모델에게 보여 주고 반복되는 실패 모드를 스스로 지목하게 한 뒤 신뢰도를 재진술

🎯 핵심 설계는 “유사 신뢰도”로도 검색한다는 점이다. 태스크만이 아니라 “내가 이 정도로 자신 있다고 말했을 때 실제로 얼마나 맞았나” 를 조회한다 — 캘리브레이션을 데이터로 회수하는 구조. 🔗 이것이 에이전트-메모리-레이어 의 새 용도다. 기존 에이전트 메모리는 무엇을 아는가를 저장했는데, 이건 자기 추정의 오차 이력을 저장한다.

✅ 분모가 공개된 수치 — 볼트가 검증할 수 있는 형태

  • 9개 벤치마크(추론·코딩·멀티모달 QA·대화형 에이전트) · 3개 패밀리 4개 모델
  • 24개 비교 중 23개에서 10샘플 self-consistency의 AUROC를 이기거나 동일
  • ECE는 훨씬 낮고, 생성 비용은 1/10(답변 1회 생성)
  • 선택적 예측: 가장 자신 없는 10%를 포기하면 에이전트 태스크 실측 성공률 최대 +8.7점

🔴 볼트가 짚는 산술 불일치: 9 벤치 × 4 모델 = 36인데 비교 수는 24다. 초록이 24의 구성을 설명하지 않는다 — 일부 벤치가 일부 모델에만 적용됐을 가능성이 높으나 확인 불가. 📌 볼트 규칙(분모를 같은 불릿에 적는다)은 지켜졌다 — 24라는 분모가 명시됐다. 다만 분모가 상위 기술(9×4)과 맞지 않는다 → 한정어-탈락 의 변종: 한정어는 있는데 산술이 닫히지 않는 경우.

✅ 실용 조건이 초록에 명시돼 있다 — 이번 배치 최고의 즉시 적용 항목

“Our estimator is format-general, requiring no logit access or weight updates, and costs only one answer generation.” 🎯 logit 접근 불필요 + 가중치 업데이트 불필요 + 포맷 무관 → API-only 모델에 그대로 적용된다. 📌 볼트/Hermes 계열 에이전트에 지금 붙일 수 있다: 과거 태스크의 (태스크·신뢰도·결과·교훈)을 남기고, 다음 판단 때 유사 신뢰도 구간의 과거 성공률을 조회하는 것 — 추가 모델이 필요 없다. 🔗 비용 구조가 결정적이다: self-consistency 10샘플 대비 1/10 비용으로 동등 이상. 즉 더 싸고 더 정확하다 — 트레이드오프가 아니다.

🔀 도메인 재판정 근거 — 왜 local-llm 인가

raw는 ai-news 로 분류했다. 볼트는 local-llm 으로 옮긴다:

  • 볼트 local-llm 템플릿의 메모리 아키텍처 질문에 정면으로 답한다(외부 에피소드 DB + 검색)
  • Hermes 적용 가능성이 즉시적이다 — logit 불필요이므로 로컬/API 무관
  • 선례: 에이전트-메모리-레이어 계열 소스가 이 도메인에 누적돼 있다 📌 이 재판정은 09-16 ZGCM-1·Vidu-S2 선례와 같은 기준(누적 인사이트가 끊기지 않는 쪽)을 따른다.

도메인별 추출 (local-llm)

  • 실용성 판단: 🎯 즉시 배포 가능. 하드웨어 요구 없음(추가 모델 없음) · 지연시간은 검색 1회 + 생성 1회 — self-consistency 10회보다 빠르다
  • 메모리 아키텍처: 외부 에피소드 저장 + 유사도 검색(RAG형). 압축·KV 방식이 아니다. 저장 단위가 (태스크, 반성, 신뢰도, 결과, 교훈) 5필드 레코드
  • Hermes 적용: 🎯 YES — 지금 당장. 필요한 것은 ① 태스크 결과 채점 로그 ② 당시 신뢰도 기록 ③ 유사 검색. 볼트 log.md 가 이미 ①의 원형이다(ingest마다 결과·자기 한계 기록)
  • 트레이드오프: 🎯 트레이드오프가 아닌 드문 사례 — 비용 1/10 + AUROC 동등 이상 + ECE 낮음. 비용은 저장소(에피소드 누적)로 이동
  • 오픈소스 구현체: 🔴 초록에 코드 링크 없음 — 확인 불가

미확인

  • 볼트는 초록만 읽었다. 24개 비교의 구성 · 유사도 검색 방식 · 에피소드 수 규모 전부 미확인
  • 콜드 스타트 문제 미언급: 과거 에피소드가 없을 때의 동작이 초록에 없다 — 실제 도입 시 첫 관문
